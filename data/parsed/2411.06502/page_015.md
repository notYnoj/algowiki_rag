<tbc>**Theorem 2.2.** _There is an_ \((n/n')^{1+o(1)}\cdot\left(\mathsf{T}_{MonMUL}(n')+n'^{2+o(1)}g(n')\right)\) _algorithm for unweighted SED, where_ \(n=|\mathbf{F}|,n'=|\mathbf{F}'|\), \(n\ge n'\)_, and_ \(\mathsf{T}_{MonMUL}(n',n',n',\mathrm{D})=\mathcal{O}(f(n')g(\mathrm{D}))\) _for some functions f,g._

We now illustrate the techniques required to obtain the above result. Suppose we have two trees \(\mathbf{F},\mathbf{F}'\) of size \(n,n'\) with spines \(\mathbf{S}=\{r,\cdots,q\},\mathbf{S}'=\{r',\cdots,q'\}\). Assume without loss of generality that \(n\gg n'\). For simplicity, we again assume Assumption B.

We can formulate the SED problem using a divide-et-impera scheme. Since \(n\gg n'\), we only decompose the larger tree **F**. For a given threshold \(\gamma\), we can efficiently find a subsequence of spine vertices _I_=\[_s_<sub>1</sub>_..s<sub>d</sub>_\] with _r=s_<sub>1</sub>_,q=s<sub>d</sub>_ such that for all _i\<d_, either \(|\mathsf{sub}(s_i)\backslash\mathsf{sub}(s_{i+1})|\le\gamma\) or _s<sub>i</sub>_ immediately precedes _s_<sub>_i_+1</sub> in **S**.

We can then compute SED recursively in a bottom-up manner. We begin by computing \(\mathsf{sim}(\mathsf{sub}(s_d),\mathbf{F}'[x'..y'))\) for all \(x',y'\in[1..2|\mathbf{F}'|+1\mathbf{J})\). Since sub(_s<sub>d</sub>_) is a single node, we can compute this efficiently. Next, for _i\<d_, given \(\mathsf{sim}(\mathsf{sub}(s_{i+1}),\mathbf{F}'[x'..y'))\) for all \(x',y'\), our hope is to compute \(\mathsf{sim}(\mathsf{sub}(s_i),\mathbf{F}'[x'..y'))\) for all \(x',y'\). First, suppose \(|\mathsf{sub}(s_i)\backslash\mathsf{sub}(s_{i+1})|\le\gamma\). In this case we recurse on the smaller problem of size \((\gamma,n')\). Since there are at most \(3n/\gamma\) sub-problems in _I_, the total time on the first case is

\(\mathsf{T}(n,n')=(3n/\gamma)\cdot\mathsf{T}(\gamma,n')\)

which yields total time \((n/n')^{1+o(1)}\cdot n'^{(3+\omega)/2}\), since when \(\gamma=\mathcal{O}(n')\), we apply the recursive scheme employed in Main Theorem 3 in time \(n'^{(3+\omega)/2}\).

Thus, it remains to handle the case where _s<sub>i</sub>_ immediately precedes _s_<sub>_i_+1</sub>. Under Assumption B, we can decompose the similarity when _s<sub>i</sub>_ is not aligned as follows:

\(\mathsf{sim}(\mathsf{sub}(s_i),\mathbf{F}'[x'..y'))=\mathrm{max}_{w^\prime\in[\mathsf{I}(r^\prime)..\mathsf{I}(q^\prime)]z^\prime\in[\mathsf{r}(q^\prime)..\mathsf{r}(r^\prime)]}\big\{\mathsf{sim}(\mathbf{F}[\mathsf{I}(s_i)..\mathsf{I}(s_{i+1})),\mathbf{F}'[x'..w'))\)<br>
\(+\mathsf{sim}(\mathsf{sub}(s_{i+1}),\mathbf{F}'[w'..z'))\)<br>
\(+\mathsf{sim}(\mathbf{F}[\mathsf{r}(s_{i+1})..\mathsf{r}(s_i)),\mathbf{F}'[z'..y'))\big\}.\) (2)

To handle the case where _s<sub>i</sub>_ is aligned, say to vertex _v_, we can add \(\eta(s_i,v)\) to the value of \(\mathsf{sim}(\mathsf{sub}(s_i),\mathbf{F}'[\mathsf{I}(v)+1..\mathsf{r}(v)))\). For completeness, we also ensure monotonicity after updating the values in a post-processing step (i.e. \(\mathsf{sim}(\mathsf{sub}(s_i),\mathbf{F}'[x'..y'))\ge\mathsf{sub}(s_i,\mathbf{F}'[\mathsf{I}(v)..\mathsf{r}(v)))\) if \(x'\le\mathsf{I}(v)<\mathsf{r}(v)\le y'\)). The computation can be written as a max-plus product of three \(\mathcal{O}(n')\times\mathcal{O}(n')\) matrices with entries bounded by \(\mathcal{O}(n')\) since each entry is a similarity measure between two forests, one of size at most \(\mathcal{O}(n')\). Since the matrices are also monotone, the summands can be combined in time \(\mathsf{T}_{\mathsf{MonMUL}}(n')=\tilde{\mathcal{O}}(n'^{(3+\omega)/2})\).

The second summand is available to us as part of the bottom-up recursion. It remains to compute the first and last summand. Consider the first summand. Observe that it is exactly the third output of FED between **F**\[I(_s<sub>i</sub>).._I(_s_<sub>_i_+1</sub>)**J** and \(\mathbf{F}'[\mathsf{I}(r')..\mathsf{I}(q'))\). Similarly, the third summand is exactly the third output of FED between **F**\[r(_s_<sub>_i_+1</sub>)_.._r(_s<sub>i</sub>_)**J** and \(\mathbf{F}'[\mathsf{r}(q')..\mathsf{r}(r'))\). Since none of the forests contain any spine nodes \(\mathbf{S},\mathbf{S}'\), all inputs to the FED instances are given by the inputs of the SED instance.

Our goal is now to compute these two FED instances. We can bound the size of **F**\[I(_s<sub>i</sub>).._I(_s_<sub>_i_+1</sub>)**J** and **F**\[r(_s_<sub>_i_+1</sub>)_.._r(_s<sub>i</sub>_)**J** by |sub(_s<sub>i</sub>_)\\sub(_s_<sub>_i_+1</sub>)|. However, it is possible that \(|\mathsf{sub}(s_i)\backslash\mathsf{sub}(s_{i+1})|=\Theta(n)\), in which case directly applying Main Theorem 4 on the FED instance already takes \(\mathcal{O}(\mathsf{T}_{\mathsf{MonMUL}}(n))\) time in this one step alone. Even if the entries are bounded by \(\mathcal{O}(n')\), the output of FED instance is already size \(\Omega(n^2)\). How can we reduce the dependence on _n_? In our SED application, we have only used the third output of FED. In fact, we show that all outputs except the first output (which has size \(\Omega(n^2)\)) can be computed efficiently.
