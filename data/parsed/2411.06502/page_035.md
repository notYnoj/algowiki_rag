**Lemma 4.12.** _Suppose we are given a_ \((\mathrm{w},\mathrm{F},\mathrm{F}')\)_-LRBBD instance of size_ \((n,n')\) _and a synchronous subforest_ \(\mathrm{F}_s\subseteq\mathrm{F}\) _of size_ |F_<sub>s</sub>_|=_n<sub>s</sub>. Further, let v_<sub>1</sub>_,...,v_<sub>|F|</sub> _be the pre-order of_ F_, and let i<sub>s</sub> be such that v<sub>i<sub>s</sub></sub>,...,v<sub>i<sub>s</sub>+n<sub>s</sub></sub> is the pre-order of_ F_<sub>s</sub>. Define_ \(\mathrm{F}_\ell=\mathrm{F}[1..\mathrm{l}(v_{i_s})\) _),_ \(\mathrm{F}_s=\mathrm{F}[\mathrm{l}(v_{i_s})..\mathrm{l}(v_{i_s+n_s+1})\) _), and_ \(\mathrm{F}_r=\mathrm{F}[\mathrm{l}(v_{i_s+n_s+1})..2|\mathrm{F}|+1\) ).

_Then, given the outputs of the four LRBBD instances_ \((\mathrm{w},\mathrm{F}_\ell,\mathrm{F}')\)_-LRBBD,_ \((\mathrm{w},\mathrm{F}_s,\mathrm{F}')\)_-LRBBD,_ \((\mathrm{w},\mathrm{F}_r,\mathrm{F}')\)_- LRBBD, and_ \((\mathrm{w},\mathrm{F}\backslash\mathrm{F}_s,\mathrm{F}')\)_-LRBBD, we can solve the_ \((\mathrm{w},\mathrm{F},\mathrm{F}')\)_-LRBBD instance in time_ \(\mathcal{O}(\mathrm{T}_\mathrm{MUL}(n',n',n))\).

_Furthermore, if the LRBBD instance has diameter_ \(\mathcal{O}(n')\)_, we can solve the_ \((\mathrm{w},\mathrm{F},\mathrm{F}')\)_-LRBBD instance in time_ \(\mathcal{O}(\mathrm{T}_\mathrm{MonMUL}(n',n',n,n'))\).

**Proof.** Let |F|=_n_, and define _i<sub>r</sub>=i<sub>s</sub>+n<sub>s</sub>_+1. Consider the alignment graph \(\tilde{\mathrm{G}}\) w.r.t. \((\mathrm{w},\mathrm{F},\mathrm{F}')\), and observe that \(\tilde{\mathrm{G}}[1..i_s][1..n']\) corresponds to the alignment graph \(\tilde{\mathrm{G}}_\ell\) w.r.t. \((\mathrm{w},\mathrm{F}_\ell,\mathrm{F}')\), \(\tilde{\mathrm{G}}[i_s..i_r][1..n']\) corresponds to the alignment graph \(\tilde{\mathrm{G}}_s\) w.r.t. \((\mathrm{w},\mathrm{F}_s,\mathrm{F}')\), and \(\tilde{\mathrm{G}}[i_r..n+1][1..n']\) corresponds to the alignment graph \(\tilde{\mathrm{G}}_r\) w.r.t. \((\mathrm{w},\mathrm{F}_r,\mathrm{F}')\). The alignment graph \(\tilde{\mathrm{G}}_\backslash s\) w.r.t. \((\mathrm{w},\mathrm{F}\backslash\mathrm{F}_s,\mathrm{F}')\), corresponds to the graph obtained by removing from \(\tilde{\mathrm{G}}\) all nodes (and their incident edges) of the set \([i_s..i_r)\times[1..(n'+1)]\), and by adding an edge from (_x,i<sub>s</sub>_-1) to (_x,i<sub>r</sub>_) of cost 0 for all \(x\in[1..(n'+1)]\). We abuse notation, and we index nodes in \(\tilde{\mathrm{G}}_\backslash s\) w.r.t. the corresponding positions in \(\tilde{\mathrm{G}}\), taking care of never using any index from the set \([i_s..i_r)\times[1..(n'+1)]\).

As before, we decompose \(\mathrm{B}^\mathrm{T}(1,1,n+1,n'+1)\) into \(I_\ell^\mathrm{T},I_s^\mathrm{T},I_r^\mathrm{T}\). See Figure 10 for a visualization of the alignment graph and computed instances.

Our goal is to compute \(\mathrm{dist}_\tilde{\mathrm{G}}(\tilde{u},\tilde{v})\) for all \(\tilde{u},\tilde{v}\) where \(\tilde{u}\in\{1\}\times[1..n'+1]\) and \(\tilde{v}\in\mathrm{B}^\mathrm{T}(1,1,n+1,n'+1)\). We proceed by case analysis on \(\tilde{v}\).

For \(\tilde{v}\in I_\ell^\mathrm{T}\), we obtain the outputs \(\mathrm{dist}_\tilde{\mathrm{G}}(\tilde{u},\tilde{v})\) using the output of the \((w,\mathrm{F}_\ell,\mathrm{F}')\)-LRBBD instance.

For \(\tilde{v}\in I_s^\mathrm{T}\), observe that for any \(i\in[1..i_s)\) either \(\pi_\mathrm{F}(i)\le i_s\) or \(\pi_\mathrm{F}(i)\ge i_r>i_s+n_s\) holds as F_<sub>s</sub>_ is a synchronous subforest of F. Hence, a path in \(\tilde{\mathrm{G}}\) that goes from \(\tilde{u}\) to \(\tilde{v}\) must pass through a node in \(i_s\times[1..(n'+1)]\), and we can write

\(\mathrm{dist}_\tilde{\mathrm{G}}(\tilde{u},\tilde{v})=\mathrm{max}_{\tilde{w}\in i_s\times[1..(n^\prime+1)]}\left\{\mathrm{dist}_\tilde{\mathrm{G}}(\tilde{u},\tilde{w})+\mathrm{dist}_\tilde{\mathrm{G}}(\tilde{w},\tilde{v})\right\}.\)

This time, we use the output of the \((\mathrm{w},\mathrm{F}_\ell,\mathrm{F}')\)-LRBBD instance and the output of the \((\mathrm{w},\mathrm{F}_s,\mathrm{F}')\)-LRBBD instance to compute the entries of the matrices since \(\tilde{\mathrm{G}}[1..i_s][1..(n'+1)]=\tilde{\mathrm{G}}_\ell\) and \(\tilde{\mathrm{G}}[i_s..i_r][1..(n'+1)]=\tilde{\mathrm{G}}_s\). Note that the matrices have shape \((n'+1)\times(n'+1)\) and \((n'+1)\times(n_s+1)\) so that the multiplication requires \(\mathcal{O}(\mathrm{T}_\mathrm{MUL}(n',n',n))\) time.
