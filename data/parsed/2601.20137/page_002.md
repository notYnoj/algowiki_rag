In wireless sensor networks, topology control protocols seek sparse communication topologies that preserve connectivity, since maintaining fewer active links reduces both energy consumption and radio interference \[13\]. Our Redundancy Elimination task provides an algorithmic primitive aligned with this objective: when a new link becomes available, the framework detects and removes an existing link that is no longer necessary for _k_-edge- connectivity, keeping the network sparse with _O(kn_) edges.

## 2 Related work

Computing the minimum cut in an undirected graph is a classic problem with a long history. Early approaches relied on network flow techniques; the Gomory-Hu \[6\] tree construction reduces the problem to _n_-1 maximum flow computations. Karger \[10\] introduced a randomized algorithm based on tree packings that finds the global minimum cut in _O(m_log<sup>3</sup>_n_) time with high probability. In the deterministic setting, Henzinger, Rao, and Wang \[9\] gave an algorithm for determining graph’s edge-connectivity, running in _O(m_log<sup>2</sup>(_n_)log(log<sup>2</sup>(_n_))) time. Li \[11\] presented a deterministic algorithm for finding minimum-cuts in weighted undirected graphs running in _m_<sup>1+_o_(1)</sup> time.

The problem of maintaining the minimum cut in a dynamically changing graph has been studied extensively, with a primary focus on efficiently reporting the value of the minimum cut rather than actively enforcing a connectivity invariant. Thorup \[16\] gave a deterministic fully dynamic algorithm that maintains the value of the minimum cut in \(\tilde{O}(\sqrt{n})\) (see Section 3) worst-case time per update. For the incremental setting, Goranci et al. \[7\] achieved _O_(log<sup>3</sup>(_n_)log(log<sup>2</sup>(_n_))) amortized update time by maintaining a set of edge-disjoint spanning forests - a sparse certificate that preserves connectivity properties. Our approach to redundancy elimination (Section 4) builds on a similar structural insight: by actively maintaining a certificate of size _O(kn_), we can efficiently identify and remove redundant edges in _O(k_log_n_) amortized time per edge addition. For connectivity restoration (Section 5), we exploit the specific properties of Dinic’s algorithm \[4\] on unit-capacity networks. While the general weighted case requires _O(n_<sup>2</sup>_m_) time, Even and Tarjan \[5\] showed that the complexity improves to _O_(min(_n_<sup>2/3</sup>_,m_<sup>1/2</sup>)_m_) for unit capacities. This bound is critical to our edge-connectivity restoration strategy.

## 3 Preliminaries and notation

We consider unweighted, simple, undirected graphs _G_=(_V,E_) with a vertex set _V_ and edge set _E_, where |_V_|=_n_ and |_E_|=_m_, using these parameters primarily to describe the computational complexity of the proposed algorithms. To simplify the asymptotic analysis, we employ the notation \(\tilde{O}(f(n))\) to denote _O(f(n_)log_<sup>k</sup>n_) for some constant \(k\ge 0\), thereby suppressing polylogarithmic factors; crucially, this notation never obscures polynomial factors. When considering several graphs, we denote the respective sets of a graph _G_ as _V(G_) and _E(G_) to avoid ambiguity. Furthermore, we denote an undirected edge connecting vertices _u_ and _v_ as the set {_u,v_}, while a directed edge (arc) from _u_ to _v_ is denoted by the ordered pair (_u,v_). For an edge _e_={_u,v_}, we write endpoints(_e_) to denote the pair of vertices incident to _e_. In pseudocode, the assignment \((u,v)\leftarrow\) endpoints(_e_) binds the two endpoints of _e_ to the variables _u_ and _v_ in arbitrary order.

For any two vertices \(u,v\in V\) , let \(\lambda(u,v;G)\) denote the local edge-connectivity, defined as the maximum number of edge-disjoint paths between _u_ and _v_ in _G_. The global edge- connectivity of _G_, denoted by \(\lambda(G)\), is the minimum local edge-connectivity over all pairs of vertices, i.e. \(\lambda(G)=min_{u,v\in V}\lambda(u,v;G)\).

The parameter _k_ represents the required global edge-connectivity and is treated as a fixed integer constant throughout the paper.

For any subset of vertices \(S\subseteq V\) and \(S\neq\emptyset\), let _G_\[_S_\]=(_S,E_\[_S_\]) denote the subgraph induced by _S_, where \(E[S]=\{\{u,v\}\in E|u,v\in S\}\) represents the set of edges with endpoints entirely contained within _S_. A cut is a partition of the vertex set into two disjoint sets \((S,\bar{S})\) such that \(S\cup\bar{S}=V\) and \(S\cap\bar{S}=\emptyset\).
