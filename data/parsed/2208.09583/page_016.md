to \(f_{i_1i_0}\in M\), agent _w_<sub>_i_<sub>1</sub></sub> must be covered by some edge that is not worse than _f_<sub>_i_<sub>0</sub>_i_<sub>1</sub></sub> and not worse than _g_<sub>_i_<sub>1</sub>(1)</sub>. Thus, we obtain that \(f_{i_2i_1}\in M\) for some _i_<sub>2</sub>_\<i_<sub>0</sub>. Now, since _f_<sub>_i_<sub>1</sub>_i_<sub>2</sub></sub>=(_u_<sub>_i_<sub>1</sub></sub>_,w_<sub>_i_<sub>2</sub></sub>)<sub>2</sub> and _g_<sub>_i_<sub>2</sub>(1)</sub>=(_u_<sub>_i_<sub>2</sub></sub>_,w_<sub>_i_<sub>2</sub></sub>)<sub>1</sub> do not block _M_ while _u_<sub>_i_<sub>1</sub></sub> prefers _f_<sub>_i_<sub>1</sub>_i_<sub>2</sub></sub> to \(f_{i_1i_0}\in M\) (as _i_<sub>2</sub>_\<i_<sub>0</sub>) and _u_<sub>_i_<sub>2</sub></sub> prefers _g_<sub>_i_<sub>2</sub>(1)</sub> to \(f_{i_2i_1}\in M\), we get that _w_<sub>_i_<sub>2</sub></sub> is covered by an edge no worse than _f_<sub>_i_<sub>1</sub>_i_<sub>2</sub></sub> and _g_<sub>_i_<sub>2</sub>(1)</sub>, and hence \(f_{i_3i_2}\in M\) for some _i_<sub>3</sub>_\<i_<sub>1</sub>. By the same argument, from the fact that _f_<sub>_i_<sub>2</sub>_i_<sub>3</sub></sub>=(_u_<sub>_i_<sub>2</sub></sub>_,w_<sub>_i_<sub>3</sub></sub>)<sub>2</sub> and _g_<sub>_i_<sub>3</sub>(1)</sub>=(_u_<sub>_i_<sub>3</sub></sub>_,w_<sub>_i_<sub>3</sub></sub>)<sub>1</sub> do not block _M_, we get that \(f_{i_4i_3}\in M\) for some _i_<sub>4</sub>_\<i_<sub>2</sub>_\<i_<sub>0</sub>. By iterating this argument, we get that there must be infinitely many _f<sub>ij</sub>_ type edges in _M_, which is a contradiction.

By using similar arguments, we get that, for any \(i\in[n]\) and \(\ell\in[2]\), we have \(h_{i(\ell)}\in M\) if and only if \(h'_{i(\ell)}\in M\). Recall that the size of _M_ is _n+k_ and observe that all _u<sub>i</sub>,w<sub>i</sub>_ agents are covered in _M_ (since otherwise \(h_{i(\ell)}\) or \(h'_{i(\ell)}\) type edges block _M_). Let \(V_1=\{v_i\in V:h_{i(1)}\in M\}\) and \(V_2=\{v_i\in V:h_{i(2)}\in M\}\). Then, \(V_1\cap V_2=\emptyset\) and the fact \(h_{i(\ell)}\in M\Leftrightarrow h'_{i(\ell)}\in M\) implies that |_V_<sub>1</sub>|+|_V_<sub>2</sub>|=_k_. Suppose that there is an edge \((v_i,v_j)\in E\) with \(v_i,v_j\in V_1\). Then, the edge _f<sub>ij</sub>_ blocks _M_, a contradiction. Similarly, if there is an edge \((v_i,v_j)\in E\) with \(v_i,v_j\in V_2\), then _e<sub>ij</sub>_ blocks _M_, a contradiction. Thus, _V_<sub>1</sub> and _V_<sub>2</sub> are disjoint independent sets with |_V_<sub>1</sub>|+|_V_<sub>2</sub>|=_k_ as required.

Suppose for contradiction that there is a polynomial-time \((2-\delta)\)-approximation algorithm for max-smpo for some fixed \(\delta>0\). For any \(\varepsilon>0\), let _G_ be an _n_-vertex graph such that there are disjoint independent sets with size \((\frac{1}{2}-\varepsilon)n\) each. We have shown in Claim 17 that there is a stable matching of size \(2n-2\varepsilon n\) in the corresponding max-smpo instance \(G'\). Using a \((2-\delta)\)-approximation algorithm for max-smpo, we can find a stable matching in \(G'\) of size at least \(\frac{1}{2-\delta}(2-2\varepsilon)n\), where we have \(\frac{1}{2-\delta}(2-2\varepsilon)n>(1+2\varepsilon)n\) if \(\varepsilon\) is small enough (for example \(\varepsilon<\frac{\delta}{6}\)). Then, by Claim 18, we can obtain two disjoint independent sets _V_<sub>1</sub> and _V_<sub>2</sub> in _G_ with \(|V_1|+|V_2|>2\varepsilon n\). Then, we get that we can find an independent set of size at least \(\varepsilon n\), which contradicts Theorem 16.
