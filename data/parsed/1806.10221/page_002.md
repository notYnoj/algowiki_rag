\(|\Psi\rangle=|\psi_1\rangle\otimes|\psi_2\rangle\otimes\dots\otimes|\psi_N\rangle\) (2)

The _N_<sup>2</sup>-qubit state \(|\Psi\rangle\) is a superposition of _N<sup>N</sup>_ basis states, where each basis state represents a particular configuration of the _N_ queens on the \(N\times N\) chessboard, such that no two queens are in the same row. Thus, by forming \(|\Psi\rangle\), we have generated a set of configurations which satisfy the Row Criteria as required. The communication channel prepares the _N_<sup>2</sup>-qubit system in \(|\Psi\rangle\) state \[25-27\] before the quantum computer implements the proposed algorithm.

The first computational task is to distinguish those basis states in \(|\Psi\rangle\) which satisfy the Column Criteria. For this purpose, it is convenient to visualize the system of _N_<sup>2</sup> qubits as _N_-blocks comprising _N_ qubits each, where the _i_th block represents the _i_th row of the matrix. In this step, we figure out an optimal algorithm to check whether there is only one queen in each column or not. Consider any particular column. We take an ancillary qubit initialized in the state \(|0\rangle\). We perform the Hadamard operation on this qubit which transforms it to \(|+\rangle\) state. We then apply a controlled phase shift \(e^{i\pi}\) to each of the corresponding qubits specifying the column, with the control being the ancilla. For example, if we are considering the first column, we would apply the given operation to the first qubits of each block. As a result, the ancillary qubit transforms to \(|-\rangle\) state if the column sum is odd, otherwise it remains in \(|+\rangle\) state. We reapply the Hadamard gate to the resultant state. As a result, the ancilla is in the state \(|1\rangle\) if the number of queens in that column is odd, and in the state \(|0\rangle\) otherwise.

Since each block of the qubits is in the _W_ state, we have the constraint that in each block only a single qubit is in \(|1\rangle\) state, which in turn implies that the system of _N_<sup>2</sup> qubits has _N_ qubits in \(|1\rangle\) state corresponding to _N_ queens being placed on the board. Hence, if there exists a column whose sum is _m_, such that _m_ is odd and _m\>_1, then there exists at least one column whose sum is zero, since the column sums add up to _N_. As a result, the ancillary qubit corresponding to such a column remains in \(|0\rangle\) state. Thus, the only possibility in which all the ancillas end up in \(|1\rangle\) state is when each column sum is 1 as followed by the Column Criteria.

However, it can be observed that, if _N_ non-negative integers add up to _N_, then there must be an even number of even numbers among them, where zero is also considered as an even number. A proof of this is presented in Supplementary Section. This enables us to perform the column checks for only _N_-1 columns instead of all _N_ columns. In our algorithm, we perform the column check operations for all columns except the last one, hence requiring _N_-1 additional qubits in total.

Our final task is to extract the basis states satisfying the Diagonal Criteria. Now that our search space has been reduced to the row permutations of \(I_{N\times N}\), there is only one queen in each row and each column. Let _Q<sub>i</sub>_ denote the queen placed in the _i_th row. We define a function _f_ as follows.

Let _Q_={_Q_<sub>1</sub>_,Q_<sub>2</sub>_,...,Q<sub>N</sub>_}<br>
\(f:Q\times Q\rightarrow\{0,1\}\) defined by,<br>
\(f(Q_i,Q_j)=\left\{\begin{array}{ c }

It can be easily seen that, if for a particular configuration \(f(Q_i,Q_j)=1\forall(Q_i,Q_j)\in Q\times Q\), then the configuration is a solution to the _N_-Queens Problem. We now propose the quantum algorithm to perform the diagonal checks to separate out the basis states of \(|\Psi\rangle\) satisfying the _N_-Queens Criteria from the reduced search space of _N_! basis states (which have been "marked" with the (_N_-1)-qubit in \(|1\rangle\) state of the entangled ancillary qubits, following the column check).
