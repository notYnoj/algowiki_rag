2. Solve _Tz_<sub>2</sub>=_r_<sub>2</sub>-_Wz_<sub>1</sub> to obtain _z_<sub>2</sub>;<tbc>

3. Form the vector _z_=(_z_<sub>1</sub>;_z_<sub>2</sub>).

As demonstrated in Algorithm 1, determining the solution requires handling two internal linear subsystems at the first and second steps. These systems feature the following coefficient matrices

\(\alpha I+T\text{and}T.\)

Because both of these matrices possess the symmetric positive definite (SPD) property, one can compute their solutions directly via Cholesky decomposition or iteratively via the Conjugate Gradient (CG) algorithm. It is worth noting that if an approximate (inexact) inner solver is employed for these subsystems, adopting the FGMRES method becomes essential to guarantee that the outer iterations remain robust and successfully converge.

Next, we explore the convergence characteristics associated with the VBP iteration scheme applied to the block linear system (2). Additionally, we discuss the spectral behavior of the preconditioned coefficient matrix \(\mathscr{P}_\mathrm{VBP}^{-1}\mathscr{A}\).

As established in the literature \[26\], the sequence of iterative vectors **u**<sup>(_k_+1)</sup> generated by (10) will successfully converge to the exact solution of (2) strictly when the spectral radius of the iteration matrix L<sub>VBP</sub>, denoted by \(\rho(\mathscr{L}_\mathrm{VBP})\), is less than unity.

**Theorem 1.** _Let_ \(W\in\mathbb{R}^{n\times n}\) _be a symmetric indefinite matrix and let_ \(T\in\mathbb{R}^{n\times n}\) _be symmetric positive definite. Let_ \(\alpha>0\) _and_ \(\gamma>0\)_. If the parameter_ \(\alpha\) _satisfies the condition_

\(\alpha>\frac{b-c}{2},\) (12)

_where_

\(c=x^*Tx>0,b=x^*WT^{-1}Wx\ge 0,\) (13)

_with_ \(x\in\mathbb{C}^n\) _such that_ \(\|x\|_2=1\)_, then the iterative scheme defined in_ (9) _converges to the unique solution for any initial guess_ \(x^{(0)}\in\mathbb{R}^n\).

_Proof._ Let \((\lambda,\mathbf{u}=(x;y))\) be an eigenpair of the iteration matrix L<sub>VBP</sub>, such that \(\|x\|_2=1\). Then, we get \(\mathscr{L}_\mathrm{VBP}(x;y)=\lambda(x;y)\), which is equivalent to

\(\mathscr{R}_\mathrm{VBP}\left[\begin{array}{ c }
x \\
y
\end{array}\right]=\lambda\mathscr{P}_\mathrm{VBP}\left[\begin{array}{ c }
x \\
y
\end{array}\right].\) (14)

It is straightforward to show that this equation is equivalent to

\(\left\{\begin{array}{ c }
\alpha x-\gamma W^2x+Wy-\gamma WTy=\lambda(Tx+\alpha x-\gamma W^2x-\gamma WTy), \\
0=\lambda(Wx+Ty).
\end{array}\right.\) (15)

If \(\lambda=0\), then there is nothing to prove. So we assume that \(\lambda\neq 0\).
