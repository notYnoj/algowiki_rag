Since each call to `Tournament` incurs error at most 2, each round incurs error at most 2, so we can show the total error is bounded by 2 times the number of rounds.

## 2.3 Selection in Rounds

Our algorithm improves the approximation factor from the previous sections algorithm with a small _O_(log_d_) additional round overhead. We use a similar approach to the maximum selection algorithm given in \[GKK<sup>+</sup>20\], where we first describe an algorithm that gives a good approximation if there are few elements around the actual answer, then describe an algorithm that gives a good approximation if there are many elements around the actual answer, then show a way to combine them to guarantee a good approximation always. Since we are looking for an element in the middle of the sorted order, however, there is some additional complexity with considering close elements on each side of the desired element.

Let _x<sub>i</sub>_ be the actual _i_-th smallest element of _X_. The first part of our algorithm guarantees a good left-side approximation if \(|X\cap[x_i-1,x_i]|\le\frac{1}{10}n^{2/3}\). Similarly, it guarantees a good right-side approximation if \(|X\cap[x_i,x_i+1]|\le\frac{1}{10}n^{2/3}\). We aim to partition _X_ into three sets \(Z,Y,\Gamma\) such that elements of _Z_ are "less than" _x<sub>i</sub>_, elements of \(\Gamma\) are "greater than" _x<sub>i</sub>_, and _Y_ is the set of "candidate" elements to be _x<sub>i</sub>_. We sample _cn_<sup>2/3</sup>log_n_ subsets of _X_ of size _n_<sup>1/3</sup>, each time sorting using the depth _d_ algorithm from the previous subsection. We then take the elements within _n_<sup>1/6</sup> of the _k/n_<sup>2/3</sup>-th element of each subset and add them to _Y_ (the set of candidates). We say that elements in positions to the left of _k/n_<sup>2/3</sup>-_n_<sup>1/6</sup> are on the left side, and the rest of the elements are on the right side. After sampling all subsets, elements which are not in the set of candidates are partitioned into _Z_ and \(\Gamma\) based on how frequently they are on the left side. Assume \(|X\cap[x_i-1,x_i]|\le\frac{1}{10}n^{2/3}\), the other case is symmetric. In this case, roughly 90% of the sampled subsets will contain no elements in \[_x<sub>i</sub>_-1_,x<sub>i</sub>_\]. For each of these subsets, since our sorting algorithm must be _gap-preserving_, the sorting must be correct with respect to \[_x<sub>i</sub>_-1_,x<sub>i</sub>_\]. It thus follows by a tail bound of the Hypergeometric distribution and a union bound that for all _x<sub>j</sub>\<x<sub>i</sub>_-1, _x<sub>j</sub>_ will end up in \(Z\cup Y\) with high probability. Similarly, for _x<sub>j</sub>\>x<sub>i</sub>_, _x<sub>j</sub>_ will end up in \(Y\cup\Gamma\) with high probability. Finally, if \(|Z|\ge k\), we return the maximum element of _Z_ computed with a depth _O_(log_d_) maximum finding algorithm from \[GKK<sup>+</sup>20\]. If |_Z_|+|_Y|\<k_, we return the minimum element of \(\Gamma\) similarly. Otherwise, we return the (_i_-|_Z_|)-th element of _Y_ as determined by a constant depth, constant approximate sorting algorithm from the previous section (since |_Y_|=_O(n_<sup>5/6</sup>)). If \(|Z|\ge i\), there must be some element of _Z_ that is \(\ge x_i\), so since the maximum finding algorithm returns a constant approximation, we return a constant left-approximation. If |_Z_|+|_Y|\<i_, we return some element of \(\Gamma\), and all elements of \(\Gamma\) are \(\ge x_i-1\). Otherwise, there can be at most _i_-|_Z_|-1 elements of _Y_ that are _\<x<sub>i</sub>_, so the actual (_k_-|_Z_|)-th element is \(\ge x_i\), so since we use a constant approximate sorting, the element we return is a constant left-approximation as desired.

The second part of our algorithm guarantees a good left side approximation given \(|X\cap[x_i-1,x_i]|>\frac{1}{10}n^{2/3}\) (and there is a symmetric algorithm that guarantees a good right side approximation). The idea is simple: sample _O(n_<sup>5/6</sup>) elements of _x_, sort them with a constant approximation algorithm in constant rounds, and then take the (_k/n_<sup>1/6</sup>-_n_<sup>5/12</sup>)-th element. By another Hypergeometric tail bound, it follows that we always get a good right-approximation, and also get a good left-approximation if \(|X\cap[x_i-1,x_i]|>\frac{1}{10}n^{2/3}\) as desired.

If this value is \(\le i-1\), we must have \(x^*\le x_i+1\). We then call the left-side dense algorithm and return the greater of the two results (according to the comparator).
