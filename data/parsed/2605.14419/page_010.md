The paper proposes a novel sorting algorithm, zSort, that bridges this performance gap while maintaining pass complexity that is invariant to key width. zSort employs a z-score based distribution hybrid recursive structure that is well aligned with modern processor, as demonstrated through the micro- architectural analysis. Experimental evaluation shows that zSort achieves better performance across a wide range of datasets, key distributions, and input sizes as compared to the other existing algorithms. The results suggest that zSort provides a practical and efficient alternative for stable sorting in modern data processing environments. Future work includes extending the proposed algorithm to fully exploit modern hardware platforms, including multicore CPUs and GPUs, as well as adapting it to external- memory and distributed architectures.
