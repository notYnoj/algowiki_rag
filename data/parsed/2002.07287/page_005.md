\(\blacktriangleright\) **Lemma 3.** _Given an N-bit sequence S consisting of k self-delimiting numbers, each in the range_ [0_,m_) (\(m\le 2^{N/\tau}\)_) and a parameter_ \(\tau\) _with_ \(logN\le\tau\le w\)_, there is a stable-sorting algorithm computing a bit sequence of N bits that stores the given self-delimiting numbers in sorted order. The algorithm runs in_ \(O(k+N/\tau)+o(2^\tau)\) _time and_ \(O(N)+o(2^\tau)\) _bits._

**Proof.** We first describe how to presort the numbers into areas _A<sub>i</sub>_. For an easier description, we define a function _f_ that maps each \(x\in S\) to its area (i.e., _x_ is in area _A_<sub>_f(x_)</sub> as follows:

\(f(x\in S)=\left\{\begin{array}{ c c } 1 & x=0 \\ 2\lfloor logx\rfloor+1 & x>0 \end{array}\right.\)

We start to reorder the numbers by copying them to a new, initially-empty sequence \(S'\) of _N_ bits to consecutively store the numbers of each area _A<sub>i</sub>_ (_i_=[1_,f(m_)]). We need to assign to each non-empty area _A<sub>i</sub>_ an offset \(B(i)=\sum_{j\in[1,i-1]}(j-1)|A_j|\) in \(S'\) such that every number of every area _j\<i_ can be written in \(S'\) by one scan over _S_. For the offset we require to know the cardinality _C(i_)=|_A<sub>i</sub>_| of every area _A<sub>i</sub>_ (\(i\in[1,f(m)]\)). We realize _C_ as a table with _f(m_) entries of \(\lceil logN\rceil\) bits each and use _C[i_] to count how many numbers in _S_ require _i_ bits as a self-delimiting number. For that, iterate over the self-delimiting numbers in _S_ and for each number \(x\in S\) increment _C[f(x_)] by one. To be able to access the offset _B(i_) of every area in constant time we also realize _B_ as an array of _f(m_) fields of \(\lceil logN\rceil\) bit each. Initialize _B_ by setting _B_[1]=1 and _B[i_]=_B[i_-1]+(_i_-1)_C[i_-1] with _i_=2_,...,f(x_). After computing the offsets we use them to write the self-delimiting numbers into a new _N_-bit sequence \(S'\) as follows: scan through _S_ and for each self-delimiting number _x_, store _x_ in \(S'\) starting from position _B[f(x_)] and increment _B[f(x_)] by _f(x_) to adjust the boundary for the next number. This completes the presorting of the numbers into a sequence \(S'\). Note that the order \(S'\) is stable.

To sort the numbers inside an area we use a folklore technique. We consider each self-delimiting number of a number _x_ in an \(2^{\tau/2}\)-ary system so that it is represented by \(\lceil f(x)/\lceil\tau/2\rceil\rceil\) digits from the alphabet \(\mathcal{A}=[0,\lceil 2^{\tau/2}\rceil-1]\), and we use radix sort in combination with a stable counting sort algorithm. Consider the area _A<sub>i</sub>_ as a sequence of _k<sub>i</sub>_ subsequently stored self-delimiting numbers, each of _i_ bits and occupying _N<sub>i</sub>_ bits in total. We sort the numbers digit-wise, starting with the least significant digit \(d=1,\dots,\lceil 2i/\tau\rceil\). We use a temporary sequence _S<sub>i</sub>_ of _N<sub>i</sub>_ bits to output the sorted numbers and subsequently replace _A<sub>i</sub>_ in _S_ by _S<sub>i</sub>_. We so sort every area _A<sub>i</sub>_ in _S_. In detail, the folklore sorting algorithm consists of the following steps, repeating in rounds for each digit. Let _d_ be the current digit. Build a histogram of the occurrences of each element of the alphabet A at digit _d_. Following that, construct a prefix-sum array of the occurrences of each element of the alphabet at _d_, also known as the integral of the histogram. The prefix-sum array is then used to partially sort the numbers by the current digit. Concretely, if we have a number with _d_th digit being \(\ell\), then a tuple (_d,_pre) that is stored at the \(\ell\)th position of the prefix-sum array tells us to write a number at index pre in the temporary sequence _S<sub>i</sub>_. For each value that is placed in the temporary sequence _S<sub>i</sub>_, the respective entry \((\ell,\text{pre})\) is replaced by \((\ell,\text{pre}-1)\). Once the numbers are partially sorted for the current digit _d_, continue with digit _d_+1 in the next round.

We now describe how to obtain simultaneously the histogram and prefix-sum array for all rounds of the sorting algorithm for an area _A<sub>i</sub>_. We begin with a pre-processing step. Construct a table _T_ with \(\lceil 2^{\tau/2}\rceil\) entries, one for each element of the alphabet A. At each index \(\ell\in\mathcal{A}\) of the table _T_ store an (initially empty) stack. Each stack at index \(\ell\) will store tuples (_d,_occ) where occ is the numbers of occurrences of \(\ell\) at digit _d_. Only tuples with occ _\>_0 are stored.
