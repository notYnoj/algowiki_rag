The initialization of _B_, _P_ and the rank-select structure requires \(O(n+\sum_{u\in V(T)}|\text{color}(\text{u})|)\) time, since it is determined by the space of _B_ and _P_. The balanced parenthesis representation can be computed within the same time. Writing and reading a number _x_ stored with _O_(log_x_) bits requires _O_(log_x/w_)=_O_(1) time on the word RAM. Reading vector(u) consequently requires _O_(deg(u)) time. \(\blacktriangleleft\)

**(C) Computing classification numbers.** Let _D_ be our data structure of Lemma 16 where we store all classification vectors. Our next goal is to replace the classification vector _D._`vector`(_u_) of all processed subtrees with root _u_ and height _h_ by a classification number (_h,q<sub>u</sub>_) with |_q<sub>u</sub>_|=_O_(min{`desc`(_u),_log_n_}) such that the componentwise-sorted classification vectors are equal exactly if they get the same classification number.

Our idea is to sort _D._`vector`(_u_) by using Theorem 4 to obtain a component-wise sorted classification vector and turn this vector into a self-delimiting number for further operation on it. We subsequently compute the dense rank to replace the self-delimiting number in _D._`vector`(_u_) by the tuple (height, dense rank). To make it work we transform each vector into a self-delimiting number by considering the bit-sequence of the vector as a number (i.e., assign the prefix \(0^\ell 0\) to each vector where \(\ell\) is the length of the vector in bits). We can store all these vectors as self-delimiting numbers in a bit-vector _Z_<sub>_h_+1</sub> of _O(n_) bits. Then we can use Theorem 5 applied to _Z_<sub>_h_+1</sub> to compute the dense ranks, which allows us to determine the classification numbers for all subtrees of height _h_+1.

**Our Algorithm.** We now combine the solutions for (A)-(C).

\(\blacktriangleright\) **Lemma 17.** _Given two rooted n-node trees T_<sub>1</sub> _and T_<sub>2</sub> _there is an algorithm that recognizes if T_<sub>1</sub> _and T_<sub>2</sub> _are isomorphic in linear-time using O(n_) _bits._

**Proof.** Computing the leaves and their classification numbers is trivial. So assume we have computed the classification numbers for the subtrees of height _h_, and we have to compute the classification numbers for the subtrees of height _h_+1. We iterate over every subtree with root _u_ and height _h_+1 by using the choice dictionary C returned by our iterator of Lemma 15.

We assume a data structure _D_ of Lemma 16 is constructed. In the following, let _k<sub>u</sub>_ be the number of children of a node _u_, let _N<sub>u</sub>_ be the number of bits of _D._`vector`(_u_) and let _V<sub>i</sub>_ be the set of nodes of height _i_ in both trees. For each node _u_, we sort the classification numbers of its children stored in _D._`vector`(_u_) into a new bit-vector _X_ of _N<sub>u</sub>_ bits by applying Theorem 4 (with parameters _N=N<sub>u</sub>_, _k=k<sub>u</sub>_ and 1log_n_) and store it by calling _D._`write`(_u,X_).

We can now construct the vectors \(Z_{h+1}^{T_1}\) and \(Z_{h+1}^{T_2}\) for the subtrees of height _h_+1 within the trees _T_<sub>1</sub> and _T_<sub>2</sub>, respectively. \(Z_{h+1}^{T_j}\) consists of the self-delimiting numbers constructed from the vector _D._`vector`(_u_) of each node _u_ in _T<sub>j</sub>_ of height _h_+1, with \(j\in\{1,2\}\). We then put \(Z_{h+1}^{T_1}\) and \(Z_{h+1}^{T_2}\) together into a total sequence _Z_ and apply Theorem 5 (with parameters \(N=O(\sum_{u\in V_{h+1}}N_u)\), _k_ being the number of self-delimiting numbers in _Z_ and \(\tau=\mathrm{log}n\)) to determine the dense rank of the numbers in _Z_. Subsequently, we iterate over the numbers _q_ in _Z_ and use their position _p_ to retrieve their dense rank _r<sub>q</sub>=R(p,q_). In parallel, we iterate over the subtrees of height _h_+1 in both trees again and replace the classification vector _q_ by calling _D._`write`(_u,(h_+1_,r<sub>q</sub>_)). After computing the classification number for each node of height _h_+1 in _T_<sub>1</sub> and _T_<sub>2</sub>, we can compare them and proceed with the next height until reaching the root in both trees. Following this, we can easily answer the question if _T_<sub>1</sub> and _T_<sub>2</sub> are isomorphic or not.
