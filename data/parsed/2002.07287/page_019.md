By the next lemma we can store the classification numbers and vectors. \(\blacktriangleright\) **Lemma 16.** _Let c\>_0 _be a constant integer and T a node-colored rooted n-node tree with_ \(\mathrm{color}:\mathrm{V}(\mathrm{T})\rightarrow\mathrm{N}\) _the function to evaluate the color of each node_ \(u\in V(T)\) _such that_ color(u) _can be evaluated in time O_(|color(u)|)_. Then there is an_ \(O(n+\sum_{u\in V(T)}|\mathrm{color}(\mathrm{u})|)\)_-bits data structure that initializes in_ \(O(n+\sum_{u\in V(T)}|\mathrm{color}(\mathrm{u})|)\) _time and, for each node u of T, provides operations_ `read(u)` _and_ `write(u)` _in constant time as well as_ `vector(u)` _in O_(deg(u)) _time._

`read(u) (u node of T): If a number x is stored for u, then x is returned. Otherwise, the result is undefined.` `write(u, x) (u node of T,_ \(0\le x\le\mathrm{min}\{2^{2c\cdot\mathtt{desc}(\mathrm{u})+|\mathrm{color}(\mathrm{u})|},\mathrm{poly}(w)\}\)_): Store number x for node u and delete all stored numbers of the descendants of u._ `vector(u) (u node of T): Returns the bit-vector of length_ \(\le 2c\cdot\mathtt{desc}(u)+\sum_{v\in\mathrm{children}(\mathrm{u})}|\mathrm{color}(\mathrm{u})|\) _consisting of the concatenation of the self-delimiting numbers stored for the children of u._

**Proof.** We assume that _T_ is given via the data structure of Corollary 12, otherwise construct it. We first describe some auxiliary data structures that we require. The first is a bit array _B_ of \(6c\cdot n+\sum_{u\in V(T)}|\mathrm{color}(\mathrm{u})|\) bits that we use to maintain the numbers, i.e., the values we read/write with the specified operations. We use a second bit array _P_ under _B_ where we mark the position in _B_ for each node _u_ of _T_ where we can store the given number for _u_. (Note that, if |color(u)|=0 for all _u_ in _T_ we can calculate the exact positions without _P_ and write into \(B[6c\cdot u_\(,6c\cdot u_\unknown]\), by exploiting the fact that for each node _u_, _u_<sub>(</sub> and _u_<sub>)</sub> are the positions of the open and closed parenthesis of a node _u_, respectively.) Given the balanced parenthesis representation we can iterate over the nodes of _T_ in pre-order and flip the _i_th bit in _P_ to 1 where _i_ is initially 0 and is incremented after each iteration over a node _u_ by \(6c\cdot\mathtt{desc}(\mathrm{u})+|\mathrm{color}(\mathrm{u})|\). Since by construction the _i_th flipped bit corresponds to the value of _u_, we can find the position _p_ of the _i_th bit by calculating a rank-select data structure on _P_ and call _p_:=select(u), i.e., we use static space allocation. Having _p_ we realize `write(u_, _x_)` and by transforming _x_ into a self-delimiting number and write it starting at _B[i_]. The operation `read(u)` is realized by reading a self-delimiting number starting from _B[i_] and transforming it into a number. To return `vector(u)`, call `read(v)` for all children of _u_ and concatenate the returned self-delimiting numbers to one bit-vector.

We now argue that the bits required to store a number _x_, written for a node _u_, fits into _B[p<sub>u</sub>,p<sub>v</sub>_) where _v_ is the next sibling of _u_ and _p<sub>u</sub>_=select(u) and _p<sub>v</sub>_=select(v). Recall that a number _x_ can be stored as a self-delimiting number with _f(x_)=3 bits if \(x\le 1\) and with \(f(x)=2\lceil logx\rceil+1\le 3\lceil logx\rceil\) bits if _x\>_1. Since \(x\le\mathrm{min}\{2^{2c\cdot\mathtt{desc}(\mathrm{u})+|\mathrm{color}(\mathrm{u})|},\mathrm{poly}(w)\}\), _x_ can be stored inside a space of \(6c\cdot\mathtt{desc}(u)+|\mathrm{color}(\mathrm{u})|\) bits. By construction of _P_ this is exactly the space between _p<sub>u</sub>_ and _p<sub>v</sub>_.

Observe that by the pre-order traversal using the balanced parenthesis representation the positions of all children of _u_ are between _p<sub>u</sub>_ and _p<sub>v</sub>_ (if a sibling _v_ exists), hence writing _x_ can overwrite only the numbers of the children of _u_.

Concerning the space note that the balanced parenthesis representation uses _O(n_) bits. The auxiliary structures _B_ and _P_ use \(O(n+\sum_{u\in V(T)}|\mathrm{color}(\mathrm{u})|)\) bits and a rank-select structure on _P_ can be constructed with the same space bound. Hence, our space bound is as stated in the lemma.
