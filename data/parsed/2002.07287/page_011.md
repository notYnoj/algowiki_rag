In detail, use the next free frame to store only ones and so mark the subsequent two frames to store the number in a binary representation instead of a self-delimiting number.

To find the index of the first bit of the number of R_<sub>i</sub>_ inside _A<sub>i</sub>_, we use static space allocation, as described in Section 2. Moreover, we use an array _P<sub>i</sub>_ of the same size as _A<sub>i</sub>_ partitioned into frames of size \(\lceil\tau/2\rceil\), where \(P_i[\ell]\) is the prefix-sum up to the \(\ell\)th frame of _A<sub>i</sub>_, including the prefix sum of the numbers in the regions 0_...i_-1. For an example, see again Fig. 2.

With the data structures defined above we can answer the competitive rank of a number \(x\in S\) as follows: compute the region \(i=\lfloor x/\lceil\tau/2\rfloor\rfloor\) of _x_. Use the pointer _F[i_] to jump to a data structure _Q<sub>i</sub>_. The number _x_ is the _q_th number inside the region R_<sub>i</sub>_ with _q=x_ mod (\(\tau/2\)). Select the starting position _p_ of the _q_th number in _A<sub>i</sub>_, accessible via static space allocation. The position _p_ lies inside the _f_th frame with \(f=\lfloor p/\lceil\tau/2\rfloor\rfloor\). Read the _f_th frame as a variable _z_ and check if the self-delimiting number _A<sub>i</sub>[q_] occupies the whole frame, i.e., check if _A<sub>i</sub>[q_] encodes the start of a large number. If not, remove all numbers inside _z_ after the number _A<sub>i</sub>[q_] and return the competitive rank of _x_ as _P[f_]+`PREFIXSUM`[_z_]. Otherwise, read the large number as _z_ and return the competitive rank of _x_ as _P[f_]+_z_

We now describe the construction of our data structure. Apply Theorem 4 on _S_ to get a sorted sequence \(S'\). Initialize _F_ with \(\lceil N/\lceil\tau/2\rceil\rceil\) zero-entries, each of \(\tau/2\) bits, and let _j_=0 be the largest competitive rank so far. Iterate over \(S'\) and for each number _x_ check if _F[i_] with \(i=\lfloor x/\lceil\tau/2\rfloor\rfloor\)contains a pointer to a data structure _Q<sub>i</sub>_. If not, initialize _Q<sub>i</sub>_ as follows: as long as the numbers are part of the same region R_<sub>i</sub>_, run through \(S'\), and count in _y_ the different numbers in that region. Since R_<sub>i</sub>_ contains \(y\le\lceil N/r\rceil\) different numbers out of _S_, we can temporarily afford to use a key value map _D_ of \(\lceil y/\lceil\tau/2\rceil\rceil\) entries, each of \(\tau\) bits, to count the number of occurrences of each number \(x\in\mathcal{R}_i\) in _S_. Let #(_x,S_) be the number of occurrences of a number _x_ in _S_.

In detail as long as the next number in \(S'\) is part of R_<sub>i</sub>_, run through \(S'\) and, for each number _x_ found in \(S'\), store the number of its occurrences #(_x,S_) as _D[x_]=#(_x,S_). Afterwards, scan through _D_ and determine the number \(N'\) of bits required to represent all numbers in _D_ as self-delimiting numbers. Create _Q<sub>i</sub>_, i.e., allocate \(2N'+\tau/2\) bits for the static space allocation of _A<sub>i</sub>_ as well as create an array with \(\lceil(3N'+\tau/2)/\lceil\tau/2\rceil\rceil\) entries of _r_ bits for _P<sub>i</sub>_. Fill _A<sub>i</sub>_ with the numbers of _D_ as follows: take the difference _d_ between the number _z_ (initially 0) and the next key number \(z'\) of _D_, jump over _d_ bits of _A<sub>i</sub>_ and store the number \(D[z']\) in _A<sub>i</sub>_ such that a number either fits into the current frame of _A<sub>i</sub>_, the next, or if the number is too large to fit into a frame, store it as described above. Moreover, sum up all written numbers in a global variable _j_ (initially 0), i.e., set \(j=j+D[z']\), which is the largest prefix sum so far. Use it to fill _P<sub>i</sub>_ every time a frame \(\ell\) is about to be written, i.e., set \(P_i[\ell]=j\). If the iteration over the numbers of the region R_<sub>i</sub>_ are finished in \(S'\), delete _D_ and continue the iteration over \(S'\).

Recall that _F[i_] contains a `null` pointer if _S_ does not contain any number of region R_<sub>i</sub>_. Otherwise, a structure _Q<sub>i</sub>_ is created. We now focus on the space complexity of _Q<sub>i</sub>_. We store in _A<sub>i</sub>_ only the amount of occurrences of each different number of R_<sub>i</sub>_ in _S_. Observe that, if a number occurs _z_ times, then _O_(log_z_) bits suffice to store the amount of occurrences as a self-delimiting number (each occurrence contributes _O_(1) bits).
