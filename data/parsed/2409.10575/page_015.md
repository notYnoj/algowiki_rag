Similarly, the modified HRT generator accepts five parameters: the number of residents (_n_), the number of hospitals (_m_), the probability of incompleteness (_p_<sub>1</sub>), the probability of starting a tie (_p_<sub>2</sub>), and the random generator of the tie length (_g_). Experimental results indicate that HRT problems with capacities uniformly distributed among hospitals present a greater challenge compared to those with randomly allocated capacities (Cao et al 2023). Therefore, the capacity is uniformly distributed among hospitals in the HRT instances.

To evaluate the efficacy of various algorithms in addressing the MAX-SMTI and MAX-HRT problems, we categorize the problems into two sizes: small and large. For the small-sized problems, we select values of _p_<sub>1</sub> that result in instances which are difficult to solve by simply applying the GS algorithm with randomly broken ties. For the large-sized problems, we set a high value for _p_<sub>1</sub> to generate more challenging instances. We systematically vary parameters across both problem sizes, with the configurations detailed in  2. Furthermore, we conduct scalability experiments to assess how the performance of our algorithms scales as the input size increases from 1,000 to 10,000, with the configurations provided in  3. In these two configuration tables, parameters are presented with specific ranges, intervals, or formulas. For instance, the notation "0.7-0.9 (0.1)" indicates values ranging from 0.7 to 0.9 in increments of 0.1. The use of commas, such as in "Geom(_p_<sub>2</sub>),Geom(1-_p_<sub>2</sub>)", denotes an alternative parameter set being considered for the parameter. Additionally, the formula "(_n_-10)_/n_" represents a value that is computed based on _n_. We define each unique combination of _n,m,p_<sub>1</sub>_,p_<sub>2</sub>, _g_ as a _configuration_. To ensure a robust evaluation, we generate 100 instances for each configuration. The randomly generated instances used in this study are available in the Science Data Bank repository, https://www.scidb.cn/en/s/ZfauMn.

## 5.2 Parameter settings

In both TBLS and TBLS-E, the parameters _c_=0.9 and _p<sub>d</sub>_=0.05 are consistently maintained across all configurations. The parameter _c_ is utilized to compute _e<sub>M</sub>_, which estimates the minimum size of the matching during the search process. Meanwhile, _p<sub>d</sub>_ denotes the probability of executing a disruption. Furthermore, the time threshold _T_ for obtaining stable matchings is set equal to the time required to obtain a stable matching with the use of the base algorithm at the beginning. The parameters _k<sub>u</sub>_ and _k<sub>w</sub>_, which are adapted according to the scale and complexity of the problem, are detailed in  4. Specifically, _k<sub>u</sub>_ and _k<sub>w</sub>_ represent the number of agents selected from sets _U_ and _W_ for disruption, respectively. In the context of the MAX-SMTI problem, _U_ and _W_ represent men and women, respectively, while in the MAX-HRT problem, _U_ and _W_ correspond to residents and hospitals, respectively. For TBLS, GS serves as the base algorithm, whereas for TBLS-E, PDB is used as the base algorithm.
