### 7.3 The Final Online Algorithm

We now provide the final online algorithm, that is described in two steps.

First, we assume that in the online sequence, all input points are doubled, that is, for \(1\le i\le m\), both in iterations (2_i_-1) and 2_i_ the algorithm receives copies of the input point _p<sub>i</sub>_; the point received at iteration (2_i_-1) is denoted by \(p'_i\), and the point received at iteration 2_i_ is denoted by \(p''_i\). The algorithm computes the collection T of trees at the beginning. When a point \(p'_i\) arrives, we can identify, for every tree \(T'\in\mathcal{T}\) , whether \(p'_i\) is the first point in any \(T'\)-box. We then add projections of the point \(p'_i\) to the corresponding strips _S(v_) as needed, all on row _R_<sub>2_i_-1</sub>. When a point \(p''_i\) arrives, we only discover whether it is the last point of any \(T'\)-box, for all \(T'\in\mathcal{T}\) , in the following iteration. Therefore, in iteration 2_i_+1, we add both the copy \(p''_i\) of \(p''_i\), and all its relevant projections, to row _R_<sub>2_i_+1</sub>. Note that at the same time, we may also add projections of point \(p'_{i+1}\) to row _R_<sub>2_i_+1</sub>. It is easy to verify that the resulting solution is precisely \(Y'\), and therefore it is a feasible solution. The cost of the solution is bounded by \(O(loglogn)\cdot\mathsf{OPT}(X)\).

Lastly, for all \(1\le i\le m\), we unify the iterations (2_i_-1) and (2_i_) into a single iteration in a straightforward way.

We describe his proof in the geometric view in more detail here. Let _k_ be an integer that is an integral power of 2, _n_=2_<sup>k</sup>_, and \(\ell=logk\). Let C be a set of columns with integral _x_-coordinates from 1 to _n_, and let L be the set of vertical lines with half-integral coordinates between 1/2 and _n_-1/2. We consider a balanced partitioning tree _T_, where for every inner vertex \(v\in V(T)\), the line _L(v_) that _v_ owns crosses the strip _L(v_) exactly in the middle. Let _P_=(_v_<sub>1</sub>_,v_<sub>2</sub>_,...,v<sub>k</sub>_) be the unique path in tree _T_, obtained by starting from the root _r=v_<sub>1</sub>, and then repeatedly following the left child of each current vertex, until a leaf _v<sub>k</sub>_ is reached, so _k_=log_n_.
