We start with _t_=1. Consider any profile \(\pi\) that is consistent with _t_. Recall that for every column \(C_j\in\mathcal{C}\), \(\pi(C_j)\in\{1,\infty\}\) must hold, and moreover, if _C<sub>i</sub>_ is the unique column containing the point \(p_1\in X\), then \(\pi(C_i)=1\) must hold. We let \(T[1,\pi]\) contain the following set of points: for every column \(C_j\in\mathcal{C}\) with \(\pi(C_j)=1\), we add the point lying in the intersection of column _C<sub>j</sub>_ and row _R_<sub>1</sub> to the point set stored in \(T[t,\pi]\). It is immediate to verify that the resulting point set is consistent with \(\pi\), it is satisfied, it contains \(X_{\le 1}=\{p_1\}\), and it is the smallest-cardinality point set with these properties.

We now assume that for some \(t\ge 1\), we have computed correctly all entries \(T[t',\pi']\) for all \(1\le t'\le t\), and for all profiles \(\pi'\) consistent with \(t'\). We now fix some profile \(\pi\) that is consistent with _t_+1, and show how to compute entry \(T[t+1,\pi]\).

Let \(r=M(\pi)\) (recall that this is the largest value of \(\pi(C_j)\) that is not \(\infty\)), and let \(\mathcal{C}_1\subseteq\mathcal{C}\) be the set of all columns _C<sub>j</sub>_ with \(\pi(C_j)=r\). Recall that, if _C<sub>j</sub>_ is the column containing the input point _p_<sub>_t_+1</sub>, then \(C_j\in\mathcal{C}_1\) must hold. Let _P_ be the set of |C<sub>1</sub>| points that lie on the intersection of the row _R_<sub>_t_+1</sub> and the columns in C<sub>1</sub>.

Consider now any profile \(\pi'\) that is legal for _t_, and let \(\hat{Z}=T[t,\pi']\). Denote \(\hat{Z}'=\mathrm{top}(\hat{Z})\). We say that profile \(\pi'\) is a _candidate profile_ if (i) \(\pi'\) is legal for _t_; (ii) the point sets \(P,\hat{Z}'\) do not conflict; (iii) \(\mathcal{C}'(\pi')\subseteq\mathcal{C}'(\pi)\cup\mathcal{C}_1\); and (iv) if we discard from \(\rho_\pi\) and from \(\rho_{\pi^\prime}\) the columns of C<sub>1</sub>, then the two orderings are defined over the same set of columns and they are identical. We select a candidate profile \(\pi'\) that minimizes \(|T[t,\pi']|\), and let \(Z=\hat{Z}\cup P\), where \(\hat{Z}\) is the point set stored in \(T[t,\pi']\). We then set \(T[t+1,\pi]=Z\).

We now verify that set _Z_ has all required properties. If the entry \(T[t,\pi']\) was computed correctly, then point set \(\hat{Z}\) is satisfied. Since \(\mathrm{top}(\hat{Z})\) and _P_ are not conflicting, from Observation 6.17 neither are \(\hat{Z}\) and _P_. Therefore, from Lemma 6.15, set _Z_ is satisfied. If the entry \(T[t,\pi']\) was computed correctly, then \(X_{\le t}\subseteq\hat{Z}\). Since \(p_{t+1}\in P\), we get that \(X_{\le(t+1)}\subseteq Z\).

Next, we show that _Z_ is consistent with the profile \(\pi\). Let \(Z'=\mathrm{top}(Z)\), and consider the ordering \(\sigma(Z)\) of the points in \(Z'\). It is easy to verify that the last |_P_| points in this ordering are precisely the points of _P_. The remaining points in this ordering can be obtained from the point set \(\hat{Z}'\), by first ordering them according to ordering \(\sigma(\hat{Z})\), and then deleting all points lying on columns of C<sub>1</sub>. From the definition of candidate profiles, it is easy to verify that for all \(1\le i\le|Z'|\), the _i_th point in \(\sigma(Z)\) lies on the _i_th column of \(\rho_\pi\). Therefore, _Z_ is consistent with profile \(\pi\).

Lastly, it remains to show that the cardinality of _Z_ is minimized among all sets with the above properties. Let _Z_<sup>∗</sup> be the point set that contains \(X_{\le t+1}\), is satisfied, is consistent with profile \(\pi\), with every point of _Z_<sup>∗</sup> lying on rows _R_<sub>1</sub>_,...,R_<sub>_t_+1</sub>, such that |_Z_<sup>∗</sup>| is minimized among all such sets. It is easy to verify that the set of points of _Z_<sup>∗</sup> lying on row _R_<sub>_t_+1</sub> must be precisely _P_. This is since point _p_<sub>_t_+1</sub> must belong to _Z_<sup>∗</sup>, and so every column _C<sub>i</sub>_ with \(\pi(C_i)=M(\pi)\) must have a point lying on the intersection of _C<sub>i</sub>_ and _R_<sub>_t_+1</sub> in _Z_<sup>∗</sup>. Moreover, there is no conflict between \(\mathrm{top}(\hat{Z})\) and _P_.
