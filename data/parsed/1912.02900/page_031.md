## 4.4.2 Second Instance

In this step we construct our second and final instance, _X_<sup>∗</sup>, that is a permutation. In order to do so, we start with the instance \(\hat{X}\), and, for every active column _C_ of \(\hat{X}\), we create _n_=log_N_ new columns (that we view as copies of _C_), _C_<sup>1</sup>_,...,C_log_N_, which replace the column _C_. We denote this set of columns by B(_C_), and we refer it as the _block of columns representing C_. Recall that the original column _C_ contains log_N_ input points of \(\hat{X}\). We place each such input point on a distinct column of B(_C_), so that the points form a monotonically increasing sequence (see the definition in Section 4.2). This completes the definition of the final instance _X_<sup>∗</sup>. We use the following bound on the optimal solution cost of instance _X_<sup>∗</sup>.

**Claim 4.6** \(\mathsf{OPT}(X^*)\ge\mathsf{OPT}(\hat{X})=\Omega(N^*loglogN^*)\).

**Proof:** Let C be the set of active columns for \(\hat{X}\). Notice that we can equivalently define \(\hat{X}\) as the instance that is obtained from _X_<sup>∗</sup> by collapsing, for every column \(C\in\mathcal{C}\), the columns of B(_C_) into the column _C_. Consider an optimal canonical solution _Y_ for _X_<sup>∗</sup> and the corresponding satisfied set \(Z=Y\cup X^*\). From Observation 2.4, for a column \(C\in\mathcal{C}\), point set _Z_<sub>|B(_C_)</sub> remains satisfied. We keep applying the collapse operations for all \(C\in\mathcal{C}\) to _Z_, and we denote the final resulting set of points by \(\hat{Z}\). Notice that \(\hat{Z}\) contains every point in \(\hat{X}\) and therefore the solution \(\hat{Z}\backslash\hat{X}\) is a feasible solution for \(\hat{X}\). Moreover, the cost of the solution is bounded by \(|Z|-|\hat{X}|=|Y|\). Therefore, \(\mathsf{OPT}(\hat{X})\le\mathsf{OPT}(X^*)\). \(\square\)
