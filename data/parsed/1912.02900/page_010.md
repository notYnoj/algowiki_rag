However, it is easy to see that there is another tree \(T'\), for which \(\mathsf{WB}_{T^\prime}(\tilde{X})=\Theta(nlogn)=\Theta(\mathsf{OPT}(\tilde{X}))\). It would be convenient for us to denote by _N_=2_<sup>n</sup>_ the number of columns with integral _x_-coordinates for instance \(\tilde{X}\).

Our next step is to define **circularly shifted** instances: for each \(0\le s\le N-1\), we obtain an instance _X<sup>s</sup>_ from \(\tilde{X}\) by circularly shifting it to the right by _s_ units. In other words, we move the last _s_ columns (with integral _x_-coordinates) of \(\tilde{X}\) to the beginning of the instance.

Our final instance is obtained by stacking the instances _X_<sup>0</sup>_,X_<sup>1</sup>_,...,X_<sup>_N_-1</sup> on top of each other in this order. Intuitively, for each individual instance _X<sup>s</sup>_, it is easy to find a partitioning tree _T<sup>s</sup>_, such that WB_<sub>T<sup>s</sup></sub>(X<sup>s</sup>_) is close to OPT(_X<sup>s</sup>_). However, the trees _T<sup>s</sup>_ for different values of _s_ look differently. In particular, we show that no single partitioning tree _T_ works well for all instances _X<sup>s</sup>_ simultaneously. This observation is key for showing the \(\Omega(loglogn/logloglogn)\) gap between the strong WB bound of the resulting instance and the value of the optimal solution for it.

In order to extend this result to the cGB bound, we perform the exponential spacing both vertically and horizontally. For every pair \(1\le s,s'\le N-1\) of integers, we then define a new instance \(X^{s,s^\prime}\), obtained by circularly shifting the exponentially spaced instance horizontally by _s_ units and vertically by \(s'\) units. The final instance is obtained by combining all resulting instances \(X^{s,s^\prime}\) for all \(1\le s,s'\le N-1\). We then turn this instance into a permutation using a straightforward transformation.

## Geometric decomposition of instances.

We employ geometric decompositions of instances in both our negative results and in our algorithms. Assume that we are given a set _X_ of input points, with |_X_|=_n_, such that each point in _X_ has integral _x_- and _y_-coordinates between 1 and _n_, and all points in _X_ have distinct _y_-coordinates. Let _B_ be a bounding box containing all points. Consider now a collection L={_L_<sub>1</sub>_,...,L_<sub>_k_-1</sub>} of vertical lines, that partition the bounding box into vertical strips _S_<sub>1</sub>_,...,S<sub>k</sub>_, for some integer _k\>_1. We assume that all lines in L have half-integral _x_-coordinates, so no point of _X_ lies on any such line. This partition of the bounding box naturally defines _k_ new instances _X_<sub>1</sub>_,...,X<sub>k</sub>_, that we refer to as _strip instances_, where instance _X<sub>i</sub>_ contains all input points of _X_ that lie in strip _S<sub>i</sub>_. Additionally, we define a _contracted instance_ \(\tilde{X}\), obtained as follows. For each \(1\le i\le k\), we collapse all columns lying in the strip _S<sub>i</sub>_ into a single column, where the points of _X<sub>i</sub>_ are now placed.

While it is easy to see that \(\sum_{i=1}^k\mathsf{OPT}(X_i)\le\mathsf{OPT}(X)\), by observing that a feasible solution to instance _X_ naturally defines feasible solutions to instances _X_<sub>1</sub>_,...,X<sub>k</sub>_, we prove a somewhat stronger result, that \(\mathsf{OPT}(\tilde{X})+\sum_{i=1}^k\mathsf{OPT}(X_i)\le\mathsf{OPT}(X)\). This result plays a key role in our algorithm, that follows a divide-and-conquer approach.

We then relate the Wilber Bounds of the resulting instances, by showing that:

\(\mathsf{WB}(X)\le O\left(\mathsf{WB}(\tilde{X})+\sum_{i=1}^k\mathsf{WB}(X_i)+|X|\right).\)

The latter result is perhaps somewhat surprising. One can think of the expression \(\mathsf{WB}(\tilde{X})+\sum_{i=1}^k\mathsf{WB}(X_i)\) as a Wilber bound obtained by first partitioning along the vertical lines in L, and then continuing the partition within each strip.
