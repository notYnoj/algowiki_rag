**Claim 4.4** _Let X be any point set that is a semi-permutation. Let_ \(0\le s<N\) _be a shift value, and let_ \(X'=X^s\) _be the instance obtained from X by a cyclic shift of its points by s units to the right. Then_ \(\mathsf{OPT}(X')\ge\mathsf{OPT}(X)-|X|\).

**Proof:** Let \(Y'\) be an optimal canonical solution to instance \(X'\). We partition \(Y'\) into two subsets: set \(Y'_1\) consists of all points lying on the first _s_ columns with integral coordinates, and set \(Y'_2\) consists of all points lying on the remaining columns. We also partition the points of \(X'\) into two subsets \(X'_1\) and \(X'_2\) similarly. Notice that \(X'_1\cup Y'_1\) must be a satisfied set of points, and similarly, \(X'_2\cup Y'_2\) is a satisfied set of points.

Next, we partition the set _X_ of points into two subsets: set _X_<sub>1</sub> contains all points lying on the last _s_ columns with integral coordinates, and set _X_<sub>2</sub> contains all points lying on the remaining columns. Since _X_<sub>1</sub> and _X_<sub>2</sub> are simply horizontal shifts of the sets \(X'_1\) and \(X'_2\) of points, we can define a set _Y_<sub>1</sub> of \(|Y'_1|\) points such that _Y_<sub>1</sub> is a canonical feasible solution for _X_<sub>1</sub>, and we can define a set _Y_<sub>2</sub> for _X_<sub>2</sub> similarly. Let _C_ be a column with a half-integral _x_-coordinate that separates _X_<sub>1</sub> from _X_<sub>2</sub> (that is, all points of _X_<sub>1</sub> lie to the right of _C_ while all points of _X_<sub>2</sub> lie to its left.) We construct a new set _Z_ of points, of cardinality |_X_|, such that \(Y_1\cup Y_2\cup Z\) is a feasible solution to instance _X_. In order to construct the point set _Z_, for each point \(p\in X\), we add a point \(p'\) with the same _y_-coordinate, that lies on column _C_, to _Z_. Notice that |_Z_|=|_X_|.

We claim that \(Z\cup(Y_1\cup Y_2)\) is a feasible solution for _X_, and this will complete the proof. Consider any two points \(p,q\in Z\cup(Y_1\cup Y_2)\cup X\) that are not collinear. Let _B_<sub>1</sub> and _B_<sub>2</sub> be the strips obtained from the bounding box _B_ by partitioning it with column _C_, so that \(X_1\subseteq B_1\) and \(X_2\subseteq B_2\). We consider two cases:

• The first case is when both _p_ and _q_ lie in the interior of the same strip, say _B_<sub>1</sub>. But then \(p,q\in X_1\cup Y_1\) must hold, and, since set \(X_1\cup Y_1\) of points is satisfied, the pair (_p,q_) of points is satisfied in \(X\cup Y_1\cup Y_2\cup Z\).<tbc>

• The second case is when one of the points (say _p_) lies in the interior of one of the strips (say _B_<sub>1</sub>), while the other point either lies on _C_, or in the interior of _B_<sub>2</sub>. Then \(p\in X_1\cup Y_1\) must hold. Moreover, since _Y_<sub>1</sub> is a canonical solution for _X_<sub>1</sub>, point _p_ lies on a row that is active for _X_<sub>1</sub>. Therefore, some point \(p'\in X_1\) lies on the same row (where possibly \(p'=p\)). But then a copy of \(p'\) that was added to the set _Z_ and lies on the column _C_ satisfies the pair (_p,q_).

\(\square\)

## 4.4 Construction of the Bad Instance

We construct two instances: instance \(\hat{X}\) on _N_<sup>∗</sup> points, that is a semi-permutation (but is somewhat easier to analyze), and instance _X_<sup>∗</sup> in _N_<sup>∗</sup> points, which is a permutation; the analysis of instance _X_<sup>∗</sup> heavily relies on the analysis of instance \(\hat{X}\). We will show that the optimal solution value of both instances is \(\Omega(N^*loglogN^*)\), but the cost of the Wilber Bound is at most _O(N_<sup>∗</sup>loglog_N_<sup>∗</sup>). Our construction uses the following three parameters. We let \(\ell\ge 1\) be an integer, and we set \(n=2^\ell\) and _N_=2_<sup>n</sup>_.
