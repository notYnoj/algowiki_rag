While i.i.d. scoring is generally fast, it is accurate only on reviews-like datasets where the ground- truth dataset also correspond to a finite range (1-5 stars). This assumption does not apply to the population of cities which lacks a well-defined range, demonstrating susceptibility of formalization- based approaches to the target language mismatch. Since each list to sort has a widely different range of populations, if all cities are small/large, the resulting score values predicted by the LLM lacks the necessary precision. Although it may be more natural to sort the cities by directly predicting the population, this case study is merely a representative of the data distribution where the range of values cannot be known in advance.

Finally, we mention the effect of _kv-cache reuse_. While each VA query requires _O(t_<sup>2</sup>) computations for _t_ input tokens, specialized inference engines \[Kwon et al., 2023, Zheng et al., 2024\] reuse the _prefix kv-cache_ over multiple queries. This affects the resource complexity of VA queries majority of which share the prefix. Due to space, we moved its theoretical and empirical analysis to the appendix.

## 5 Verbalized Clustering

Topic clustering attempts to cluster a set of strings _S_ into a family of subsets S based on their similarity. The challenge with text-based clustering is that no _a priori_ metric space for clustering exists. While traditional approach toward this task performs _k_-Means or other standard clustering algorithms on the distance matrix over the vector embeddings of the input strings, _Verbalized Clustering_ instead leverage _triplet comparison query_ or _cluster agreement query_ to LLM. Triplet comparison takes three elements _x_, _y_ and _z_ in a metric space \(\|\cdot\|\) and query if \(\|x-z\|<\|y-z\|\), i.e., we ask the LLM a question such as "Is Z similar to X than is to Y? X: _x_, Y: _y_, Z: _z_". Cluster agreement query takes two elements _x_ and _y_, then query if \(x\in C\Leftrightarrow y\in C\), i.e., we ask the LLM a question such as "Does X and Y belong to the same class, category, etc.? X: _x_, Y: _y_". Similar to sorting, while some methods utilize LLM-based triplet comparisons for clustering \[Zhang et al., 2023, Viswanathan et al., 2024\], these methods are driven by practical considerations rather than algorithmic complexity analysis.

We propose two verbalized algorithms. The first is **Verbalized Approximate Nearest Neighbor Tree Ensemble Clustering** (Vanntec, Alg. 1), which combines _O(n_log_n_) triplet-based approximate nearest neighbor tree construction algorithm \[Haghiri et al., 2017\] which was originally developed for _k_-Approximate Nearest Neighbor Search, and Evidence Accumulation Clustering \[Fred and Jain, 2005, 2002, EAC\] consensus clustering (ensemble clustering) algorithm. It constructs multiple trees, views them as an ensemble of hierarchical clustering, then aggregates the results to return the final clustering. The EAC step does not involve LLM calls, thus _O(n_log_n_) with a large constant factor for LLM calls dominates the runtime. The parallel runtime is _O_(log_n_). The second algorithm is **Verbalized KwickCluster** based on \[Ailon et al., 2008\]. In each iteration, it samples a pivot and performs a cluster agreement query to collect elements in the same cluster. It has the worst-case _O(n_<sup>2</sup>) queries and _O(n_) parallel runtime yet practically runs much faster, and its _O_(log_n_) parallel time improvement exists in the literature \[Pan et al., 2015\]. We compared VA clustering with **embedding baseline**, which uses all-MiniLM-L6-v2/granite-embedding-125m-english/Qwen3-8B-Embedding from Sentence Transformer library and apply K-Means \[MacQueen, 1967\].

We evaluated the methods across three datasets. **Medrxiv** \[Muennighoff et al., 2022\] contains the titles and the categories of medical papers on Medrxiv. **MD3** \[Eisenstein et al., 2023\] contains English transcripts of people from three regions with different dialects (US, India, Nigeria) playing a guessing game. **GoEmotions** \[Demszky et al., 2020\] contains sentences labeled with emotion tags. We sampled one tag per sentence to form clusters.

Fig. 4 shows the accuracy-runtime Pareto front using the Adjusted Mutual Information \[Vinh et al., 2009, 2010\]. (See appendix Fig. 8 for Adjusted Rand Index \[Hubert and Arabie, 1985\] results). Overall, VAs spent significantly longer runtime, but outperformed the baselines on accuracy. Vanntec performed better on tasks where the clustering criteria is ambiguous (due to emotion label sampling, or the nature of dialectal differences). KwickCluster performed better on Medrxiv where the cluster is clear and categorical and clustering agreement can be answered reliably. Thinking was not cost- effective, as it only marginally helped the accuracy with x10-x100 more runtime. On the contrary, symmetrization sometimes doubled the accuracy with a small runtime increase.
