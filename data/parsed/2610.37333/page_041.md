As discussed in Section 2.3, the cost of a reverse-mode gradient is one backward sweep independent of the parameter count, \(O(T(n)+n_\theta)\), whereas forward mode carries one tangent system per parameter and scales as \(O(n_\theta T(n))\), and Figure 10b and e exhibit this separation, with the reverse- mode cost of every library nearly independent of the number of weights and the forward-mode cost growing with it. Consistent with the forward benchmarks, we find that `diff-soup` is one to two orders of magnitude faster than the CPU codes at scale, since each step of the backward sweep requires one sparse direct solve with the transposed pencil matrix, which is performed by the same GPU-accelerated factorization as the forward solve. We measure accuracy in Figure 10a and d as the relative _L_<sup>2</sup> error against the reference gradient of Section 7.1, which we validated against central finite differences. On the Cahn-Hilliard problem, the gradient error of every library remains above 10<sup>-3</sup> at all tolerances, since the unstable spatial modes of Eq. (20) amplify the local error of the solve into the gradient. The GPU acceleration also extends the range of network sizes over which forward mode remains practical, owing to the tangent batching of Section 2.3, which assembles all tangents into a single batched multiple right-hand-side solve against the primal factorization, so that `diff-soup` differentiates networks of hundreds to thousands of weights in forward mode, whereas the CPU codes complete only the smallest network close to the wall cap. Finally, the checkpointed adjoint bounds the memory of the backward sweep, so reverse mode reaches the largest states of both ladders in Figure 10c and f, whereas forward mode stores one tangent of the full state per parameter and, with 128 parameters, exhausts the device memory beyond about 10<sup>5</sup> degrees of freedom on the Brusselator ladder. As we explore in Section 5.2, these performance advantages enable the training of embedded neural networks at scale within a general-purpose stiff PDE solver.
