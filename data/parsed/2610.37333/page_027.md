First, the observed data streams are registered as measurement objects and collected together with the corresponding lowered problem in an experiment object. Using one or more experiments, the user then defines an inference problem over the parameters of interest and solves it using `ds.inference.optsolve` with the desired first-order or second-order optimization algorithm. After solving, the result object provides the optimized parameters, the cost history, a termination status, and diagnostics of the solution quality.

We provide extensive support for posing the inference problem as a statistical estimation problem to determine the maximum likelihood estimate (MLE) under a frequentist approach or the maximum a posteriori (MAP) estimate under a Bayesian approach. To compute the MLE, a likelihood can be specified, as in Listing 3. To compute the MAP, in addition to the likelihood, priors can be declared on the parameters. After the inference problem is solved, a Laplace approximation to the posterior can be derived from the Hessian or Gauss-Newton Hessian approximation around the MAP. For more sophisticated posterior estimation, the posterior can be sampled using the Markov chain Monte Carlo No-U-Turn sampler (NUTS) in `blackjax` with preconditioning from the Laplace covariance.
