where \(y\in\mathbb{R}^n\) is the state, _t_ is time, \(\theta\) is the parameter vector, and _z(t_) is the control state that carries externally prescribed inputs. These systems are solved on the interval [_t_<sub>0</sub>_,t<sub>f</sub>_] and the initial state is prescribed as _y(t=t_<sub>0</sub>)=_y_<sub>0</sub>. For many systems, this generally reduces to mass-matrix form

\(M(y,t)\cdot y'=f(y,\theta,z(t),t),\) (2)

where _M(y,t_) is the (non-)singular mass matrix. We partition the state variable into the local differential states, \(y_d\in\mathbb{R}^{n_d}\), which carry explicit time derivatives in the governing form, local algebraic states, \(y_a\in\mathbb{R}^{n_a}\), which are specified through algebraic constraints with a sparse structure, and global algebraic variables, \(y_g\in\mathbb{R}^{n_g}\), _n<sub>g</sub>_, which are treated as dense and typically arise from global constraints on the state variables. Since \(n_g\checkmark n_a+n_d\), this split lets us handle the global variables separately (Sec. 2.2). In this section, we discuss the relevant background on the three main computational aspects of `diff-soup`: robust methods for numerical integration of stiff equations, exploiting sparse structure to accelerate computations, and computing sensitivities of differential algebraic equations for PDE-constrained optimization.

## 2.1. Variable Step, Variable Order Algorithms

In this work, we consider stiff systems with a defined sparse structure, as is typical for the discretization of partial differential equations using the method of lines. Partial differential equations are naturally stiff due to the decaying spectrum of the underlying differential operators that translates to a large, resolution-dependent ratio between the minimum and maximum eigenvalues [29]. Stable integration therefore requires specialized methods, since explicit methods are limited by a CFL time scale and naive implicit methods need a prohibitive number of steps to resolve fast dynamics.[54, 55]. We consider the variable step, variable order (VSVO) class of numerical integration algorithms [56, 57] which we separate into two families based on the discretization of the time derivative: backward differentiation formula (BDF) [58] in fixed-leading-coefficient (FLC) form [59] and the numerical differentiation formula (NDF) [60] in quasi-constant step size (QSS) form [35]. We implement three algorithms in `diff-soup`: the JAX implicit differential algebraic (`JIDA`) solver based on the popular `IDA` implementation in SUNDIALS [31], the JAX BDF solver (`JBDF`) based on the `CVODE\_BDF` implementation in SUNDIALS [31] and `FBDF` implementation in `DifferentialEquations.jl` [34], and the JAX NDF solver (`JNDF`) based on the `ode15s` algorithm [35] and implementation of `QNDF` in `DifferentialEquations.jl` [34].
