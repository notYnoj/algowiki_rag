The column operation (Algorithm 2) works as follows. Let local variable _M_ hold the current matching for this column, and let local variable _Q_ be the set of rotations corresponding to _M_. Iteratively we first test if _r(M)\<r(M<sub>opt</sub>_) setting _M<sub>opt</sub>_ to _M_ if so. We now check whether \(d_U(M)\ge d_W(M)\). If it is, then any further rotation for this column will only make _r(M_) larger, and so we stop iterating for this column, returning _M<sub>opt</sub>_. Next, we find the set of rotations \(Q'\) in the closure of \(R_b(M)\subseteq R\) that are not already eliminated to reach _M_. If eliminating these rotations would either increase the men’s degree or not decrease the women’s degree, then we return _M<sub>opt</sub>_. Otherwise, set _M_ to be the matching found when eliminating these rotations.

If after the column operation, _d<sub>U</sub>(M<sub>opt</sub>_)=_d<sub>W</sub>(M<sub>opt</sub>_), then we have a regret-equal matching and it is immediately returned on Lines 10 or 24 of Algorithm 1.

The column operation described above is called first from the man-optimal stable matching _M_<sub>0</sub> on Line 8, to iterate down the first column. Then for each man _m<sub>i</sub>_ we do the following. Let _M_ be set to _M_<sub>0</sub>. Iteratively we eliminate (_m<sub>i</sub>,M(m<sub>i</sub>_)) from _M_ by eliminating rotation \(\rho\) and its predecessors (not already eliminated to reach _M_) such that \((m_i,M(m_i))\in\rho\). We continue doing this until both the men’s degree increases and rank(_m<sub>i</sub>,M(m<sub>i</sub>_))=_d<sub>U</sub>(M_) (in the same operation). This has the effect of jumping our focus from some column of possible degree pairs, to another column further to the right with _m<sub>i</sub>_ being one of the lowest ranked men in _M_. Once we have moved to a new column we perform the column operation described above. If either _m<sub>i</sub>_ has the same partner in _M_ as in _M<sub>z</sub>_ (hence there are no rotations left that move _m<sub>i</sub>_) or _d<sub>U</sub>(M)\>d<sub>W</sub>(M_) (further rotations will only increase the regret-equality score), then we stop iterating for _m<sub>i</sub>_. In this case we restart this process for the next man, or return _M<sub>opt</sub>_ if we have completed this process for all men. Note that since at the end of a while loop iteration, if _r(M_)=0 then _M<sub>opt</sub>_ is returned, it is not possible for the condition _d<sub>U</sub>(M_)=_d<sub>W</sub>(M_) to ever be satisfied in the while loop clause.
