\(\blacktriangleright\) **Lemma 4.** _M<sub>T</sub>=reduced_(M).

**Proof.** Let stable matching \(M'\) of size _n_ exist in M_<sub>T</sub>_. If we transform _I<sub>T</sub>_ to _I_ then we are adding preference list pairs (_m<sub>i</sub>,w<sub>j</sub>_) where rank(_m<sub>i</sub>,w<sub>j</sub>)\>_rank(_m<sub>i</sub>,M<sup>i</sup>(m<sub>i</sub>_)). But then, (_m<sub>i</sub>,w<sub>j</sub>_) cannot constitute a blocking pair and so \(M'\) must be stable in _I_ with \(M'\in\mathcal{M}\). Also, since \(M'\) is in _I<sub>T</sub>_ it must be the case that \(\mathrm{rank}(m_i,w_j)\le a\). Hence \(\mathcal{M}_T\subseteq\mathrm{reduced}(\mathcal{M})\).

Let stable matching \(M''\) exist in reduced(M). By the definition of reduced(M) and _I<sub>T</sub>_ all pairs in \(M''\) must exist in preference lists of the truncated instance _I<sub>T</sub>_. If we transform _I_ to _I<sub>T</sub>_ we will only be removing some pairs from preference lists that do not exist in \(M''\). Therefore since we are only removing pairs, it is not possible to introduce pairs into _I<sub>T</sub>_ that would block \(M''\) and so \(M''\) is stable in _I<sub>T</sub>_. Hence \(\mathcal{M}_T\supseteq\mathrm{reduced}(\mathcal{M})\).

Therefore M_<sub>T</sub>_=reduced(M), as required.

\(\blacktriangleright\) **Theorem 5.** _Let I be an instance of_ SMi. _Algorithm MRS produces a min-regret sum stable matching in O(d<sub>sm</sub>_) _time, where d<sub>s</sub>=d<sub>U</sub>(M<sub>z</sub>_)-_d<sub>U</sub>(M_<sub>0</sub>)_, m is the total length of all preference lists, and M_<sub>0</sub> _and M<sub>z</sub> are the man-optimal and woman-optimal stable matchings respectively._

**Proof.** Let _M_ be a min-regret sum stable matching in _I_ with _d<sub>U</sub>(M_) minimum among all min-regret sum stable matchings. We show that it is not possible to miss a stable matching \(M'\) with \(d(M')=d(M)\), during the execution of Algorithm MRS. On Line 5 of Algorithm 3, we iterate over all possible men’s degrees that may correspond to a min-regret sum stable matching, and will enter the while loop for degree value _a=d<sub>U</sub>(M_). Since _a=d<sub>U</sub>(M_), we know that \(M\in\mathrm{reduced}(\mathcal{M})\) and so by Lemma 4, \(M\in\mathcal{M}_T\). We also know by Lemma 4, that \(M_z^T\in\mathcal{M}\). Let \(R'\) and \(R_z^T\) be the set of rotations associated with _M_ and \(M_z^T\) in _I_. On Line 7 of the algorithm we find the woman-optimal stable matching \(M_z^T\) in M_<sub>T</sub>_ and so we must have \(\mathrm{rank}(w_j,M_z^T(w_j))\le\mathrm{rank}(w_j,M(w_j))\), for all women _w<sub>j</sub>_, since \(M\in\mathcal{M}_T\). From this inequality, we know \(R'\subseteq R_z^T\), and since _d<sub>U</sub>(M_)=_a_ it must be that \(d_U(M_z^T)=a\). Additionally, this inequality implies \(d_W(M_z^T)\le d_W(M)\). As _M_ is a min-regret sum stable matching, there cannot be a stable matching with man degree _a_ and woman degree _\<d<sub>W</sub>(M_), but as \(d_W(M_z^T)\le d_W(M)\), we must have \(d_W(M_z^T)=d_W(M)\). Hence, \(d(M_z^T)=d(M)\). Note that due to the choice of _M_, with _d<sub>U</sub>(M_) minimum among all min-regret sum stable matchings, it is not possible for _M<sub>opt</sub>_ to be updated to a min-regret stable matching prior to this point in the algorithm. Therefore, _M<sub>opt</sub>_ is updated to \(M_z^T\) on Line 9. Additionally, as _M<sub>opt</sub>_ is now a min-regret stable matching it will not be possible for it to be updated to another stable matching after this point, and so _M<sub>opt</sub>_ is returned on Line 13, as required.

Truncation of our instance requires only a single pass through preference lists of men and women and is therefore an _O(m_) operation. The man-optimal and woman-optimal stable matchings can found in _O(m_) time both within and outwith the while loop. Since the number of potential men’s degrees that we iterate over is bounded by _d<sub>s</sub>=d<sub>U</sub>(M<sub>z</sub>_)-_d<sub>U</sub>(M_<sub>0</sub>), we have an overall time complexity of _O(d<sub>sm</sub>_) for Algorithm MRS.
