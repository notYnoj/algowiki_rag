These modifications also allow for a query and communication complexity to be parameterized by the min-cut/max-flow value of the residual graph _G<sub>F</sub>_ as well.

For now, we summarize the results of applying the modified RSW algorithm in both computational models with the full implementation details deferred to Section 4.

**Lemma 3.2** (Modified RSW via cut query)**.** _Let_ G=(_G,F_) _be an input mixed graph where G is undirected and unweighted, and F be a directed bounded-weighted that is known explicitly. Then, there exists an algorithm that makes_ \(\widetilde{O}(n^{4/3}\nu(\mathcal{G})^{1/3})\) _cut-queries to G and w.h.p. computes a mini mum s-t cut of_ G.

**Lemma 3.3** (Modified RSW via communication)**.** _Let_ G=(_G,F_) _be an input mixed graph where G is undirected and unweighted and is partitioned among two players, and F be a directed bounded- weighted that is known explicitly. Then, there exists an_ \(\widetilde{O}(n\cdot\nu(\mathcal{G})^{2/3})\)_-bit deterministic protocol that Alice and Bob jointly outputs a minimum s-t cut of_ G.

We now restrict our attention to Step 1 as it is key algorithmic design of this work. We first state the results on both computation models.

**Lemma 3.4** (Finding a large flow via cut query)**.** _Let G be an input graph, and let_ \(\Delta\le n\) _be an additive error parameter. Then, there is a randomized algorithm that computes_ \(H\unknown G\) _with_ \(\nu(H)\ge\nu(G)-\Delta\)_. The algorithm makes_ \(\widetilde{O}\left(\frac{n^2}{\sqrt{\Delta}}+\frac{n^3}{\Delta^2}\right)\) _cut queries to G and succeeds w.h.p._

**Lemma 3.5** (Finding a large flow via communication)**.** _Let G be an input graph, and let_ \(\Delta\le n\) _be an additive error parameter. Then, there is a deterministic protocol that computes_ \(H\unknown G\) _with_ \(\nu(H)\ge\nu(G)-\Delta\)_. The protocol uses_ \(\widetilde{O}\left(\frac{n\cdot\nu(G)}{\sqrt{\Delta}}+\frac{n\cdot\nu(G)^2}{\Delta^2}\right)\) _bits of communication and always succeeds._

Our algorithms for both lemmas share the same principle. To best understand it, we study a simplified question in a model-independent setting: suppose we are given three parameters \(k'<k\le f\) with a promise that \(\nu(G)\ge f\), and also given for free is a graph \(H\unknown G\) such that \(\nu(H)\ge f-k\). Our goal is to sequentially add (a small number of) edges from _G_\\_H_ to _H_ so that it eventually becomes _H_after with \(\nu(H^\mathrm{after})\ge f-k'\). In later sections, we show that an efficient algorithm for this toy question leads to both Lemma 3.4 and Lemma 3.5.

At a high level, our algorithm proceeds in a greedy-like manner. For any graph G, we define a set of _witnesses_, denoted W(G), with an invariant that \(\nu(\mathcal{G})\ge f-k'\) if and only if \(\mathcal{W}(\mathcal{G})=\emptyset\). Our procedure starts with \(H_1\leftarrow H\). In each round _i_=1,2_,..._, we determine an edge \(e_i\in G\backslash H_i\) that reduces the number of witnesses by a non-trivial fraction; that is, _e<sub>i</sub>_ is such that \(|\mathcal{W}(H_i\cup\{e_i\})|\le(1-\gamma)\cdot|\mathcal{W}(H_i)|\) for some fixed value \(\gamma\) that may depend on _n,k_, or \(k'\). We call such edges with that property \(\gamma\)_-good_. We then set \(H_{i+1}\leftarrow H_i\cup\{e_i\}\), and repeat. The procedure terminates at the earliest round _T_ where \(\mathcal{W}(H_T)=\emptyset\), ensuring that the final graph _H_after:=_H<sub>T</sub>_ has \(\nu(H_T)\ge f-k'\) via our invariant.

Following this greedy-like approach, there are two main questions that need to be addressed. First, what is the correct definition of a _witness_? Recall that we want to maintain the invariant that \(\nu(\mathcal{G})\ge f-k'\) if and only if \(\mathcal{W}(\mathcal{G})=\emptyset\). A strong candidate for a witness is a cut of size at most \(f-k'-1\) in G, thanks to the Max-Flow Min-Cut Theorem. This, however, is only partially correct. We define a witness as a _redundant_ representation of a small cut on G, consisting of a cut (_S,T_) of small size \(|E_\mathcal{G}(S,T)|\le f-k'-1\), the set _E_<sub>G</sub>(_S,T_) of edges crossing such cut, and a set _X_ of _non-existing edges_ that cross this cut, with \(|X|=f-k'-1-|E_\mathcal{G}(S,T)|\ge 0\).
