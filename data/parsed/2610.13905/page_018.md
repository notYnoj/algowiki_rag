For \(j\in I_i^C\) let _c<sub>j</sub>=A_<sub>0</sub>(_j,J<sub>i</sub>_) and define \(v_j\in\mathbb{C}[\varepsilon]^m\) to be the vector satisfying the following:

\(v_j\big|_{I_i}=-\text{adj}(N_i)^Tc_j^T,v_j(j)=\Delta_i(\varepsilon),\text{and}v_j\big|_{\{I_i\cup j\}^C}=0.\) (3.14)

This vector has polynomial entries because adj(_N<sub>i</sub>_), _c<sub>j</sub>_, and \(\Delta_i(\varepsilon)\) all have entries in \(\mathbb{C}[\varepsilon]\).

Then, by construction, we have

\(v_j^TA_0(\cdot;J_i)=(v_j\big|_{I_i^C})^TA_0(I_i^C,J_i)+(v_j\big|_{I_i})^TN_i=\Delta_i(\varepsilon)c_j-c_j\text{adj}(N_i)N_i=\Delta_i(\varepsilon)c_j-\Delta_i(\varepsilon)c_j=0.\) (3.15)

Moreover, \(v_1,\dots,v_{m-\rho}\) are clearly linearly independent, as each contains the nonzero entry \(\Delta_i(\varepsilon)\) where the others are zero. Since there are \(m-\rho\) such vectors, and \(\text{rank}_{\mathbb{C}(\varepsilon)}(A_0)=\rho\), \(v_1,\dots,v_{m-\rho}\) must form a \(\mathbb{C}(\varepsilon)\)-basis of the left null space of _A_<sub>0</sub>.

Finally, to complete the proof we update (3.11) - i.e., since \(y'\) (as defined in (3.10)) might need to be replaced by \(y'+v_j\), where each entry of _v<sub>j</sub>_ is a polynomial of degree at most \(\rho(\beta-\alpha)\). Shifting (3.11) accordingly gives the listed exponent range.

Theorem 3.2 not only guarantees that **Next-Vector** can find Laurent-polynomial-based solutions but also bounds the corresponding range of exponents in the its entries. This can be used to further accelerate the Algorithm 3 - e.g., by providing Z3 with a narrower range of exponents to search over. Of course, for this to be usable we need to bound _H_ and _k_. This can be done by applying the following identity to the \(\Delta_i(\varepsilon)\).

**Proposition 3.3** (Hilbert nullstellensatz)**.** _Let_ \(f_1,\dots,f_m\in\mathbb{C}[\varepsilon]\)_, and let D_=max_<sub>i</sub>_deg_f<sub>i</sub>. If_

\(gcd(f_1,\dots,f_m)=1\) (3.16)

_then there exist polynomials_ \(a_1(\varepsilon),\dots,a_m(\varepsilon)\in\mathbb{C}[\varepsilon]\) _such that_ \(\sum_{i=1}^ma_i(\varepsilon)f_i(\varepsilon)=1\) _where_ \(dega_i\le max\{3,D\}\) _for every i._

_Proof._ This is a classical result in algebraic geometry. For the degree bound, see \[43\].

In particular, suppose that \(g(\varepsilon)=gcd(\Delta_1(\varepsilon),\dots,\Delta_m(\varepsilon))\). Since Theorem 3.2 assumes that the ideal generated by the \(\Delta_i(\varepsilon)\) contains a monomial, \(g(\varepsilon)\) divides a monomial and is therefore one itself (up to a nonzero scalar). With this in mind, write \(g(\varepsilon)=c\varepsilon^r\) for some \(c\neq 0\) and \(r\ge 0\). Since \(g(\varepsilon)\) divides the \(\Delta_i(\varepsilon)\), and recalling that each \(\Delta_i(\varepsilon)\) has degree at most \(\rho(\beta-\alpha)\), we have

\(0\le r\le\rho(\beta-\alpha).\) (3.17)

For each _i_, write \(\Delta_i(\varepsilon)=c\varepsilon^rf_i(\varepsilon)\). By construction, gcd(_f_<sub>1</sub>_,...,f<sub>m</sub>_)=1 and

\(degf_i=deg\Delta_i-r\le\rho(\beta-\alpha)-r,\) (3.18)

so Theorem 3.3 implies that there exist polynomials \(a_i(\varepsilon)\in\mathbb{C}[\varepsilon]\) such that \(\sum_ia_i(\varepsilon)f_i(\varepsilon)=1\) and \(dega_i\le\rho(\beta-\alpha)-r\). Multiplying by \(c\varepsilon^r\), we obtain

\(\sum_ia_i(\varepsilon)\Delta_i(\varepsilon)=c\varepsilon^r.\) (3.19)

Thus, in Theorem 3.2, we can take _k=r_ and \(H\le max\{3,\rho(\beta-\alpha)-r\}\). Notice that, because we simply need to keep the constants the same to have a vector with same or better weight, we can set _B_<sub>-</sub>=_B_<sub>+</sub>=0.

## 3.2.2 Optimality

With the above results, Algorithm 3 is guaranteed to achieve optimal sparsity, as measured by (3.4) and (3.5), under the assumption that **Next-Vector** returns an admissible vector whenever one exists (guaranteed as long as the first condition of Theorem 3.2 holds for the corresponding encoding matrix). This can be shown by simply replicating the optimality proof from \[32\], interpreting the notations of span, rank, and independence as defined over \(\mathbb{C}(\varepsilon)\). Note that this still holds under alternative definitions of \(weight(\cdot)\), meaning Algorithm 3 is adaptable to other notions of sparsity.
