As mentioned above, the parameter _p_ is tunable and in particular determines how much to penalize variable entries in \(v^TU(\varepsilon)\). ## 3.2.1 Implementation Details

There are a handful of technical questions concerning Algorithm 3 that we address below:

1. How does **Generate-Constraints** work? In Theorem 3.1, we demonstrate that it is sufficient to define constraints in terms of a basis for the kernel of \(\phi_\varepsilon^{-1}\).<tbc>

2. Is Algorithm 3 well-posed - i.e., can **Next-Vector** always find a solution with Laurent-polynomial entries? Moreover, can this be done without sacrificing sparsity? Theorem 3.2 verifies that the answer to both is yes (under certain conditions).

We start with the subroutine **Generate-Constraints**, which can be implemented by computing a basis for the kernel of \(\phi_\varepsilon^{-1}\) (in the vector space \(\mathbb{C}(\varepsilon)^n\)) and subsequently defining the set of constraints as those that guarantee that the next vector _v_ has a nontrivial inner product with at least one of these basis vectors. This follows from a basic linear algebra result (see e.g., \[32, Theorem 3.2\]), which we state here for \(\mathbb{C}(\varepsilon)\).

**Proposition 3.1.** _Let_ \(v_1,\dots,v_m\in\mathbb{C}(\varepsilon)^n\) _and let_ \(A\in\mathbb{C}(\varepsilon)^{m\times n}\) _be the matrix whose i-th row is_ \(v_i^T\)_. Suppose that q_<sub>1</sub>_,...,q<sub>r</sub> form a basis for the kernel of A and let_ \(v\in\mathbb{C}(\varepsilon)^n\)_. In this case,_ \(v\notin\mathrm{span}\left\{v_1,\dots,v_m\right\}\) _if and only if_ \(q_i^Tv\neq 0\) _for at least one i. Hence, kernel basis vectors of A can be used to certify the independence of v from the rows of A._

With this, **Next-Vector** can be implemented (symbolically) via the Z3 satisfiability solver in Python, which takes the constraints implied by Theorem 3.1 and searches for admissible vectors in \(\mathbb{C}[\varepsilon,\varepsilon^{-1}]\) such that \(\mathrm{weight}(v^TU(\varepsilon))\) is minimal. In practice, this corresponds to solving \(v^TU(\varepsilon)=u\) for _u_ a vector with Laurent polynomial entries and a pre-set weight value. The following technical result guarantees that such a system - subject to the linear-independence constraints obtained from **Generate-Constraints** - can be solved over \(\mathbb{C}[\varepsilon,\varepsilon^{-1}]^{m_0k_0}\) if it is solvable over \(\mathbb{C}(\varepsilon)^{m_0k_0}\), thereby guaranteeing that Algorithm 3 is well-posed. For details on how the Z3 solver chooses candidates _u_ and/or decides to terminate the search for a given value of \(\mathrm{weight}(\cdot)\), we refer readers to \[19\].

**Theorem 3.2.** _Let_ \(A\in\mathbb{C}[\varepsilon,\varepsilon^{-1}]^{m\times n}\) _have_ \(\mathrm{rank}_{\mathbb{C}(\varepsilon)}(A)=\rho\le n\)_, and assume every nonzero entry of A has exponent support contained in_ \([\alpha,\beta]\) _for_ \(\alpha\le 0\)_. Let_ \(d=\beta-\alpha\) _and let_ \(b\in\mathbb{C}[\varepsilon,\varepsilon^{-1}]^n\) _have entries with exponents in_ \[_B_<sub>-</sub>_,B_<sub>+</sub>\]_, again with_ \(B_-\le 0\)_. Define_ \(A_0=\varepsilon^{-\alpha} A\)_, whose entries are polynomials in_ \(\varepsilon\) _of degree at most d. Finally, let N<sub>i</sub> be the full-rank_ \(\rho\times\rho\) _minors of A_<sub>0</sub> _with_ \(\Delta_i(\varepsilon)=\mathrm{det}(N_i)\) _and let_ \(S\subseteq\mathbb{C}[\varepsilon,\varepsilon^{-1}]^m\) _be a collection of vectors. Suppose that the following hold:_

1. _There exist polynomials_ \(h_i(\varepsilon)\in\mathbb{C}[\varepsilon]\) _with_ \(\mathrm{deg}h_i\le H\) _for all i such that_ \(\sum_ih_i(\varepsilon)\Delta_i(\varepsilon)=c\varepsilon^k\) _for an integer_ \(k\ge 0\) _and a nonzero constant_ \(c\in\mathbb{C}\).<tbc>
