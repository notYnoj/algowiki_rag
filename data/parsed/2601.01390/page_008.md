However, it is not clear how canonical subsets can be obtained from this algorithm, since it does not work via divide-and-conquer or dyadic intervals. Our new idea is to invoke the algorithm for Lemma 3.3 multiple times on different inputs associated with different dyadic intervals. Bounding the total cost of these multiple invocations may at first appear problematic, but luckily the following simple observation comes to the rescue:

**Observation 3.5.** _Let X be a sorted list of numbers. Suppose X is partitioned into contiguous sublists X_<sub>1</sub>_,...,X<sub>m</sub>. Then_ \(|\Sigma_{\le k}(X_1)\cap[t]|+\cdots+|\Sigma_{\le k}(X_m)\cap[t]|\le O(k)|\Sigma(X)\cap[t]|\).

_Proof._ For a fixed _i_, \(\Sigma_i(X_1),\dots,\Sigma_i(X_m)\) are disjoint, since every element in \(\Sigma_i(X_j)\) is smaller than every element in \(\Sigma_i(X_{j+1})\) for every _j_. Thus, \(|\Sigma_i(X_1)\cap[t]|+\cdots+|\Sigma_i(X_m)\cap[t]|\le|\Sigma_i(X)\cap[t]|\). The observation then follows by summing over all \(i\in[k]\).

**Lemma 3.6** (Canonical subset generation)**.** _Given a constant_ \(\delta\in(0,1]\)_, a set X of n integers in_ \([u/(1+\delta),u]\)_, and numbers t and b, we can generate a collection_ C _of_ \(\widetilde{O}(b|\Sigma(X)\cap[t]|)\) _"canonical" subsets of X each of size at most_ \((1+\delta)b\)_, in_ \(\widetilde{O}(b^{O(1)}|\Sigma(X)\cap[t]|\sqrt{n})\) _deterministic time, satisfying the following property:_

_For every subset_ \(S\subseteq X\) _with_ \(\sigma(S)\le t\)_, there exists a subset_ \(\hat{S}\subseteq X\) _such that_ \(\sigma(\hat{S})=\sigma(S)\) _and_ \(\hat{S}\) _is expressible as a union of O_((|_S|/b_+1)log_n_) _disjoint canonical subsets in_ C.

_Proof._ W.l.o.g., assume that _n_ is a power of 2. Sort the elements _x_<sub>1</sub>_,...,x<sub>n</sub>_ of _X_. For each dyadic interval \(I=(a,a+\ell]\subseteq(0,n]\), run the algorithm in Lemma 3.3 with \(A=\emptyset\), _k=b_, and _t_ replaced by min{_t,bu_}, on the input set \(X_I:=\{x_j:j\in I\}\), to get output set \(\mathrm{OUT}_I\). For each dyadic interval _I_ and each \(y\in\mathrm{OUT}_I\subseteq\Sigma(X_I)\cap[\mathrm{min}\{t,bu\}]\), find one subset \(S_I[y]\subseteq X_I\) with \(\sigma(S_I[y])=y\), and add the subset to the collection C. Note that \(|S_I[y]|\le bu/(u/(1+\delta))=(1+\delta)b\). By Observation 3.5, the sum of \(|\Sigma(X_I)\cap[\mathrm{min}\{t,bu\}]|=|\Sigma_{\le(1+\delta)b}(X_I)\cap[\mathrm{min}\{t,bu\}]|\) over all dyadic intervals _I_ of a fixed length is at most \(O(b|\Sigma(X)\cap[\mathrm{min}\{t,bu\}]|)\); thus, the sum over all dyadic intervals _I_ of all lengths is \(O(b|\Sigma(X)\cap[\mathrm{min}\{t,bu\}]|\mathrm{log}n)\). So, the total number of subsets in C is bounded by \(O(b|\Sigma(X)\cap[t]|\mathrm{log}n)\), and the computation time is \(\widetilde{O}(b^{O(1)}|\Sigma(X)\cap[t]|\sqrt{n})\).

To prove that C satisfies the stated property, consider an arbitrary subset \(S\subseteq X\). First partition (0_,n_\] into a collection I(_S_) of disjoint dyadic intervals, each containing at most _b_ indices of \(\{j:x_j\in S\}\): namely, we start by visiting the root dyadic interval, and when we visit a dyadic interval containing more than _b_ indices of \(\{j:x_j\in S\}\), we recursively visit its two child intervals. The number of dyadic intervals visited per level is _O_(|_S|/b_+1). Thus, the number of dyadic intervals generated is \(|\mathcal{I}(S)|\le O((|S|/b+1)\mathrm{log}n)\). For each interval \(I\in\mathcal{I}(S)\), let \(y_I=\sigma(S\cap X_I)\in\Sigma_{\le b}(X_I)\cap[\mathrm{min}\{t,bu\}]\subseteq\mathrm{OUT}_I\). Define \(\hat{S}\) to be the union of _S<sub>I</sub>_\[_y<sub>I</sub>_\] over all \(I\in\mathcal{I}(S)\); these sets \(S_I[y_I]\subseteq X_I\) are obviously disjoint because the intervals in I(_S_) are disjoint; and \(\sigma(S_I[y_I])=\sigma(S\cap X_I)\). Therefore, \(\sigma(\hat{S})=\sigma(S)\).
