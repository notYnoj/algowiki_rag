They left the complexity of detecting such a set as an open problem. Direct enumeration of vertex subsets can test this condition, but the number of candidates grows exponentially in the worst case.

We give a polynomial-time algorithm for detecting and constructing small blocking sets. We first compute a maximum-cardinality critical independent set using an existing algorithm [11] and perform an initial classification according to its difference and cardinality. For the remaining boundary case, where the critical difference is zero and the selected set contains exactly half the vertices, we establish an equivalence between the existence of a small blocking set in the graph and the existence of a nonempty proper tight subset within the selected independent set. This reduces the search over the entire graph to a structural test within a fixed independent set. We then use a perfect matching to construct a digraph, translate tightness into the absence of arcs leaving a vertex subset, and compute the condensation digraph using a strongly connected component algorithm [12]. A vertex of outdegree zero in the condensation digraph corresponds to a sink strongly connected component (sink SCC), whose corresponding vertices on the independent-set side form a tight subset. If this set contains strictly fewer than half the vertices of the original graph, it is the required small blocking set. If the auxiliary digraph is strongly connected, its only component corresponds to the entire independent set and does not satisfy the strict cardinality condition. Together, these steps give a polynomial-time detection and construction algorithm.
