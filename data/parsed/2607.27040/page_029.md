## D In-Place Conversion

We now present the process for converting the algorithm that uses additional buffers in Section 2 to the full in-place algorithm in Section 3.

As stated in Section 3, the buffer memory is made up of buffer elements, which are all greater or equal to a pivot _p_, whilst all active elements are less than _p_, allowing active and buffer elements to be differentiated via 1 comparison against _p_.

The bit vector _V_ is also formed by two blocks _L_ and _R_, where the pair of elements (_l<sub>i</sub>,r<sub>i</sub>_) are used to represent the _i_th bit. Initially, every element in _L_ needs to be strictly less than every element in _R_ (so no pair can be equal).

We now show how these regions are created, beginning with the bit vector. Using heapselect, select the smallest and largest _v=n/_lg<sup>2</sup>_n_ elements and place them in contiguous blocks at the front and back of A, changing the configuration of A to \(LA'R\). We use a single comparison to verify if the last element in _L_ is strictly less than the first element of _R_. If so, the block \(A'\) contains only equal values, then the entire input array is already sorted, and the algorithm terminates. Conversely, if the blocks _L_ and _R_ pass the test above, they can be used to simulate a bit vector of _n/_lg<sup>2</sup>_n_ bits. As \(m\le n\), the bit vector is sufficiently large for all instances of sorting. This step requires _O(n+v_lg_n_)=_O(n_) comparisons and moves.

Now, we repeatedly create active and buffer regions in a partition-based loop. At any iteration, the configuration of \(A'\) is _AS<sub>U</sub>_, where _AS<sub>S</sub>_ contains elements in their correct sorted position and _A<sub>U</sub>_ unsorted elements. Particularly, if _A<sub>U</sub>_ were sorted using some algorithm, the entire block \(A'\) would be sorted, and _A_ would also be sorted as a whole. Initially, _AS<sub>S</sub>_ is empty and _A<sub>U</sub>_ contains the entire block \(A'\). Every iteration shrinks the size of _A<sub>U</sub>_ by a factor of at least 1/4, until eventually \(|A_U|\le 2^{19}=524288\), then the entire _A<sub>U</sub>_ is sorted as a base case. The process for the _i_th iteration, where _n<sub>i</sub>_=|_A<sub>U</sub>|_, is as follows:

**1.** By the in-place selection algorithm of [5], find the element _p_ in _A<sub>U</sub>_ with rank \(\lceil n_i/4\rceil\).

**2.** Partition _A<sub>U</sub>_ by pivot _p_, such that the configuration of _A<sub>U</sub>_ becomes \(A_< pB_\ge\), where _A<sub><o>A</o><sub></o><sub></sub> contains elements _\<p_, and \(B_\ge\) contains elements \(\ge p\). We denote |_A<sub><o>A</o><sub></sub>|=n<sub>i</o>,<o></o>_ and \(|B_\ge|=n_{i,\ge}\). As _p_ has rank \(\lceil n_i/4\rceil\), \(n_{i,<}\le\lceil n_i/4\rceil-1\le n_i/4\), then \(n_{i,\ge}\ge n_i-\lceil n_i/4\rceil\ge(3/4)n_i-1\).

**3.** Sort the block _A<sub><o>A</o><sub></o><sub></sub>_ by the algorithm from Section 2, using the blocks _L_ and _R_ to simulate the bit vector _V_ , and \(B_\ge\) as the buffer memory. We can differentiate active elements originating from _A<sub><o>A</o><sub></sub>_ with buffer elements originating from \(B_\ge\) by a single comparison against _p_. As \(n_{i,\ge}\ge 3n_i/4-1=3n_{i,<}-1\), \(B_\ge\) is indeed adequately large to function as the buffer memory to sort _A<sub><o>A</o><sub></sub><sub></sub>_. This leaves _A<sub>U</sub>_ in the form _A<sub><o>A</o><sub></sub>,<o>S</o>_\(B'_\ge\), where _A<sub><o>A</o><sub></o>,<o>S</o>_ is the sorted sequence _A<sub><o>A</o><sub></sub>_ and \(B'_\ge\) is some permutation of \(B_\ge\).

**4.** Partitioning \(B'_\ge\) by pivot _p_, we isolate all elements =_p_ in \(B'_\ge\). The resulting structure of _A<sub>U</sub>_ is _A<sub><o>A</o><sub></sub>,<o>S</o>_\(pPB_\ge\), where _P_ contains _n<sub>i,</sub>_= elements which are =_p_ and _B<sub><o>A</o><sub></sub><sub></sub>_ contains _n<sub>i,</sub>_ elements that are _\>p_.

**5.** Notice that the elements _A<sub><o>A</o><sub></sub>,<o>S</o><sub></sub>_\(pP\) are already in their correct sorted order, thus we update _AS<sub>S</sub>_ to include _A<sub><o>A</o><sub></sub>,<o>S</o>_\(pP\), and shrink _A<sub>U</sub>_ to only include _B<sub>><o>A</o><sub></sub><sub></sub>_, then start a new iteration with _n<sub>i</sub>_+1=|_B<sub><o>A</o><sub></sub></sub>|_. If \(n_{i+1}\le 2^{19}\), we sort the entire _A<sub>U</sub>_ by the method in Section 2.7 without using a buffer, then terminate. As _p_ has rank \(\lceil n_i/4\rceil\), \(|B_\ge|\le n_i-\lceil n_i/4\rceil\le(3/4)n_i\).
