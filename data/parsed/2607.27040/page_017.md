**5.** Check if the gap invariant was violated, by verifying if _k_=7, as the insertion would add an additional active representative, creating a gap with 8 active representatives, violating the invariant. If so, execute the dynamic rebalancing procedure on _Li<sub>i</sub>_, which redistributes active representatives among other gaps to ensure the gap invariant is restored.

**6.** Verify if \(s_\#=2s'_\#\). If this is the case, the structure has reached its maximum capacity, and requires a resize operation that expands the library so it can hold more active representatives. The resulting library structure _L_ is made up of twice the gaps \(L_1\dots L_{s_\#}^{^\prime}\) where each gap _Li<sub>i</sub>_ contains a single active representative \(R'_i\) and 7 buffer representatives. The process is as follows:

**i.** Linearly scan through \(L_1\dots L_{s_\#}^{^\prime}\) for the active representatives \(R'_1\dots R'_{s_\#}\), exchanging them to a contiguous block at the front of _D_. The scanning process begins at the \(\ell_2\) of each gap as \(\ell_1\) is guaranteed to be active by the gap invariant and linearly scans rightwards until it meets a buffer representative, exchanging the found active representatives in the process.

**ii.** Transport all active representatives back into _L_, where \(R'_i\) is exchanged with the buffer representative at position 8(_i_-1) in _L_, placing \(R'_i\) at the front of _Li<sub>i</sub>_.

**iii.** Lastly, update \(s'_\#:=s_\#=2s'_\#\) to account for the resize.

After insertion, the global order of active representatives is preserved. The initial search step finds the last active representative \(\le x\) by _R._search(_x_), then _x_ is placed in the position directly after that position, ensuring the new active representative \(R'_z\) is constructed in its correct sorted position, obeying \(R'_{z-1}\le R'_z<R'_{z+1}\). The resize operation collects all active representatives in the rebuild buffer and then places each \(R'_i\) at position 8(_i_-1). Since the sequence 8(_i_-1) is monotone increasing with _i_, the active representatives appear in the same order as they were collected, maintaining the global sorted sequence \(R'_1\dots R'_{s_\#}\).

Let us now derive the standard cost of _R._insert(_x_) excluding the cost of dynamic rebalancing. The first step requires at most \(lgs'_\#+3\) comparisons by Lemma A.1. The second step requires exactly lg8=3 comparisons as 8 is a power of 2. The third step exchanges \(k-j+1\le 7\) active representatives, which requires _O_(lg_m_) comparisons and _O_(lg_m_) moves. Constructing the representative in step 4 requires _O_(lg_m_) moves. Verifying if _k\<_8 was violated in step 5 requires only _O_(1) arithmetic operations.

The resize in step 6 is triggered following \(s'_\#\) insertions into the structure since the last resize. The initial scanning phase makes _k_ comparisons and _k_ exchanges for a gap containing _k_ active representatives, thus in total it makes exactly _s<sub>#</sub>_ comparisons and representative exchanges. Then, each active representative is exchanged back into the library. Spread among \(s'_\#\) insertions, using \(s_\#=2s'_\#\), this is 2 comparisons and 4 representative exchanges per insertion, which are _O_(lg_m_) comparisons and _O_(lg_m_) moves. Following the resize, \(s'_\#\) has doubled, and the structure requires \(s'_\#\) subsequent insertions to trigger another resize, which has equal amortized cost by the same argument.
