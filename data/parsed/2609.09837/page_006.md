For \(x\in I\), let N<sub>P</sub>(_x_) be the set of blocks containing a neighbor of _x_. A coloring represented by P extends to _I_ if and only if |N<sub>P</sub>(_x_)|_\<q_ for every \(x\in I\). Indeed, distinct blocks receive distinct colors, while _I_ is independent.

For a block _P_ and a color _c_, define \(w(P,c)=|P\backslash\varphi^{-1}(c)|+|\{x\in I:\varphi(x)=c\), \(N(x)\cap P\neq\emptyset\}|\). Thus, _w(P,c_) counts the flips forced by assigning color _c_ to the block _P_: vertices of _P_ not already colored _c_ and color-_c_ vertices of _I_ adjacent to _P_ must be recolored. If \(\pi:\mathcal{P}\rightarrow[q]\) is injective, then the minimum number of flips among extensions using color \(\pi(P)\) on _P_ is exactly \(\sum_{P\in\mathcal{P}}w(P,\pi(P))\). The first terms count changes on _C_. A vertex of _I_ must change precisely when its initial color is used by a neighboring block. It is counted exactly once because \(\pi\) is injective, and, by the extension condition, it can then be given any available color.

It remains to find a minimum-cost injective assignment of blocks to colors. Writing _r_=|P|, this is a rectangular assignment problem on the complete bipartite graph between the _r_ blocks and the _q_ colors. Its weights can be computed in O(_m+kq_) time. Since \(r\le q\), a minimum-cost matching saturating all block vertices can be found in \(\mathcal{O}(r^2q)\subseteq\mathcal{O}(k^2q)\) time by the Hungarian method for unbalanced bipartite graphs \[30\]. There are at most (_k_+1)_<sup>k</sup>_=2<sup>O(_k_log_k_)</sup> partitions of _C_. Taking the best over all partitions proves the theorem.
