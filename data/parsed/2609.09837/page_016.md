## A Detailed Algorithmic Proofs

### A.1 The vertex-cover assignment algorithm

We give the full correctness and running-time argument for Theorem 1. We can assume that \(q\le n\). Let \(\varphi'\) be a coloring realizing a minimum number of flips and suppose \(\varphi\) and \(\varphi'\) use \(n<p\le q\) distinct colors in total. If _s_ is the number of colors used by both \(\varphi\) and \(\varphi'\), and \(\varphi'\) uses _r_ colors unused by \(\varphi\), then \(s+r\le n\) as there are only _n_ vertices to color. We can then injectively map the \(r\varphi'\)-only colors first to the \(\varphi\)-only colors and then to colors not used by \(\varphi\) if necessary and thereby ensure the total number of colors used is at most _n_. This does not increase the number of color flips as all vertices colored with a \(\varphi'\)-only color needed to be recolored anyway. We can therefore assume that the number of available colors is at most _n_. Let _C_ be a minimum vertex cover of size _k_ and let _I=V(G_)\\_C_. A target coloring induces a partition P of _C_ into its nonempty color classes. Each block is independent, different blocks receive different color names, and \(|\mathcal{P}|\le q\). Conversely, every such partition together with an injective map \(\pi:\mathcal{P}\rightarrow[q]\) specifies a proper coloring on _C_.

Fix an independent-block partition P. For \(x\in I\), let N<sub>P</sub>(_x_) be the set of blocks _P_ with \(N(x)\cap P\neq\emptyset\). Since _I_ is independent, an injection \(\pi\) extends to a proper coloring of _G_ if and only if |N<sub>P</sub>(_x_)|_\<q_ for every \(x\in I\). The condition is independent of the actual color names: the neighbors of _x_ use exactly |N<sub>P</sub>(_x_)| distinct colors. If this number is smaller than _q_, at least one color remains available for _x_.

**Lemma 3.** _For a fixed admissible partition_ P _and injection_ \(\pi:\mathcal{P}\rightarrow[q]\)_, the minimum number of flips among all extensions is_ \(\sum_{P\in\mathcal{P}}w(P,\pi(P))\)_, where_ \(w(P,c)=|P\backslash\varphi^{-1}(c)|+|\{x\in I:\varphi(x)=c,N(x)\cap P\neq\emptyset\}|\).

_Proof._ The first term counts exactly the vertices of _C_ whose color changes. Consider \(x\in I\) and put \(a=\varphi(x)\). The vertex _x_ can keep its color if and only if no neighboring block is assigned _a_. Since \(\pi\) is injective, at most one block _P_ satisfies \(\pi(P)=a\). Hence, if _x_ has to change, it is counted exactly once by the second term of \(w(P,\pi(P))\). If it does not have to change, it is not counted.

It remains to see that all counted changes can be made simultaneously. For every uncounted vertex of _I_, retain its initial color. For every counted vertex _x_, choose any color not used by the blocks in N<sub>P</sub>(_x_). Such a color exists by admissibility. Choices for different vertices of _I_ cannot conflict because _I_ is independent. Thus the lower bound given by the sum is attained.

The optimal injection \(\pi\) is a rectangular assignment problem with left side P, right side \[_q_\], and edge costs _w(P,c_). If desired, one may add _q_-|P| dummy block vertices with zero-cost incident edges and solve a square minimum-weight perfect matching instance. For one partition, all neighborhood sets and all second cost terms are computed by scanning the edges once while ensuring that no vertex \(x\in I\) is counted more than once for any fixed assignment of color _c_ to an adjacent block _P_.
