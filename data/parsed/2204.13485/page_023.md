_Proof._ The problem is clearly in NP. To show NP-hardness, we reduce from x3c, see the definition in Section 2.

Let _I_ be an instance of x3c. We construct an instance \(I'\) with _H_=(_U,W;F_) of forced- spe as follows. Let _P_={_p_<sub>1</sub>_,...,p_<sub>3_n_</sub>} be a set of agents corresponding to the ground set _S_, and _Q_={_q_<sub>1</sub>_,...,q<sub>m</sub>_} be a set of agents corresponding to the 3-sets. These two sets of agents form one color class of the bipartite graph which will be referred to as men. Agents in _X_={_x_<sub>1</sub>_,...,x<sub>m</sub>_}, _Y_={_y_<sub>1</sub>_,...,y<sub>m</sub>_} and _Z_={_z_<sub>1</sub>_,...,z_<sub>3_n_</sub>} form the other color class of the bipartite graph which will be referred to as women. Finally, we add a special agent _u_ to the set of men and a special agent _w_ to the set of women. So \(U=P\cup Q\cup\{u\}\), \(W=X\cup Y\cup Z\cup\{w\}\).

The forced matching is \(\mu=\{uw,p_iz_i|i\in[3n]\}\). The fixed preferences of the agents on the edges of \(\mu\) are the following:

• for _u_, the rank of _M(u_) is _m-n_+1,<tbc>

• for a man _p<sub>i</sub>_, the rank of _M(p<sub>i</sub>_) is 2,<tbc>

• for a woman _z<sub>i</sub>_, the rank of _M(z<sub>i</sub>_) is set arbitrarily.

We further add the edges \(\{ux_i,x_iq_i,q_iy_i|i\in[m]\}\) to _F_, and for each 3-set _C<sub>j</sub>_={_s_<sub>_i_<sub>1</sub></sub>_,s_<sub>_i_<sub>2</sub></sub>_,s_<sub>_i_<sub>3</sub></sub>} of _I_ we add the edges _y<sub>j</sub>p_<sub>_i_<sub>1</sub></sub>, _y<sub>j</sub>p_<sub>_i_<sub>2</sub></sub> and _y<sub>j</sub>p_<sub>_i_<sub>3</sub></sub>.

We claim that there is an exact 3-cover in _I_ if and only if the preferences can be extended in a way that there is a stable matching _M_ containing \(\mu\). Let us first suppose that _C_<sub>_i_<sub>1</sub></sub>_,...,C<sub>i<sub>n</sub></sub>_ is a solution of the x3c instance _I_. Let _M_ be the matching obtained by adding the edges \(\{x_{i_j}q_{i_j}|j\in[n]\}\) and the edges \(\{q_ky_k|k\notin\{i_1,\dots,i_n\}\}\) to \(\mu\). The preferences are set such that the _m-n_ places worse than that of _uw_ for _u_ are given to the edges \(\{ux_k|k\notin\{i_1,\dots,i_n\}\}\). For \(k\notin\{i_1,\dots,i_n\}\), we set _q<sub>k</sub>_ to prefer _y<sub>k</sub>_ to _x<sub>k</sub>_. For \(j\in[n]\), we set _q<sub>i<sub>j</sub></sub>_ to prefer _x<sub>i<sub>j</sub></sub>_ to _y<sub>i<sub>j</sub></sub>_ and _x<sub>i<sub>j</sub></sub>_ to prefer _q<sub>i<sub>j</sub></sub>_ to _u_. Also for each _i_=1_,..._3_n_, we set the worst position of _p<sub>i</sub>_ to be the _y<sub>j</sub>_ corresponding to the set \(C_j\in\{C_{i_1},\dots C_{i_n}\}\) containing the element _a<sub>i</sub>_. Since _C_<sub>_i_<sub>1</sub></sub>_,...,C<sub>i<sub>n</sub></sub>_ is a partition, there is no collision when doing this. Then, all edges not in _M_ are dominated: each edge of type _ux<sub>j</sub>_ is dominated at either _u_ or _x<sub>j</sub>_, each edge \(q_jx_j\notin M\) is dominated at _q<sub>j</sub>_, each edge \(q_jy_j\notin M\) is dominated at _q<sub>j</sub>_, and each edge _p<sub>i</sub>y<sub>j</sub>_ is dominated at either _y<sub>j</sub>_ or _p<sub>i</sub>_.

For the other direction, suppose there is a preference extension and a matching _M_ with \(\mu\subseteq M\) that satisfy the conditions. For any triple _x<sub>i</sub>_, _q<sub>i</sub>_, and _y<sub>i</sub>_, one of these vertices must be uncovered in _M_ since the only possible partner of both _x<sub>i</sub>_ and _y<sub>i</sub>_ is _q<sub>i</sub>_ as the other neighbors are already matched in \(\mu\). There are _m-n_ women _x<sub>i</sub>_ such that _x<sub>i</sub>_ is worse for _u_ than _w_. At the same time, there must be _n_ women _x_<sub>_i_<sub>1</sub></sub>_,...,x<sub>i<sub>n</sub></sub>_ that are better, so for the edges _ux<sub>i<sub>j</sub></sub>_ to be dominated we must have \(x_{i_j}q_{i_j}\in M'\). Then _y<sub>i<sub>j</sub></sub>_ cannot be matched for _j_=1_,...n_, hence the edges that join these vertices to _P_ must be dominated at the vertices of _P_. But there are at least _n_ such _y<sub>i<sub>j</sub></sub>_-s with altogether 3_n_ edges incident to them and each \(p_i\in P\) can dominate at most one such edge, therefore _C_<sub>_i_<sub>1</sub></sub>_,...,C<sub>i<sub>n</sub></sub>_ is necessarily a partition. \(\square\)

**Remark 33.** If the size of the maximal matching _M_ containing \(\mu\) is larger than the size of \(\mu\) only by a constant, then the problem can be solved in polynomial time.

**Remark 34.** The proof of Theorem 32 implies that the bipartite variant of forced-spe when the preferences are set on _M_ only for one class of the agents is also NP-complete.

**Remark 35.** If the graph is a complete bipartite graph, or a complete graph and the preferences are only set on the edges of \(\mu\), then the problem can be solved in polynomial time. First, check whether the edges that connect vertices matched by \(\mu\) can all be dominated as we did before. If this is possible, then find a perfect matching _M_ containing \(\mu\) and set the edges of \(M\backslash\mu\) as the best edges for every agent. Then _M_ is clearly a stable matching.
