**Abstract**

We provide a deterministic algorithm that outputs an _O(n_<sup>3/4</sup>log_n_)-approximation for the Longest Common Subsequence (LCS) of two input sequences of length _n_ in near-linear time. This is the first deterministic approximation algorithm for LCS that achieves a sub-linear approximation ratio in near-linear time.
