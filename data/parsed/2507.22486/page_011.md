## A Symbols Occurrences Data Structure (Proof of Lemma 6)

In this section, we prove Lemma 6; restated below. \(\blacktriangleright\) **Lemma 6.** _There exists a data structure maintaining a dynamic sequence x supporting the following operations:_ \(\text{Init}(x)\text{\textit{- initialize the data structure; runs in}}\tilde{O}(|x|)\text{\textit{time.}}\) \(\text{Occ}(\sigma)\text{\textit{- returns all the indices in which the symbol}}\sigma\text{\textit{occur, i.e.,}}\{i|x_i=\sigma\}\text{\textit{; runs in}}\tilde{O}(\#_\sigma(x))\text{\textit{time.}}\) \(\text{Delete}(i)\text{\textit{- deletes the ith element of}}x\text{\textit{; runs in}}\tilde{O}(1)\text{\textit{time.}}\)

**Proof.** We implement the data structure as follows. We initialize a self-balancing search tree (e.g. AVL tree or Red-Black tree) _T<sub>I</sub>_ with |_x_| elements, where initially the _i_th element of _T<sub>I</sub>_ corresponds to the _i_th element _x<sub>i</sub>_ of _x_. Every node of _T<sub>I</sub>_ also stores as auxiliary information the size of the sub-tree below it in _T<sub>I</sub>_. This information can be straightforwardly maintained in _O_(log_n_) time when _T<sub>I</sub>_ undergoes a deletion, and it can be used to decide the current rank of a node among all remaining nodes in _O_(log_n_) time. For each symbol \(\sigma\in\Sigma\), the algorithm initializes a balanced search tree \(T_\sigma\) storing all indices in _x_ in which \(\sigma\) occurs. The indices in _x_ are not stored explicitly as integers, but as pointers to the elements of _T<sub>I</sub>_ - so when an index _i_ is deleted from _T<sub>I</sub>_, all remaining indices larger than _i_ are implicitly shifted accordingly. Clearly, given a letter \(\sigma\) we can find all indices in _x_ in which \(\sigma\) occurs in \(\tilde{O}(\#_\sigma(x))\) time using _T<sub>I</sub>_ and \(T_\sigma\). Deletion of the _i_th element is implemented by removing the _i_th element of _T<sub>i</sub>_ and the corresponding element in _T<sub>xi</sub>_. \(\blacktriangleleft\)
