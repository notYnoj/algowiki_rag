Apply _L_<sup>-1</sup>, interchange short fields _i,j_, then apply _L_. This uses exactly one recursive interchange. The unchanged coordinate _g_ lies between the two groups of fields and is simply part of the gap in this allowed interchange.

Both triangular maps use only scans. Process their coordinates in descending address order. Each target coordinate is scaled by a fixed nonzero rational and shifted by a fixed combination of earlier coordinates. With earlier coordinates fixed, the target values index consecutive blocks. A cyclic shift splits these blocks at its wraparound; a fixed integer scaling coprime to _q_ splits them into constantly many increasing streams. Reverse these procedures for inverses and use reversals for signs. All prefixes share the work streams. The fixed dimension and fixed coefficients imply _O(V_) sequential tape steps, including rewinds and cleanup, and a fixed number of buffers; these are the same triangular-coordinate procedures used in OpenAI [Ope26, Lemma 4]. The choice of _q_ includes the finitely many coefficients of all these factorizations, so every identity and inverse remains valid modulo _q<sup>f</sup>_ for all _f_. No unrestricted change of basis is being charged as a scan.

## Distributing the input among circuit inputs.

A fixed prefix identifies a contiguous segment containing all values of (_H,g,D,z_). Distribute these segments cyclically among _W_ streams: segment _Wj+i_ becomes segment _j_ of stream _i_. Each stream has _V/W_ bits, and its within-segment coordinates are unchanged. All _W_ streams carry independent arbitrary data, including those assigned to the auxiliary inputs.

## Changing storage order along edges.

A gate with subspace _U_ stores each logical stream in the address order _D<sub>P<sub>U</sub></sub>_. Along a wire of a data or auxiliary register, apply _D<sub>P<sub>V</sub></sub>D<sub>P<sub>U</sub></sub>_ to change from the storage order specified by _U_ to that specified by _V_ . At an XOR gate whose streams use this common storage order, the same permutation is applied to every operand, so it commutes with positionwise XOR. Temporary copies are first made in the source’s storage order, reordered for their target gates, used by those gates, and discarded. These changes of storage order contribute to _S_; no independent stream is assigned to an unused temporary register.

For an actual input _F<sub>i</sub>_, define the logical stream _G<sub>i</sub>=D<sub>P<sub>s<sub>i</sub></sub></sub>F<sub>i</sub>_ only in the analysis. Since \(D_{P_{s_i}}^2=I\), the actual input already has the required storage order, with no preprocessing. Correctness of the XOR circuit delivers _G<sub>i</sub>_ to its designated output. For _X<sub>a</sub>_, the source and output projection labels are _P<sub>U<sub>a</sub></sub>_ and _I-P<sub>U<sub>a</sub></sub>_; their partial swaps compose to _D<sub>I</sub>_. For the other data input and every auxiliary input, these labels are 0_,I_, also composing to _D<sub>I</sub>_. Consequently every actual output is exactly the corresponding input with _H,D_ interchanged. Returning output stream \(\sigma(i)\) to its original cyclic segment positions undoes the circuit’s permutation of the register streams.

## Counting and buffering the recursive calls.

Every label change on a data or auxiliary register is between nested subspaces; each temporary conversion also has comparable endpoint spaces. Their total difference rank is _S_, so the rank-one factorization above gives exactly _S_ child interchanges, each of width _f_ on _V/W_ bits. All copying, XOR, triangular-coordinate operations, and stream distribution require _O(V_) sequential tape steps because the entire circuit is fixed. Prefix divisibility also passes to every child: if the parent has _P_<sub>pre</sub> prefix segments with _W<sup>k</sup>|P_<sub>pre</sub>, then a short interchange beginning at _H<sub>i</sub>_ has (_P_<sub>pre</sub>_/W)q_<sup>_f(i_-1)</sup> prefixes after stream distribution. This is divisible by _W_<sup>_k_-1</sup>. The triangular changes leave all coordinate cardinalities unchanged.
