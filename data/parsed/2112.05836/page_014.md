1. Let \(\mathcal{D}:=\{1,2,4,\dots,2k\tau/\epsilon^2\}\). For _X_<sub>1</sub> and each _d_ in D, identify a set \(\tilde{\mathcal{W}}_{1,d}\) of "representative" strings such that (i) \(|\tilde{\mathcal{W}}_{1,d}|=O(n\tau/\epsilon d)\) and (ii) for every window _W_<sub>1_,i_</sub>, there is some string \(\mathtt{shift}_d(W_{1,i})\in\tilde{\mathcal{W}}_{1,d}\) in such that \(\delta_E(W_{i,\Delta,p},\mathtt{shift}_d(W_{i,\Delta,p}))\le\epsilon d\).<tbc>

2. For each other string _X<sub>i</sub>_,each value of _d_ in D, and each value of \(\Delta\), identify a set of "representative" length \(\tau+\Delta\) strings \(\tilde{\mathcal{W}}_{i,d,\Delta}\) such that (i) \(|\tilde{\mathcal{W}}_{i,d,\Delta}|=O(n(\tau+\Delta)/\epsilon d)\), and (ii) for every window \(W_{i,\Delta,p}\), there is some string \(\mathtt{shift}_d(W_{i,\Delta,p})\in\tilde{\mathcal{W}}_{i,d,\Delta}\) such that \(\delta_E(W_{i,\Delta,p},\mathtt{shift}_d(W_{i,\Delta,p}))\le\epsilon d\).<tbc>

3. Let \(\tilde{\mathcal{W}}_{i,d}=\cup_\Delta\tilde{\mathcal{W}}_{i,d,\Delta}\). For each \(d\in\mathcal{D}\) and every _k_-tuple of strings \(\tilde{W}_{1,d},\tilde{W}_{2,d}\dots\tilde{W}_{k,d}\) in \(\tilde{\mathcal{W}}_{1,d}\times\tilde{\mathcal{W}}_{2,d}\times\cdots\times\tilde{\mathcal{W}}_{k,d}\), compute the median distance of this _k_-tuple if it is less than _d_. Store this as \(\delta_E(\tilde{W}_{1,d},\tilde{W}_{2,d}\dots\tilde{W}_{k,d})+\epsilon kd\). If the true median distance of these windows is greater than _d_, store \(\delta_E(\tilde{W}_{1,d},\tilde{W}_{2,d}\dots\tilde{W}_{k,d})=\infty\) instead.<tbc>

4. Our algorithm solves the following dynamic program:<tbc>

\(c(x_1,x_2,\dots x_k)=min\left\{\begin{array}{ c }
min_{i\neq 1}c(x_1,x_2,\dots,x_i-\sigma,\dots,x_k)+\sigma \\
min_{W_1,\dots W_k\in\mathcal{W}_1\times\cdots\times\mathcal{W}_k:\forall_i\mathsf{e}(W_i)=x_i,W_1=\cdots=W_k}[c(\mathsf{s}(W_1)-1,\dots,\mathsf{s}(W_k)-1)] \\
min_{W_1,\dots W_k\in\mathcal{W}_1\times\cdots\times\mathcal{W}_k:\forall_i\mathsf{e}(W_i)=x_i}[c(\mathsf{s}(W_1)-1,\dots,\mathsf{s}(W_k)-1) \\
+min_{d\in\mathcal{D}}\delta_E(\mathtt{shift}_d(W_1),\dots,\mathtt{shift}_d(W_k))]
\end{array}\right.\)

For every _k_-tuple such that _x_<sub>1</sub> is a multiple of \(\tau\), _x_<sub>2</sub>_,...,x<sub>k</sub>_ are all multiples of \(\sigma\), and such that \(|x_i-x_1|\le 4D\) for all _i_.<br>
The base case is _c_(0,0_,...,_0)=0, and our final output is _c_(|_X_<sub>1</sub>|_,R<sub>u</sub>(N_<sub>2</sub>)_,...R<sub>u</sub>(N<sub>k</sub>_)), where _R<sub>u</sub>(x_) denotes _x_ rounded up to the nearest multiple of \(\sigma\).

At a high-level, in steps 1 and 2 of _k_-ED-Alg we exploit the compression of the input strings to identify a small set of "representative" strings for each _X<sub>i</sub>_, such that for each window in _X<sub>i</sub>_ there is a representative string within small edit distance of that window. In step 3, we then compute the median distance between _k_-tuples of representative strings (instead of between all _k_-tuples of windows). Since all windows are within a small distance of some representative string, this also gives for all _k_-tuples of windows a reasonable approximation of their median distance. Step 4 of _k_-ED-Alg uses these approximations to solve a natural DP for finding an optimal window-respecting alignment. This DP is the same as the standard DP for edit distance, but instead of matching characters we are only allowed to match windows, at cost equal to (the approximation of) their median distance.

We first bound the runtime of _k_-ED-Alg. The following lemmas show that Steps 1 and 2 of _k_-ED-Alg can be performed efficiently (as well as their correctness):

**Lemma 4.6.** _Given a straight-line program_ **G** _of size n that generates a string X of size n, a length parameter_ \(\tau\)_, and a parameter_ \(\delta_\mathrm{max}\le\tau\)_, there exists an algorithm that in time O_(|_X_|) _finds (an implicit representation of) a set S of_ \(O(n\tau/\delta_\mathrm{max})\) _substrings of length at most_ \(\tau\) _such that for every length_ \(\tau\) _substring of X, x, there is a string `shift`(x_) _in S such that_ \(\delta_E(x,\mathtt{\textit{shift}}(x))\le\delta_\mathrm{max}\)_. We can also construct a data structure that identifies `shift`(x_) _given the starting location of x in X using O_(|_X_|) _preprocessing time and O_(1) _query time._

_Proof._ If \(\delta_\mathrm{max}\ge\tau\), we can trivially choose _S_ that only contains the empty substring, and the data structure just returns the empty substring for any query. So assume \(\delta_\mathrm{max}<\tau\).

Given that **G** has size _n_, the optimal LZ77 factorization of _X_ has size at most _n_ \[Ryt03\]. We will first show the existence of _S_ for any _X_ that has an LZ77 factorization of size at most _n_. For brevity, we will not go into the details of LZ77 factorization here. The key property we need is that a string _X_ that has a LZ77 factorization of size _n_ can be written as \(X_1\circ X_2\circ X_3\), where _X_<sub>1</sub> is a string with LZ77 factorization of size _n_-1, _X_<sub>2</sub> is a substring of _X_<sub>1</sub>, and _X_<sub>3</sub> is a single character. Moreover, the factorization gives the location of _X_<sub>2</sub> in _X_<sub>1</sub>.

Inductively, suppose we have constructed _S_, a set of at most \(3(n-1)\tau/\delta_\mathrm{max}\) substrings that has the desired properties for _X_<sub>1</sub>. For all "good" indices \(i<|X_2|-\tau\), the length \(\tau\) substring starting at the _i_th character in _X_<sub>2</sub> is fully contained in _X_<sub>2</sub>, and thus is a substring in _X_<sub>1</sub>. This leaves at most \(\tau+1\) "bad" indices where the length \(\tau\) substring starting at these indices may not have a nearby string in _S_: those starting at indices \(|X_1|-\tau+1\) to |_X_<sub>1</sub>| of _X_<sub>1</sub>, and the substring starting at index \(|X_2|-\tau+2\) of _X_<sub>2</sub>.
