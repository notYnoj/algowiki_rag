<tbc>this, let us fix an arbitrary index _j_ such that _A<sub>j</sub>_ is a non-terminal of **G**_<sub>j</sub>_ and \(A_j\rightarrow A'_jA''_j\). We then consider three cases:

1. _F<sub>j</sub>_ is contained within the prefix \(exp(A'_j)\) of exp(_A<sub>j</sub>_). In this case, we set \(A_\mathbf{F}\rightarrow A_{\mathbf{F}^{\prime\prime}}\), where \(F'_j\) is the fragment of \(exp(A'_j)\) corresponding to _F<sub>j</sub>_ and \(F'_i=F_i\) for \(i\neq j\). Note that _F<sub>j</sub>_ cannot be a suffix of exp(_A<sub>j</sub>_) and, if _F<sub>j</sub>_ is a prefix of exp(_A<sub>j</sub>_), then \(F'_j\) is a prefix of \(exp(A'_j)\). Thus, \(\mathbf{F}'\) is a relevant tuple.<tbc>

2. _F<sub>j</sub>_ is contained within the suffix \(exp(A''_j)\) of exp(_A<sub>j</sub>_). In this case, we set \(A_\mathbf{F}\rightarrow A_{\mathbf{F}^{\prime\prime}}\), where \(F''_j\) is the fragment of \(exp(A''_j)\) corresponding to _F<sub>j</sub>_ and \(F''_i=F_i\) for \(i\neq j\). Note that _F<sub>j</sub>_ cannot be a prefix of exp(_A<sub>j</sub>_) and, if _F<sub>j</sub>_ is a suffix of exp(_A<sub>j</sub>_), then \(F''_j\) is a suffix of \(exp(A''_j)\). Thus, \(\mathbf{F}''\) is a relevant tuple.<tbc>

3. _F<sub>j</sub>_ overlaps both the prefix \(exp(A'_j)\) and the suffix \(exp(A''_j)\) of exp(_A<sub>j</sub>_). In this case, we set \(A_\mathbf{F}\rightarrow A_{\mathbf{F}^{\prime\prime}} A_{\mathbf{F}^{\prime\prime}}\), where \(F'_j\) is the suffix of \(exp(A'_j)\) overlapping _F<sub>j</sub>_, \(F''_j\) is the prefix of \(exp(A''_j)\) overlapping _F<sub>j</sub>_, and for every \(j\neq i\) we have \(F_i=F'_iF''_i\) with \(|F'_i|=|F'_j|\) and \(|F''_i|=|F''_j|\).<br>
Note that \(F'_j\) is a suffix of \(exp(A'_j)\) and \(F''_j\) is a prefix of \(exp(A''_j)\). Moreover, if _F<sub>j</sub>_ is a prefix of exp(_A<sub>j</sub>_), then \(F'_j\) is a prefix of \(exp(A''_j)\). Finally, for \(i\neq j\), if _F<sub>i</sub>_ is a prefix of exp(_A<sub>i</sub>_), then \(F'_i\) is a prefix of exp(_A<sub>i</sub>_), and if _F<sub>i</sub>_ is a suffix of exp(_A<sub>i</sub>_), then \(F''_i\) is a suffix of exp(_A<sub>i</sub>_). Thus, both \(\mathbf{F}'\) and \(\mathbf{F}''\) are relevant tuples.

Next, for each _i_, we interpret the string _P<sub>i</sub>_ generated by \(\mathbf{G}_i^P\) as a decomposition of _X<sub>i</sub>_ into \(|P_i|=O(\frac{N}{\tau})\) phrases. Each phrase is of the form exp(_A_) for a symbol _A_ of \(\mathbf{G}_i^+\) satisfying \(|A|\le\tau\). Let _B<sub>i</sub>_ be the set of phrase boundaries of this decomposition of _X<sub>i</sub>_ (i.e., \(B_i=\{|exp(P_i[1..j])|:i\in[0..|P_i|]\}\)), and let \(B=\bigcup_{i=1}^kB_i\).

For each string _X<sub>i</sub>_, let us construct another partition \(X_i=X_{i,1}\circ\cdots\circ X_{i,r}\) with phrase boundaries _B_ (if \(0=b_0<\cdots<b_r=N\) are the elements of _B_, then _X<sub>i,j</sub>=X<sub>i</sub>(b_<sub>_j_-1</sub>_..b<sub>j</sub>_]). Since \(B_i\subseteq B\), each phrase _X<sub>i,j</sub>_ can be represented as a fragment of exp(_A<sub>i,j</sub>_) for a symbol _A<sub>i,j</sub>_ of \(\mathbf{G}_i^+\) satisfying \(|A_{i,j}|\le\tau\). Moreover, for each _j_, there exists \(i_p\in[1..k]\) such that _X<sub>i<sub>p</sub>,j</sub>_ is a prefix of exp(_A<sub>i<sub>p</sub>,j</sub>_) and \(i_s\in[1..k]\) such that _X<sub>i<sub>s</sub>,j</sub>_ is a suffix of exp(_A<sub>i<sub>s</sub>,j</sub>_). (This is because \(b_{j-1}\in B_{i_p}\) and \(b_j\in B_{i_s}\) holds for some _i<sub>p</sub>_ and _i<sub>s</sub>_.) Hence, for each \(j\in[1..r]\), there exists a relevant tuple \(\mathbf{F}_j=(X_{i,j})_{i=1}^k\). Thus, it suffices to add to **G** a starting symbol \(S\rightarrow\circ_{j=1}^rA_{\mathbf{F}_j}\).

Due to the assumption that _k=O_(1), the total running time and the size |**G**| are both \(O(\frac{N}{\tau}+\tau^{k-1}\prod_{i=1}^kn_i)\). Optimizing for \(\tau\in[1..N]\), this becomes \(O(\prod_{i=1}^kn_i+(\prod_{i=1}^kn_i)^{1/k}N^{1-1/k})\). If the first term dominates, then \(\prod_{i=1}^kn_i>N\). However, a trivial _O(N_)-size straight-line program representing _X_ can be constructed in _O(N_) time by decompressing each string _X<sub>i</sub>_. Thus, we can always construct a straight-line program representing _X_ in time \(O((\prod_{i=1}^kn_i)^{1/k}N^{1-1/k})\).

**Corollary 7.2.** _Given k=O_(1) _straight-line programs_ **G**_<sub>i</sub> of size n<sub>i</sub> representing strings_ \(X_i\in\Sigma_i^N\) _of the same length N\>_0 _and a function_ \(\delta:\times_{i=1}^k\Sigma_i\rightarrow\mathbb{R}\) _that can be evaluated in O_(1) _time, the value_ \(\delta(X_1,\dots,X_k):=\sum_{j=1}^N\delta(X_1[j],\dots,X_k[j])\) _can be computed in_ \(O((\prod_{i=1}^kn_i)^{1/k}N^{1-1/k})\) _time._

_Proof._ Let \(X=\otimes_{i=1}^kX_i\) and let **G** be a straight-line program representing _X_ constructed using Proposition 7.1. For each symbol _A_ of **G**, we compute a value \(\delta(A)\) defined as \(\sum_{j=1}^{|A|}\delta(exp(A)[j])\). Note that if _A_=(_A_<sub>1</sub>_,...,A<sub>k</sub>_) is a non-terminal, then \(\delta(A)=\delta(A_1,\dots,A_k)\) can be evaluated in _O_(1) time. Otherwise, if \(A\rightarrow\circ_{\ell=1}^rB_\ell\), then \(\delta(A)=\sum_{\ell=1}^r\delta(B_\ell)\), so \(\delta(A)\) can be computed in _O_(|rhs(_A_)|) time. Consequently, constructing **G** and computing \(\delta(A)\) for every symbol _A_ of **G** costs \(O((\prod_{i=1}^kn_i)^{1/k}N^{1-1/k})\) time in total. This allows retrieving \(\delta(X_1,\dots,X_k)\) as the value \(\delta(S)\) for the starting symbol _S_ of **G**.

In particular, we can set \(\delta=\delta_H\) for _k_=2 (defined for characters _x,y_ with \(\delta_H(x,y)=0\) if _x=y_ and \(\delta_H(x,y)=1\) if \(x\neq y\)). Possible generalizations to an arbitrary number of strings include the following two definitions of \(\delta(x_1,\dots,x_k)\) for characters _x_<sub>1</sub>_,...,x<sub>k</sub>_:

• \(\delta(x_1,\dots,x_k)=0\) if \(x_1=\cdots=x_k\) and \(\delta(x_1,\dots,x_k)=1\) otherwise (the straightforward generalization).<tbc>

• \(\delta(x_1,\dots,x_k)=min_{i=1}^k\sum_{j=1}^k\delta_H(x_i,x_j)\) (the generalization corresponding to the median string problem).

In either case, Corollary 7.2 allows computing \(\delta(X_1,\dots,X_k)\) in \(O((\prod_{i=1}^kn_i)^{1/k}N^{1-1/k})\) time.
