If (_i,j_)=(1,1), then Definition 3.4 and Observation 3.3 yield \(D_{x,y}^{1,1}=d(v_{0,0},v_{x,y})\), and this value can be retrieved from the _DIST_<sub>_B_<sub>1,1</sub></sub> matrix in \(\widetilde{O}(1)\) time. Thus, we henceforth assume \((i,j)\neq(1,1)\).

Consider a portal-respecting (_i,j_)-walk _W_ to a vertex \(v_{x,y}\in\mathrm{out}^{B_{i,j}}\). By Definition 3.4, _W_ is a concatenation of two walks \(W'\) and \(W''\) such that \(W''\) starts at a vertex \(v_{x^\prime,y^\prime}\in\mathbf{P}\cap\mathrm{in}^{B_{i,j}}\) and is entirely contained within _B<sub>i,j</sub>_, whereas \(W'\) is a portal-respecting (_i,j_-1)-walk to \(v_{x^\prime,y^\prime}\) or a portal respecting (_i_-1_,j_)-walk to \(v_{x^\prime,y^\prime}\). Observe that, for a fixed portal \(v_{x^\prime,y^\prime}\in\mathbf{P}\cap\mathrm{in}^{B_{i,j}}\), the lengths of \(W'\) and \(W''\) can be optimized independently. Consequently, by Observation 3.3,

\(D_{x,y}^{i,j}=\mathrm{max}\left(\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i-1,j}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i-1,j}+d(v_{x^\prime,y^\prime},v_{x,y})\right\},\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i,j-1}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i,j-1}+d(v_{x^\prime,y^\prime},v_{x,y})\right\}\right).\)

A matrix (indexed by \(v_{x,y}\in\mathbf{P}_{i,j}\) and all vertices \(\mathbf{P}_{i-1,j}\cap\mathrm{in}^{B_{i,j}}\)) containing the values \(D_{x^\prime,y^\prime}^{i-1,j}+d(v_{x^\prime,y^\prime},v_{x,y})\) can be obtained from a submatrix of the _DIST<sub>B<sub>i,j</sub></sub>_ matrix by adding \(D_{x^\prime,y^\prime}^{i-1,j}\) to all entries in the column of \(v_{x^\prime,y^\prime}\). These modifications preserve the Monge property, so the resulting matrix is a Monge matrix with \(\widetilde{O}(1)\)-time random access. Consequently, the SMAWK algorithm \[AKM<sup>+</sup>87\] allows computing row-minima, i.e., the values \(\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i-1,j}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i-1,j}+d(v_{x^\prime,y^\prime},v_{x,y})\right\}\). A symmetric procedure allows computing the values \(\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i,j-1}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i,j-1}+d(v_{x^\prime,y^\prime},v_{x,y})\right\}\), which lets us derive the costs \(D_{x,y}^{i,j}\) for all the vertices \(v_{x,y}\in\mathbf{P}_{i,j}\). The SMAWK algorithm takes nearly linear time with respect to the sum of matrix dimensions, so the overall time complexity is \(\widetilde{O}(|\mathbf{P}\cap B_{i,j}|)\).

Each vertex belongs to at most four boxes, so the overall running time is \(\widetilde{O}(|\mathbf{P}|)\).

**Lemma 3.6.** _Let_ **B** _be a box decomposition of the graph G<sub>X,Y</sub> for_ \(X,Y\in\Sigma^+\) _and let_ \(\alpha>0\) _be a real number. Suppose that_ **P** _consists of all the grid vertices and all the boundary vertices v<sub>x,y</sub> of_ **B** _satisfying_ \(|x-y|=\lfloor(1+\alpha)^r\rfloor\) _for some integer r. Then, every vertex_ \(v_{x,y}\in B_{i,j}\) _satisfies_ \(D_{x,y}^{i,j}\le(1+2\alpha)^{i+j}d_{x,y}\).

_Proof._ We proceed by induction on _i+j_. The base case is trivially satisfied due to \(D_{x,y}^{1,1}=d_{x,y}\) for \(v_{x,y}\in B_{1,1}\). We henceforth fix \(v_{x,y}\in B_{i,j}\) with \((i,j)\neq(1,1)\). By Observation 3.3, there is a shortest path from _v_<sub>0,0</sub> to _v<sub>x,y</sub>_ contained within _G_<sub>_X_\[1_..x_\]_,Y_\[1_..y_\]</sub>. Let \(v_{x^\prime,y^\prime}\) be the first vertex of _B<sub>i,j</sub>_ on this path. Observe that \(v_{x^\prime,y^\prime}\in\mathrm{in}^{B_{i,j}}\) and \(d_{x,y}=d_{x^\prime,y^\prime}+d(v_{x^\prime,y^\prime},v_{x,y})\). By symmetry, we may assume without loss of generality that \(v_{x^\prime,y^\prime}\in\mathrm{out}^{B_{i-1,j}}\).

Let us choose \(v_{x^\prime,y^{\prime\prime}}\in\mathbf{P}_{i-1,j}\cap\mathrm{out}^{B_{i-1,j}}\) as close as possible to \(v_{x^\prime,y^\prime}\). Since grid vertices are portals, such \(v_{x^\prime,y^{\prime\prime}}\) exists. Moreover, by the choice of the remaining portals, \(d(v_{x^\prime,y^\prime},v_{x^\prime,y^{\prime\prime}})\le\alpha|x'-y'|\le\alpha d_{x^\prime,y^\prime}\). Let us construct a portal-respecting (_i,j_)-walk to _v<sub>x,y</sub>_ by concatenating a shortest portal-respecting (_i_-1_,j_)-walk to \(v_{x^\prime,y^{\prime\prime}}\) and a shortest path from \(v_{x^\prime,y^{\prime\prime}}\) to _v<sub>x,y</sub>_ (by Observation 3.3, we may assume that this path is contained in _B<sub>i,j</sub>_). This proves \(D_{x,y}^{i,j}\le D_{x,y}^{i-1,j}+d(v_{x^\prime,y^{\prime\prime}},v_{x,y})\). The inductive assumption further yields \(D_{x,y}^{i-1,j}\le(1+2\alpha)^{i+j-3}d_{x^\prime,y^{\prime\prime}}\), and thus \(D_{x,y}^{i,j}\le(1+2\alpha)^{i+j-3}d_{x^\prime,y^{\prime\prime}}+d(v_{x^\prime,y^{\prime\prime}},v_{x,y})\le(1+2\alpha)^{i+j-3}(d_{x^\prime,y^\prime}+d(v_{x^\prime,y^\prime},v_{x^\prime,y^{\prime\prime}}))+d(v_{x^\prime,y^\prime},v_{x^\prime,y^{\prime\prime}})+d_{x,y}-d_{x^\prime,y^\prime}\le(1+2\alpha)^{i+j-3}(d_{x^\prime,y^\prime}+\alpha d_{x^\prime,y^\prime})+\alpha d_{x^\prime,y^\prime}+d_{x,y}-d_{x^\prime,y^\prime}\le(1+2\alpha)^{i+j-2}d_{x,y}\).

## 3.2 A Grammar-Based Box Decomposition

Hermelin et al. \[HLLW13\] presented an algorithm that, given two grammar-compressed strings \(X,Y\in\Sigma^+\) and an integer parameter \(\tau\), constructs a box decomposition **B** of _G<sub>X,Y</sub>_ with \(p_X=O(\lceil\frac{1}{\tau}|X|\rceil)\) and \(p_Y=O(\lceil\frac{1}{\tau}|Y|\rceil)\), along with an oracle providing random access to the _DIST<sub>B<sub>i,j</sub></sub>_ matrices of all the boxes _B<sub>i,j</sub>_. However, their construction costs \(\Omega(|X|+|Y|)\) time, which is prohibitive in most of our applications. In this section, we achieve the same goal avoiding the linear dependency on the lengths of _X_ and _Y_ . The bottleneck of \[HLLW13\] is constructing appropriate decompositions of _X_ and _Y_ into phrases. In the following lemma, we implement an analogous step more efficiently by building a grammar-compressed representation of the sequence of phrases, with each phrase represented by a symbol in an auxiliary grammar.

**Lemma 3.7.** _Given a straight-line program_ **G** _generating a string X and an integer_ \(\tau\ge 1\)_, in O_(|**G**|) _time one can construct straight-line programs_ **G**<sup>+</sup> _and_ **G**_<sup>P</sup> of size O_(|**G**|) _such that:_

• _the terminal symbols of_ **G**_<sup>P</sup> are the symbols A of_ **G**<sup>+</sup> _satisfying_ \(|A|\le\tau\),<tbc>

• **G**_<sup>P</sup> generates a string P such that_ exp<sub>**G**<sup>+</sup></sub>(_P_)=_X and_ \(|P|\le\big\lceil\frac{3}{\tau}|X|\big\rceil\).

_Proof._ If \(\tau\ge|X|\), then we simply set **G**<sup>+</sup>=**G** and set **G**_<sup>P</sup>_ to be a grammar with no non-terminals whose starting symbol is the starting symbol of **G**; this construction clearly satisfies the required conditions.
