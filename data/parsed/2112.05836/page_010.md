**Lemma 3.16.** _Given_ \(\widetilde{O}(1)\)_-time random access to the DIST<sub>B<sub>i,j</sub></sub> matrix, the values_ \(D_{x^\prime,y^\prime}^{i-1,j}\) _for all vertices_ \(v_{x^\prime,y^\prime}\in\mathbf{P}_{i-1,j}\) _(if i\>_1_), and the values_ \(D_{x^\prime,y^\prime}^{i,j-1}\) _for all vertices_ \(v_{x^\prime,y^\prime}\in\mathbf{P}_{i,j-1}\) _(if j\>_1_), the values_ \(D_{x,y}^{i,j}\) _for any q_ query vertices \(v_{x,y}\in\mathrm{out}^{B_{i,j}}\) _can be computed in_ \(\widetilde{O}(q+|\mathbf{P}\cap\mathrm{in}^{B_{i,j}}|)\) _time._

_Proof._ If (_i,j_)=(1,1), then Definition 3.4 and Observation 3.3 yield \(D_{x,y}^{1,1}=d(v_{0,0},v_{x,y})\), and this value can be retrieved from the _DIST_<sub>_B_<sub>1,1</sub></sub> matrix in \(\widetilde{O}(1)\) time. Thus, we henceforth assume \((i,j)\neq(1,1)\).

Consider a portal-respecting (_i,j_)-walk _W_ to a vertex \(v_{x,y}\in\mathrm{out}^{B_{i,j}}\). By Definition 3.4, _W_ is a concatenation of two walks \(W'\) and \(W''\) such that \(W''\) starts at a vertex \(v_{x^\prime,y^\prime}\in\mathbf{P}\cap\mathrm{in}^{B_{i,j}}\) and is entirely contained within _B<sub>i,j</sub>_, whereas \(W'\) is a portal-respecting (_i,j_-1)-walk to \(v_{x^\prime,y^\prime}\) or a portal respecting (_i_-1_,j_)-walk to \(v_{x^\prime,y^\prime}\). Observe that, for a fixed portal \(v_{x^\prime,y^\prime}\in\mathbf{P}\cap\mathrm{in}^{B_{i,j}}\), the lengths of \(W'\) and \(W''\) can be optimized independently. Consequently, by Observation 3.3,

\(D_{x,y}^{i,j}=\mathrm{max}\left(\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i-1,j}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i-1,j}+d(v_{x^\prime,y^\prime},v_{x,y})\right\},\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i,j-1}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i,j-1}+d(v_{x^\prime,y^\prime},v_{x,y})\right\}\right).\)

A matrix (indexed by the query vertices \(v_{x,y}\in\mathrm{out}^{B_{i,j}}\) and all vertices \(\mathbf{P}_{i-1,j}\cap\mathrm{in}^{B_{i,j}}\)) containing the values \(D_{x^\prime,y^\prime}^{i-1,j}+d(v_{x^\prime,y^\prime},v_{x,y})\) can be obtained from a submatrix of the _DIST<sub>B<sub>i,j</sub></sub>_ matrix by adding \(D_{x^\prime,y^\prime}^{i-1,j}\) to all entries in the column of \(v_{x^\prime,y^\prime}\). These modifications preserve the Monge property, so the resulting matrix is a Monge matrix with \(\widetilde{O}(1)\)-time random access. Consequently, the SMAWK algorithm \[AKM<sup>+</sup>87\] allows computing row-minima, i.e., the values \(\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i-1,j}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i-1,j}+d(v_{x^\prime,y^\prime},v_{x,y})\right\}\). A symmetric procedure allows computing the values \(\mathrm{max}_{v_{x^\prime,y^\prime}\in\mathbf{P}_{i,j-1}\cap\mathrm{in}^{B_{i,j}}}\left\{D_{x^\prime,y^\prime}^{i,j-1}+d(v_{x^\prime,y^\prime},v_{x,y})\right\}\), which lets us derive the costs \(D_{x,y}^{i,j}\) for all the query vertices \(v_{x,y}\in\mathrm{out}^{B_{i,j}}\). The SMAWK algorithm takes nearly linear time with respect to the sum of matrix dimensions, so the overall time complexity is \(\widetilde{O}(q+|\mathbf{P}\cap\mathrm{in}^{B_{i,j}}|)\).

**Lemma 3.17.** _Given a box decomposition_ **B** _of G<sub>X,Y</sub>, a parameter_ \(\epsilon\in(0,1]\)_, and_ \(\widetilde{O}(1)\)_-time random access to the DIST matrices of all the boxes of_ **B**_, a_ \((1+\epsilon)\)_-approximation of_ LCS(_X,Y_) _can be computed in_ \(\widetilde{O}(\epsilon^{-1}(p_X+p_Y)^2)\) _time._

_Proof._ Let us choose \(\alpha=\Omega(\frac{\epsilon}{p_X+p_Y-2})\) so that \((1+\alpha)^{p_X+p_Y-2}=1+\epsilon\). We process boxes \(B_{i,j}\in\mathbf{B}\) in the order of non-decreasing values _i+j_, constructing the output portals _P<sub>i,j</sub>_ according to Lemma 3.15 and computing the values \(L_{x,y}^{i,j}\) for all \(v_{x,y}\in\mathbf{P}_{i,j}\). By Lemma 3.15, the value \(L_{|X|,|Y|}^{p_X,p_Y}\) is guaranteed to be a \((1+\epsilon)\)-approximation of LCS(_X,Y_).

The ordering of boxes lets us compute the values \(L_{x,y}^{i,j}\) for any _q_ vertices \(v\in\mathrm{out}^{B_{i,j}}\) in \(\widetilde{O}(q+|\mathbf{P}\cap\mathrm{in}^{B_{i,j}}|)\) time. By symmetry, we may focus without loss of generality on the right boundary of _B<sub>i,j</sub>_, i.e., vertices _v<sub>x,y</sub>_ with \(x=b_i^X\) and \(y\in[b_{j-1}^Y\dots b_j^Y]\). Note that the corresponding values \(L_{x,y}^{i,j}\) are non-decreasing: \(D_{x,y}^{i,j}\le D_{x,y-1}^{i,j}+1\) implies \(L_{x,y}^{i,j}\ge L_{x,y-1}^{i,j}\). First, we apply Lemma 3.16 to derive \(L_{x,y}^{i,j}\) for the two extreme values \(y\in\{b_{j-1}^Y,b_j^Y\}\). Next, for each value \(r\in[\lfloor\mathrm{log}_{1+\alpha} L_{x,b_{j-1}^Y}^{i,j}\rfloor\dots\lfloor\mathrm{log}_{1+\alpha} L_{x,b_j^Y}^{i,j}\rfloor]\), we binary search for the smallest \(y\in[b_{j-1}^Y\dots b_j^Y]\) such that \(\mathrm{log}_{1+\alpha} L_{x,y}^{i,j}\ge r\), and include _v<sub>x,y</sub>_ in **P**_<sub>i,j</sub>_. The binary searches are executed in parallel, with Lemma 3.16 applied to determine \(L_{x,y}^{i,j}\) for all the current pivots. This way, the algorithm is implemented in \(\widetilde{O}(1+\mathrm{log}_{1+\alpha} L_{x,b_j^Y}^{i,j}-\mathrm{log}_{1+\alpha} L_{y,b_{j-1}^Y,y}^{i,j}+|\mathbf{P}\cap\mathrm{in}^{B_{i,j}}|)\) time. Due to \(L_{y,b_{j-1}^Y}^{i,j}\ge L_{y,b_{j-1}^Y}^{i,j-1}\), the first term sums up to \(\widetilde{O}(\mathrm{log}_{1+\alpha}|Y|)=\widetilde{O}(\epsilon^{-1}(p_X+p_Y))\) across \(j\in[1\dots p_Y]\), and to \(\widetilde{O}(\epsilon^{-1}(p_X+p_Y)^2)\) across \(B_{i,j}\in\mathbf{B}\). This also bounds the number of portals created, so the second term, which sums up to |**P**| across all boxes, is also \(\widetilde{O}(\epsilon^{-1}(p_X+p_Y)^2)\).

_Proof of Theorem 3.14._ The algorithm uses Corollary 3.9 and Lemma 3.17. Due to \(p_X+p_Y=\frac{N+M}{\tau}\) , the overall running time is \(\widetilde{O}\big(nm\tau+\frac{(N+M)^2}{\epsilon\tau^2}\big)\). Optimizing \(\tau\), we get the running time of \(\widetilde{O}(nm+\epsilon^{-1}+(nm(N+M))^{2/3}\epsilon^{-1/3})\).

If the first term dominates, then \(nm\ge(nm(N+M))^{2/3}\epsilon^{-1/3}\ge(N+M)^2\epsilon^{-1}\). However, \(O(NM)=O((N+M)^2\epsilon^{-1})\) time is enough to compute LCS(_X,Y_) exactly without compression. If the second term dominates, then \(\epsilon^{-1}\ge(nm(N+M))^{2/3}\epsilon^{-1/3}\ge nm(N+M)\). However, \(\widetilde{O}(\sqrt{nm}(N+M))=\widetilde{O}(nm(N+M))\) time is enough to compute LCS(_X,Y_) exactly using Proposition 3.13 with _D=N+M_.
