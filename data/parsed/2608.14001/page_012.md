## 4) Case 1 (Ideal Dynamics and Ideal Measurement):

Theorem 8 suggests that the delay-coordinate map is an isometry when the conditioning parameter \(\delta_0=0\), which occurs when _A_<sub>1</sub>=_A_<sub>2</sub> and \(\kappa_1=\kappa_2\). When _A_<sub>1</sub>=_A_<sub>2</sub>, it implies that the underlying attractor M is "uniformly-stretched" in each dimension, and \(\kappa_1=\kappa_2\) implies that **h** observes each of the dimensions of M with the same magnitude. To numerically simulate this idealized scenario as a way to confirm Theorem 8, we ensure _A_<sub>1</sub>=_A_<sub>2</sub> by generating the \(\mathcal{A}_\unknown\)-eigenvectors with \(\mathbf{v}_j=\frac{\sqrt{2}}{2}(\mathbf{e}_{2j-1}+i\mathbf{e}_{2j})\), where \(\{\mathbf{e}_j\}_{j=1}^d\) are the canonical basis vectors in R_<sup>n</sup>_, so that **v**_<sub>j</sub>_ and \(\mathbf{v}_j^H\) form a conjugate pair.

For an observation function that ensures \(\kappa_1=\kappa_2\), define **c**=**V1**, where \(\mathbf{1}=\left[11\cdots 11\right]^T\), so that the vector observes the same magnitude of each dimension of the attractor; then, set \(\mathbf{h}=\sqrt{\frac{2d}{\ell}}\frac{\mathbf{c}}{\left\|\mathbf{c}\right\|_2}\) for the specific choice of \(\ell\).
