<tbc>Thus, each query reveals the corresponding matrix entry _K[i,j_]. Since correctly answering all _p_<sup>2</sup> queries uniquely determines _M_ and \(p=\Theta(min\{\sigma,n\})\), any subset sensitivity oracle requires \(\Omega(p^2)=\Omega\left(min\{\sigma^2,n^2\}\right)\) bits of space. □
