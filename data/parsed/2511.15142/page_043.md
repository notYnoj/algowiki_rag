**Lemma E.9** (Minimal paths and cycles)**.** _If Y is extreme:_

1. _For any minimal cycle C in H, we have_ \(Y\triangle C\in\mathcal{I}_1\cap\mathcal{I}_2\).<tbc>

_2._ _For any minimal path_ \(P\in\mathcal{P}(y,t)\)_, we have_ \(Y\triangle P\in\mathcal{I}_1\cap\mathcal{I}_2\).

_Proof of Lemma E.9._ For the proof of part (1), suppose \(Z:=Y\triangle C\notin\mathcal{I}_1\cap\mathcal{I}_2\), assume by symmetry that \(Z\notin\mathcal{I}_1\). Let _N,M_ be the matching edges in _C_ corresponding to M<sub>1</sub> and M<sub>2</sub> respectively. Using Lemma E.6(a), we know that there exists a different matching \(N'\neq N\) between the vertices \(VC\cap Y\) and _VC_\\_Y_ with edges corresponding to M<sub>1</sub>.

Consider the multiset union of edges \(N\cup N'\cup 2M\) which takes two copies of every edge from _M_ and a copy of every edge from _N_ and \(N'\). Since these set of edges enter and leave every vertex exactly twice, the set of edges can be decomposed into a collection of cycles _C_<sub>1</sub>_,...,C<sub>p</sub>_ for some \(p\ge 2\) such that some of the cycles have strictly fewer vertices than _C_. We also have \(\sum_{i\in p}\ell(C_i)=2\ell(C)\). Using Lemma E.8(i), we know \(\ell(C_i)\ge 0\) and since \(p\ge 2\), there exists a cycle _C<sub>i</sub>_ with lesser weight or the same weight with lesser number of vertices as _C_ contradicting the minimality of _C_.

The proof of part (2) proceeds in a few steps:

(2a) (**No re-entry**) First, we prove that a minimal path in P(_y,t_) never re-enters _X_<sub>1</sub> again. If _P_=(_x_<sub>0</sub>_,y_<sub>1</sub>_,x_<sub>1</sub>_,...,y<sub>k</sub>,x<sub>k</sub>,...,x_<sub>_t_-1</sub>_,y<sub>t</sub>_) with \(x_k\in X_1\), then observe that there is an edge from _y<sub>k</sub>_ to _x_<sub>0</sub> because \(Y+x_0\in\mathcal{I}_1\) as \(x_0\in\mathcal{I}_1\) which implies \(Y+x_0-y_k\in\mathcal{I}_1\) and hence the edge. If we let _C_=(_x_<sub>0</sub>_,y_<sub>1</sub>_,x_<sub>1</sub>_,...,y<sub>k</sub>,x_<sub>0</sub>), and \(P'=(x_k,y_{k+1},\dots,x_{t-1},y_t)\), we have \(\ell(P)=\ell(C)+\ell(P')\) implying that \(P'\) has smaller length and lesser number of arcs than _P_ as \(\ell(C)\ge 0\) from Lemma E.8(i) contradicting the minimality of _P_. An identical argument can be used to show that vertices are not revisited again in minimal paths.<tbc>
