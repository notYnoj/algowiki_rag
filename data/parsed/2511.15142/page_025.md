2. A certificate C is _valid_ if \(\langle w^*,x_i-x_j\rangle\ge 0\) for all \((i,j)\in\mathcal{C}\).

Hence a valid _y_-certificate implies that _y_ is a minimizer of \(\langle w^*,x\rangle\) among points in P. In fact, the minimum number of queries needed to find an optimal solution is lower bounded by the minimum size of a valid certificate.

Recall that given a set \(V\subseteq\mathbb{R}^d\) of vectors, the cone generated by _V_ is the set of all vectors that can be written as positive linear combinations of vectors from _V_ ; this is denoted by cone(_V_). Formally,

\(\mathrm{cone}(V)=\left\{x\in\mathbb{R}^d:x=\sum_{v\in V}\alpha_vv,\alpha_v\ge 0\right\}.\)

The following lemma gives a characterization of _y_-certificates based only on the geometry of the point set P.

**Lemma A.1.** _A set_ \(\mathcal{C}\subseteq[N]\times[N]\) _is a y-certificate iff_ \(\mathcal{P}\subseteq y+\mathrm{cone}\left(\{x_i-x_j\}_{(i,j)\in\mathcal{C}}\right)\).

_Proof._ Suppose C is a _y_-certificate. Then, the definition implies that the system:

\(\langle w,x_i-x_j\rangle\ge 0\forall(i,j)\in\mathcal{C}\langle w,x-y\rangle<0\) (14)

is infeasible for any \(x\in\mathcal{P}\). By Farkas’ lemma, this implies that \(x-y\in\mathrm{cone}\left(\{x_i-x_j\}_{(i,j)\in\mathcal{C}}\right)\).

Conversely, if \(x-y\in\mathrm{cone}\left(\{x_i-x_j\}_{(i,j)\in\mathcal{C}}\right)\) and \(\langle w,x_i-x_j\rangle\ge 0\) for all \((i,j)\in\mathcal{C}\), then \(\langle w,x-y\rangle\ge 0\) follows immediately.

**Definition A.2.** For a sequence \(\sigma=(x_{i_1},x_{i_2},\dots,x_{i_k})\), the _induced certificate_ is defined as \(\mathcal{C}_\sigma=\{(i_\ell,i_{\ell+1}):1\le\ell\le k-1\}\)

## A.1.1 Basic Subsequences

For a set \(\mathcal{Y}\subseteq\mathbb{R}^d\) with ConicDim(Y)=_k_ and any sequence \(\sigma=(y_1,\dots,y_n)\in\mathcal{Y}^n\), consider a process that maintains a subsequence \(\pi_t\) of \(\sigma\) for each \(0\le t\le n\). We start with the empty sequence \(\pi_0=\langle\rangle\), and at step _t_+1, we update

\(\pi_{t+1}=\left\{\begin{array}{ c c }
\pi_t\circ y_{t+1}, & \text{if}y_{t+1}-y_1\notin\mathrm{env}(\pi_t) \\
\pi_t, & \text{otherwise.}
\end{array}\right.\)

An analogy can be made to Kruskal’s algorithm, where we add the next element in the sequence precisely when it is not conically spanned by the envelope of the current set. We observe:

1. the sequence \(\pi_t\) is a prefix of \(\pi_{t+1}\), and moreover, \(\pi_{t+1}\) contains at most one more element.<tbc>

2. \(|\pi_n|\le k\).

<tbc>The first observation is immediate from the construction, and the second follows by contradiction: if \(|\pi_n|>k\), then some subsequence of size _k_+1 contradicts the definition of conic dimension. Let \(B(\sigma):=\pi_n\) be the subsequence of \(\sigma\) obtained by this process; we call this the "basis" of \(\sigma\).

**Lemma A.3.** _Given a sequence_ \(\sigma=(y_1,\dots,y_n)\in\mathcal{Y}^n\)_, we have:_

\(\mathrm{cone}(\{y_j-y_1\}_{1\le j\le n})\subseteq\mathrm{env}(B(\sigma))\subseteq\mathrm{env}(\sigma).\) (15)
