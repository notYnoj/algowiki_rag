**Lemma 23.** _The amortized running time of_ cleanupStep(_i_) _is zero._

_Proof._ We first show that cleanupStep(_i_) does not create any bills: Moving leaders to _L_<sub>_i_+1</sub> has no effect on the number of bills. For consecutive leaders _t,u,v,w_ where _u,v_ have the same parent _p_, we only activate _p_ if \(height(p)\le min(height(t),height(w))+1\). Thus, this activation does not create any bills either.

Next, we analyze the number of coins. Let _N_ be the total size of _L_<sub>0</sub>_,...,L<sub>i</sub>_ at the start of cleanupStep(_i_), and let \(N'\) be the total size of _L_<sub>0</sub>_,...,L<sub>i</sub>_ at the end of cleanupStep(_i_). We claim that \(N-N'\in\Omega(N)\). We have \(N\ge 20\cdot 4^{2^{i+2}}\) since we only run cleanupStep(_i_) if \(|L_i|\ge 20\cdot 4^{2^{i+2}}\). And, by Lemma 21, we have \(N'\le\sum_{j=0}^i16\cdot 4^{2^{j+2}}\le 17\cdot 4^{2^{i+2}}\). Thus, \(N'\le\frac{17}{20}N\), so \(N-N'\ge\frac{3}{20}N\).

For every leader _u_ that we move to _L_<sub>_i_+1</sub>, we get one coin since _u_ stops being unpromoted. Also, whenever we activate a node _p_ with children _u,v_, we get at least one coin. Indeed, we get four coins for destroying the leaders _u,v_, but we need two or three coins for the new leader _p_, depending on whether _p_ is unpromoted. These are the only two operations that decrease the total size of _L_<sub>0</sub>_,...,L<sub>i</sub>_. Thus, we get at least \(N-N'\ge\frac{3}{20}N\) coins in total. In particular, during cleanupStep(_i_), we may spend _O(N_) time for free.

When promoting leaders from _A_ to _L_<sub>_i_+1</sub>, we always promote a block of \(\Omega(2^i)\) leaders. Thus, we spend constant time per promoted leader, so _O(N_) time in total.
