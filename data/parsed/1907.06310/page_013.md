There are other ways to implement insertion and deletion. Sleator and Tarjan analyze an extension of Splay which supports mutation operations by using splits and joins \[61\]. Tarjan implements `push` and `inject` by inserting at the top of the tree \[65\]. Zip trees insert and delete keys starting from the middle of the tree and rearrange descendants to restore the binary search tree invariants \[66\]. Common implementations of deletion in computers replace the deleted node with the node holding the predecessor or successor of the removed key, a technique originally devised by Hibbard \[36\]. Our version of deletion originates from Cole’s analysis of the "dynamic finger" theorem \[18\]. Its main advantage is enabling our proof of Theorem 5.2. We leave as open problems determining whether Tarjan’s implementation of deque operations or algorithms that use Hibbard’s variant of deletion are reducible to algorithms in our model of mutation.

## 6 Natural Algorithms

Our results readily generalize. We say an algorithm is _natural_ if the rooted hulls of its executions are always the access paths for the requested keys and the transition trees for isomorphic rooted hulls are isomorphic. Splay is a natural algorithm. We incorporate mutation in the same way as for Splay. A natural algorithm inserts by searching in the augmented tree and deletes by successively searching in increasing order for all in the neighborhood of the deleted key, then rotating at the predecessor if present, followed by removing the key. To construct the _transition digraph_ G_<sub>n</sub>_(A) for natural algorithm A, assign a vertex to every binary search tree with keys {1_,...,n_}, and for every \(T\in\mathcal{G}_n(\mathcal{A})\) and \(x\in T\) add an arc from _T_ to the result of executing a search for _x_ in _T_ with A.

**Theorem 6.1.** _A natural algorithm whose transition digraph is strongly connected for binary search trees of some size at least three is dynamically optimal for instances with mutation if and only if it is eventually monotone for instances without mutation._

_Proof._ Let A be a natural algorithm and let _N_ be the smallest integer greater than two for which G_<sub>N</sub>_(A) is strongly connected. Choose a map _P_ from each pair \(q,q'\in\mathcal{G}_N(\mathcal{A})\) to some request sequence whose execution by A starting from _q_ has a sequence of after-trees which, when prefixed by _q_, comprises a directed path of minimal length connecting _q_ to \(q'\) in G_<sub>N</sub>_(A). Let \(T'\) be the after-tree of transforming _T_ with rooted hull _Q_ and transition tree \(Q'\). If \(Q=Q'\) or |_T|\<N_ then define \(C_T(Q,Q')=\mathrm{root}(Q')\). Otherwise, choose rooted hulls _q_<sub>1</sub>_,...,q<sub>k</sub>_ and transition trees \(q'_1,\dots,q'_k\) for enacting restricted rotations in an identical manner to Theorem 3.4, except that each transition tree has size _N_, rather than size four, and set \(C_T(Q,Q')=\oplus_{i=1}^kP(q_i,q'_i)\). The output of _P_ contains at most one request per vertex in G_<sub>N</sub>_(A). There are (2_N_)!/(_N_!(_N_+1)!) binary trees with keys {1_,...,N_} \[57\]. (This is the Catalan number for _N_.) Each access path contains at most every node in the tree. Thus, the cost for A to execute \(C_T(Q,Q')\) starting from _T_ is at most 4(2_N_)!/((_N_+1)!(_N_-1)!)\(|Q'|\), which is linear in the transition tree’s size. This execution’s final tree is \(T'\) whenever \(|T|\ge N\).

The map \(\mathcal{S}(E)=\oplus_{i=1}^MC_T(Q_i,Q'_i)\), where _Q_<sub>1</sub>_,...,Q<sub>m</sub>_ and \(Q'_1,\dots,Q'_m\) are the rooted hulls and transition trees of some execution _E_ for _X_ starting from _T_, is a simulation embedding for A. Similarly, \(\mathcal{F}(k,X,T)=k*(X\oplus C_T(T,V))\), where _V_ is the final tree in the execution of _X_ starting from _T_ by A, is a repeater for A. Thus, by Theorem 4.2, if A is eventually monotone then it is dynamically optimal for instances without mutation.
