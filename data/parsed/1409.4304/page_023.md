First, let us build an intuition what has to happen to match each _x<sub>Cj</sub>_. Note that we have to create some edge {_x<sub>Cj</sub>,w<sub>li,j</sub>_} of _E_<sub>3</sub> for every clause _C<sub>j</sub>_, but in the beginning all those edges are blocked through _E_<sub>2</sub>. During the dynamics per variable we can switch one edge of _E_<sub>2</sub> to _E_<sub>1</sub> freeing the other _w_-vertex. Then this vertex can be used to "visit" all the adjacent clauses in increasing order before creating the second edge of _E_<sub>1</sub>. But the _w_-vertex which switched first remains blocked and thus can be used for none of the clauses. Thus, the choice whether to create {_u<sub>xi</sub>,w<sub>xi</sub>_} or {_u<sub><o>x</o><sub>i</sub></sub>,w<sub><o>x</o><sub>i</sub></sub>_} first can be seen as the choice whether to set _x<sub>i</sub>_ true or false (by creating the opposite edge first). All clauses that include the variable in the corresponding assignment then can be matched using _w<sub>xi</sub>_ respectively _w<sub><o>x</o><sub>i</sub></sub>_. We will now formally prove the correctness of the reduction.

Assume that the 3Sat formula is satisfiable. Then we pick a satisfying assignment and for each variable generate the edge of _E_<sub>1</sub> which symbolizes the inverses of the assignment. Now the _w_-vertex in the assigned value of every variable is unmatched and we one by one generate the incident edges leading to the clause variables in increasing order starting from the smallest unblocked edge. As for every clause at least one literal is satisfied and the edges are created in increasing order and thus cannot block each other, by the end of this phase all vertices _x<sub>Cj</sub>_ were matched at least once. It remains to generate the second edge for every variable, and we have reached _M_<sup>∗</sup> with a sequence of the desired form.

Assume that we can reach _M_<sup>∗</sup> from _M_<sub>0</sub> with a sequence matching each _x<sub>Cj</sub>_ at least once. For each clause _C<sub>j</sub>_ pick a vertex _w<sub>li,j</sub>_ which was matched to _x<sub>Cj</sub>_.
