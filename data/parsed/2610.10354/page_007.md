<tbc>stronger statement by showing that low-rank 3SUM is in subquadratic time. Another advantage is that the structure measure can be defined for sets rather than sequences, which turns out cleaner:

**Definition 1.3** (Rank)**.** The _rank_ of a set \(A\subseteq\mathbb{Z}\), denoted _r(A_), is defined as the smallest integer \(r\ge 0\) such that there is a set \(X\subseteq\mathbb{Z}\) of size _r_ satisfying \(A\subseteq X+X\).

This notion has been considered before in the additive combinatorics literature, see, e.g., \[EN77, BvHK25\].<sup>4</sup> Observe that the rank of _A_ ranges from \(\lceil\sqrt{|A|}\rceil\) to |_A_|+1. Sets with low rank are considered structured; for instance intervals or arithmetic progressions have rank close to \(\sqrt{|A|}\). At the other extreme, random-like sets have rank close to |_A_|. We show that for sets with rank up to \(|A|^{1-\epsilon}\), 3SUM can be solved in subquadratic time:

**Theorem 1.4** (Informal Theorem 4.1)**.** _Let_ \(\epsilon>0\)_. Any 3SUM instance_ (_A,B,C_) _where one of the sets has rank at most_ \(O(n^{1-\epsilon})\) _can be solved in time_ \(O(n^{2-\epsilon^\prime})\) _for some_ \(\epsilon'>0\).

Interestingly, Theorem 1.4 generalizes and unifies _all_ previously known special cases of 3SUM that are known to be in truly subquadratic time:

• _Small-Universe 3SUM:_ When \(A,B,C\subseteq[u]\), 3SUM can be solved in time \(\widetilde{O}(u)\) by the Fast Fourier Transform. This is truly subquadratic when \(u\le n^{2-\epsilon}\). In this case, all three sets have rank \(O(\sqrt{u})\le n^{1-\epsilon/2}\) (witnessed by \(X=\{0,1,\dots,\lceil\sqrt{u}|-1\}\cup\{\lceil\sqrt{u}|,2\lceil\sqrt{u}|,\dots,\lceil\sqrt{u}|^2\})\).<tbc>

• _Small-Doubling 3SUM:_ As a vast generalization to Small-Universe 3SUM, Abboud, Bringmann, and Fischer \[ABF23\] and Jin and Xu \[JX23\] considered 3SUM on inputs with \(|A+A|\le K|A|\), and gave truly subquadratic time algorithm provided \(K\le n^\delta\) where \(\delta>0\) is sufficiently small.<sup>5</sup> For example, \[JX23\]’s algorithm for this case runs in \(\widetilde{O}(Kn^{1.5})\) time, which is truly subquadratic provided \(K\le n^{0.5-\epsilon}\). As an improvement to their algorithms, our Theorem 1.4 implies a truly subquadratic 3SUM algorithm whenever \(K\le n^{1-\epsilon}\).

This implication follows from the following simple fact: if \(|A+A|\le|A|^{2-\delta}\), then there exists a set _X_ of size \(|X|\le\widetilde{O}(|A|^{1-\delta/2})\) such that \(A\subseteq X+X\). Such _X_ exists by a simple probabilistic argument: Pick random subsets \(Y\subseteq-A\) and \(Z\subseteq A+A\) with sizes \(|Y|,|Z|=\Theta(|A|^{1-\delta/2}\sqrt{log|A|})\) and let \(X=Y\cup Z\). Since each \(a\in A\) is represented as _a=y+z_ by at least |_A_| distinct pairs \((y,z)\in(-A)\times(A+A)\), with high probability at least one pair (_y,z_) survives in \(Y\cup Z\) for every \(a\in A\).

• _Clustered 3SUM._ Chan and Lewenstein \[CL15\] studied _clustered_ 3SUM, where a set is clustered if it can be covered by \(n^{1-\delta}\) intervals of length _n_ for some \(\delta>0\). They showed a truly subquadratic-time algorithm for this case. It is simple to show that if _A_ is clustered, then a low-rank decomposition of _A_ can be found efficiently: Let _S_ be the set of the smallest numbers in each of the intervals. Then notice that \(A\subseteq X+X\) where \(X=(S+\{0,1,\dots,n^{\delta/2}\})\cup\{n^{\delta/2},2n^{\delta/2},\dots,n\}\), which has size \(O(n^{1-\delta/2})\).<sup>6</sup><tbc>
