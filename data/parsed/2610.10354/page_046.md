**Proof.** Let A be such an \(O(n^{3/2-\epsilon})\) time algorithm. Similar as before, it suffices to give a truly sub-quadratic time algorithm for Min-Plus Convolution instances (_A,B_) where the elements are from \(\lfloor\sqrt{n}\rfloor\) while we need to list up to \(\sqrt{n}\) witnesses per output.

By trying all sampling rates _p_=1,2<sup>-1</sup>,2<sup>-2</sup>_,..._, and only keeping sampled elements in _B_ as their original values while setting all other elements as \(\perp\), then with high probability, there will be a round where the number of witnesses for _C_\[_k_\] is \(\Theta(\sqrt{n})\) if the number of witnesses for _C_\[_k_\] in the original instance is more than \(\sqrt{n}\). Hence, we only need to handle _C_\[_k_\] with \(O(\sqrt{n})\) witnesses. By padding the sequences with _O(n_) additional \(\perp\)’s, we can further assume that we only need to handle _C_\[_k_\] with \(\sqrt{n}\) witnesses.

Let _N_ be a prime number from \[2_n,_4_n_\], which can be found deterministically in \(\widetilde{O}(n)\) time. We extend _A_ and _B_ to length _N_, where the extra elements are padded as \(\perp\). Now the Min-Plus Convolution _C_ between _A_ and _B_ can be equivalently defined by \(C[k]=\mathrm{min}_{i\in\mathbb{F}_N}\{A[i]+B[k-i]\}\).

We repeat the following \(\widetilde{O}(\sqrt{n})\) iterations: sample _x_∼F_<sub>N</sub>_\\{0} and _y_∼F_<sub>N</sub>_. Create a length-_N_ sequence \(A'\) where \(A'[xi]=A[i]\) for every \(i\in\mathbb{F}_N\); create a length-\(\lfloor\sqrt{N}\rfloor\) sequence \(B'\) where \(B'[xj+y]=B[j]\) if \(xj+y\in\{0,1,\dots,\lfloor\sqrt{N}\rfloor\}\). We can use A to compute \(C'=A'*B'\) in \(O(n^{3/2-\epsilon})\) time. By the standard sampling-based approach (Lemma 2.14 generalized to input sequences of different lengths), we can also list a witness for each \(C'[k]\) in \(\widetilde{O}(n^{3/2-\epsilon})\) time, by using A as a black-box. Observe that, if some _C_\[_k_\] has witnesses (_i,j_) where _A_\[_i_\]+_B_\[_j_\]=_C_\[_k_\], and if \(xj+y\in\{0,1,\dots,\lfloor\sqrt{N}\rfloor\}\), then (_xi,xj+y_) will be a witness for \(C'[xk+y]\). Given a witness for \(C'[xk+y]\), we can convert it back to a witness for _C_\[_k_\]. By repeating \(\widetilde{O}(\sqrt{n})\) iterations, we can list multiple witnesses for _C_\[_k_\], though there might be repeated witnesses from different iterations. It remains to analyze the success probability of collecting all witnesses for each _C_\[_k_\].

Let _J<sub>k</sub>_ be the set of \(j\in\mathbb{F}_N\) where _j_ is a witness for _C_\[_k_\] (i.e., _A_\[_k-j_\]+_B_\[_j_\]=_C_\[_k_\]). Recall we only need to list witnesses for _C_\[_k_\] where \(|J_k|\le\sqrt{n}\). Let \(j_0\in J_k\) be an arbitrary witness, and we focus on a particular iteration. Let _X<sub>j</sub>_ denote the event that \(B[j]=B'[xj+y]\) in this iteration, i.e., \(xj+y\in\{0,1,\dots,\lfloor\sqrt{N}\rfloor\}\). If only _X_<sub>_j_<sub>0</sub></sub> happens, and _X<sub>j</sub>_ does not happen for other \(j\in J_k\backslash\{j_0\}\), then the algorithm is able to discover _j_<sub>0</sub> as a witness for _C_\[_k_\] in this iteration. Using the near-independence between \(X_{j^\prime}\) and _X<sub>j</sub>_ for \(j\neq j'\) by the way we sample _x_ and _y_, this happens with probability

\(\mathbb{P}\left[X_{j_0}\wedge\wedge_{j\in J_k\backslash\{j_0\}}\neg X_j\right]=\mathbb{P}\left[X_{j_0}\right]-\mathbb{P}\left[X_{j_0}\wedge\vee_{j\in J_k\backslash\{j_0\}}X_j\right]\)<br>
\(\ge\mathbb{P}\left[X_{j_0}\right]-\sum_{j\in J_k\backslash\{j_0\}}\mathbb{P}\left[X_{j_0}\wedge X_j\right]\)<br>
\(=\frac{\lfloor\sqrt{N}\rfloor+1}{N}-(|J_k|-1)\cdot\frac{\lfloor\sqrt{N}\rfloor+1}{N}\cdot\frac{\lfloor\sqrt{N}\rfloor}{N-1}\)<br>
\(\ge\frac{1}{\sqrt{N}}-\sqrt{n}\cdot\left(\frac{\sqrt{N}+1}{N}\right)^2\)<br>
\(=\Omega(N^{-1/2}),\)

where the last step is because \(n\le N/2\). Hence, in \(\widetilde{O}(N^{1/2})\) iterations, we can list all witnesses for _C_\[_k_\] with high probability.
