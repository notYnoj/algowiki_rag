Now suppose the PESS oracle returns two distinct subsets \(X,Y\subseteq[N]\) such that \(\sum_{i\in X}a_i=\sum_{j\in Y}a_j\). From this collision, the reduction outputs the lattice vector \(\mathbf{v}=\sum_{i\in X}\mathbf{x}^{(i)}-\sum_{j\in Y}\mathbf{x}^{(j)}\). Because the base _W_ is much larger than the magnitude of every summed digit (i.e., there can be at most 2_N_ sums of O(_BN_<sup>2</sup>) digits), equality of the encoded sums implies that there are no carries between digit positions. Hence the corresponding rounded quantities cancel coordinate- wise, and the only loss comes from the rounding error. If we plug in the parameters, this yields \(\|\mathbf{v}\|_2\le N^5\cdot\lambda_n(\mathcal{L})\). Thus, any successful PESS call gives a sufficiently short lattice vector.

The main technical issue is to guarantee that the decoded vector is _nonzero_. To address this, we analyze a modified experiment (similarly to the tossing argument \[AKS01, Reg04\]). Let \(\mathbf{v}^*\in\mathcal{L}\) be a shortest nonzero vector. Instead of sampling only from _D_<sub>L_,s_</sub>, we first sample \(\mathbf{x}'^{(1)},\dots,\mathbf{x}'^{(N)}\sim D_{\mathcal{L},s}\) and then independently choose bits \(b_1,\dots,b_N\in\{0,1\}\), replacing each sample by \(\mathbf{x}^{(i)}=\mathbf{x}'^{(i)}+b_i\mathbf{v}^*\).

Since _s_ is large, the distributions _D_<sub>L_,s_</sub> and _D_<sub>L_,s_</sub>+**v**<sup>∗</sup> are statistically close, so the original and modified sampling procedures are nearly indistinguishable. On the other hand, the random primes (and the random shifts) in the encoding make it unlikely that adding **v**<sup>∗</sup> changes any encoded integer. Therefore, with high probability, the PESS oracle sees the same instance in both experiments. However, if we flip one bit _b<sub>t</sub>_, then the decoded lattice output changes by \(\pm\mathbf{v}^*\). Hence, among the two paired executions, at most one can output the zero vector. It follows that the modified reduction outputs a nonzero short vector with constant probability; therefore, so does the original reduction, up to negligible loss.

Finally, the preprocessing, sampling, and encoding steps all run in time \(\mathcal{O}(2^{\varepsilon n})\) for some very small \(\varepsilon>0\). The dominant term is the call to the assumed PESS algorithm on _N_ integers of magnitude at most _M_, which presumably runs in time:

\(\mathrm{poly}(n)\cdot M^{o(1/\mathrm{log}N)}\checkmark\mathrm{poly}(n)\cdot M^{\varepsilon^2/\mathrm{log}N}\)<br>
\(=(BN)^{\mathcal{O}(\varepsilon^2n/\mathrm{log}N)}=2^{\mathcal{O}(\varepsilon n)},\)

as _N_=poly(_n_) and \(B=n^{\mathcal{O}(1/\varepsilon)}\). Therefore, for any constant \(\varepsilon>0\) the assumed fast PESS algorithm yields a \(2^{\mathcal{O}(\varepsilon n)}\)-time algorithm that with high probability outputs a nonzero vector of length \(N^5\cdot\lambda_n(\mathcal{L})\le n^{10}\cdot\lambda_n(\mathcal{L})\), contradicting Hypothesis 1. See Section 5 for a complete proof.

## 2.3 Techniques behind Theorem 1.3 and Theorem 1.4

Theorem 1.3 and Theorem 1.4 are based on the same two-level filtering framework via the _filtering algorithm_ (see below). We partition the _n_ input integers into four equal blocks, enumerate all subset sums inside each block, and then perform two rounds of merging: first modulo _p_, and then modulo _q_. Thus, in both settings, the output of the filtering stage is a final list of subset sums that agree modulo _pq_. This agreement modulo _pq_ is only an intermediate condition. In the modular setting, to obtain a collision modulo _M=pqr_, one must additionally ensure collision in the residual _r_-part, after which the Chinese Remainder Theorem yields a collision modulo _M_. In the integer setting, agreement modulo _pq_ again controls only the low-order bits, and one must additionally understand carry propagation and the remaining high-order contribution. Thus, the main difference lies not in the algorithmic template, but in its analysis - in particular, the analysis of the collision variable that denotes the number of collisions in the final list. The modular setting is relatively simpler, due to uniform distributions, CRT, and modular arithmetic. Whereas in the integer setting, even the first-moment calculation of the collision variable becomes substantially more intricate. Nevertheless, the modular analysis remains crucial. As we will see later, controlling the success probability requires a second-moment bound, and in the integer case, this is obtained by comparison with the more tractable modular collision variable.
