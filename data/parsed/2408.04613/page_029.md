When we find the right values _j_ and _k_ for the given _i_, we set \(dp(\nu,i,\ell):=k\) and compute \(dp'(\nu,i,\ell)\) as described below. In constant time we can compute the indices _i_<sup>lo</sup> and _j_<sup>lo</sup> in \(s_\nu^{\mathrm{lo}*}\) corresponding to the indices _i_ and _j_ in \(s_\nu^\mathrm{lo}\) using the rpos mapping for \(s_\nu^\mathrm{lo}\). Similarly, in constant time we can compute the indices _j_<sup>hi</sup> and _k_<sup>hi</sup> in \(s_\nu^{\mathrm{hi}*}\) corresponding to the indices _j_ and _k_ in \(s_\nu^\mathrm{hi}\). If _A<sub>i,j</sub>_=0, all the elements of the longest increasing subsequence lie in \(s_\nu^\mathrm{hi}\), and thus we set \(dp'(\nu,i,\ell):=dp'(\nu_R,j^\mathrm{hi},\ell)\). Analogously, if _B<sub>j,k</sub>_=0, all the elements of the longest increasing subsequence lie in \(s_\nu^\mathrm{lo}\), and we set \(dp'(\nu,i,\ell):=dp'(\nu_L,i^\mathrm{hi},\ell)\). Finally, if _A<sub>i,j</sub>\>_0 and _B<sub>j,k</sub>\>_0, the longest increasing subsequence is split across \(s_\nu^\mathrm{lo}\) and \(s_\nu^\mathrm{hi}\), and thus we set \(dp'(\nu,i,\ell):=((\nu_L,i^\mathrm{lo},A_{i,j}),(\nu_R,j^\mathrm{hi},B_{j,k}))\).

After computing \(dp(\nu,i,\ell)\) and \(dp'(\nu,i,\ell)\), we increment _i_ and continue the algorithm. At each step of the algorithm, we increment one of the variables _i,j_, or _k_ and recompute the corresponding values _A<sub>i,j</sub>_, _B<sub>j,k</sub>_, and _C<sub>i,k</sub>_ using the horizontally or vertically adjacent recomputation of lco.

We now analyze the time complexity of the algorithm. First, we analyze it for a fixed recursion node \(\nu\). For \(\ell=1\), it takes \(\mathcal{O}(n_\nu)\) time to compute \(dp(\nu,\cdot,\ell)\) and \(dp'(\nu,\cdot,\ell)\). For any other \(\ell\), we go through all indices \(i\in[0..n_\nu)\), and, for each one of them, find the corresponding _j_ and _k_ and then compute the dynamic programming values. All operations except for finding _j_ and _k_ take constant time. The index _k_ is increased by at most \(n_\nu\) across all iterations. Whenever it is increased, we spend \(\mathcal{O}(\delta_{\cdot,k}(C)+1)\) time to recompute _C<sub>i,k</sub>_, which sums up to \(\mathcal{O}(\delta(C)+n_\nu)\) time in total. Furthermore, we spend \(\mathcal{O}(\delta_{\cdot,k}(B)+1)\) time to recompute _B<sub>j,k</sub>_, which sums up to \(\mathcal{O}(\delta(B)+n_\nu)\) time in total. Analogously, the index _j_ is increased by at most \(n_\nu\) across all iterations, and we spend at most \(\mathcal{O}(n_\nu+\delta(A)+\delta(B))\) time in total on it. Finally, the index _i_ is increased by at most \(n_\nu\) across all iterations, and we spend at most \(\mathcal{O}(n_\nu+\delta(A)+\delta(C))\) time in total on it. Overall, the computation of \(dp(\nu,\cdot,\ell)\) and \(dp'(\nu,\cdot,\ell)\) takes time \(\mathcal{O}(n_\nu+\delta(A)+\delta(B)+\delta(C))\) in total, which is equal to \(\mathcal{O}(n_\nu)\) due to Corollary B.11.

Across all \(\ell\), the algorithm takes time \(\mathcal{O}(n_\nu\tau)\). There are O(log_n_) recursion levels, and the values \(n_\nu\) sum up to _n_ on each level, so the total time complexity is \(\mathcal{O}(n\tau\mathrm{log}n)\). \(\triangleleft\)

This concludes the preprocessing phase, which takes \(\mathcal{O}(n\mathrm{log}^2n+n\tau\mathrm{log}n)=\mathcal{O}(n\mathrm{log}^{3-\alpha} n)\) time in total. We now describe how to answer a query. Suppose that we are asked to report the longest increasing subsequence of _s_\[_i_<sub>0</sub>_..j_<sub>0</sub>\] for some \(0\le i_0<j_0\le n\). Let \(\ell_0=\mathsf{LIS}(s[i_0..j_0))\). Note that \(M_{i_0,j_0}^s=\ell_0\) and every longest path from (_i_<sub>0</sub>,0) to (_j_<sub>0</sub>_,n_) in _G<sup>s</sup>_ corresponds to a longest increasing subsequence of _s_\[_i_<sub>0</sub>_..j_<sub>0</sub>\] due to Lemma B.8. We backtrack one such path through the recursion tree of Lemma B.13. Let the current backtracking recursive call be \((\nu,i,j)\) (initially, it is \((\rho,i_0,j_0)\)). Let \(\ell:=\mathsf{LIS}(s_\nu[i..j))\). If \(dp(\nu,i,\tau)>j\), we have \(\ell<\tau\). We then set \(\ell_0=1\) and increment it as long as \(dp(\nu,i,\ell_0+1)\le j\), that is, as long as \(\ell_0<\ell\). We use \(dp'\) to reconstruct the underlying longest increasing subsequence.

Hence, from now on we assume that \(dp(\nu,i,\tau)\le j\), and thus \(\ell\ge\tau\). Note that \(M^{s_\nu}\) was obtained as the (max,+)-product of \(M^{s_\nu^\mathrm{lo}}\) and \(M^{s_\nu^\mathrm{hi}}\) for two subpermutations \(s_\nu^\mathrm{lo}\) and \(s_\nu^\mathrm{hi}\) that \(s_\nu\) was decomposed into. Due to Theorem 4.7, in time O(log_n_) we can reconstruct the witness _h_ such that \(M_{i,j}^{s_\nu}=M_{i,h}^{s_\nu^\mathrm{lo}}+M_{h,j}^{s_\nu^\mathrm{hi}}\), that is, some longest increasing subsequence in \(s_\nu[i..j)\) uses the values from \(s_\nu^\mathrm{lo}\) in \[_i..h_\], and then the values from \(s_\nu^\mathrm{hi}\) in \[_h..j_\]. In constant time, we can recompute the indices in \(s_\nu^{\mathrm{lo}*}\) corresponding to _i_ and _h_ in \(s_\nu^\mathrm{lo}\) using the rpos mapping for \(s_\nu^\mathrm{lo}\) and recursively compute the prefix of the longest increasing subsequence in \(s_\nu^\mathrm{lo}[i..h)\). By analogously recursing in the other direction, we compute the suffix of the longest increasing subsequence in \(s_\nu^\mathrm{hi}[h..j)\).
