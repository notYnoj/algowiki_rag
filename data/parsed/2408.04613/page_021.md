<tbc>_lst<sub>i</sub>=j_, which is indeed correct. As _lst_ is non-decreasing, we have \(lst_{i-1}\ge lst_i=j\), so the invariant holds when we decrement _i_.

We now prove that we computed the core of _C_ correctly. At each step, we compute \(C_{i,j}^\square\) and add \((i,j,C_{i,j}^\square)\) to the core of _C_ if and only if \(C_{i,j}^\square\neq 0\). Note that in the _i_-th row for \(i\in[0..p-1)\), we visited exactly the cells (_i,j_) with \(j\in[lst_{i+1}..lst_i]\). Therefore, we computed all core elements \((i,j,C_{i,j}^\square)\in\mathrm{core}(C)\) with \(j\in[\mathrm{max}\{0,lst_{i+1}\}..\mathrm{min}\{r-2,lst_i\}]\). If this is not the case, we either have \(j\in[0..lst_{i+1})\) or \(j\in(lst_i..r-1)\). In the first case, we have \(j+1\le lst_{i+1}\le lst_i\). Therefore, \(C[i..i+1][j..j+1]=C^L[i..i+1][j..j+1]\). Hence, \(\{(i,j,C_{i,j}^\square)\in\mathrm{core}(C)|j<lst_{i+1}\}=\{(i,j,C_{i,j}^{L\square})\in\mathrm{core}(C^L)|j<lst_{i+1}\}\). Analogously, in the second case, we have \(j>lst_i\ge lst_{i+1}\), and thus \(C[i..i+1][j..j+1]=C^R[i..i+1][j..j+1]\). Hence, \(\{(i,j,C_{i,j}^\square)\in\mathrm{core}(C)|j>lst_i\}=\{(i,j,C_{i,j}^{R\square})\in\mathrm{core}(C^R)|j>lst_i\}\). Therefore, the core of _C_ and the entire condensed representation of _C_ were computed correctly.

It remains to analyze the time complexity of the presented recursive procedure. We first analyze the time complexity of a single call without further recursive calls. The compression and decompression procedures take time \(\mathcal{O}(p^*+q^*+r^*+\delta(A^*)+\delta(B^*))\). If _p=r_=1, we compute _C_ in O(_q_) time. Otherwise, we sort core(_A_) and core(_B_) using counting sort and pick _m_ in \(\mathcal{O}(\delta(A)+\delta(B)+q)=\mathcal{O}(\delta(A)+\delta(B))\) time. Building the condensed representations of _A<sup>L</sup>,A<sup>R</sup>,B<sup>L</sup>_, and _B<sup>R</sup>_ using Lemma 4.5 takes \(\mathcal{O}(p+q+r+\delta(A)+\delta(B))=\mathcal{O}(\delta(A)+\delta(B))\) time. Note that _A<sup>L</sup>_ and _A<sup>R</sup>_ are disjoint contiguous submatrices of _A_, and thus \(\delta(A^L)+\delta(A^R)\le\delta(A)\). Analogously, \(\delta(B^L)+\delta(B^R)\le\delta(B)\). In particular, we have \(\delta(A^L),\delta(A^R)\le\delta(A)\) and \(\delta(B^L),\delta(B^R)\le\delta(B)\). As \(C^L=A^L\otimes B^L\) and \(C^R=A^R\otimes B^R\), we have \(\delta(C^L),\delta(C^R)\le 2\cdot(\delta(A)+\delta(B))\) due to Theorem 1.1. Therefore, constructing lco(_C<sup>L</sup>_) and lco(_C<sup>R</sup>_) takes time \(\mathcal{O}(\delta(A)+\delta(B))\). After that, we initialize _i=p_-1 and _j_=-1 and perform at most _p+r_ loop iterations as each iteration either decrements _i_ or increments _j_. Therefore, all loop operations except for maintaining the values of _C<sup>L</sup>\[i..i_+1\]\[_j..j_+1\] and _C<sup>R</sup>\[i..i_+1\]\[_j..j_+1\] take O(_p+r_) time.

We now analyze the time of maintaining the values of _C<sup>L</sup>\[i..i_+1\]\[_j..j_+1\]. We initially set _i=p_-1 and _j_=-1 and only compute \(C_{i,j+1}^L\) in constant time as it is the only existing entry of _C<sup>L</sup>\[i..i_+1\]\[_j..j_+1\]. Furthermore, whenever in the loop _j_ is incremented, the values \(C_{i,j}^L\) and \(C_{i+1,j}^L\) for the new _j_ are already computed, and computing \(C_{i,j+1}^L\) and \(C_{i+1,j+1}^L\) using horizontally adjacent recomputation takes \(\mathcal{O}(\delta_{..j}(C^L)+1)\) time. Analogously, when _i_ is decremented, it takes \(\mathcal{O}(\delta_{i..}(C^L)+1)\) time to recompute the values using the vertically adjacent recomputation. In total, it takes \(\mathcal{O}(1+\sum_{j\in[0..r-1)}(\delta_{..j}(C^L)+1)+\sum_{i\in[0..p-1)}(\delta_{i.}(C^L)+1))=\mathcal{O}(\delta(C^L)+p+r)\) time to maintain the values of _C<sup>L</sup>\[i..i_+1\]\[_j..j_+1\]. Analogously, maintaining the values of _C<sup>R</sup>\[i..i_+1\]\[_j..j_+1\] takes \(\mathcal{O}(\delta(C^R)+p+r)\) time. Overall, it takes \(\mathcal{O}(\delta(C^L)+\delta(C^R)+p+r)=\mathcal{O}(\delta(A)+\delta(B))\) time to traverse the matrix _C_.

Finally, filtering out the elements of core(_C<sup>L</sup>_) and core(_C<sup>R</sup>_) and computing the values of the topmost row and the leftmost column of _C_ takes \(\mathcal{O}(\delta(C^L)+\delta(C^R)+p+r)=\mathcal{O}(\delta(A)+\delta(B))\) time. Hence, the complete call without recursive calls takes time \(\mathcal{O}(p^*+q^*+r^*+\delta(A^*)+\delta(B^*))\).
