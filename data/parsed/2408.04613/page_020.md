If _p_=1 and _r_=1, we compute the only entry of the \(1\times 1\) matrix _C_ (and thus, its condensed representation) trivially. Otherwise, we pick the largest index \(m\in(0..q)\) with \(\delta(A[0..p)[0..m))+\delta(B[0..m)[0..r))\le(\delta(A)+\delta(B))/2\). Such an _m_ can be computed by traversing the lists core(_A_) and core(_B_) sorted (using counting sort) according to the second and the first coordinate respectively.

Let _A<sup>L</sup>_:=_A_\[0_..p_\]\[0_..m_), _B<sup>L</sup>_:=_B_\[0_..m_\]\[0_..r_), _A<sup>R</sup>_:=_A_\[0_..p_\]\[_m..q_), and _B<sup>R</sup>_:=_B_\[_m..q_\]\[0_..r_). We compute the condensed representations of all these matrices using Lemma 4.5. Furthermore, we recursively compute the condensed representations of \(C^L:=A^L\otimes B^L\) and \(C^R:=A^R\otimes B^R\), and build lco(_C<sup>L</sup>_) and lco(_C<sup>R</sup>_) of Lemma 4.4. As shown below, the desired matrix _C_ is the element-wise minimum of _C<sup>L</sup>_ and _C<sup>R</sup>_. Moreover, there exists a non-increasing sequence \((lst_i)_{i\in[0..p)}\) such that \(C_{i,j}=C_{i,j}^L\le C_{i,j}^R\) for \(j\in[0..lst_i]\) and \(C_{i,j}=C_{i,j}^R<C_{i,j}^L\) for \(j\in(lst_i..r)\). We now compute the sequence _lst_ along with the core elements of _C_ located on the "border" between the values of _C_ taken from _C<sup>L</sup>_ and the values of _C_ taken from _C<sup>R</sup>_. We start traversing the matrix _C_ in the direction from bottom-left to top-right. At every point in time, we consider some cell (_i,j_) with \(i\in[0..p)\) and \(j\in[-1..q)\). We maintain all values in _C<sup>L</sup>_\[_i..i_+1\]\[_j..j_+1\] and _C<sup>R</sup>_\[_i..i_+1\]\[_j..j_+1\] that are well-defined (that is, within the matrix boundaries). Initially, we set _i_:=_p_-1 and _j_:=-1. At each step, we compute the values in _C_\[_i..i_+1\]\[_j..j_+1\] as the element-wise minima of the values in _C<sup>L</sup>_\[_i..i_+1\]\[_j..j_+1\] and _C<sup>R</sup>_\[_i..i_+1\]\[_j..j_+1\], and if \(C_{i,j}^\square\neq 0\), we add \((i,j,C_{i,j}^\square)\) to the core of _C_. Furthermore, if _j_+1_\<r_ and \(C_{i,j+1}^L\le C_{i,j+1}^R\), we have that \(lst_i\ge j+1\), and thus we increment _j_ by one and compute the values in _C<sup>L</sup>_\[_i..i_+1\]\[_j_+1_..j_+1\] and _C<sup>R</sup>_\[_i..i_+1\]\[_j_+1_..j_+1\] using the horizontally adjacent recomputation of lco(_C<sup>L</sup>_) and lco(_C<sup>R</sup>_). Otherwise, we set _lst<sub>i</sub>=j_ and decrement _i_ by one. We maintain the values in _C<sup>L</sup>_\[_i..i_\]\[_j..j_+1\] and _C<sup>L</sup>_\[_i..i_\]\[_j..j_+1\] using vertically adjacent recomputation of lco(_C<sup>L</sup>_) and lco(_C<sup>R</sup>_). We terminate the process when _i_ becomes negative.

After computing _lst<sub>i</sub>_ for all \(i\in[0..p)\), we traverse all the elements \((i,j,C_{i,j}^{L\square})\in core(C^L)\) and add them to core(_C_) if _j\<lst_<sub>_i_+1</sub>. Analogously, we traverse all the elements \((i,j,C_{i,j}^{R\square})\in core(C^R)\) and add them to core(_C_) if _j\>lst<sub>i</sub>_. Finally, we compute the elements in the topmost row and the leftmost column of _C_ as the element-wise minima of the elements in the topmost rows and the leftmost columns of _C<sup>L</sup>_ and _C<sup>R</sup>_. Having computed core(_C_), the topmost row of _C_, and the leftmost column of _C_, we can return the condensed representation of _C_.

We now prove the correctness of the presented algorithm. We first show that _C_ is the element-wise minimum of _C<sup>L</sup>_ and _C<sup>R</sup>_. By definition, for every \(i\in[0..p)\) and \(k\in[0..r)\), we have

\(min\{C_{i,k}^L,C_{i,k}^R\}=min\{min\{A_{i,j}+B_{j,k}|j\in[0..m)\},min\{A_{i,j}+B_{j,k}|j\in[m..q)\}\}\)<br>
\(=min\{A_{i,j}+B_{j,k}|j\in[0..q)\}\)<br>
\(=C_{i,k}.\)

Furthermore, \(C_{i,k}=C_{i,k}^L\le C_{i,k}^R\) if \(\mathcal{W}_{i,k}^{A,B}<m\) and \(C_{i,k}=C_{i,k}^R<C_{i,k}^L\) if \(\mathcal{W}_{i,k}^{A,B}\ge m\).
