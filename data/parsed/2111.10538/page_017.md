## 3 LCS Step 1: Sparsification via Birthday Triangle Inequality

Recall that we are given two sets of windows _W<sub>A</sub>_ and _W<sub>B</sub>_ for the strings and our goal is to approximate the LCS of all but a few pairs of windows from \(W_A\times W_B\). For simplicity, we put all the windows in the same basket \(W=W_A\cup W_B\) and denote the windows by _w_<sub>1</sub>_,w_<sub>2</sub>_,...,w<sub>k</sub>_ where _k_ is the total number of windows. Since the windows have different lengths, we define \(\mathsf{w}_\mathsf{max}=\mathrm{max}_{i\in[k]}|w_i|\) to be the maximum length of the windows. Similarly, we also define \(\mathsf{w}_\mathsf{min}=\mathrm{min}_{i\in[k]}|w_i|\) to be the minimum length of the windows. Let w<sub>gap</sub>=w<sub>max</sub>/w<sub>min</sub>. Let w<sub>layers</sub> denote the number of different window sizes. Notations w<sub>gap</sub> and w<sub>layers</sub> will be used in the later analysis.

In order to approximate the LCS’s we fix a \(\lambda\in\{\epsilon\lambda_0,(1+\epsilon)\epsilon\lambda_0,(1+\epsilon)^2\epsilon\lambda_0,\dots,1\}\) and sparsify graph \(\mathsf{G}_\lambda\). In Section 3.1, we present a sparsification algorithm (Algorithm 1) which provides \((1-\epsilon)\lambda^2\)-approximation when \(\lambda\) is constant. The formal guarantee of the algorithm is provided in Theorem 3.13. In Section 3.2, we present a sparsification which provides \(\Omega(\lambda^3)\)-approximation for any (potentially sub-constant) \(\lambda\).
