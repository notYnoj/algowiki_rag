<tbc>The three required arguments have the same meaning as in the previous modules. The `problem\_type` argument needs to be from the set {ref,dih} if at least one of the graph classes is the class of alternating paths, due to the use of Corollary 2.10.

The computation of Ramsey numbers is carried out via the `number\_finder.py` module by arranging the numbers in an infinite matrix in which the rows correspond to the orders of graphs from the first graph class, while the columns correspond to those from the second graph class. More precisely, the rows and columns correspond to the orders 3,4,5_,..._, if the graph class is not _M_<sup>nest</sup>, and 4,6,8,10_,..._, otherwise. The entries are grouped by the minimum of their row and column indices in a layer-like manner, as shown in  1. The computation proceeds layer by layer, with the last processed layer being the one whose diagonal entry is the first to yield a timeout according to the configured SAT instance generation and Kissat time limits. Within each layer, the entries are computed from the diagonal entry onward to the right and downward. In each direction, the traversal is terminated after three occurrences of a timeout or once the graph order exceeds a configurable threshold. The computation of Ramsey numbers is optimized through the use of Corollaries 2.8- 2.10. In addition, if the two graph classes corresponding to the rows and the columns are the same, then only the upper-triangular part of the infinite matrix, including the diagonal, is considered.

The `grid\_explorer.py` module also saves the computed results to a CSV file with the header `a, b, exact, number`. Here, the columns `a` and `b` specify the graph orders of the two arguments, while `number` stores the computed value. The `exact` column contains a Boolean flag indicating whether the value in the `number` column has been determined to be the exact Ramsey number or is only known to be a lower bound. The auxiliary script `table\_generator.py`, whose source code is mostly based on the `src/sat\_solving/kissat\_output\_parser.py` script from \[5\], can then be used to read all the saved CSV files and automatically generate LATEX code that displays the computed results in tables.

**Example 3.4.** Consider the following command:

`python grid\_explorer.py palt pmon ref`

This command can be used to automate the computation of Ramsey numbers of the form \(R_\mathrm{ref}(P_a^\mathrm{alt},P_b^\mathrm{mon})\) with \(a,b\ge 3\). Next, consider the following command:

`python table\_generator.py`

The execution of this command scans the saved CSV file and automatically generates the LATEX code for the corresponding table. \(\Diamond\)
