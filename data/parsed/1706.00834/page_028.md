## Regret Bounds.

Similar to the knapsack problem, we turn this problem into a shortest- path problem: We first modify the graph so that all paths have equal length of _n_ (which is the length of the longest path) and the gain of each path remains fixed. We apply a method introduced in György et al. (2007), which adds O(_n_<sup>2</sup>) vertices and edges (with gain zero) to make all paths have the same length of _D=n_. Then we define a loss for each edge _e_ as \(\ell_e=1-g_e\) in which _g<sub>e</sub>_ is the gain of _e_. Call this new DAG \(\bar{\mathcal{G}}\). Similar to the knapsack problem, we have \(L_\bar{\mathcal{G}}(\unknown)=n-G_\mathcal{G}(\unknown)\) for all paths \(\unknown\). Note that in both G and \(\bar{\mathcal{G}}\), there are N=2<sup>_n_-1</sup> paths. Thus using Theorem 10 we obtain<sup>10</sup>

\(G^*-\mathbb{E}[G_\mathrm{EH}]=(nT-L^*)-(nT-\mathbb{E}[L_\mathrm{EH}])\)<br>
\(=\mathbb{E}[L_\mathrm{EH}]-L^*=\mathcal{O}(n\sqrt{L^*}).\)

Notice that the number of multiedges/edges in \(\bar{\mathcal{G}}\) is |_M_|=|_E_|=_O(n_<sup>2</sup>) and each path consists of _D=n_ edges. Therefore using Theorem 14 we obtain:

\(G^*-\mathbb{E}[G_\mathrm{CH}]=(nT-L^*)-(nT-\mathbb{E}[L_\mathrm{CH}])\)<br>
\(=\mathbb{E}[L_\mathrm{CH}]-L^*=\mathcal{O}(n^\frac{1}{2}(\mathrm{log}n)^\frac{1}{2}\sqrt{L^*}).\)

## 5.6 Weighted Interval Scheduling

Consider the online version of _weighted interval scheduling_ problem (Kleinberg and Tardos, 2006): We are given a set of _n_ intervals _I_<sub>1</sub>_,...,I<sub>n</sub>_ on the real line. In each trial, the algorithm predicts with a _scheduling_ which is a subset of non-overlapping intervals. Then, for each interval _I<sub>j</sub>_, the adversary reveals \(p_j\in[0,1]\) which is the _profit_ of including _I<sub>j</sub>_ in the scheduling. The gain of the algorithm is defined as the total profit over chosen intervals in the scheduling in that trial. The goal is to predict with a sequence of schedulings minimizing regret which is the difference between the total gain of the algorithm and the total gain of the single best scheduling chosen in hindsight. See Figure 10 as an example. Note that this problem is only interesting when the number of solutions (i.e. schedulings) are exponential in _n_.
