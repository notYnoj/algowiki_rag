_where n<sub>j</sub>, c(j), and_ \(\omega(j)\) _depend only on j, and_

\(\mathrm{lim}_{j\rightarrow\infty} c(j)=\mathrm{lim}_{j\rightarrow\infty}\omega(j)=0.\)

\(\{\{B_{n,j}\}_n\}_j\longrightarrow^{a.c.s.}\{A_n\}_n\) _denotes that_ {{_B<sub>n,j</sub>}<sub>n</sub>}<sub>j</sub> is an a.c.s. for_ {_A<sub>n</sub>}<sub>n</sub>._

In intuitive terms, we say that the family {{_B<sub>n,j</sub>}<sub>n</sub>}<sub>j</sub>_ forms an a.c.s. for {_A<sub>n</sub>}<sub>n</sub>_ if, for all sufficiently large values of _j_, the sequence {_B<sub>n,j</sub>}<sub>n</sub>_ provides an accurate asymptotic approximation of {_A<sub>n</sub>}<sub>n</sub>_. More precisely, each matrix _A<sub>n</sub>_ can be decomposed into the sum of the corresponding matrix _B<sub>n,j</sub>_, a perturbation of rank negligible with respect to the dimension of _A<sub>n</sub>_, and a remainder whose norm is arbitrarily small. As _j_ increases, both the rank and the norm of these perturbation terms become increasingly insignificant for large values of _n_.<br>
The following theorem represents the expression of a related convergence theory and it is a powerful tool used, for example, in the construction of the GLT ∗-Algebra.

**Theorem 2.1** _Let_ {_A<sub>n</sub>}<sub>n</sub>,_ {_B<sub>n,j</sub>}<sub>n</sub>, with_ \(j,n\in\mathbb{N}\)_, be matrix sequences and let_ \(\psi,\psi_j:D\subset\mathbb{R}^d\rightarrow\mathbb{C}^{r\times r}\) _be measurable functions defined on a set D with positive and finite Lebesgue measure. Suppose that:_

1. \(\{B_{n,j}\}_n\sim_\sigma\psi_j\) _for every j;_<tbc>

2. \(\{\{B_{n,j}\}_n\}_j\longrightarrow^{a.c.s.}\{A_n\}_n\);<tbc>

_3._ \(\psi_j\rightarrow\psi\) _in measure._

_Then_

\(\{A_n\}_n\sim_\sigma\psi.\)

**Theorem 2.2** _Given a Hermitian matrix sequence_ {_A<sub>n</sub>}<sub>n</sub>, let_ {_B<sub>n,j</sub>}<sub>n</sub>, be a class of Hermitian matrix sequences and let_ \(\psi,\psi_j:D\subset\mathbb{R}^d\rightarrow\mathbb{C}^{r\times r}\) _be measurable functions defined on a set D with positive and finite Lebesgue measure. Suppose that:_

1. \(\{B_{n,j}\}_n\sim_\lambda\psi_j\) _for every j;_<tbc>

_2._ \(\{\{B_{n,j}\}_n\}_j\longrightarrow^{a.c.s.}\{A_n\}_n\);<tbc>

_3._ \(\psi_j\rightarrow\psi\) _in measure._

_Then_

\(\{A_n\}_n\sim_\lambda\psi.\)

For clarity, we note that we will occasionally consider so-called _constant_ families of matrix sequences of the form {{_B<sub>n</sub>}<sub>n</sub>}<sub>j</sub>_, where the underlying sequence {_B<sub>n</sub>}<sub>n</sub>_ is independent of the index _j_. In such cases, the parameter _j_ plays no effective role and serves only as a formal label. As an example, the family {{_I<sub>n</sub>}<sub>n</sub>}<sub>j</sub>_ represents the constant identity matrix sequence, since the element associated with each value of _j_ coincides with the same sequence {_I<sub>n</sub>}<sub>n</sub>_.
