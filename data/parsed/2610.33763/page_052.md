The symbol plays a central role in determining the singular value distribution and, in the Hermitian setting, the eigenvalue distribution of GLT matrix sequences.<br>
It can be proven that the set of multilevel block GLT sequences is the ∗-algebra generated by the three classes of sequences defined in Sections 4.3, 4.4, 4.5: zero- distributed sequences, multi-level block Toeplitz sequences, and block diagonal sampling matrix sequences. The GLT class satisfies several algebraic and topological properties, which are discussed in detail in \[11, 10, 41, 42\]. Here, we focus on the main operative properties listed below, which provide a complete characterization of GLT sequences, equivalent to the full constructive definition.

**GLT 1** _If_ \(\{A_n\}_n\sim_\mathrm{GLT}\kappa\)_, then_ \(\{A_n\}_n\sim_\sigma\kappa\) _in the sense of Definition 2.1, with t_=2_d and_ \(D=[0,1]^d\times[-\pi,\pi]^d\)_. If moreover each A<sub>n</sub> is Hermitian, then_ \(\{A_n\}_n\sim_\lambda\kappa\)_, again in the sense of Definition 2.1, with t_=2_d._

**GLT 2** _It holds_

• \(\{T_\mathbf{n}(f)\}_\mathbf{n}\sim_\mathrm{GLT}\kappa(\mathbf{x},\theta)=f(\theta)\) _for any_ \(f:[-\pi,\pi]^d\rightarrow\mathbb{C}^{r\times r}\) _with_ \(f\in L^1([-\pi,\pi]^d)\);<tbc>

• \(\{D_\mathbf{n}(a)\}_\mathbf{n}\sim_\mathrm{GLT}\kappa(\mathbf{x},\theta)=a(\mathbf{x})\) _for any Riemann-integrable_ \(a:[0,1]^d\rightarrow\mathbb{C}^{r\times r}\);<tbc>

• \(\{Z_n\}_n\sim_\mathrm{GLT}\kappa(\mathbf{x},\theta)=O_r\) _if and only if_ \(\{Z_n\}_n\sim_\sigma 0\)_, i.e.,_ {_Z<sub>n</sub>}<sub>n</sub> is zero- distributed._

**GLT 3** _If_ \(\{A_n\}_n\sim_\mathrm{GLT}\kappa\) _and_ \(\{B_n\}_n\sim_\mathrm{GLT}\varsigma\)_, then_

• \(\{A_n^*\}_n\sim_\mathrm{GLT}\bar{\kappa}\)_, where_ \(A_n^*\) _denotes the conjugate transpose of A<sub>n</sub> and_ \(\bar{\kappa}\) _the complex conjugate of_ \(\kappa\);<tbc>

• \(\{\alpha A_n+\beta B_n\}_n\sim_\mathrm{GLT}\alpha\kappa+\beta\varsigma\) _for any_ \(\alpha,\beta\in\mathbb{C}\);<tbc>

• \(\{A_nB_n\}_n\sim_\mathrm{GLT}\kappa\varsigma\);<tbc>

• \(\{A_n^\dagger\}_n\sim_\mathrm{GLT}\kappa^{-1}\) _for any_ \(\kappa\) _invertible a.e., where_ \(A_n^\dagger\) _denotes the Moore-Penrose pseudoinverse of A<sub>n</sub>._

**GLT 4** \(\{A_\mathbf{n}\}_\mathbf{n}\sim_\mathrm{GLT}\kappa\) _if and only if there exist_ \(\{B_{\mathbf{n},j}\}_\mathbf{n}\sim_\mathrm{GLT}\kappa_j\) _such that_ \(\{\{B_{\mathbf{n},j}\}_\mathbf{n}\}_j\longrightarrow^{a.c.s.wrt j}\{A_\mathbf{n}\}_\mathbf{n}\) _and_ \(\kappa_j\rightarrow\kappa\) _in measure._

**GLT 5** _If_ \(\{A_\mathbf{n}\}_n\sim_\mathrm{GLT}\kappa\) _and A**<sub>n</sub>**=X**<sub>n</sub>**+Y**<sub>n</sub>**, where_

• _every X**<sub>n</sub>** is Hermitian,_<tbc>

• ||_X**<sub>n</sub>_||, \(||Y_\mathbf{n}||\le C\) _for some constant C independent of n,_<tbc>

• \(N(\mathbf{n})^{-1}\|Y_\mathbf{n}\|_1\rightarrow 0\),

_then_ \(\{A_\mathbf{n}\}_n\sim_\lambda\kappa\).

**GLT 6** _If_ \(\{A_\mathbf{n}\}_n\sim_\mathrm{GLT}\kappa\) _and each A**<sub>n</sub>** is Hermitian, then_ \(\{f(A_\mathbf{n})\}_n\sim_\mathrm{GLT}f(\kappa)\) _for every continuous function_ \(f:\mathbb{C}\rightarrow\mathbb{C}\).
