## Case 1 - Example 2.

Here, the zero set of the rearranged spectral symbol has a measure

\(1-\frac{1}{4\pi}\approx 0.9204.\)

The measured proportions appear to approach this value with an O(_n_<sup>-1</sup>) rate of decay, with the error falling below 10<sup>-3</sup> by _n_=160.

## Case 2 - Example 1.

Here the expected spectral symbol is zero, but the momentary symbol perturbation, as observed in Figure 9.5, produces an apparent plateau 0.5 up to _n_=320, where the proportion jumps to 1 and the measured error vanishes. Since the momentary perturbation does not create proper outliers, as observed in **Case 1 - Example 2**, a faster convergence can reasonably be expected in this case.
