An important challenge consists thus in identifying efficient algorithms for the enumeration of PMCs. Since BT-enum is output-quadratic, a natural question is whether an output-linear time PMC enumeration algorithm can be built. This question is part of the list of open problems in parameterized and exact computations at IPEC 2006 conference \[2\], and was also stated in several articles \[12, 18, 21, 23, 29\] as a way to obtain a faster exponential time algorithm for Treewidth. Indeed, a PMC enumeration algorithm running in \(O(n^{O(1)}|\Pi_G|)=\tilde{O}(|\Pi_G|)^1\) would imply the same time complexity for Treewidth, improving the current \(\tilde{O}(|\Delta_G|^2)\), especially on graphs where values \(|\Delta_G|\) and \(|\Pi_G|\) are close. In this paper, we answer positively to this open question.

A bunch of results on PMCs deals with their number in function of _n_. Fomin and Villanger presented the two most recent ones. In the first one \[15\], they prove that \(|\Pi_G|=O(1.7549^n)\) and, moreover, the list \(\Pi_G\) can be computed in time _O_(1.7549_<sup>n</sup>_), matching tightly this upper bound. In the second one \[16\], they establish exactly the same contributions, but with the new bound _O_(1.7346_<sup>n</sup>_). Since the computation of PMCs is the bottleneck for Treewidth, this latter result offers the possibility to solve it in exponential time _O_(1.7346_<sup>n</sup>_). This is, to the best of our knowledge, the lower running time for Treewidth if we look at exact exponential-time algorithms, function of _n_. Unfortunately, this enumeration algorithm for PMCs admits some limits in practice, since it may take time \(\Theta(1.7346^n)\) while the size of \(\Pi_G\) is much smaller. Moreover, this bound is probably not tight. For these reasons, the importance of designing an output-linear time algorithm for PMC enumeration is reinforced.

While Fomin and Villanger studied deeply the enumeration of PMCs through extremal combinatorics, they also identified other applications \[12, 15, 16\]. One of their interesting results follows \[16\]. Given a graph _G_, an integer \(t\ge 0\), and sets \(\Delta_G\) and \(\Pi_G\), one can compute the largest induced subgraph of treewidth at most _t_ in time \(O(n^{O(t)}(|\Pi_G|+|\Delta_G|))\). We call this problem \(\text{lis-}(\text{tw}\le t)\). Since enumerating PMCs can be done in time \(O(n^2m|\Delta_G|^2)\) as written above, this result can be restated as function of the input graph only. Given a graph _G_ and an integer \(t\ge 0\), \(\text{lis-}(\text{tw}\le t)\) can be solved in time \(O(n^{O(t)}|\Delta_G|^2)\). Again, our main contribution to PMC enumeration will allow us to improve this statement.

Furthermore, a few years later, this result was generalized to a larger set of problems in \[14\]. In fact, given a graph _G_ and its set of PMCs \(\Pi_G\), an integer \(t\ge 0\), and a CMSO<sup>2</sup> formula \(\varphi\), one can compute in time \(O(n^{O(t)}\cdot f(t,\varphi)\cdot|\Pi_G|)\) the largest set of vertices \(X\subseteq F\) such that _F_ has treewidth at most _t_ and \((G[F],X)\vDash\varphi\), where _f_ is some exponential function. Behind this rather abstract formulation - let us call it \(\text{max-}(\text{tw}\le t,\varphi)\) - we can find many problems, classical ones as Maximum Independent Set and Maximum Induced Forest and more exotic ones as Independent Cycle Packing and Maximum Induced Subgraph with \(\le\ell\) copies of _p_-cycles.

In 2014, a major algorithmic impact of PMCs came with the design of a polynomial-time algorithm for Maximum Weight Independent Set (MWIS) on _P_<sub>5</sub>-free graphs by Lokshtanov, Vatshelle and Villanger \[24\]. The algorithm consists in two steps: first the computation of a polynomial-size family F of particular PMCs, second a dynamic programming procedure based on F to retrieve the maximum-weighted independent set.
