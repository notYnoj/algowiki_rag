<tbc>(_a,v_)-path _P_ intersecting _S_ only in _b_. Path _P_ necessarily traverses a variable gadget to go from _a_ to _b_ without intersecting _S_, since clause vertices belong to _S_ (they are adjacent to _a_). Hence, some "column" of a variable gadget (of the form \(\overline{\alpha_i},\beta_i\) or \(\alpha_i,\overline{\beta_i}\)) does not belong to _S_, so to \(\Omega\). As this column is adjacent to \(a_i,b_i\in M\), then, \(a_i,b_i\in S\). If \(v\notin\{\beta_i,\overline{\beta_i}\}\), we have a contradiction: it is not possible to build an (_a,v_)-path intersecting _S_ only in _a<sub>i</sub>_, this path will necessarily intersect either _b_ or a clause vertex, which are also in _S_. Else, if \(v\in\{\beta_i,\overline{\beta_i}\}\), then it is not possible to build an (_a,v_)-path intersecting _S_ only in _a<sub>p</sub>_, with \(p\neq i\), without passing through either _b_ or a clause vertex. Consequently, _S_ is not minimal, contradicting \(b\in S\). Thus, \(\Omega\) contains a minimal (_a,b_)-separator _S_.

We pursue with the hypothesis \(b\in\Omega\) since it does not influence the validity of this explanation. We must necessarily have at least two vertices per gadget to obtain an (_a,b_)- separator \(S=N(C(a,\Omega))\). Moreover, for each variable gadget, we cannot pick only the \(\beta\)-vertices, as it would create a conflict pair (_b,a<sub>i</sub>_). Same observation for \(\alpha\)-vertices: it would create a conflict pair (_b<sub>i</sub>,b<sub>p</sub>_), with any \(p\neq i\). In summary, for any variable gadget \(1\le i\le n\), two of the vertices in \(T_i=\Omega\cap\{\alpha_i,\beta_i,\overline{\alpha_i},\overline{\beta_i}\}\) form a diagonal pair, for instance \(\alpha_i,\beta_i\). In addition with it, if we have |_T<sub>i</sub>_|=3 for some index _i_, then a vertex of _T<sub>i</sub>_ will for sure not see _b_. So, for any \(1\le i\le n\), |_T<sub>i</sub>_|=2 and _T<sub>i</sub>_ is made up with diagonal pairs. In this situation, \(C(a,\Omega)\) is adjacent to all vertices of \(\Omega\) except _b_, in particular \(M\unknown N(C(a,\Omega))=S\). As a conclusion, \(\Omega\) contains a minimal (_a,b_)-separator _S_ extending _M_.

**Corollary 4.** PMC Subset _is NP-complete._
