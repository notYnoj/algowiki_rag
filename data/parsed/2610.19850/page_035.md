<tbc>_D_<sub>_i_+1</sub> was already inclusion-wise minimal. Finally, we fix _C_<sub>_i_+1</sub> as the connected component of \(G\backslash(\Omega\cup D_{i+1})\) containing _a_. By definition of _D_<sub>_i_+1</sub> and \(D'_{i+1}\), properties (a) and (b) are satisfied. As \(C'_i\cup\{d_{i+1}\}\subseteq C_{i+1}\) and previously \(C_i\subseteq C'_i\), the inclusion property (e) is satisfied. Given that _C_<sub>_i_+1</sub> is a connected component of \(G\backslash(\Omega\cup D_{i+1})\) which contains _a_, then obviously \(a\notin D_{i+1}\) and thus \(a\notin D'_{i+1}\), which gives (c). It remains to prove that \(D_{i+1}\subseteq N_G(C_{i+1})\).

Observe again that \(D'_i\) and _D_<sub>_i_+1</sub> are minimal separators of the same pair (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>) in the same graph \(G[\overline{\Omega}\cup\{u_{i+1},v_{i+1}\}]\). Since _D_<sub>_i_+1</sub> is the close (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>)-separator of this graph, then \(D'_i\) and _D_<sub>_i_+1</sub> are parallel (Lemma 5). As a consequence, for any \(x\in D_{i+1}\), there exists a path _P<sub>x</sub>_ from _x_ to some \(y\in D'_i\) whose internal vertices do not belong to \(\Omega\cup D'_i\cup D_{i+1}\) (Lemma 3). Therefore, any path from _a_ to \(y\in D'_i\) whose internal vertices belong to \(C'_i\) can be extended to \(x\in D_{i+1}\): the obtained path has internal vertices belonging to \(V\backslash(\Omega\cup D_{i+1})\). Said differently, the connected component of \(G\backslash(\Omega\cup D_{i+1})\) containing _a_ admits the whole set _D_<sub>_i_+1</sub> in its neighborhood: \(D_{i+1}\subseteq N_G(C_{i+1})\). Finally, (d) is also completed.

**Case B**: all pairs separated by \(D'_i\) are separated closely, but there exists a pair (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>) separated by \(D'_i\) in \(G[\overline{\Omega}\cup\{u_{i+1},v_{i+1}\}]\) such that, among {_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>}, none of these two vertices is at the same time fully adjacent to \(D'_i\) and disconnected from \(C'_i\).

Assume w.l.o.g. that _u_<sub>_i_+1</sub> is fully adjacent to \(D'_i\): \(D'_i\subseteq N_G(u_{i+1})\). In Case B, necessarily, _u_<sub>_i_+1</sub> is adjacent to \(C'_i\). Therefore, _v_<sub>_i_+1</sub> is not adjacent to \(C'_i\). Consequently, _v_<sub>_i_+1</sub> is not fully adjacent to \(D'_i\), otherwise Case B would not be satisfied (because of _v_<sub>_i_+1</sub>). We fix _D_<sub>_i_+1</sub> as the close (_v_<sub>_i_+1</sub>_,u_<sub>_i_+1</sub>)-separator in \(G[\overline{\Omega}\cup\{u_{i+1},v_{i+1}\}]\). Separators \(D'_i\) and _D_<sub>_i_+1</sub> are different as _v_<sub>_i_+1</sub> is not fully adjacent to \(D'_i\). As they separate the same pair in the same graph, \(D'_i\backslash D_{i+1}\neq\emptyset\). As \(C'_i\) is not adjacent to _v_<sub>_i_+1</sub>, then \(D_{i+1}\cap C'_i=\emptyset\). Furthermore, component \(C'_i\) is fully adjacent to \(D'_i\) (consequence of (d)), so graph \(G\backslash(\Omega\cup D_{i+1})\) contains a connected component which includes \(C'_i\) (as \(D_{i+1}\cap C'_i=\emptyset\)) and its adjacent vertices \(D'_i\backslash D_{i+1}\). Let _C_<sub>_i_+1</sub> be this connected component which contains _a_. Finally, we fix \(D'_{i+1}\subseteq D_{i+1}\) as an inclusion-wise minimal separator between pairs of \(S\times S\).

Again, by definition, items (a) and (b) are satisfied. The observations above lead us to the same conclusion for item (e): \(C_i\unknown C'_i\cup(D'_i\backslash D_{i+1})\subseteq C_{i+1}\). As for Case A, _C_<sub>_i_+1</sub> contains _a_, so _D_<sub>_i_+1</sub> and \(D'_{i+1}\) do not, fulfilling (c). To finish, we use the same observation as for Case A: _D_<sub>_i_+1</sub> and \(D'_i\) are separators of the same pair in the same graph, and _D_<sub>_i_+1</sub> is closer to _v_<sub>_i_+1</sub>. Therefore, for any \(x\in D_{i+1}\), there exists a path from _a_ to _x_ passing through some vertex \(y\in D'_i\). The internal vertices of this path belong to \(V\backslash(\Omega\cup D_{i+1})\). In other words, any vertex of _D_<sub>_i_+1</sub> belongs to the neighborhood of _C_<sub>_i_+1</sub>, which completes item (d).

_Conclusion._ We were able to introduce an inductive process which produces successive separators while the given \(D'_i\) does not satisfy the theorem requirements. Figure 11 provides an example of such shutter construction. Note that the sequence \((C_i)_{i\ge 1}\) is strictly increasing. Since it cannot grow infinitely (|_C<sub>i</sub>|\<n_), the process will necessarily stop at some moment \(k\ge 0\). This will occur when neither Case A nor Case B will be satisfied. Thus, all pairs separated by \(D'_k\) will be separated closely. Moreover, as Case B is not satisfied, for each pair separated by \(D'_k\), at least one separated vertex will be not only adjacent to the whole \(D'_k\) but also non adjacent to \(C'_k\), the connected component of \(G\backslash(\Omega\cup D'_k)\) which contains _a_. Set \(D'_k\) is thus an _a_-shutter (Definition 21), this completes our proof of existence. Note that either \(D'_0=\{a\}\) is returned, or it is \(D'_k\) with _k\>_0 and then \(a\notin D'_k\) by (c).
