whose internal vertices belong to \(\overline{\Omega}\cap C_G(T,S)\subseteq\overline{X'}\).<tbc>

• For any \(s\in S\backslash\{x\}\), \(T\subseteq R_G(s,X')\): again, as \(\Omega\) is a PMC of _G_, there is path from _s_ to any \(t\in T\) whose internal vertices belong to \(\overline{\Omega}\cap C_G(T,S)\subseteq\overline{X'}\).<tbc>

• \(S\backslash\{x\}\subseteq R_G(a,X')\): the reason is quite different here, _S_ is a minimal separator of _G_ and _C<sub>G</sub>(a,S_) is a full component for _S_ in _G_. Therefore, as \(a\in C_G(a,S)\) by definition, for each \(s\in S\backslash\{x\}\), there exists a path from _a_ to _s_ in _G_ whose internal vertices only belong to _C<sub>G</sub>(a,S_)\\{_a_}. This gives also a path from _a_ to _s_ whose internal vertices belong to \(\overline{X'}\), as \((C_G(a,S)\backslash\{a\})\cap X'=\emptyset\).

Consequently, the only conflictual pairs of \(X'\) belong to \(S\times S\), or more precisely to \((S\backslash\{x\})\times(S\backslash\{x\})\). Note also that pairs in \((S\backslash S_D)\times(S\backslash S_D)\) are not conflictual: if one such pair was, then it would contradict Definition 22 as for some pair separated by _D_, none of its vertices would belong to _S<sub>D</sub>_. Finally, we conclude that conflictual pairs only involve pairs in \(S_D\times S_D\) and \(S_D\times(S\backslash S_D)\).

We pursue the removal process, by first removing all conflicts for \(y\in S\backslash S_D\) and, second selecting new protected vertices in _S_\\_S<sub>D</sub>_ if it is possible, otherwise in _S<sub>D</sub>_ if all vertices of _S_\\_S<sub>D</sub>_ do not have any conflict. As vertices of \(T\cup\{a\}\) are not involved in any conflictual pair, the obtained set \(\Omega_a\) contains \(T\cup\{a\}\). Remember that the native connected components of _X_ could not be adjacent to the whole set \(T\cup\{a\}\): since only native connected components can avoid our resulting set to be a PMC (Theorem 5), there is no chance it can occur as \(T\cup\{a\}\unknown\Omega_a\). As a conclusion, \(\Omega_a\) is a PMC. Moreover, as we avoid the removal of vertices in _S_\\_S<sub>D</sub>_ by selecting them as protected vertices, we have \(X'\backslash\Omega_a\unknown S_D\). More generally, as \(x\in S_D\), we have \(X\backslash\Omega_a=S\backslash\Omega_a\subseteq S_D\). In summary, \(\Omega_a\) contains \(T\cup\{a\}\) together with some vertices of _S_, denoted by \(\widehat{S}\), such that \(S\backslash\widehat{S}=X\backslash\Omega_a\subseteq S_D\), proving the first part of the theorem.

It remains to prove that \((\Omega_a,\Omega)\in\mathcal{N}\). Consider thus the set \(\Omega_a\) and fix _u_<sup>∗</sup>=_a_ (following Definition 20). We obtain the PMC superset \(X^*=\Omega_a\cup N_G(a)\). As all vertices removed from _X_ in the process, _i.e._ in \(X\backslash\Omega_a\), belong to _S<sub>D</sub>_ and are adjacent to _a_, we have \(\Omega\unknown X^*\) and, even, \(\Omega=X^*\cap(S\cup C_G(T,S))\). Fix \(b^*\in T\). As \(\Omega\) is a PMC of _G_, vertex _b_<sup>∗</sup> reaches all vertices of _S_ via internal vertices in \(C_G(T,S)\backslash T\subseteq\overline{X^*}\). Hence, _S_ is the _X_<sup>∗</sup>-close (_b_<sup>∗</sup>_,u_<sup>∗</sup>)-separator of _G:S_<sup>∗</sup>=_S_. As all vertices of \(\Omega\) belong to \(S\cup C_G(b^*,S^*)\), the removal of \(X^*\backslash(S\cup C_G(b^*,S^*))\) gives us the PMC \(\Omega\).

## 4.3.2 When _a_ does not belong to the _a_-shutter

The notion of shutter-close set needs to be slightly adapted to this different scenario.
