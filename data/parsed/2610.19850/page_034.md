(d) _C<sub>i</sub>_ is the connected component of \(G\backslash(\Omega\cup D_i)\) which contains _a_, _i.e._ \(C_i=C_G(a,\Omega\cup D_i)\), and such that _D<sub>i</sub>_ is included into the neighborhood of _C<sub>i</sub>_, _i.e._ \(D_i\subseteq N_G(C_i)\);<tbc>

(e) for any \(i\ge 2\), \(C_{i-1}\unknown C_i\).

At each step, we show that if \(D'_i\) does not satisfy the theorem requirements, then we can define _D_<sub>_i_+1</sub>, \(D'_{i+1}\) and _C_<sub>_i_+1</sub> satisfying the induction properties. Since _C<sub>i</sub>_ augments at each step (condition (e)), then the process necessarily stops at some moment and the theorem holds.

_Base case: iteration i_=1. We fix _D_<sub>1</sub> as the close (_u_<sub>1</sub>_,v_<sub>1</sub>)-separator in graph \(G[\overline{\Omega}\cup\{u_1,v_1\}]\). Set _D_<sub>1</sub> does not contain _a_ as \((a,u_1)\notin E(G)\). Hence, graph \(G\backslash(\Omega\cup D_1)\) admits a connected component containing _a_: we fix it as _C_<sub>1</sub>. If _D_<sub>1</sub> is not inclusion-wise minimal, we fix \(D'_1\) any proper subset of _D_<sub>1</sub> which is inclusion-wise minimal and separate pairs of \(S\times S\). By definition, bullets (a), (b), (c) are satisfied and (e) does not have to be checked for the case _i_=1. For (d), by definition, _C_<sub>1</sub> contains _a_, but it remains to prove that \(D_1\subseteq N_G(C_1)\). Since _D_<sub>0</sub>={_a_} was an (_u_<sub>1</sub>_,v_<sub>1</sub>)-separator in \(G[\overline{\Omega}\cup\{u_1,v_1\}]\), any path from _u_<sub>1</sub> to _v_<sub>1</sub> whose internal vertices belong to \(\overline{\Omega}\) passes through vertex _a_. Furthermore, as _D_<sub>1</sub> is a minimal (_u_<sub>1</sub>_,v_<sub>1</sub>)-separator in the same graph \(G[\overline{\Omega}\cup\{u_1,v_1\}]\), for every \(d\in D_1\), there exists a path from _u_<sub>1</sub> to _v_<sub>1</sub> passing through _d_ and whose internal vertices belong to \(\overline{\Omega\cup D_1}\). Consequently, this highlights the existence, for each \(d\in D_1\), of a path from _a_ to _d_ whose internal vertices belong to \(V(G)\backslash(\Omega\cup D_1)\). In brief, _C_<sub>1</sub> is adjacent to _d_ in _G_, for each \(d\in D\), so \(D_1\subseteq N_G(C_1)\).

_Induction step_. Assume by induction hypothesis that all properties (a)-(e) hold for some \(i\ge 1\). We also assume that \(D'_i\) does not satisfy the theorem requirements, otherwise we are done. There can be two reasons for that: either \(D'_i\) separates some pair "unclosely", or for some pair separated closely by \(D'_i\), the "close vertex" of the pair is adjacent to the connected component of _a_. We distinguish these two cases.

**Case A:** there exists a pair (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>) which is separated by \(D'_i\) in \(G[\overline{\Omega}\cup\{u_{i+1},v_{i+1}\}]\) but not closely.

We denote by \(C'_i\) the connected component of \(G\backslash(\Omega\cup D'_i)\) which contains _a_. Naturally, \(C_i\subseteq C'_i\) as \(D'_i\subseteq D_i\): indeed, the removal of vertices from _D<sub>i</sub>_ to obtain \(D'_i\) could only make the component _C<sub>i</sub>_ grow up. Moreover, as _D<sub>i</sub>_ was fully adjacent to _C<sub>i</sub>_, then its subset \(D'_i\) will also be fully adjacent to \(C'_i\supseteq C_i\), in brief \(D'_i\subseteq N_G(C'_i)\).

A crucial observation is here: _u_<sub>_i_+1</sub> and _v_<sub>_i_+1</sub> cannot be both adjacent to the connected component \(C'_i\). Otherwise, _D<sub>i</sub>_ would not be a (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>)-separator. Assume w.l.o.g. that either _v_<sub>_i_+1</sub> is adjacent to \(C'_i\) in _G_ or none of these two vertices {_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>} are adjacent to \(C'_i\). We fix _D_<sub>_i_+1</sub> equal to the close (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>)-separator in \(G[\overline{\Omega}\cup\{u_{i+1},v_{i+1}\}]^6\). As \(D'_i\) does not separate (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>) closely, there exists a vertex \(d_{i+1}\in D'_i\) such that _u_<sub>_i_+1</sub> is not adjacent to _d_<sub>_i_+1</sub>. _D_<sub>_i_+1</sub> thus satisfies \(D_{i+1}\neq D'_i\). Moreover, as they are minimal separators of the same pair (_u_<sub>_i_+1</sub>_,v_<sub>_i_+1</sub>) in the same graph \(G[\overline{\Omega}\cup\{u_{i+1},v_{i+1}\}]\), they cannot be included one into another. Hence, \(D'_i\backslash D_{i+1}\) is nonempty and will contain at least _d_<sub>_i_+1</sub>. As a consequence, regarding graph \(G\backslash(\Omega\cup D_{i+1})\), component \(C'_i\) will _grow up_ in a larger component containing _d_<sub>_i_+1</sub>, as _D_<sub>_i_+1</sub> is closer to _u_<sub>_i_+1</sub> than \(D'_i\), and \(d_{i+1}\in N_G(C'_i)\). Formally, set \(C'_i\cup\{d_{i+1}\}\) is included into the connected component of \(G\backslash(\Omega\cup D_{i+1})\) containing _a_.
