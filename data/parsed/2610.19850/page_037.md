As _S<sub>D</sub>_ is defined as inclusion-wise minimal, we have \(S_D\neq S\). Indeed, if it was the case, _D_ would be adjacent to any \(s\in S\), by definition of _S<sub>D</sub>_. For any fixed \(x\in S\), for all separated pairs containing _x_, _i.e._ of the form (_x,y_), we could put _y_ inside _S<sub>D</sub>_ instead of _x_ and hence _x_ could be removed: Definition 22 would still hold as all separated pairs are represented but \(S_D\subseteq S\backslash\{x\}\). This fact is the consequence of the following lemma, which implies that _S_\\_S<sub>D</sub>_ is nonempty.

**Lemma 18** (Property of shutter-close sets)**.** _Consider an a-nice_ \(PMC\Omega\) _of G,_ \(S=N(C_G(a,\Omega))\) _and an a-shutter D with shutter-close set S<sub>D</sub>. There is at least one pair_ \((x,y)\in S\times S\) _separated by D in_ \(G[\overline{\Omega}\cup\{x,y\}]\)_, such that_ \(x\in S_D\) _and_ \(y\notin S_D\).

_Proof._ Assume by way of contradiction that no such pair exists. According to Definition 22, every pair separated by _D_ admits at least one of its vertices in _S<sub>D</sub>_. Consequently, all pairs separated by _D_ are included into \(S_D\times S_D\). Consider any element \(x\in S_D\) and let \(\varphi_S(x)\) be the set of vertices which are separated from _x_ by _D_: due to our hypothesis, \(\varphi_S(x)\unknown S_D\). Consider set \(S'_D=S_D\backslash\{x\}\): it satisfies \(\varphi_S(x)\subseteq S'_D\). As \(S'_D\unknown S_D\), naturally all vertices of \(S'_D\) are fully adjacent to _D_. Moreover, since separated pairs involving _x_ admit a second vertex inside _S<sub>D</sub>_, then all pairs separated by _D_ are intersected in \(S'_D\). Set \(S'_D\) satisfies the two bullets of Definition 22 and is a proper subset of _S<sub>D</sub>_, contradicting the minimality of _S<sub>D</sub>_.

We can see also the shutter-close set as a _minimal colored vertex cover_ of some bicolored graph \(H(\Omega,D)\) whose vertex set is made up of _S_ and two vertices \((v,w)\in S\times S\) are adjacent iff they are separated by _D_ in \(G[\overline{\Omega}\cup\{v,w\}]\). We color in blue the vertices which are fully adjacent to _D_, in red the others. By Definition 21, we know that the blue vertices form a vertex cover of \(H(\Omega,D)\). Nevertheless, this blue vertex cover is not necessarily inclusion-wise minimal, which justifies the definition of shutter-close sets: see Figure 12 for an illustration.

In the remainder, set _S<sub>D</sub>_ represents a set of candidates to be withdrawn from \(\Omega\) in order to obtain another \(PMC\Omega'\) such that \((\Omega',\Omega)\in\mathcal{N}\). We will consider first the case where _D_={_a_}.
