<tbc>Finally, there are now _T_! orders in which the remaining queens might have been placed on the board. Thus, the number of ways to obtain the configuration is at most

\(Y:=\genfrac(){pt}{2}{n}{2(n-T)}(2(n-T))!!\times 2^{n-T}\times T!\le n^{2(n-T)}(2(n-T))^{2(n-T)}2^{n-T}n!\)<br>
\(\le\left(1+\tilde{O}(n^{-\alpha})\right)^nn!.\)

Applying Stirling’s approximation:<tbc>

\(Y\le\left(\left(1+\tilde{O}(n^{-\alpha})\right)\frac{n}{e}\right)^n.\)

<tbc>Therefore, the number of _n_-queens configurations satisfies

\(\mathcal{Q}(n)\ge\frac{X}{Y}\ge\frac{\left(\left(1-\tilde{O}(n^{-\alpha})\right)\frac{n^2}{e^4}\right)^n}{\left(\left(1+\tilde{O}(n^{-\alpha})\right)\frac{n}{e}\right)^n}\ge\left(\left(1-\tilde{O}(n^{-\alpha})\right)\frac{n}{e^3}\right)^n,\)

as desired.

## 6. Concluding remarks

\(\bullet\) We have established that \(liminf_{n\rightarrow\infty}\frac{\mathcal{Q}(n)^{1/n}}{n}\ge e^{-3}\). In \[8\] the first author proved that for \(\alpha\approx 1.587\), \(limsup_{n\rightarrow\infty}\frac{\mathcal{Q}(n)^{1/n}}{n}\le e^{-\alpha}\). It would be interesting to close this gap. In particular, \[16\] provides numerical evidence that for \(\beta\approx 1.944\), \(lim_{n\rightarrow\infty}\frac{\mathcal{Q}(n)^{1/n}}{n}=e^{-\beta}\).<tbc>

\(\bullet\) A curious feature of our algorithm is that although, ultimately, it constructs a _non-toroidal_ configuration, the random greedy algorithm actually constructs an approximate _toroidal_ configuration.

As mentioned in the introduction the toroidal algorithm has a regularity which makes its analysis more amenable than its non-toroidal counterpart. Nevertheless, in computer simulations we have found the non-toroidal algorithm extremely successful at constructing approximate configurations. Furthermore, (for \(n\ge 100\) and as large as 10<sup>7</sup>) we have never seen Algorithm 2.2 fail to obtain a complete configuration.

Ours is not the first random greedy algorithm used to construct _n_-queens configurations: In \[9\] configurations were generated by proceeding through the board’s rows from top to bottom, where in each row a queen was placed uniformly at random among the available positions. Finally, a min-conflicts algorithm was used to modify the board and find a complete solution. This algorithm was found to construct complete configurations with ease, but it was not analyzed formally. We have found this algorithm to possess a non-uniformity making its analysis challenging as well.

Conversely, we wonder if the output of Algorithm 2.1 can be completed to a toroidal configuration (assuming _n_=1,5mod6, which is a necessary condition). If so, this would give a lower bound of ((1-_o_(1))_ne_<sup>-3</sup>)_<sup>n</sup>_ on such configurations, matching an upper bound of the first author \[8, Theorem 1.2\].<tbc>
