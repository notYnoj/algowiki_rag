<tbc>Line 20. Note that by the time we get to Line 20, the only vertices remaining in _G_ must have been marked heavy, because otherwise the while loop in Line 11 would continue. We now show that if _x_ and _y_ are marked heavy then \(\mathrm{dist}_{G_0}(x,y)\le D/2\), which implies that the algorithm does not terminate in Line 20. To see that \(\mathrm{dist}_{G_0}(x,y)\le D/2\), recall that we are assuming the statement of Claim 6.7, so \(\mathrm{Ball}_{G_0}^{in}(x,D/4)>|V(G_0)|/2\) and \(\mathrm{Ball}_{G_0}^{out}(x,D/4)>|V(G_0)|/2\), so there is some vertex _w_ in the intersection of the two balls, so \(\mathrm{dist}_{G_0}(x,y)\le\mathrm{dist}_{G_0}(x,w)+\mathrm{dist}_{G_0}(w,y)\le D/4+D/4=D/2\). (Note that _w_ might not be marked heavy and also might have been removed from _G_, which is why we only guarantee weak diameter.)

Thus, since Claim 6.7 holds with probability \(\ge 1-O(1/n^{19})\), we know that with this same probability the algorithm does not terminate in Line 20, and does not terminate in the the second condition of Line 15.

We now need to bound the probability of terminating in the first condition of Line 15 (i.e. _R<sub>v</sub>\>D/_4). Recall that _p_=min{1,80log(_n)/D_} and the definition of the geometric distribution (Definition 6.2). Every time the algorithm samples _R<sub>v</sub>_∼Geo(_p_) in Line 12 we have that Pr\[_R<sub>v</sub>\>D/_4\]=Pr\[the first D/4 coins are all tails\]=\((1-p)^{D/4}\le(1-\frac{80\mathrm{log}(n)}{D})^{D/4}<1/n^{20}\). Since each variable _R<sub>v</sub>_ is associated with a specific vertex _v_, a union bound over all \(|V(G_0)|\le n\) vertices completes the proof.

## 6.4 Bounding \(Pr[e\in E^{rem}]\)

Observe that \(e\in E^{rem}\) if in one of the recursive calls it is either (i) added to _E<sup>boundary</sup>_ on Line 14, or (ii) added to _E<sup>rem</sup>_ before a recursive call terminates on Lines 15 and 20. The latter case was shown in the previous subsection (Claim 6.8) to happen with probability _O(n_<sup>-19</sup>) in each recursive call, thus with probability _O(n_<sup>-18</sup>log(_n_)) over all _O(n_log_n_) recursive calls (Observation 6.4). Below (Corollary 6.10), we show that the former case happens with probability \(O\left(\frac{w(e)\cdot(\mathrm{log}n)^2}{D}\right)\) over all recursive calls. So, the probability that _e_ is added to _E<sup>rem</sup>_ in any of the recursive calls is \(O\left(\frac{w(e)\cdot(\mathrm{log}n)^2}{D}+\frac{\mathrm{log}(n)}{n^{18}}\right)=O\left(\frac{w(e)\cdot(\mathrm{log}n)^2}{D}+n^{-10}\right)\) as claimed.

**Lemma 6.9.** _In a single call of Algorithm 3 (ignoring all future recursive calls),_

\(Pr[e\in E^{boundary}]=O\left(\frac{w(e)\cdot(\mathrm{log}n)}{D}\right).\)

_Proof intuition._ We provide a formal proof of Lemma 6.9 in Appendix D. For an intuition, note that since _R<sub>v</sub>_ is the number of coin tosses until obtaining the first head (Definition 6.2), the algorithm can be viewed as the following _ball-growing process:_ Start with a ball \(\mathrm{Ball}_G^*(v,1)\) of radius 1 at some vertex _v_ and \(*\in\{in,out\}\). We flip a coin that turns head with probability _p_. Every time we get a tail, we increase the radius of the ball by one. We stop when we get a head. We then put all edges in \(\partial\mathrm{Ball}_\mathrm{G}^*(v,R_v)\) into _E<sup>boundary</sup>_ and cut out the ball. We may then repeat the ball growing process from a new vertex.

To analyze \(Pr[e\in E^{boundary}]\), consider any edge (_x,y_). Consider the first time that _x_ is contained in a ball \(B_G^*(v,r)\) (for some _r_) during the ball-growing process above. Observe that if the next _w(x,y_) coin tosses all return tails, then (_x,y_) will _not_ be in _E<sup>boundary</sup>_ (because _y_ is either in the ball \(B_G^*(v,r+w(x,y))\) or is no longer in _G_). In other words, \(Pr[e\in E^{boundary}]\) is at most the probability that one of the next _w(x,y_) coin tosses returns head. This is at most \(p\cdot w(x,y)=O\left(\frac{w(e)\cdot(\mathrm{log}n)}{D}\right)\).

**Corollary 6.10.** _For any edge e, the probability that_ one _of the recursive calls adds e to E<sup>boundary</sup> is_ \(O\left(\frac{w(e)\cdot(\mathrm{log}n)^2}{D}\right)\).
