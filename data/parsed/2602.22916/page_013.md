It is highly beneficial to describe the algorithm in terms of part-wise aggregations. Then, the algorithm can be applied simultaneously in multiple subgraphs via low-congestion shortcuts. This is often used in the applications, where also the spanning tree _T_ of _G_ might be arbitrary, which (from our perspective) is given as input. Thus, we assume a given partition of _G_ into vertex-disjoint bi- connected subgraphs \(\{G_i\}_{i=1}^k\), and for each _G<sub>i</sub>_ an arbitrary spanning tree _T<sub>i</sub>_, and describe the algorithm for a specific subgraph _G<sub>i</sub>_ assuming we have low-congestion shortcuts constructed. This guarantees the algorithm can run on all _G<sub>i</sub>_ simultaneously at the same round complexity. If one only wants to compute a separator of _O(D_) vertices in _G_, then we compute a BFS tree _T_ of depth _O(D_) of _G_ in _O(D_) rounds [17], and apply the algorithm on _G_ with _T_ as an input. To simplify notation, in the remainder of this section we use _G_ and _T_ instead of _G<sub>i</sub>_ and _T<sub>i</sub>_.

**Learning the cotree** _T_<sup>∗</sup> **(Step 1).** This step is the same as that of [9]. Intuitively, the given spanning tree _T_ of _G_ defines a dual cotree _T_<sup>∗</sup> s.t. an edge is in _T_<sup>∗</sup> iff it is not in _T_ (Lemma 1). Since vertices of _G_ know their incident _T_ edges, they also know their incident _T_<sup>∗</sup> edges. The correspondence between primal edges and dual edges (IDs of faces that contain them) is known in \(\tilde{O}(D)\) rounds by Lemma 9.

**Lemma 12** (Learn cotree [9])**.** _In deterministic_ \(\tilde{O}(D)\) _rounds, each vertex_ \(v\in G\) _learns for each incident e edge whether it is in T_<sup>∗</sup>.

_Proof._ We use Lemma 9 to assign each face _f_ of _G_ an ID. In the output format, for each face _f_, vertices _v_ on _f_ know the ID of _f_. In addition, _v_ learns for each incident edge _e_ the two IDs of the faces containing _e_ (i.e., the endpoints of _e_ in _G_<sup>∗</sup>). Given this information, learning the cotree _T_<sup>∗</sup> is immediate since all edges that are not in _T_ are in _T_<sup>∗</sup> (Lemma 1). Thus, each vertex \(v\in G\) knows for each incident edge if it is in _T_<sup>∗</sup>.

**Reducing vertex-weights to face-weights (Step 2).** This step simplifies upon the approaches of [9, 12] for computing face-weights and is the core of our algorithm. To compute the face weights, we compute a summation operator over the faces of _G_, and the result is then the faces’ weights as in Observation 1. The input of a vertex _v_ for a face _f_ that contains it is simply _v_’s weight if _v_ chose to transfer its weight to _f_ and zero otherwise (e.g., _v_ transfers its weight to the minimal ID face that contains it).

**Lemma 13** (Assign face weights)**.** _Given a weight assignment_ \(w_v(\cdot)\) _to the vertices of G, in deterministic_ \(\tilde{O}(D)\) _rounds, each face f of G is assigned a weight w<sub>F</sub>(f_) _equivalent to the sum of weights of vertices that transfer their weight to f (as in Observation 1). Upon termination, all vertices of a face f learn w<sub>F</sub>(f)._

_Proof._ We want to assign each node _f_ in _T_<sup>∗</sup> a weight as in Observation 1, that is, each vertex _v_ that participates in faces _f_<sub>1</sub>, _f_<sub>2</sub>, _..._, _f<sub>k</sub>_ chooses an arbitrary face _f<sub>i</sub>_ to transfer its weight to. Then, the weight _w<sub>F</sub>(f_) of a face _f_ is the total weight of \(w_v(v)\) for vertices _v_ that choose to transfer their weight to _f_.

To compute _w<sub>F</sub>(f_) for all faces _f_ in _G_, we use Lemma 10. Note, in the input format, each vertex on a face _f_ has an input for _f_. The input _v<sub>f</sub>_ of a vertex _v_ for a face _f_ that contains it is, \(w_v(v)\) iff _v_ chose _f_, and zero otherwise. In order for vertices to be able to choose their inputs, they need to know the faces that contain them, which is done by Lemma 9. Hence, each \(v\in G\) picks an arbitrary face (e.g. face with the minimal ID) of the faces that contains it to transfer its weight to it. Since now vertices know their inputs, via Lemma 10 (with the aggregate operator SUM), we compute in deterministic \(\tilde{O}(D)\) rounds the weight of each face as in Observation 1. Indeed, each vertex contributes to the weight of exactly one arbitrary face that contains it. Moreover, in the output format of Lemma 10, all vertices on a face _f_ know the face’s output _w<sub>F</sub>(f_).

In order to implement this step, we mainly use Lemma 11 to compute subtree sums on _T_<sup>∗</sup>, where the input for each node of _T_<sup>∗</sup> is its assigned weight from the previous step.
