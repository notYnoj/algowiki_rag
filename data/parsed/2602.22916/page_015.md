**Lemma 15** (Step S4 of \[9\])**.** _Assume that all vertices of a bi-connected graph G know the ID of_ \(\big(\frac{1}{4},\frac{3}{4}\big)\)_- balanced node f if exists, and otherwise, the ID of a_ \(\big(\frac{1}{4},\frac{3}{4}\big)\)_-critical node f. In deterministic_ \(\tilde{O}(D)\) _rounds, each vertex_ \(v\in G\) _knows its incident edges on P (if any), where P is a_ 3/4_-balanced path separator of G. In addition,_ \(P\cup\{e\}\) _is a fundamental cycle C(T,e_) _after adding the edge e_=(_u,v), where u,v are the endpoints of P. If_ \(e\notin G\)_, then u,v learn the ID of each other, and a local ordering (embedding) of e that preserves planarity._

**Removing the bi-connectivity assumption (concluding Theorem 1).** We remove the bi-connectivity assumption as in \[14\]. We mention that \[14\]’s procedure was originally randomized for using the connectivity algorithms of \[7, 9\]. Hence, it is easily derandomized as in Section 5.1.

**Lemma 16** (Appendix B.1 of \[14\])**.** _Given a planar graph G, there is a set of artificial edges_ \(E'\)_, such that,_ \(G'=G\cup E'\) _is a bi-connected planar graph._ \(G'\) _is computed in deterministic_ \(\tilde{O}(1)\) _part-wise aggregation tasks. Moreover, any round of communication in_ \(G'\) _is simulated deterministically within O_(1) _rounds in G._

We use the above to conclude the proof of Theorem 1. That is, we compute \(G'\) and run the algorithm on \(G'\). Note that _T_ is indeed a spanning tree of \(G'\) (as the algorithm expects). However, _T_’s edges are edges of _G_ (not artificial), and since the separator _P_ is a path of _T_, it is also a path of _G_. Obviously, _P_ is a balanced separator also for _G_ because there is no change in the vertex-weights. Hence:

**Theorem 1.** _Let G be an embedded planar graph of hop-diameter D, T be a spanning tree of G, and_ \(w(\cdot)\) _be a weight assignment to G’s vertices s.t. no vertex weighs more than_ \(\frac{1}{12}\) _fraction of the total weight of G. There is a deterministic_ \(\tilde{O}(D)\)_-round distributed algorithm that finds a u-to-v path P in T that is a_ \(\frac{3}{4}\)_-balanced separator of G. Adding the edge e_=(_u,v_) _to G (if it does not already exist), closes a fundamental cycle_ \(P\cup\{e\}\) _in T. Setting T to be a BFS tree produces a separator of size O(D)._

**Generalization to multiple subgraphs.** Note, given a partition \(\{G_i\}_{i=1}^k\) of _G_ into vertex-disjoint connected subgraphs, with spanning trees \(\{T_i\}_{i=1}^k\), where _T<sub>i</sub>_ is an arbitrary spanning tree of _G<sub>i</sub>_, we have described the algorithm for computing a separator of a single subgraph _G<sub>i</sub>_ in deterministic \(\tilde{O}(D)\) rounds. It easily extends to run on all subgraphs _G<sub>i</sub>_ simultaneously in the same round complexity. This follows from standard use of low-congestion shortcuts \[9, 10, 18\]. A proof is provided in Appendix A.2

**Theorem 3.** _Let_ \(\{G_i\}_{i=1}^k\) _be a partition of G into vertex-disjoint connected subgraphs, and_ \(\{T_i\}_{i=1}^k\) _be spanning trees of G<sub>i</sub>s. In addition let_ \(\{w_i(\cdot)\}_{i=1}^k\) _be_ 1/12_-proper weight assignments to G<sub>i</sub>s’ vertices. Then, there is a deterministic_ \(\tilde{O}(D)\)_-round distributed algorithm that for each G<sub>i</sub> finds a_ 3/4_-balanced path separator P<sub>i</sub> w.r.t._ \(w_i(\cdot)\) _of O_(depth(_T<sub>i</sub>_)) _vertices. In addition,_ \(P_i\cup\{e\}\) _is a fundamental cycle of T<sub>i</sub>, where e_=(_u,v_) _and u,v are the endpoints of P. In case_ \(e\notin G_i\)_, then u,v learn the ID of each other, and a local ordering (embedding) of e that preserves planarity._

## 6 Applications

Computing a balanced separator lies at the core of state-of-the-art distributed algorithms for many classical optimization problems in planar graphs. In most cases, the separator algorithm is their _only_ randomized component. In particular, it was shown in \[12\] that the (near-optimal) randomized algorithm of \[9\] for computing a DFS tree can be derandomized by replacing the randomized separator algorithm with the deterministic one of \[12\]. However, it was not mentioned in \[12\], that a deterministic separator algorithm implies a derandomization to a collection of other state-of-the-art algorithms that use the _Bounded Diameter Decomposition_ (BDD) as their only randomized component<sup>6</sup>.
