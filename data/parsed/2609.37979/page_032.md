3. **Player 2’s Turn:** Suppose the current play is at \(v'_k\in V'_2\), meaning the shadow vertex _v<sub>k</sub>_ satisfies \(v_k\in V_2\). Player 2 chooses an arbitrary edge \((v'_k,v'_{k+1})\) with weight _W_. By Lemma 7.6 (Neighborhood Preservation), since \(\chi_\infty^G(v_k)=\chi_\infty^{G^\prime}(v'_k)\), there exists an outgoing edge from _v<sub>k</sub>_ to some vertex _v_<sub>_k_+1</sub> in _G_ such that \(\chi_\infty^G(v_{k+1})=\chi_\infty^{G^\prime}(v'_{k+1})\) and _w(v<sub>k</sub>,v_<sub>_k_+1</sub>)=_W_. We append this _v_<sub>_k_+1</sub> to the shadow play.

Through this induction, every infinite play \(\pi'\) in \(G'\) conforming to \(\sigma'\) maps to a valid shadow play \(\pi\) in _G_ conforming to \(\sigma\). Crucially, the sequence of edge weights traversed in \(\pi'\) is identical to that in \(\pi\). Because \(\sigma\) is winning in _G_, the energy level along \(\pi\) satisfies \(E_k\ge 0\) for all \(k\ge 0\). Since the step-by-step weights match exactly, the energy level in \(G'\) also satisfies \(E'_k=E_k\ge 0\) for all \(k\ge 0\). Thus, \(\sigma'\) is a winning strategy for Player 1 in \(G'\).

## 7.4 Proof of Theorems 7.2 and 7.4

_Proof of Theorem 7.2._ We describe the different phases of the algorithm.

**Preprocessing:** For each graph \(G_i\in\mathcal{S}\), we run the 1-WL algorithm (Theorem 7.9) and compute its complete invariant for 1-WL equivalence (Theorem 7.10). Both subroutines run in time _O_((_n+m_)log_n_) time. We insert each string \(\mathrm{WL}_1(G_i)\in\{0,1\}^*\) into a binary search tree, where the _i_-th letter determines whether we take the left/right subtree on the _i_-th level. This takes time proportional to the length of the string WL<sub>1</sub>(_G<sub>i</sub>_), i.e., it can be done in time _O_((_n+m_)log_n_). For the corresponding node where the key WL<sub>1</sub>(_G<sub>i</sub>_) is saved, we save the _OPT<sub>i</sub>_ as well as an optimal solution path (if provided) and the stable coloring \(\chi^{G_i}\).

Note that, if two graphs \(G_i,G_j\in\mathcal{S}\) yield the same invariant, they are 1-WL equivalent (Theorem 7.10). In particular, by Theorem 7.11, this implies _OPT<sub>i</sub>=OPT<sub>j</sub>_, and no conflicting values can be assigned to a single node of the search tree. Overall, processing all _k_ graphs takes _O(k(n+m_)log_n_) time.

**Query:** Given the query graph _H_, we run the 1-WL algorithm (Theorem 7.9) and compute its complete invariant for 1-WL equivalence (Theorem 7.10) in _O_((_n+m_)log_n_) time. Looking up the computed invariant in the binary search tree takes _O_((_n+m_)log_n_) time, allowing us to return _OPT(H_)=_OPT<sub>i</sub>_ (which is correct by Theorem 7.11). If the string WL<sub>1</sub>(_H_) is not contained in the search tree, then we can correctly claim that _H_ is not isomorphic to any graph in S because graphs that are not 1-WL equivalent are not isomorphic. The total query time is _O_((_n+m_)log_n_).

**Reconstruction:** If optimal paths are stored, the lookup yields the optimal path _P<sub>i</sub>_=(_v_<sub>0</sub>_,e_<sub>1</sub>_,v_<sub>1</sub>_,...,e<sub>r</sub>,v<sub>r</sub>_) from the equivalent graph _G<sub>i</sub>_. Because \(H\equiv_{1\text{-WL}}G_i\), analogous to the proof of Theorem 7.11, we can inductively construct a correspondind walk in _H_: if we are currently at \(u'\in V(H)\) corresponding to \(v_j\in P_i\), we scan the outgoing edges of \(u'\) to find an edge \(e'\) with the same attributes as _e_<sub>_j_+1</sub> that leads to a vertex \(v'\) with the same 1-WL stable color as _v_<sub>_j_+1</sub>. The existence of such an edge is guaranteed by Lemma 7.6 (Neighborhood Preservation). Scanning for the next edge takes time proportional to the out-degree of the current vertex. Over the entire path, this takes at most _O(n+m_) time. This procedure yields a valid walk \(W'\) in _H_ with identical cost and length to _P<sub>i</sub>_. Finally, we remove cycles from \(W'\) in _O(n_) time to produce a simple optimal path _P<sub>H</sub>_. The total query time for the path remains _O_((_n+m_)log_n_).
