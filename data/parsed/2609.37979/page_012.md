## From GI with Promise to Maximum Independent Set.

Now we reduce GI with the \(G'\cong G\cong H\) promise from above to Maximum Independent Set (equivalently, Maximum Clique) with a single prior. (This reduction already exists in \[Koz78\].) Assume for contradiction that there exists an algorithm _A_ that takes a prior graph _Z_ alongside the size of its maximum independent set<sup>11</sup>, denoted \(\alpha(Z)\), preprocesses this information in polynomial time, and subsequently, for every query graph \(Z'\), either computes \(\alpha(Z')\) or declares that \(Z'\unknown\cong Z\) in polynomial time. We use _A_ to solve GI under our single-prior setting as follows.

_Constructing Prior Graph Z_: Upon receiving the prior pair (_G,H_) for GI, our reduction constructs a prior graph _Z_ as follows. For every \(u\in V(G)\) and \(v\in V(H)\), we create a vertex _z<sub>u,v</sub>_ in _Z_. We add an edge between distinct vertices _z<sub>u,v</sub>_ and \(z_{u^\prime,v^\prime}\) if the assignments \(u\mapsto v\) and \(u'\mapsto v'\) violate the isomorphism condition; i.e., we add an edge if either: (i) \((u=u')\oplus^\text{12}\) (\(v=v'\)), or (ii) the adjacency is not preserved, meaning \((u,u')\in E(G)\) but \((v,v')\notin E(H)\), or vice versa. Observe that \(\alpha(Z)=|V(G)|\) if and only if \(G\cong H\).<sup>13</sup> By the \(G\cong H\) promise, we know that \(\alpha(Z)=|V(G)|\). Thus, we pass _Z_ and its solution \(\alpha(Z)=|V(G)|\) to algorithm _A_ for preprocessing.

_Constructing Query Graph_ \(Z'\): Upon receiving a query pair \((G',H')\) for GI, we construct a graph \(Z'\) using the exact same procedure; hence, \(\alpha(Z')=|V(G')|\) if and only if \(G'\cong H'\). We then query algorithm _A_ with \(Z'\). If _A_ returns \(\alpha(Z')=|V(G')|\), we output \(G'\cong H'\); otherwise, we declare that \(G'\unknown\cong H'\).

We claim that this is always correct. If \((G,H)\cong(G',H')\), our construction guarantees that \(Z\cong Z'\) (meaning our reduction is _isomorphism-preserving_). Consequently, _A_ must output \(\alpha(Z')=|V(G')|\). Conversely, if \((G,H)\unknown\cong(G',H')\), the promise that \(G'\cong G\cong H\) forces the conclusion that \(G'\unknown\cong H'\).<sup>14</sup> Thus, _A_ must either return \(\alpha(Z')<|V(G')|\) or declare \(Z\unknown\cong Z'\), both of which trigger our reduction to correctly declare \(G'\unknown\cong H'\).

Finally, observe the crucial role of the isomorphism-preserving property here. If our reduction was not isomorphism-preserving, the condition \(Z\unknown\cong Z'\) could arise regardless of whether \((G,H)\cong(G',H')\) or \((G,H)\unknown\cong(G',H')\). In such a scenario, if algorithm _A_ outputs \(Z\unknown\cong Z'\), we would be unable to distinguish whether \((G,H)\cong(G',H')\) (which dictates we must return \(G'\cong H'\) due to the \(G'\cong G\cong H\) promise) or if \((G,H)\unknown\cong(G',H')\).
