<tbc>_r(G_<sub>1</sub>)_,...,_\(\tilde{G}_k:=r(G_k)\) in time \(\widetilde{O}(kn^2)\). To be more specific, let \(w_1,\dots w_m\in\mathbb{R}\) be an enumeration of all edge-weights of graphs in S. Note that \(m\le k\cdot n^2\). We compute the vector **r**=(_r_<sub>1</sub>:=_r(w_<sub>1</sub>)_,...,r<sub>m</sub>_:=_r(w<sub>m</sub>_)) in time \(\widetilde{O}(kn^2)\). Further, we store each _r<sub>i</sub>_ with the corresponding _w<sub>i</sub>_ into a binary data structure \(R_\mathcal{S}:\mathbb{R}\rightarrow\mathbb{F}_p\). Note that we can evaluate _R_<sub>S</sub>(_w_) in time \(O(log(kn^2))=\widetilde{O}(1)\). We write \(A_{\tilde{G}_i}\) for the adjacency matrix of \(\tilde{G}_i\). Note that this is a matrix over F_<sub>p</sub>_.

Next, we define \(f_\Delta(G):=\frac{1}{6}\mathrm{Tr}(A_\tilde{G}^3)\).<sup>22</sup> Computing \(A_\tilde{G}^3\) takes time \(\widetilde{O}(n^\omega)\). Therefore, calculating all \(f_\Delta(G_i)\) is in time \(\widetilde{O}(kn^\omega)\). For each \(i\in[k]\), we compute \(f_\Delta(G_i)\) and store the value together with _OPT(G<sub>i</sub>_) in a linear data structure. Formally, we define a data structure _D_<sub>S</sub> that on input _x_ either returns _D_<sub>S</sub>(_x_)=_OPT(G<sub>i</sub>_) for a graph _G<sub>i</sub>_ with \(f_\Delta(G_i)=x\) or returns that no such graph exist. _D_<sub>S</sub> can be constructed in time \(\widetilde{O}(k)\) and can be queried in time \(\widetilde{O}(1)\). Hence, the preprocessing phase takes time \(\widetilde{O}(kn^\omega)\).

**Query:** Given an input graph _H_, we use enc<sub>S</sub> to check that all weights of _H_ correspond to weights of matrices in S. If this is not the case then our algorithm claims that _H_ is not isomorphic to any graph in S. Next, we use the data structure _R_<sub>S</sub> to compute \(\dot{H}:=r(H)\) in time \(\widetilde{O}(n^2)\). We then again apply fast matrix multiplication to compute \(f_\Delta(H)\) in time \(\widetilde{O}(n^\omega)\). Lastly, we check if \(x:=f_\Delta(H)\) is in _D_<sub>S</sub>. If this is the case then we return _D_<sub>S</sub>(_x_), otherwise we report that _H_ is not isomorphic to any graph in S. This can be done in time \(\widetilde{O}(1)\). Hence, the whole query time is in \(\widetilde{O}(n^\omega)\).

**Correctness:** As a first step, we show<tbc>

\(f_\Delta(G):=\frac{1}{6}\mathrm{Tr}(A_\tilde{G}^3)=\sum_{w_1\le w_2\le w_3}c_{w_1,w_2,w_3}r(w_1)r(w_2)r(w_3)=P_\Delta(G)(\mathbf{r}),\) (1)

<tbc>where \(P_\Delta(G)(\mathbf{r})\) denotes the evaluation of \(P_\Delta(G)\) where we assign the value _r(w<sub>i</sub>_) to each variable _x<sub>w<sub>i</sub></sub>_. A standard result (e.g. \[FH15, Fact 1\]) states that

\(\mathrm{Tr}(A_\tilde{G}^3)=\sum_{x_1\in V(G)}\sum_{x_2\in V(G)}\sum_{x_3\in V(G)}r(w(x_1,x_2))\cdot r(w(x_2,x_3))\cdot r(w(x_3,x_1)),\)

where _w(x<sub>i</sub>,x<sub>j</sub>_) is equal to the weight of the edge from _x<sub>i</sub>_ to _x<sub>j</sub>_ and _r(w(x<sub>i</sub>,x<sub>j</sub>_))=0 if there is no edge from _x<sub>i</sub>_ to _x<sub>j</sub>_. Next, observe that the vertices \(x_1,x_2,x_3\in V(G)\) form a triangle in _G_ if and only if \(r(w(x_1,x_2))\cdot r(w(x_2,x_3))\cdot r(w(x_3,x_1))\) appears exactly six times in the sum above.<sup>23</sup> This yields Equation (1).

Let _H_ be a graph on which we are queried. The graph _H_ can be isomorphic to some \(G_i\in\mathcal{S}\) only if all edge-weights of _H_ appear as edge-weights in S. If this is not the case the our query algorithm rejects. Thus, we assume that all edge-weights in _H_ appear in the list _w_<sub>1</sub>_,...,w<sub>m</sub>_.

We now consider two cases. First, suppose that _H_ is isomorphic to some _G<sub>i</sub>_. Then, \(f_\Delta(G_i)=f_\Delta(H)\) due to Equation (1) and the fact that \(P_\Delta(G_i)\equiv P_\Delta(H)\) since \(H\cong G_i\). Thus, \(D_\mathcal{S}(f_\Delta(H))\) returns _OPT(G<sub>i</sub>_) as long as there aren’t any different graphs _G<sub>j</sub>_ with \(f_\Delta(G_i)=f_\Delta(G_j)\) and \(OPT(G_i)\neq OPT(G_j)\). By Lemma 6.5, this only occurs if \(P_\Delta(G_i)\unknown\equiv P_\Delta(G_j)\) but \(P_\Delta(G_i)(\mathbf{r})=P_\Delta(G_j)(\mathbf{r})\). Since all _r<sub>i</sub>_ are chosen independently and uniformly at random over F_<sub>p</sub>_, Lemma 6.1 yields that the event \(P_\Delta(G_i)\unknown\equiv P_\Delta(G_j)\) and \(P_\Delta(G_i)(\mathbf{r})=P_\Delta(G_j)(\mathbf{r})\) has probability at most \(\frac{3}{p}\) for every fixed index \(j\neq i\). Using union bound, we obtain that the failure probability is at most \(\frac{3k}{p}\le k^{-1}n^{-\mathrm{log}(n)}\). Thus, our success probability is at least 1-_k_<sup>-1</sup>_n_<sup>-log(_n_)</sup> and there w.h.p with respect to the query size _n_.
