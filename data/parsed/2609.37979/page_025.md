**Lemma 6.7.** _Let G and H be two graphs. If_ \(P_{ST}(G)\equiv P_{ST}(H)\) _then for any target B, G contains a spanning tree of total weight B if and only if H contains a spanning tree of total weight B._

_Proof._ If \(P_{ST}(G)\equiv P_{ST}(H)\) then the coefficients of every corresponding monomial match exactly, i.e. _c_<sub>_w_<sub>1</sub>_,...,w_<sub>_n_-1</sub></sub>(_G_)=_c_<sub>_w_<sub>1</sub>_,...,w_<sub>_n_-1</sub></sub>(_H_) for all combinations of weights. Consequently, _G_ contains a spanning tree that uses weights _w_<sub>1</sub>_,...,w_<sub>_n_-1</sub> if and only if _H_ contains the same number spanning tree.

_Proof of Theorem 6.3._ Let S:={_G<sub>i</sub>_=(_V<sub>i</sub>,E<sub>i</sub>,c<sub>i</sub>,d<sub>i</sub>,B<sub>i</sub>_)}<sub>_i_=1_...k_</sub> be a database of prior instances and assume that for each \(i\in[k]\) we are given _OPT<sub>i</sub>_ that indicates the optimal value of CST.

**Preprocessing:** Given S, we first compute a prime number \(p\ge k^2n^{log(n)+1}\) and construct a finite field F_<sub>p</sub>_. Note that all basic operations in F_<sub>p</sub>_ can be performed in time \(O(logp)=\widetilde{O}(1)\). Next, we assign arbitrarily a unique non-zero element in F_<sub>p</sub>_ to each edge-weight of the graphs _G<sub>i</sub>_ and store the edge-weights together with the corresponding field elements in a binary search tree. Remember that the edge weight _w(e_) of an edge \(e\in E_i\) is defined as the tuple (_c<sub>i</sub>(e),d<sub>i</sub>(e_)). Formally, we construct a function \(\text{enc}_\mathcal{S}:\mathbb{R}^2\rightarrow\mathbb{F}_p\cup\{\perp\}\) that, on input _x_, either outputs an unique element in F_<sub>p</sub>_ if _x_ is the weight of some graph in S, or returns \(\perp\) otherwise. Note that enc<sub>S</sub> can be computed in time \(O(k\cdot n^2\cdot logp)\), and evaluating enc<sub>S</sub> on some _x_ takes time \(O(log(kn^2)\cdot logp)=\widetilde{O}(1)\).

Given a graph _G<sub>i</sub>_, we write enc<sub>S</sub>(_G<sub>i</sub>_) for graph where each edge weight _w_ was replaced with enc<sub>S</sub>(_w_). This can be done in time \(\widetilde{O}(kn^2)\).

We construct a \((k\cdot n^2)\)-wise independent family of hash functions \(h:\mathbb{F}_p\rightarrow\mathbb{F}_p\) using \[Vad12, Construction 3.32\]. Concretely, we sample a random polynomial over F_<sub>p</sub>_ of degree at most \(k\cdot n^2-1\). Note that such a hash function can be constructed in time \(O(k\cdot n^2)\). Give an edge-weight _w_, we define _r(w_):=_h_(enc<sub>S</sub>(_w_)). For a graph _G<sub>i</sub>_, we write _r(G<sub>i</sub>_) for the graph obtained by replacing each edge weight _w_ with _r(w_).

Let \(x_1,\dots,x_m\in\mathbb{F}_p\), where \(m\le k\cdot n^2\), be a sequence of values. Using the Fast Fourier Transformation, we can evaluate _h(x<sub>i</sub>_) for all _i_ in time \(\widetilde{O}(k\cdot n^2)\). Thus, we can compute \(\tilde{G}_1:=r(G_1),\dots,\tilde{G}_k:=r(G_k)\) in time \(\widetilde{O}(kn^2)\). To be more specific, let \(w_1,\dots w_m\in\mathbb{R}^2\) be an enumeration of all edge-weights of graphs in S. Note that \(m\le k\cdot n^2\). We compute the vector \(\mathbf{r}=(r_1:=r(w_1),\dots,r_m:=r(w_m))\) in time \(\widetilde{O}(kn^2)\). Further, we store each _r<sub>i</sub>_ with the corresponding _w<sub>i</sub>_ into a binary data structure \(R_\mathcal{S}:\mathbb{R}^2\rightarrow\mathbb{F}_p\). Note that we can evaluate _R_<sub>S</sub>(_w_) in time \(O(log(kn^2))=\widetilde{O}(1)\). We write \(L^{\tilde{G}_i}\) for the Laplacian matrix of \(\tilde{G}_i\). Further, for each \(j\in[n]\),<sup>24</sup> we write \(\tilde{L}_j^{\tilde{G}_i}\) for the matrix that is obtained by removing the _j_-th row and the _j_-th column from \(L^{\tilde{G}_i}\). Note that \(\tilde{L}_j^{\tilde{G}_i}\) is a matrix over F_<sub>p</sub>_.

Next, we define \(f_{ST}(G):=det(\tilde{L}_1^{\tilde{G}_i})\) which can be computed in time \(\widetilde{O}(n^\omega)\). For each \(i\in[k]\), we compute \(f_\Delta(G_i)\) and store the value together with _OPT<sub>i</sub>_ in a linear data structure. Formally, we define a data structure _D_<sub>S</sub> that on input _x_ either returns _D_<sub>S</sub>(_x_)=_OPT<sub>i</sub>_ for a graph _G<sub>i</sub>_ with \(f_\Delta(G_i)=x\) or returns that no such graph exist. _D_<sub>S</sub> can be constructed in time \(\widetilde{O}(k)\) and can be queried in time \(\widetilde{O}(1)\). Hence, the preprocessing phase takes time \(\widetilde{O}(kn^\omega)\).

**Query:** Given an input graph _H_, we use enc<sub>S</sub> to check that all weights of _H_ correspond to weights of matrices in S. If this is not the case then our algorithm claims that _H_ is not isomorphic to any graph in S. Next, we use the data structure _R_<sub>S</sub> to compute \(\tilde{H}:=r(H)\) in time \(\widetilde{O}(n^2)\). We then compute _f<sub>ST</sub>(H_) in time \(\widetilde{O}(n^\omega)\). Lastly, we check if \(x:=f_\Delta(H)\) is in _D_<sub>S</sub>. If this is the case then we return _D_<sub>S</sub>(_x_), otherwise we report that _H_ is not isomorphic to any graph in S. This can be done in time \(\widetilde{O}(1)\). Hence, the whole query time is in \(\widetilde{O}(n^\omega)\).

<sup>24</sup>For simplicity, we assume that _G<sub>i</sub>_ has _n_ vertices which is why _L<sup>G<sub>i</sub></sup>_ is a \(n\times n\)-matrix.
