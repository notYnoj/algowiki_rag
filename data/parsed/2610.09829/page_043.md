**Definition 5.13.** Consider a solution D for \(\Pi_{\mathcal{P},\alpha,h}(\gamma_i,h_i,\theta_i)_{i\in[b]}\), and for \(i\in[b]\), let \(\delta_i\in\mathcal{D}\) be such that \(\gamma_i\) is the \((\alpha,\mathcal{D})\)-representative for \(\delta_i\). For \(q\in[\tilde{p}]\), let \(\widetilde{\delta}_q=\delta_{q_j}\). We define the following numbers (see Figure 18).

1. For \(q\in[\tilde{p}]\), let \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1\) be the set containing each \(\gamma_i\), where: i) \(\gamma_i\in\{\widetilde{\psi}_q,\widetilde{\tau}_q\}\), and ii) \(\theta_i=(\psi_i,\tau_i)\) and \(\widetilde{\gamma}_q\in\Gamma_{\alpha,R,\gamma_i}[\psi_i,\tau_i]\backslash\{\psi_i,\tau_i\}\), or \(\theta_i=\mathsf{e}\). Also, if \(\alpha\in\{\widetilde{\psi}_q,\widetilde{\tau}_q\}\), then add \(\alpha\) to \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1\). Notice that if \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1\neq\emptyset\), then its size can be at most 2, and furthermore, \(\widetilde{\gamma}_q\) must be an endpoint of the connected component \(\widetilde{H}\) (in which case \(\widetilde{H}\) must be a path), where \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1\cap V(\widetilde{H})=\emptyset\). Let \(X=\cup_{q\in\{1,\tilde{p}\},\gamma\in\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1}E(\gamma)\), and _w_<sup>1</sup>(D)=_w(X_\\_E_(P)).<tbc>

2. For \(q\in[\tilde{p}]\), let \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^2\) be the set containing each \(\gamma_i\), where: i) \(\gamma_i\in\Gamma_{\alpha,R,\widetilde{\gamma}_q}[\widetilde{\psi}_q,\widetilde{\tau}_q]\backslash\{\widetilde{\psi}_q,\widetilde{\tau}_q\}\), and ii) \(\theta_i=(\psi_i,\tau_i)\) and \(\widetilde{\gamma}_q\in\{\psi_i,\tau_i\}\). Also, let \(w^2(\mathcal{D})=\sum_{q\in[\tilde{p}]}\sum_{\gamma_i\in\Gamma_{\alpha,R,\widetilde{\gamma}_q}^2}w(E(\widetilde{\gamma}_q\cap\delta_i)\backslash E(\mathcal{P}))\).<tbc>

3. For \(q\in[\tilde{p}]\), let \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^3\) be the set containing each \(\gamma_i\), where: i) \(\gamma_i\in\Gamma_{\alpha,R,\widetilde{\gamma}_q}[\widetilde{\psi}_q,\widetilde{\tau}_q]\backslash\{\widetilde{\psi}_q,\widetilde{\tau}_q\}\), and ii) \(\theta_i=\mathsf{e}\), or \(\widetilde{\gamma}_q\in\Gamma_{\alpha,R,\gamma_i}[\psi_i,\tau_i]\backslash\{\psi_i,\tau_i\}\). Also, if \(\alpha\in\Gamma_{\alpha,R,\gamma_i}[\psi_i,\tau_i]\backslash\{\psi_i,\tau_i\}\), add \(\alpha\) to \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^3\). Let \(w^3(\mathcal{D})=\sum_{q\in[\tilde{p}]}\sum_{\gamma_i\in\Gamma_{\alpha,R,\widetilde{\gamma}_q}^3}w(E(\widetilde{\gamma}_q\cap\gamma_i)\backslash E(\mathcal{P}))\).

Due to the above definition, the "best" choice of \((\varepsilon_1,\varepsilon_\tilde{p})\in\widetilde{\mathcal{A}}_1\times\widetilde{\mathcal{A}}_\tilde{p}\) is independent on its second and third item. Note the first term of the definition is applicable only when \(\widetilde{H}\) is a path. Another term that our dynamic programming has not accounted for, is when \(\widetilde{H}\) is a cycle, the edges (outside of P) common to \(\widetilde{\beta}_1\) and \(\widetilde{\beta}_\tilde{p}\) (see Definition 5.12). The above motivates our next definition.

For \(\varepsilon_1=(u_1,v_1)\in\widetilde{\mathcal{A}}_1\) and \(\varepsilon_\tilde{p}=(u_\tilde{p},v_\tilde{p})\in\widetilde{\mathcal{A}}_\tilde{p}\), we define the _overcounted weight_, \(w^\mathsf{ovr}(\varepsilon_1,\varepsilon_\tilde{p})\) as follows. First let us consider the case when \(\widetilde{H}\) is a cycle (which must have at least 3 vertices from Observation 5.9). In this case, we set \(w^\mathsf{ovr}(\varepsilon_1,\varepsilon_\tilde{p})\) as the weight of the common edges (outside of P) in these two cycles. That is, if \(\widetilde{H}\) is a cycle then set \(w^\mathsf{ovr}(\varepsilon_1,\varepsilon_\tilde{p})=w(E(\widetilde{\gamma}_1[u_1,v_1]\cap\widetilde{\gamma}_\tilde{p}[u_\tilde{p},v_\tilde{p}])\backslash E(\mathcal{P}))\) (see Lemma 5.2).

We now consider the case when \(\widetilde{H}\) is a path. Intuitively speaking, we construct \(w^\mathsf{ovr}(\varepsilon_1,\varepsilon_\tilde{p})\) in accordance with Definition 5.13 (1) as follows. For \(q\in[\tilde{p}]\), let \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1\) be the set containing each \(\gamma_i\), where: i) \(\gamma_i\in\{\widetilde{\psi}_q,\widetilde{\tau}_q\}\), and ii) \(\theta_i=\mathsf{e}\), or \(\theta_i=(\psi_i,\tau_i)\) and \(\widetilde{\gamma}_q\in\Gamma_{\alpha,R,\gamma_i}[\psi_i,\tau_i]\backslash\{\psi_i,\tau_i\}\). Also, if \(\alpha\in\{\widetilde{\psi}_q,\widetilde{\tau}_q\}\), then add \(\alpha\) to \(\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1\). Let \(X=\cup_{q\in\{1,\tilde{p}\},\gamma\in\Gamma_{\alpha,R,\widetilde{\gamma}_q}^1}E(\gamma)\), and \(w^\mathsf{ovr}(\varepsilon_1,\varepsilon_\tilde{p})=w(X\backslash E(\mathcal{P}))\).

We are ready to pick a pair from \(\widetilde{\mathcal{A}}_1\times\widetilde{\mathcal{A}}_\tilde{p}\), which we will prove to be the "best" choice.

\((\varepsilon_1^*,\varepsilon_\tilde{p}^*)=argmax_{\varepsilon_1\in\widetilde{\mathcal{A}}_1,\varepsilon_\tilde{p}=(u_\tilde{p},v_\tilde{p})\in\widetilde{\mathcal{A}}_\tilde{p}:\tilde{p}=1\text{or}(\varepsilon_1,\varepsilon_\tilde{p})\text{is}d\text{-diverse}}\big(\Lambda_{\varepsilon_1,\varepsilon_\tilde{p}}(\tilde{p},u_\tilde{p},v_\tilde{p})-w^\mathsf{ovr}(\varepsilon_1,\varepsilon_\tilde{p})\big).\)

In the above, if the maximum is \(-\infty\) (due to empty maximum, or for some other reason), then we take \((\varepsilon_1^*,\varepsilon_\tilde{p}^*)=(\phi,\phi)\). The next observation handles the case when \((\varepsilon_1^*,\varepsilon_\tilde{p}^*)=(\phi,\phi)\).

**Observation 5.10.** _If_ \((\varepsilon_1^*,\varepsilon_\tilde{p}^*)=(\phi,\phi)\)_, then there is no solution for_ \(\Pi_{\mathcal{P},\alpha,h}(\gamma_i,h_i,\theta_i)_{i\in[b]}\).
