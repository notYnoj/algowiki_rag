Then the edges covered by C_<sub>N</sub>_ are exactly the edges covered by P<sup>∗</sup>, and by Definition 5.5, (_k-h_<sup>∗</sup>) is P<sup>∗</sup>-valid. Note that \(z\ge\Pi_{\mathcal{P}^*}(C_r,h^*)\), so to conclude that \(z\ge w(\mathcal{C})\), it is enough to argue that C_<sub>T</sub>_ satisfies all the conditions stated in Definition 5.6, for P<sup>∗</sup>, _h_<sup>∗</sup>, and _C<sub>r</sub>_. By the construction of _h_<sup>∗</sup> and as \(C_r\in\mathcal{C}\), Definition 5.6 (1) is satisfied by C_<sub>T</sub>_. As _C<sub>r</sub>_ is the root of T , trivially Definition 5.6 (2) is satisfied by C_<sub>T</sub>_. Now we argue that for each \(C\in\mathcal{C}_T\) and \(P\in\mathcal{P}^*\), we have \(w(C\cap P)\le d\). Note that _P_ is a longitudinal path, say an _s-t_ longitudinal path, for pole _s,t_. As \(P\in\mathcal{P}^*\), there exists \(C'\in\mathcal{C}_N\), such that \(C'=P\cup P'\), where both \(P,P'\) are _s-t_ longitudinal paths with \(V(P)\cap V(P')=\{s,t\}\). Moreover, as \(C'\) is a non-tree cycle, Proposition 5.2 (2) implies that there is a unique splittable node \(\gamma\) in T , such that \(P,P'\) are non-consecutive paths of \(\mathcal{P}_\mathbf{s}(\gamma)\). The above together with the fact that C is _d_-diverse and _C_ is a tree cycle (and Proposition 5.1), implies that the edges (if they exist) in \(E(C)\cap E(C')\) must lie in at most one of the paths \(P,P'\). Thus we can conclude that \(w(C\cap P)\le d\). This concludes the proof that \(z\ge w(\mathcal{C})\).

We now show that \(z\le w(\mathcal{C})\) (and again assume that \(z\neq-\infty\)). Consider \(\mathcal{P}'\subseteq\mathcal{Q}\), an integer \(h'\in[k]\) where \(k-h'\) is \(\mathcal{P}'\)-valid, such that \(z=\Pi_{\mathcal{P}^\prime}(C_r,h')\). Furthermore, let C<sub>1</sub> be the set of tree cycles satisfying the conditions stated in Definition 5.6 for \(\mathcal{P}'\), \(h'\), and _C<sub>r</sub>_, such that \(\Pi_{\mathcal{P}^\prime}(C_r,h')=w(\mathcal{C}_1\cup\mathcal{P}')\). As \(k-h'\) is \(\mathcal{P}'\)-valid, there exists a set of _d_-diverse non-tree cycles \(\mathcal{C}_2=\{C_1,C_2,\dots,C_{k-h^\prime}\}\), such that C<sub>2</sub> exactly covers \(\mathcal{P}'\) (see Definition 5.5). Let \(\mathcal{C}'=\mathcal{C}_1\cup\mathcal{C}_2\), and note that \(w(\mathcal{C}')=z\le w(\mathcal{C})\), where C is an optimal solution for \((G,w,k,d,\ell)\). Thus, it is enough to argue that \(\mathcal{C}'\) is a solution for \((G,w,k,d,\ell)\). Note by construction, \(|\mathcal{C}'|=k\), and to establish the statement above, it is enough to argue that for \(C_1\in\mathcal{C}_1\) and \(C_2\in\mathcal{C}_2\), we have \(w(C_1\cap C_2)\le d\). As \(C_2=P\cup P'\) is a non-tree cycle (see Proposition 5.2 (2)), it must be some _s-t_ splittable cycle where \(P,P'\in\mathcal{P}'\) are _s-t_ longitudinal paths. Similar to the arguments used while proving the other inequality, note we can obtain that _E(C_<sub>1</sub>) can intersect with edges in at most one of the paths \(P,P'\). This implies that \(w(C_1\cap C_2)\le d\) (see Definition 5.6 (3)).

This concludes the proof of Theorem 1.2 (subject to the proof of Lemma 5.5).
