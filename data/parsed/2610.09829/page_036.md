**Correctness of the algorithm.** Consider \(\alpha\in V(\mathcal{T})\), and a positive integer _h_, where \(1\le h\le k\). The correctness of the base case (and the sanity check) is immediate from its description. So we now consider the case when \(\alpha\) is a non-leaf node of T , _h\>_1 and \(\{\alpha\}\) is _d_-diverse from P. Our goal will be to show that \(\Pi_\mathcal{P}(\alpha,h)=\mathrm{max}_{x\in M}x\).<br>
_Proof of_ \(\Pi_\mathcal{P}(\alpha,h)\le\mathrm{max}_{x\in M}x\). Suppose that \(\Pi_\mathcal{P}(\alpha,h)\neq-\infty\) (else the inequality is trivially satisfied), and let C<sup>∗</sup> be an optimal solution for \(\Pi_\mathcal{P}(\alpha,h)\) (see Definition 5.6). Let \(B=\{\beta_i^*|i\in[b]\}\) be the set of solution descendants of \(\alpha\) in C<sup>∗</sup> (see Definition 5.7), where note that \(1\le b\le h-1\). Furthermore, for each \(i\in[b]\), let \(\gamma_i\) be the \((\alpha,\mathcal{C}^*)\)-representative for \(\beta_i^*\) (see Definition 5.8), and let \(R=\{\gamma_i|i\in[b]\}\). From Observation 5.3, \(R\in\mathcal{R}_{\alpha,b}\). For \(i\in[b]\), let \(h_i=|\mathcal{C}^*\cap V(\mathcal{T}_{\beta_i^*})|\), and note that \((h_i)_{i\in[b]}\in\mathcal{H}_b\). For \(i\in[b]\), we construct \(\theta_i\in\mathcal{S}_{\alpha,R}\) as follows. If \(\beta_i^*=\gamma_i\), set \(\theta_i=\mathsf{e}\). If \(\beta_i^*\neq\gamma_i\) and \(E(\beta_i^*)\cap E(\delta)=\emptyset\) for all \(\delta\in\Gamma_{\alpha,R,\gamma_i}\), set \(\theta_i=\mathsf{n}\). Otherwise, we set \(\theta_i=(\psi_i,\tau_i)\), where \(\emptyset\neq\Gamma_{\alpha,R,\gamma_i,\beta_i^*}=\Gamma_{\alpha,R,\gamma_i}[\psi_i,\tau_i]\) (see Observation 5.6).

By construction, \((\theta_i)_{i\in[b]}\in\mathcal{S}_{\alpha,R}\). Furthermore, C<sup>∗</sup> is a solution for \(\Pi_{\mathcal{P},\alpha,h}(\gamma_i,h_i,\theta_i)_{i\in[b]}\). Thus, at the iteration where the algorithm considers _b_, \((h_i)_{i\in[b]}\), _R_, \((\theta_i)_{i\in[b]}\), the correctness of Lemma 5.6 implies that \(\mathsf{ans}(\gamma_i,h_i,\theta_i)_{i\in[b]}=\{\beta_i|i\in[b]\}\), and there is an optimal solution C for \(\Pi_{\mathcal{P},\alpha,h}(\gamma_i,h_i,\theta_i)_{i\in[b]}\) such that for each \(i\in[b]\), \(\beta_i\in\mathcal{C}\) and \(\gamma_i\) is the \((\alpha,\mathcal{C})\)-representative of \(\beta_i\). Note that \(w(\mathcal{C}\cup\mathcal{P})\ge w(\mathcal{C}^*\cup\mathcal{P})\), and thus C is an optimal solution for \(\Pi_\mathcal{P}(\alpha,h)\). For \(i\in[b]\), let \(\mathcal{C}_i=\mathcal{C}\cap V(\mathcal{T}_{\beta_i})\), and notice that from Observation 5.1 (4), \(\Pi_\mathcal{P}(\beta_i,h_i)=w(\mathcal{C}_i\cup\mathcal{P})\). Let \(\varkappa=w(E'\backslash E(\mathcal{P}))\), where \(E'=\cup_{\beta,\beta^\prime\in\{\alpha\}\cup\{\beta_i|i\in[b]\},\beta\neq\beta^\prime} E(\beta)\cap E(\beta')\). From the above, together with Lemma 5.2 and Observation 5.4 we can obtain that,

\(\Pi_\mathcal{P}(\alpha,h)=w(\mathcal{C}\cup\mathcal{P})=w(E(\alpha)\backslash E(\mathcal{P}))-(b-1)\cdot w(\mathcal{P})+\big(\sum_{i\in[b]}w(\mathcal{C}_i\cup\mathcal{P})\big)-\varkappa\)<br>
\(=w(E(\alpha)\backslash E(\mathcal{P}))-(b-1)\cdot w(\mathcal{P})+\big(\sum_{i\in[b]}\Pi_\mathcal{P}(\beta_i,h_i)\big)-\varkappa\)

Thus, we can conclude that \(\Pi_\mathcal{P}(\alpha,h)\le\mathrm{max}_{x\in M}x\).<br>
_Proof of_ \(\Pi_\mathcal{P}(\alpha,h)\ge\mathrm{max}_{x\in M}x\). Suppose that \(\mathrm{max}_{x\in M}x\neq-\infty\) (else the inequality is trivially satisfied), and let \(x^*=\mathrm{max}_{x\in M}x\), where _x_<sup>∗</sup> was added to _M_ for the iteration where the algorithm considered \(b\in[h-1]\), \((h_i)_{i\in[b]}\in\mathcal{H}_b\), \(R=\{\gamma_i|i\in[b]\}\in\mathcal{R}_{\alpha,b}\) and \((\theta_i)_{i\in[b]}\in\mathcal{S}_{\alpha,R}\). Furthermore, the answer returned by Lemma 5.6, for \((G,w,k,d,\ell)\), T,P, \(\alpha,h\), \(R,(h_i)_{i\in[b]},(\theta_i)_{i\in[b]}\) is \(\mathsf{ans}(\gamma_i,h_i,\theta_i)_{i\in[b]}=\{\beta_i|i\in[b]\}\), where there is an optimal solution C for \(\Pi_{\mathcal{P},\alpha,h}(\gamma_i,h_i,\theta_i)_{i\in[b]}\) such that for each \(i\in[b]\), \(\beta_i\in\mathcal{C}\) and \(\gamma_i\) is the \((\alpha,\mathcal{C})\)-representative of \(\beta_i\). For this iteration we have \(\varkappa=w(E'\backslash E(\mathcal{P}))\), where \(E'=\cup_{\beta,\beta^\prime\in\{\alpha\}\cup\{\beta_i|i\in[b]\},\beta\neq\beta^\prime} E(\beta)\cap E(\beta')\). Note that C must also be a solution for \(\Pi_\mathcal{P}(\alpha,h)\) (see Definition 5.9), and furthermore, \(w(\mathcal{C}\cup\mathcal{P})=x^*\). Thus, \(\Pi_\mathcal{P}(\alpha,h)\ge x^*\).

This concludes the proof of Lemma 5.5 (subject to the proof of Lemma 5.6).
