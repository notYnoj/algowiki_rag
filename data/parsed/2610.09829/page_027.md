• Consider the case when _d\<g(G)/_2. Notice that for any \(i\in[x]\), any two distinct non-tree _d_-diverse cycles that are each union of two paths from P_<sub>i</sub>_ must actually be edge-disjoint (also see Proposition 5.2 (3)). Thus, we can declare that _q_ is not P-valid if one of the following holds: i) |P_<sub>i</sub>_| is odd, for some \(i\in[x]\), or ii) \(\sum_{i=1}^x|\mathcal{P}_i|/2\neq q\). Consider the case when for some \(i\in[x]\), _c<sub>i</sub>_=1. In the above case, if _P_<sub>_i,_1</sub>_,P_<sub>_i,_2</sub> are consecutive in the ordering of paths in \(\mathcal{P}_\mathsf{s}(\alpha_i)\), or \(P_{i,1}\cup P_{i,2}=\alpha_i\) then \(\mathcal{P}_i\subseteq\mathcal{P}\) cannot be covered with non-tree cycles as required by Definition 5.5, so we can declare that _q_ is not P-valid. Else, notice that the non-tree cycle \(P_{i,1}\cup P_{i,2}\) covers the paths in P_<sub>i</sub>_. Now consider any \(i\in[x]\), where _c<sub>i</sub>\>_1. Notice that the cycles \(C_j=P_{i,j}\cup P_{i,c_i+j}\), for \(j\in[c_i]\), exactly cover P_<sub>i</sub>_ and they are pairwise edge-disjoint (and thus _d_-diverse). We will now show that unless we have declared that _q_ is not P-valid in the previous discussions, then _q_ is P-valid. Note the above discussed procedure can be executed in polynomial time, and we next argue the correctness.<tbc>

<tbc>So we consider the case that has not been already covered before, and note that in that case, for each \(i\in[x]\), we constructed a set of non-tree cycles, C_<sub>i</sub>_, which has _d_-diverse shortest cycles that exactly covers P_<sub>i</sub>_. Let \(\mathcal{C}=\cup_{i=1}^x\mathcal{C}_i\), and note that |C|=_q_ by the construction we described. We now argue that C is _d_-diverse, thus implying that _q_ is P-valid. To prove this it is enough to argue that for any distinct \(i,i'\in[x]\), and cycles \(C\in\mathcal{C}_i\) and \(C'\in\mathcal{C}_{i^\prime}\), \(w(C\cap C')\le d\). Recall that P is _d_-diverse and the non-tree cycles _C_ and \(C'\) must be associated with distinct splittable nodes (otherwise, they are already edge-disjoint), say \(\alpha\) and \(\alpha'\) of T , respectively, where \(\alpha=X\cup Y,\alpha'=X'\cup Y'\), where \(X,Y\in\mathcal{P}_\mathsf{s}(\alpha)\) and \(X',Y'\in\mathcal{P}_\mathsf{s}(\alpha')\). Note that _C_ (resp. \(C'\)) can contain edges of at most one of the paths _X,Y_ (resp. \(X',Y'\)). The above discussions together with the assumption that P is _d_-diverse and \(C,C'\) are non-tree cycles, implies that \(w(C\cap C')\le d\).<tbc>

• Now consider the case when _d=g(G)/_2. Recall that for each \(i\in[x]\), we have \(|\mathcal{P}_i|\ge 2\) and \(|\mathcal{P}_\mathsf{s}(\alpha_i)|\ge 4\). Similar to the previous case, notice that if for some \(i\in[x]\), |P_<sub>i</sub>_|=2, where either the two paths in P_<sub>i</sub>_ are consecutive in the ordering of paths in \(\mathcal{P}_\mathsf{s}(\alpha_i)\), or their union exactly gives the tree cycle \(\alpha_i\), then _q_ is not P-valid. Similarly, if for \(i\in[x]\), |P_<sub>i</sub>_|=3 and all the three paths in P_<sub>i</sub>_ are consecutive in \(\mathcal{P}_\mathsf{s}(\alpha_i)\), then _q_ is not P-valid. Now we assume that we are not in the above case and construct numbers _y<sub>i</sub>,z<sub>i</sub>_, for \(i\in[x]\) which denote the minimum number of non-tree cycles needed to exactly cover P_<sub>i</sub>_, and the maximum number of non-tree cycles that exactly cover P_<sub>i</sub>_. Consider any \(i\in[x]\). Note that to cover the paths in P_<sub>i</sub>_ we need \(\lceil\mathcal{P}_i/2\rceil\) non-tree cycles, and such a set of non-tree cycles exists; so we set \(y_i=\lceil\mathcal{P}_i/2\rceil\). Let H_<sub>i</sub>_ be the set of (unordered) pairs of distinct paths from P_<sub>i</sub>_ that are either consecutive in ordering of paths in \(\mathcal{P}_\mathsf{s}(\alpha_i)\), or it is the (unordered) pair that has the first and the last path of \(\mathcal{P}_\mathsf{s}(\alpha_i)\). Let \(\genfrac(){pt}{2}{\mathcal{P}_i}{2}\) be the set of pairs of distinct paths from P_<sub>i</sub>_, and \(\mathcal{Z}_i=\genfrac(){pt}{2}{\mathcal{P}_i}{2}\backslash\mathcal{H}_i\). Notice that Z_<sub>i</sub>_ is _d_-diverse, i.e., for any distinct unordered pairs \(\{\iota,\iota'\},\{\delta,\delta'\}\in\mathcal{Z}_i\), we have \(w((\iota\cup\iota')\cap(\delta\cup\delta'))\le d\). Similar to the previous case, note that for distinct \(i,i'\in[x]\), and \(C=\iota\cup\iota'\), for \(\{\iota,\iota'\}\in\mathcal{Z}_i\) and \(C'=\delta\cup\delta'\), for \(\{\delta,\delta'\}\in\mathcal{Z}_{i^\prime}\), we can obtain that \(w(C\cap C')\le d\). Thus (unless already stated otherwise by the previous arguments), _q_ is P-valid if and only if \(\sum_{i\in[x]}y_i\le q\le\sum_{i\in[x]}z_i\), which can be tested in polynomial time.
