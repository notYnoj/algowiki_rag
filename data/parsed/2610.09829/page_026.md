Recall from Proposition 5.2 (2), each non-tree cycle must consist of longitudinal paths, and from Lemma 5.1 ((ii)) the number of longitudinal paths is O(_k_). So instead of keeping track of the non-tree cycles, we will "guess" (or, more precisely, iterate over choices of the exact subset of) longitudinal paths participating in non-tree cycles. This leads us to the following definitions (and some results regarding them).

Let _U_ be the set of all splittable nodes of T (see Definition 5.4 (2)), and for \(\alpha\in U\), let \(\alpha\) be an \(s_\alpha,t_\alpha\)-splittable cycle (see Definition 5.3).<sup>2</sup> We let \(\mathcal{Q}=\cup_{\alpha\in U}\mathcal{P}_\mathsf{s}(\alpha)\). Note Q is the set of all longitudinal paths, and we can find it in polynomial time (see Lemma 5.1 (ii)). For \(\mathcal{P}\subseteq\mathcal{Q}\), P is _d-diverse_ if for every distinct \(P,P'\in\mathcal{P}\), \(w(P\cap P')\le d\). (Recall our notation that \(w(P\cap P')=w(E(P)\cap E(P'))\).) We now define the validity of coverage of paths in a _d_-diverse \(\mathcal{P}\subseteq\mathcal{Q}\) using _q_ many non-tree cycles.

**Definition 5.5.** Consider \(\mathcal{P}\subseteq\mathcal{Q}\) and an integer _q_, where P is _d_-diverse and \(0\le q\le k\). We say that _q_ is P_-valid_ if there is a set of _d_-diverse shortest non-tree cycles \(\mathcal{C}'=\{C_1,C_2,\dots,C_q\}\), where for \(i\in[q]\), \(C_i=P_i\cup Q_i\), for _s<sub>i</sub>-t<sub>i</sub>_ longitudinal paths _P<sub>i</sub>,Q<sub>i</sub>_ for some pole _s<sub>i</sub>,t<sub>i</sub>_ with \(V(P_i)\cap V(Q_i)=\{s_i,t_i\}\),<sup>3</sup> such that \(\mathcal{P}=\{P_i,Q_i|i\in[q]\}\). In the above we say that \(\mathcal{C}'\) _exactly covers_ P.

Recall a solution for \((G,w,k,d,\ell)\) must have _exactly k_ shortest cycles (satisfying other conditions). So in our states, we need to keep track of different values of _q_ that are P-valid, as for the same set \(\mathcal{P}\subseteq\mathcal{Q}\), we may be able to construct different numbers of _d_-diverse shortest cycles exactly covering P. We next give an observation for testing P-validity.

**Lemma 5.4.** _Given_ \(\mathcal{P}\subseteq\mathcal{Q}\) _and an integer_ \(0\le q\le k\)_, in time polynomial in n we can do the following: i) test if_ P _is d-diverse, and ii) if_ P _is d-diverse, test if q is_ P_-valid._

_Proof._ The proof of the first item follows from Lemma 5.1 (ii). We now focus on the proof of the second item, and assume that P is _d_-diverse.

Note that if \(\mathcal{P}=\emptyset\), then _q_ is P-valid if and only if _q_=0. We now assume that \(\mathcal{P}\neq\emptyset\). Recall that _U_ is the set of all splittable nodes in T . Note that for distinct \(\alpha,\alpha'\in U\), \(\mathcal{P}_\mathsf{s}(\alpha)\cap\mathcal{P}_\mathsf{s}(\alpha')=\emptyset\) (see Proposition 5.2 (3)). Let \(U'=\{\alpha_1,\alpha_2,\dots,\alpha_x\}\subseteq U\) be the set such that for each \(\alpha\in U'\), \(\mathcal{P}\cap\mathcal{P}_\mathsf{s}(\alpha)\neq\emptyset\). Furthermore, for each \(i\in[x]\), let \(\mathcal{P}_i=\mathcal{P}\cap\mathcal{P}_\mathsf{s}(\alpha_i)\). Note the above gives us a partition of P, and it can be computed in polynomial time. For \(i\in[x]\), let _s<sub>i</sub>,t<sub>i</sub>_ be the pole of the splittable cycle \(\alpha_i\), and note that each path in P_<sub>i</sub>_ is an _s<sub>i</sub>-t<sub>i</sub>_ shortest path in _G_ of length exactly _g(G)/_2. We next do some sanity checks where we can directly rule out that _q_ is P-valid.

If for any \(i\in[x]\), \(|\mathcal{P}_\mathsf{s}(\alpha_i)|\le 3\) (in which case it must be exactly 3), then note all three cycles formed by a pair of paths from \(\mathcal{P}_\mathsf{s}(\alpha_i)\) must be tree cycles of T(_G_) (one of these will be the parent, and the other two its children in T(_G_)). As Definition 5.5 requires only non-tree cycles, if for any \(i\in[x]\), \(|\mathcal{P}_\mathsf{s}(\alpha_i)|\le 3\), then there cannot exist any P-valid integer, so we conclude that _q_ is not P-valid. If for any \(i\in[x]\), |P_<sub>i</sub>_|=1, then there is no P-valid integer, so we can declare that _q_ is not P-valid. Hereafter, we assume that for each \(i\in[x]\), \(|\mathcal{P}_i|\ge 2\) and \(|\mathcal{P}_\mathsf{s}(\alpha_i)|\ge 4\).

For each \(i\in[x]\), let \(\mathcal{P}_\mathsf{s}(\alpha_i)=\{P_{i,0},P_{i,1},P_{i,2},\dots,P_{i,b_i}\}\), where \(\alpha_i=P_{i,0}\cup P_{i,b_i}\), and the paths in \(\mathcal{P}_\mathsf{s}(\alpha_i)\) appear in the stated order inside the curve of \(\alpha_i\) in _G_’s embedding. Note we can construct these orderings in polynomial time, and paths in \(\mathcal{P}_\mathsf{s}(\alpha_i)\) are internally pairwise vertex-disjoint (see Proposition 5.2 (3)).
