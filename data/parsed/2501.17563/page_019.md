However, this constraint is not violated since: \(X'_{ri}+X'_{ir}+\sum_{k\in(i\unknown r)}Z'_{kir}\ge(X_{ri}+n\Delta)+(X_{ir}-\Delta)+\sum_{k\in(i\unknown r)}(Z_{kir}-\Delta)\ge 1+\Delta\). Finally, observe that \(D'_r\le D_r-\Delta\) and for \(i\neq r\): \(D'_i\le D_i+n\cdot n\Delta\). Therefore the difference in values of the LP is: \(value(X',w)-value(X,w)=\sum_iw_i\cdot(D'_i-D_i)\le\sum_{i\neq r}\frac{w_i}{w_r}\cdot w_r\cdot n^2\Delta-w_r\Delta<(n\cdot\frac{1}{n^4}\cdot n^2-1)\cdot w_r\Delta<0\). Therefore, every optimal point with respect to _w_ satisfies that \(\forall i:X_{ir}=0\).

Theorem 3.6 does not rule out an integer vertex _P_ of the LP such that _P<sub>D</sub>_ is not on the lower envelope of P_<sub>D</sub>_. Indeed, Theorem 3.7 shows that such vertices exist. Conveniently, their projection does not affect our normals method since we relax P_<sub>D</sub>_ to only deal with lower-envelope facets.

**Theorem 3.7.** For any \(n\ge 3\), and any tree topology _U_ with _n_ nodes, the LP defined by _U_ has integer vertices that are not induced by an STT (Definition 1.4).

The proof shows two generic classes of such integer vertices. The first relies on non-transitivity in ancestral relationship, in opposition to an STT property not captured by the LP. The second defines an LCA implicitly but not explicitly.

_Proof._ Given a topology _U_, Let \(\mathbb{P}'\) be the set of all feasible solutions such that every variable is 0 or 1, and in each ancestry constraint, exactly one variable is 1. We argue that every point in \(\mathbb{P}'\) is a vertex. Let \(P\in\mathbb{P}'\). _P_ is a vertex if and only if there is no non-zero direction _R_ such that \(P\pm\epsilon R\) are both feasible. If _R_ is nonzero in some zero coordinate of _P_, one direction is infeasible due to negativity. Similarly, _R_ cannot be nonzero in a coordinate where _P_ is 1, because in order to preserve the ancestry feasibility to which this coordinate is the sole contributor, _R_ must be non-zero on some other zero coordinate of _P_ with opposite sign. But since we already argued that _R_ is zero in all the zero coordinates of _P_, no such direction _R_ exists and we conclude that _P_ is a vertex.

Let \(\mathbb{P}\subseteq\mathbb{P}'\) contain all the feasible solutions such that _Z<sub>kij</sub>_=0 for all _i_, _j_, and \(k\in(i\unknown j)\), and for every pair _i,j_ choose \(X_{ij},X_{ji}\in\{0,1\}\) such that _X<sub>ij</sub>+X<sub>ji</sub>_=1. We define two classes of points in P which do not correspond to STTs.

1. We choose \(P\in\mathbb{P}\) such that there is a triplet of indices _i,j,k_ (this is why the claim requires \(n\ge 3\)) for which _X<sub>ij</sub>=X<sub>jk</sub>=X<sub>ki</sub>_=1. No STT has such a cyclic relation, because if _i_ is an ancestor of _j_ which is an ancestor of _k_, then _i_ is also an ancestor of _k_.<tbc>

2. Start from a point \(P'\in\mathbb{P}'\) induced by an STT _T_ that has at least one node that is an LCA (_T_ is not a path). Denote the LCA by _a_ and the two nodes that it separates by _b_ and _c_. Define _P_ to have the same values as \(P'\) except that we set _Z<sub>abc</sub>_=0 and _X<sub>bc</sub>_=1_,X<sub>cb</sub>_=0. One can verify that _P_ is feasible. We say that _a_ remains an implicit ancestor of _b_ and _c_ since we still have that _X<sub>ab</sub>_=1, _X<sub>ac</sub>_=1, but _Z<sub>abc</sub>_=0. If we replace every variable _Z<sub>kij</sub>_=1 as we did for _Z<sub>abc</sub>_, we get a point in P. Note that as a side-effect, we showed some non-STT integer vertices that belong to \(\mathbb{P}'\) and not to P (some ancestors were made implicit but not all of them).

**Remark 3.8.** Theorem 3.7 shows the existence of non-STT, even integer, vertices. In fact, a simple counting argument shows that they are the majority for large _n_. Let _S_ be the set of all STT vertices, and P and \(\mathbb{P}'\) as in the proof of Theorem 3.7. We have that \(|\mathbb{P}'|>|\mathbb{P}|=2^\genfrac(){pt}{2}{n}{2}\), while \(|S|\le n!\) since a permutation uniquely defines an STT by choosing a root and recursing on the suffix (multiple permutations may define the same STT). Finally, note that \(S\subset\mathbb{P}'\).
