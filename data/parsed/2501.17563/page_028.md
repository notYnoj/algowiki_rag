holds for any triplet, if \(k\in(i\unknown\rightarrow j)\) it is implied by path monotonicity, because then \(X_{ik}\ge X_{ij}\), and \(X_{jk}\le 1\) for a minimization objective.)<tbc>

3. LCA separation: For \(k\in(i\unknown\rightarrow j)\), if _k_ is an ancestor of _i_, then _i_ cannot be an ancestor of _j_. Assume that _i_ is an ancestor of _j_ too, then by the transitivity of ancestry _k_ would be an ancestor of _j_ as well, but since _k_ is between _i_ and _j_, it separates them in contradiction to _i_ being an ancestor of _j_. We can represent this in a linear form as \(X_{ki}+X_{ij}\le 1\). Furthermore, we can also require \(X_{ji}+X_{ij}\le 1\) for any STT, thus overall: \(\forall k\in(i\unknown\rightarrow j]:X_{ki}+X_{ij}\le 1\).<tbc>

4. Refining _Z_: we originally defined \(Z_{kij}\le X_{ki},X_{kj}\) as a linearization of _Z<sub>kij</sub>_=min{_X<sub>ki</sub>,X<sub>kj</sub>_}. Considering STTs for which _X_ has 0/1 values, we can restrict further and also demand: \(Z_{kij}\ge X_{ki}+X_{kj}-1\).<tbc>

5. Row-Min/Column-Max: Consider the ancestry matrix _X_ of some STT with root _r_. The minimum in each row \(i\neq r\) is 0 because _X<sub>ir</sub>_=0, and the minimum in row _r_ is 1 because \(\forall j:X_{rj}=1\). Similarly, the maximum in each column \(i\neq r\) is 1, and 0 in column _r_. We can define new variables _m<sub>i</sub>_ for the minimum in row _i_ and _M<sub>i</sub>_ for the maximum in column _i_, and add the constraints: \(\forall j:X_{ji}\le M_i\), \(\forall j:m_i\le X_{ij}\) and \(\sum_iM_i=n-1\), \(\sum_im_i=1\). (The counterparts max-row and min-column are less useful because they change for \(i\neq r\) depending on the STT.)

So far it looks very promising, few natural constraints of STTs were missing from the LP, which we can add. Moreover, we introduced only _O_(|_X_|)+|_Z_| extra inequalities, so the problem is still polynomial.<sup>10</sup> However, these extra inequalities do not fix the polytope, and non-integer vertices remain plentiful where they exist. It may remove some, and create others (due to new hyperplanes), but it does not remove all of them which is what we hoped for, if this was an extended formulation. To see this, we only need to go back to our main example, the vertex _P_ in Figure 3. It satisfies all the additional constraints, as we prove:

1. Path monotonicity: \(X_{12}=X_{13}=\frac{1}{2}>X_{14}=X_{15}=X_{16}=X_{17}=0\); _X_<sub>23</sub>=1_\>X_<sub>24</sub>=_X_<sub>25</sub>=_X_<sub>26</sub>=\(\frac{1}{2}>X_{27}=0\); _X_<sub>3_i_</sub>=0 for all \(i\neq 3\); _X_<sub>43</sub>=1_\>X_<sub>42</sub>=_X_<sub>41</sub>=_X_<sub>46</sub>=\(\frac{1}{2}>X_{47}=0\); \(X_{54}=X_{53}=\frac{1}{2}>X_{52}=X_{51}=X_{56}=X_{57}=0\); _X_<sub>63</sub>=1_\>X_<sub>6_i_</sub>=\(\frac{1}{2}\) for all \(i\neq\{3,6\}\); \(X_{7i}=\frac{1}{2}\) for all \(i\neq 7\).<tbc>

2. Ancestry transitivity: note that if \(X_{ij},X_{jk}\le\frac{1}{2}\) then the inequality becomes trivial because \(X_{ik}\ge 0\) anyway. So the only entries that can possible make _P_ infeasible are pairs that include at least one of the entries _X_<sub>23</sub>=_X_<sub>43</sub>=_X_<sub>63</sub>=1. If \(i\in\{2,4,6\}\) and _j_=3 then _X<sub>jk</sub>_=0 regardless of _k_ and we get the constraint \(X_{ik}\ge 0\) (always true). If \(j\in\{2,4,6\}\) and _k_=3 we need to check that \(X_{i3}\ge X_{ij}\) for any \(i\notin\{j,3\}\). This holds because \(X_{i3}\ge\frac{1}{2}\ge X_{ij}\) (here \(j\neq 3\)).<tbc>

3. LCA separation: If \(X_{ki},X_{ij}\le\frac{1}{2}\) then \(X_{ki}+X_{ij}\le 1\) is satisfied. Then, to verify that _P_ is feasible, we only need to consider the case that _i_=3 or _j_=3. If _i_=3 then _X<sub>ij</sub>_=0 for any _j_ and the inequality is satisfied. For _j_=3 we consider \(i\in\{2,4,6\}\), which is a neighbor of _j_, hence _k=j_=3 is the only option for _k_, and the inequality holds.<tbc>

<sup>10</sup>|_X_| and |_Z_| denote the numbers of _X_ and of _Z_ variables, respectively.
