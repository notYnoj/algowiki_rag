One can verify that each such assignment defines a feasible integer point. We proceed to prove that every vertex corresponds to an assignment that satisfies these conditions. We do this by showing that if any of the three conditions does not hold at a feasible point _P_, then there is a direction _R_ such that \(P'_\pm=P\pm\epsilon R\) are both feasible for some \(\epsilon>0\), thus \(P=\frac{1}{2}(P'_++P'_-)\) is not a vertex. The coordinates of _R_ are either 0 or \(\pm 1\), and we say that a coordinate of _R_ that equals 1 is _increased_ and a coordinate of _R_ that equals -1 is _decreased_. Once we prove that some condition holds, we assume it to hold when we consider other conditions in later arguments.

First note that every variable is bounded in \[0,1\]. Non-negativity is by definition of the LP. If there are variables larger than 1, let _R_ decrease all the variables that are larger than 1 (indeed \(P\pm\epsilon R\) are both feasible).

To prove Condition 3, for fixed \(i,j\neq 1\) note that these variables only participate in the constraint \(X_{ij}+X_{ji}\ge 1-Z_{1ij}\). If _X<sub>ij</sub>+X<sub>ji</sub>\>_1-_Z_<sub>1_ij_</sub>, since \(Z_{1ij}\le 1\) one of _X<sub>ij</sub>_ and _X<sub>ji</sub>_ is positive, and we can choose _R_ to decrease it. Thus _X<sub>ij</sub>+X<sub>ji</sub>_=1-_Z_<sub>1_ij_</sub>. If \(X_{ij},X_{ji}\in(0,1-Z_{1ij})\) (note that if _Z_<sub>1_ij_</sub>=1 this range is empty) then both are positive, and _R_ increases _X<sub>ij</sub>_ and decreases _X<sub>ji</sub>_. We conclude that _X<sub>ij</sub>_ is either 0 or 1-_Z_<sub>1_ij_</sub> and _X<sub>ji</sub>_=1-_Z_<sub>1_ij_</sub>-_X<sub>ij</sub>_. This proves Condition 3.

To prove Condition 2, consider the case _X_<sub>_i_1</sub>+_X_<sub>1_i_</sub>_\>_1 for some _i_. Since both variables are at most 1, both are positive, and _X_<sub>_i_1</sub> only participates in this single inequality, so take _R_ which increases _X_<sub>_i_1</sub>. Now that we have _X_<sub>_i_1</sub>+_X_<sub>1_i_</sub>=1, if _z<sub>i</sub>\<X_<sub>1_i_</sub>_\<_1 then _X_<sub>_i_1</sub>_\>_0, so take _R_ which decreases _X_<sub>1_i_</sub> and increases _X_<sub>_i_1</sub>. (In both cases, the strict inequality ensures that \(P\pm\epsilon R\) are both feasible, so we must have equalities as argued.)

To prove Condition 1, let 0_\<a\<_1 be the largest non-integer value of some _Z_ variable, if such exists. For each _Z_<sub>1_ij_</sub>=_a_ we have \((X_{ij}+X_{ji})\ge(1-a)>0\), so let _A<sub>ij</sub>_ denote a positive variable among _X<sub>ij</sub>_ and _X<sub>ji</sub>_ (if both are, pick one arbitrarily). Then _R_ increases all the _X_ and _Z_ variables whose value is in \[_a,_1\), decreases the variables _A<sub>ij</sub>_ that correspond to an increased _Z_<sub>1_ij_</sub>, and if _X_<sub>1_i_</sub> was increased (because \(a\le X_{1i}<1\)), recall that since Condition 2 holds, _X_<sub>1_i_</sub>+_X_<sub>_i_1</sub>=1, so we also decrease _X_<sub>_i_1</sub> to maintain feasibility in the direction -_R_. \(P\pm\epsilon R\) are both feasible, so if _P_ is a vertex, every \(Z_{1ij}\in\{0,1\}\) as required by Condition 1.

## 3.4 Extending Topologies

In this section we prove that if the LP for a topology has non-integer vertices, the LP of topologies that extend it in some ways also have non-integer vertices. This explains formally, for example, why the three topologies with 8 nodes that are colored in red in Figure 6 must have non-integer vertices once we know that the red topology with 7 nodes has non-integer vertices. We then discuss another kind of extension, when we combine topologies through a new common node.

**Definition 3.11.** We define a single extension of a graph _G_ to \(G'\) and denote it \(G\rightarrow G'\) as the action of adding a new node to _G_ and connecting it to some existing node as a new leaf, or between two adjacent nodes, i.e., subdividing an existing edge into two new edges. We say that _G_ extends _H_, or that _H_ is a shrinking of _G_, if there is a sequence of extensions of length |_G_|-|_H_| such that \(H\rightarrow H'\rightarrow\dots\rightarrow G\).

**Theorem 3.12.** If the LP for a topology _U_ has non-integer vertices, so does the LP for any extension of _U_. The claim holds both for the original space of (_X,Z,D_) variables, and also when only considering the depths _D_.
