If \((a,b)\in T\), then _a_ and _b_ have opposite parity. Therefore \((\sigma(a),\sigma(b))\) is either (0,1) or (1,0) and still belongs to _T_. Applying \(\sigma\) to an assignment therefore preserves every constraint that was already satisfied. Thus every assignment can be replaced by a Boolean assignment satisfying at least the same constraints.

The restriction of _T_ to {0,1} is precisely CUT={(0,1),(1,0)}. In this sense, _T_ is essentially the same relation as CUT. Every assignment over the original domain can be mapped to a Boolean assignment without losing a satisfied constraint, while every Boolean assignment is already available over the original domain. It follows that restricting the domain to {0,1} preserves satisfiability, the minimum number of unsatisfied constraints, and the maximum number of satisfied constraints. This is also the reason the bipartiteness argument above works, but the map \(\sigma\) states it in a form that extends to every relation.

Formally, a map that preserves a relation in this way is called an _endomorphism_, defined formally in Section 3.4. The _core_ of a relation is obtained by choosing an endomorphism with the smallest possible image and restricting the relation to that image. In this example, \(\sigma\) has image {0,1}, and no endomorphism can have a one-element image because _T_ contains no pair (_a,a_). We therefore have core(_T_)=CUT.

Notice that \(\mathsf{NRD}_n(\mathsf{CUT})=\Theta(n)\). If a CUT-instance is satisfiable and nonredundant, its graph must be a forest because every edge on a cycle is implied by the remaining edges. If it is unsatisfiable and nonredundant, removing any edge must make it bipartite, so its nonisolated part is an odd cycle. In either case it has _O(n_) edges, while a forest gives the matching lower bound. Reducing to the core therefore replaces the incorrect quadratic parameter NRD_<sub>n</sub>(T_) by the correct linear parameter NRD_<sub>n</sub>_(CUT).

The examples above suggest the following general statement, which we prove formally in Section 4.

**Theorem 2.1** (Informal Lemmas 4.2 and 4.3)**.** _For every relation R, replacing each R-constraint by the_ core(_R)-constraint on the same scope preserves satisfiability, the minimum number of unsatisfied constraints, and the maximum number of satisfied constraints. Consequently, this replacement preserves the one-pass streaming space of all three problems we consider._

Moreover, this reduction can be performed as the stream arrives. Whenever an _R_-constraint appears, we replace it by the core(_R_)-constraint on the same scope and give it to the algorithm for the core relation.

Now, the remaining task is to prove tight space bounds for the core relation. The satisfiability upper bound now follows immediately. We reduce the stream to the core and apply the algorithm of Sharma and Velusamy [SV26a], which uses _O<sub>R</sub>_(NRD_<sub>n</sub>_(core(_R_))log_n_) space. As we will see later in Section 2.3, the upper bound for exact-optimization follows as well using a simple argument. It remains to prove the lower bound matching this up to the logarithmic factor.

For both the lower bounds, we use the standard connection between streaming algorithms and one-way communication together with the hard problem INDEX, where Alice receives a string \(b\in\{0,1\}^m\) and Bob receives an index _j_ and must recover _b<sub>j</sub>_. At a high level, we reduce this communication problem to a streaming problem as follows. Alice runs the streaming algorithm on constraints determined by her input and sends its memory state to Bob. Bob then appends constraints determined by his query and uses the output to recover the answer. The difficulty is that every constraint Bob appends must be a constraint of the core relation. He cannot directly fix variables to the values determined by his query. The next subsection explains how the core property lets him simulate this operation for satisfiability. The corresponding construction for exact optimization will require a stronger version of the same idea.
