We consider the following problem as _Pareto Sum Verification_: Given \(A,B,C\subseteq\mathbb{Z}^d\), determine whether

\(\forall a\in A\forall b\in B\exists c\in C:a+b\le c.\)

The complexity of Pareto Sum Verification<sup>11</sup> is tightly connected to output-sensitive algorithms for Pareto Sum. Specifically, solving Pareto Sum Verification reduces to _computing_ the Pareto sum _C_ when given inputs _A,B_ of size at most _n_ with the promise that \(|C|=\Theta(n)\); see Section 7 for details. The work of Hespe et al. [37] gives a practically fast _O(n_<sup>2</sup>)-time algorithm in this case for _d_=2; note that for \(d\ge 3\), we still obtain an \(\tilde{O}(n^2)\)-time algorithm via our Baseline Algorithm, which is described in the full version of the paper.

### 1.2.3.1 A problem pair that is complete for FOP<sub>Z</sub>

As a pair, these two geometric problems turn out to be fine-grained complete for the class FOP<sub>Z</sub>.

\(\blacktriangleright\) **Theorem 4.** _There is a function_ \(\epsilon(d)>0\) _such that both of the following problems can be solved in time_ \(O(n^{2-\epsilon(d)})\)

_Pareto Sum Verification,_ _Hausdorff distance under n Translations,_ _if and only if for each problem P in_ \(\mathsf{FOP}_\mathbb{Z}^k\) _with_ \(k\ge 3\) _there exists an_ \(\epsilon_P>0\) _such that P can be solved in time_ \(O(n^{k-1-\epsilon_P})\).

The above theorem shows that a single pair of natural problems captures the fine-grained complexity of the expressive and diverse class FOP<sub>Z</sub>. As an illustration just how expressive this class is, we observe the following barriers:<sup>12</sup> **1.** If there is some \(\epsilon>0\) such that all problems in \(\mathsf{FOP}_\mathbb{Z}(\exists\exists\vee)\) (or \(\mathsf{FOP}_\mathbb{Z}(\forall\exists\exists)\)) can be solved in time \(O(n^{2-\epsilon})\), then OVH (and thus SETH) is false [7, Theorem 16]. **2.** If there is some \(\epsilon>0\) such that all problems in \(\mathsf{FOP}_\mathbb{Z}(\exists\forall\exists)\) (or \(\mathsf{FOP}_\mathbb{Z}(\forall\exists\vee)\)) can be solved in time \(O(n^{2-\epsilon})\), then the Hitting Set Hypothesis is false [7, Theorem 12]. **3.** If for all problems _P_ in \(\mathsf{FOP}_\mathbb{Z}(\exists\exists\vee)\) (or \(\mathsf{FOP}_\mathbb{Z}(\forall\exists\exists)\)), there exists some \(\epsilon>0\) such that we can solve _P_ in \(O(n^{2-\epsilon})\), then the 3-uniform Hyperclique Hypothesis is false [7, Theorem 15]. **4.** If for all problems _P_ in \(\mathsf{FOP}_\mathbb{Z}(\exists\exists\exists)\) (\(\mathsf{FOP}_\mathbb{Z}(\forall\forall\vee)\), \(\mathsf{FOP}_\mathbb{Z}(\forall\exists\exists)\), or \(\mathsf{FOP}_\mathbb{Z}(\exists\exists\vee)\)), there exists some \(\epsilon>0\) such that we can solve _P_ in time \(O(n^{2-\epsilon})\), then the 3-SUM Hypothesis is false (Theorem 1 with Lemma 11). Theorem 4 raises the question whether for any constant dimension _d_, the Hausdorff distance under _n_ Translations admits a subquadratic reduction to Pareto Sum Verification. A positive answer would establish Pareto Sum Verification as complete for the _entire_ class FOP<sub>Z</sub>. We elaborate on this in Section 8.

<sup>11</sup>We remark that our problem definition only checks a single of the three given conditions, specifically, condition (2). However, in Section 7, we will establish that the verifying _all three_ conditions reduces to verifying this single condition. More specifically, for sets _A,B,C_ of size at most _n_, we obtain that if we can solve Pareto Sum Verification in time _T(n_), then we can check whether _C_ is the Pareto sum of _A,B_ in time _O(T(n_)). <sup>12</sup>The first three statements follow from FOP<sub>Z</sub> generalizing the class _PTO_ studied in [7], see Section 1.3. The remaining statements rely on the additive structure of FOP<sub>Z</sub>.
