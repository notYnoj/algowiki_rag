<u>_Handling the Certain Instance (Algorithm 3)_</u>. For the certain instance, each item _x_ has a sampling probability \(p_x(\alpha,\beta)=1\). Therefore, Algorithm 3 simply collects and returns all these items in the corresponding buckets, giving the following lemma.

Lemma 4.5. _Algorithm 3 returns a correct PSS result with parameters_ \((\alpha,\beta)\) _on the set of items in the certain instance in_ \(O(1+\ell)\) _time, where_ \(\ell\) _is the number of items sampled._

<u>_Handling Each Significant Group (Algorithm 4)_</u>. We now discuss the details for handling each \((\alpha,\beta)\)- significant group _G<sub>X</sub>(j_). The core idea of Algorithm 4 is to first obtain a subset _T<sub>Y<sub>j</sub></sub>_ of the next-level item set _Y<sub>j</sub>_ such that each next-level item \(y_i\in Y_j\) is sampled independently with probability \(\mathrm{min}\left\{1,\frac{w(y_i)}{W_X(\alpha,\beta)}\right\}\). To achieve this, Algorithm 4 invokes a PSS query with parameters \((0,W_X(\alpha,\beta))\) on _Y<sub>j</sub>_. As each next-level item _y<sub>i</sub>_ corresponds to a bucket _B<sub>X</sub>(i),T<sub>Y<sub>j</sub></sub>_ is treated as a list of the buckets corresponding to its next-level items. And each bucket \(B_X(i)\in T_{y_j}\) is called a _candidate bucket_ because it has a chance to contain a _potential item_ \(x\in B_X(i)\) which is sampled with probability of \(p=\mathrm{min}\left\{1,\frac{2^{i+1}}{W_X(\alpha,\beta)}\right\}\). If a candidate bucket _B<sub>X</sub>(i_) is confirmed via rejection sampling to have at least a potential item in it, then _B<sub>X</sub>(i_) is called a _promising bucket_.

The next step is to extract items from the candidate bucket. As this step will be reused later, we summarize the steps in Algorithm 5. Specifically, Algorithm 5 accepts each candidate bucket \(B_X(i)\in T_{Y_j}\) as a promising bucket by the following steps, depending on two cases. Denote by _n<sub>i</sub>=|B<sub>X</sub>(i_)| the number of items in _B<sub>X</sub>(i_).

**Case 1** (\(p\cdot n_i\ge 1\)**):** In this case, bucket _B<sub>X</sub>(i_) indeed has probability of 1 to be included in _T<sub>Y<sub>j</sub></sub>_, i.e., \(\mathrm{Pr}[B_X(i)\in T_{Y_j}]=1\). Algorithm 5 generates a random variate _k_∼B-Geo(_p,n<sub>i</sub>_+1). If _k\>n_<sub>1</sub>, which happens with probability _q_=(1-_p)<sup>n<sub>i</sub></sup>_, then reject _B<sub>X</sub>(i_) because \(\mathrm{Pr}[B_X(i)\in T_{Y_j}]\cdot q=(1-p)^{n_i}\) is exactly the probability that _B<sub>X</sub>(i_) has no potential items. Otherwise, _B<sub>X</sub>(i_) is accepted as a promising bucket and the _k_<sup>th</sup> item _x_ in _B<sub>X</sub>(i_) is a potential item sampled with probability _p_.

**Case 2** (\(p\cdot n_i<1\)**):** In this case, \(\mathrm{Pr}[B_X(i)\in T_{Y_j}]=p\cdot n_i\). Algorithm 5 generates a Bernoulli coin \(c\sim\mathrm{Ber}\left(\frac{1-(1-p)^{n_i}}{p\cdot n_i}\right)\). If _c_=0, then reject _B<sub>X</sub>(i_). Otherwise, _B<sub>X</sub>(i_) is accepted as a promising bucket, observing that this event happens with probability \(\mathrm{Pr}[B_X(i)\in T_{Y_j}]\cdot\mathrm{Pr}[c=1]=1-(1-p)^{n_i}\), which is exactly the probability of _B<sub>X</sub>(i_) containing at least one potential item. However, the most tricky aspect is to find the first potential item, _x_, in _B<sub>X</sub>(i_) conditioned on the fact that _B<sub>X</sub>(i_) is a promising bucket, such that _x_ is still equivalently sampled with probability of _p_. To overcome this, Algorithm 5 generates a _truncated geometric_ random variate _k_∼T-Geo(_p,n<sub>i</sub>_), where the truncated geometric distribution guarantees to return an index _k_ such that (i) \(k\le n_i\), and (ii) \(\mathrm{Pr}[k=j]=\frac{p(1-p)^{j-1}}{1-(1-p)^{n_i}}\). As discussed in Section 3, the value of _k_ has the same distribution as the smallest sampled index in \[1_,n<sub>i</sub>_\], each sampled with probability _p_, conditioned on that at least one index being sampled. Therefore, the _k_<sup>th</sup> item in _B<sub>X</sub>(i_) has a probability of _p_ to be sampled as a potential item.

As a result, in either case, if _B<sub>X</sub>(i_) is confirmed as a promising bucket, Algorithm 5 always gives the index _k_ of the first potential item _x_ in _B<sub>X</sub>(i_) with correct probability, _p_.
