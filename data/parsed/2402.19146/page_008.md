Observation 1 implies the following lemma:

**Lemma 2** _Let S_<sub>1</sub>=1_<sup>n</sup> and S_<sub>2</sub> _be a binary string of length n. Then, S_<sub>1</sub> _and S_<sub>2</sub> _CT-match if and only if S_<sub>2</sub>=0_<sup>i</sup>_1<sup>_n-i_</sup> _for some integer_ \(i\ge 0\).

From now on, we discuss the case where 0 appears in both _S_<sub>1</sub> and _S_<sub>2</sub>.

**Lemma 3** _For two binary strings S_<sub>1</sub> _and S_<sub>2</sub> _of length n both containing_ 0_, S_<sub>1</sub> _and S_<sub>2</sub> _CT-match if and only if there exist a string w and two integers_ \(i\ge 1\), \(j\ge 1\) _such that S_<sub>1</sub>=_w_0_<sup>i</sup>_1<sup>_n_-|_w_|-_i_</sup> _and S_<sub>2</sub>=_w_0_<sup>j</sup>_1<sup>_n_-|_w_|-_j_</sup>.

_Proof_ (\(\Longleftrightarrow\)) Since _S_<sub>1</sub> and _S_<sub>2</sub> CT-match, _PD(S_<sub>1</sub>)=_PD(S_<sub>2</sub>) (by Theorem 1). Let _p_ (resp., _q_) be the smallest integer such that _S_<sub>1</sub>\[_p..n_\]=0_<sup>i</sup>_1_<sup>j</sup>_ (resp., _S_<sub>2</sub>\[_q..n_\]=0_<sup>i</sup>_1_<sup>j</sup>_) for some \(i\ge 1\), \(j\ge 0\). Assume that \(1\le q<p\). Since _S_<sub>1</sub>\[_p_-1\]=1 and _S_<sub>1</sub>\[_p_\]=0, either _PD(S_<sub>1</sub>)\[_p_\]=0 or _PD(S_<sub>1</sub>)\[_p_\]_\>_1 holds (i.e., \(PD(S_1)[p]\neq 1\)). On the other hand, _PD(S_<sub>2</sub>)\[_p_\]=1 holds since \(S_2[p-1]\le S_2[p]\). Then \(PD(S_1)[p]\neq PD(S_2)[p]\), which is a contradiction. By a similar discussion, \(1\le p<q\) also leads a contradiction. Next, we assume that _p=q_=1. This assumption implies that the statement holds since \(w=\varepsilon\). Assume that 1_\<p=q_. Suppose on the contrary that \(S_1[1..p-1]\neq S_2[1..p-1]\). There exists an integer _j_<sup>∗</sup> such that \(j^*=max_{1\le j\le p-1}\{j|S_1[j]\neq S_2[j]\}\). This means that _S_<sub>1</sub>\[_j_<sup>∗</sup>+1.._p_-1\]=_S_<sub>2</sub>\[_j_<sup>∗</sup>+1.._p_-1\]. We assume w.l.o.g. that _S_<sub>1</sub>\[_j_<sup>∗</sup>\]=0 and _S_<sub>2</sub>\[_j_<sup>∗</sup>\]=1 (the other case is symmetric).

• If 0 does not appear in _S_<sub>1</sub>\[_j_<sup>∗</sup>+1.._p_-1\], _PD(S_<sub>1</sub>)\[_p_\]=_p-j_<sup>∗</sup>_\>_0 holds. On the other hand, either _PD(S_<sub>2</sub>)\[_p_\]=0 or _PD(S_<sub>2</sub>)\[_p_\]_\>p-j_<sup>∗</sup> holds. Thus \(PD(S_1)\neq PD(S_2)\), which is a contradiction.<tbc>

• If 0 appears in _S_<sub>1</sub>\[_j_<sup>∗</sup>+1.._p_-1\], there exists an integer _i_<sup>∗</sup> such that \(i^*=min_{j^*+1\le j\le p-1}\{j|S_1[j]=S_2[j]=0\}\) holds. This implies that _PD(S_<sub>1</sub>)\[_i_<sup>∗</sup>\]=_i_<sup>∗</sup>-_j_<sup>∗</sup>_\>_0 holds. On the other hand, either _PD(S_<sub>2</sub>)\[_i_<sup>∗</sup>\]=0 or _PD(S_<sub>2</sub>)\[_i_<sup>∗</sup>\]_\>i_<sup>∗</sup>-_j_<sup>∗</sup> holds. Thus \(PD(S_1)\neq PD(S_2)\), which is a contradiction.<tbc>

<tbc>Therefore, _S_<sub>1</sub>=_w_0_<sup>i</sup>_1<sup>_n-p_+1-_i_</sup> and _S_<sub>2</sub>=_w_0_<sup>j</sup>_1<sup>_n-p_+1-_j_</sup> hold for some integers _i,j_ where _w=S_<sub>1</sub>\[1.._p_-1\]=_S_<sub>2</sub>\[1.._p_-1\].<br>
(\(\Longleftrightarrow\)) If \(w=\varepsilon\), it is clear that _S_<sub>1</sub> and _S_<sub>2</sub> CT-match. We consider the case of \(w\neq\varepsilon\). We show that _PD(S_<sub>1</sub>)=_PD(S_<sub>2</sub>) holds, which is suffice due to Lemma 1. It is easy to see that _PD(S_<sub>1</sub>)\[_i_\]=_PD(S_<sub>2</sub>)\[_i_\] for all _i_ that satisfies \(1\le i\le|w|\). Moreover, _PD(S_<sub>1</sub>)\[_i_\]=_PD(S_<sub>2</sub>)\[_i_\]=1 also holds for all _i_ with \(|w|+1<i\le n\). If 0 does not appear in _w_, _PD(S_<sub>1</sub>)\[|_w_|+1\]=_PD(S_<sub>2</sub>)\[|_w_|+1\]=0. We assume that 0 appears in _w_ for the remaining case. Let \(j^*=max_{1\le j\le|w|}\{j|w[j]=0\}\). Since _S_<sub>1</sub>\[|_w_|+1\]=_S_<sub>2</sub>\[|_w_|+1\]=0 and _S_<sub>1</sub>\[1..|_w_|\]=_S_<sub>2</sub>\[1..|_w_\]\], _PD(S_<sub>1</sub>)\[|_w_|+1\]=_PD(S_<sub>2</sub>)\[|_w_|+1\] holds. Therefore _PD(S_<sub>1</sub>)=_PD(S_<sub>2</sub>).
