<tbc>_Example 1._ Let _H_ be the graph _K_<sub>3</sub>+_e_ which is a triangle on vertices 1,2, and 3 and an edge {3,4}. Then, we have Ind<sub>_P_<sub>3</sub>_,H_</sub>=_y_<sub>1</sub>_y_<sub>3</sub>_y_<sub>4</sub>+_y_<sub>2</sub>_y_<sub>3</sub>_y_<sub>4</sub>, Sub<sub>_P_<sub>3</sub>_,H_</sub>=3_y_<sub>1</sub>_y_<sub>2</sub>_y_<sub>3</sub>+_y_<sub>1</sub>_y_<sub>3</sub>_y_<sub>4</sub>+_y_<sub>2</sub>_y_<sub>3</sub>_y_<sub>4</sub>, and Sub<sub>_K_<sub>3</sub>_,H_</sub>=_y_<sub>1</sub>_y_<sub>2</sub>_y_<sub>3</sub>. By the above inclusion- exclusion formula, we have Ind<sub>_P_<sub>3</sub>_,H_</sub>=Sub<sub>_P_<sub>3</sub>_,H_</sub>-3Sub<sub>_K_<sub>3</sub>_,H_</sub>.

Given an _H_, the problem of detecting whether there is an induced _G_ in _H_ is the same as checking whether the polynomial Ind<sub>_G,H_</sub> is not the identity (zero) polynomial. Since the coefficients of all monomials are either 0 or 1 in Ind<sub>_G,H_</sub>, this is equivalent to testing whether it is non-zero modulo _p_ for any prime _p_. In the above example, we can take _p_=3 and then checking whether \(\mathrm{Ind}_{P_3,H}\neq 0\) is equivalent to checking \(\mathrm{Sub}_{P_3,H}\neq 0\). That is, taking modulo 3 eliminated the Sub<sub>_K_<sub>3</sub>_,H_</sub>. It remains to compute Sub<sub>_P_<sub>3</sub>_,H_</sub> efficiently given _H_. However, we don’t know how to do this. Instead, we compute a polynomial where the multilinear monomials correspond to the monomials of Sub<sub>_P_<sub>3</sub>_,H_</sub> and then test whether this new polynomial has a multilinear monomial.

The multilinear monomials of Hom<sub>_P_<sub>3</sub>_,H_</sub> are in 2-to-1 correspondence with the monomials of Sub<sub>_P_<sub>3</sub>_,H_</sub>. This is because _P_<sub>3</sub> has two automorphisms. Therefore, we have now reduced the problem to that of checking whether Hom<sub>_P_<sub>3</sub>_,H_</sub> has a multilinear monomial modulo 3. There is a linear-time algorithm to check whether the polynomial has a multilinear monomial modulo _p_ given a circuit computing it for any _p_ given by Koutis and Williams \[8\]. Moreover, the polynomial Hom<sub>_P_<sub>3</sub>_,H_</sub> can be computed in _O(n+m_)-time as \(\sum_{v\in V(H)}y_v(\sum_{\{u,v\}\in E(H)}y_u)^2\). Therefore, we have a _O(n+m_)-time algorithm for detecting induced _P_<sub>3</sub>.

For the pattern _P_<sub>4</sub>, the above method is not as straightforward as we have to do arithmetic modulo 2 to obtain Ind<sub>_P_<sub>4</sub>_,H_</sub>=Sub<sub>_P_<sub>4</sub>_,H_</sub>. But _P_<sub>4</sub> also has two automorphisms. Therefore, modulo 2 arithmetic will eliminate all multilinear monomials from Hom<sub>_P_<sub>4</sub>_,H_</sub>. We can circumvent this problem by ensuring that only the multilinear monomials corresponding to _P_<sub>4</sub>-homomorphisms where \(\phi(2)<\phi(3)\) survive. We call this condition an _automorphism avoiding condition_. Now, the multilinear monomials of that polynomial will be the same as that of Sub<sub>_P_<sub>4</sub>_,H_</sub>. We sketch the part of the dynamic programming algorithm based on a tree decomposition of _P_<sub>4</sub> to show how this is ensured. Consider _P_<sub>4</sub> labeled as 1--2--3--4 and the tree decomposition _B_<sub>1</sub>--_B_<sub>2</sub>--_B_<sub>3</sub> where _B_<sub>1</sub>={1,2}, _B_<sub>2</sub>={2,3} and _B_<sub>3</sub>={3,4}. For each bag _B<sub>i</sub>_, the algorithm iterates over elements of _V(H_)<sup>|_B<sub>i</sub>_|</sup> and checks whether we can map the vertices in _B<sub>i</sub>_ to the elements in this tuple. So when we iterate over _V(H_)<sup>2</sup> for the bag _B_<sub>2</sub> and we consider the element (_u,v_), we will check that \(\{u,v\}\in E(H)\) and that _u\<v_ (This is the check \(\phi(2)<\phi(3)\)). Therefore for any _P_<sub>4</sub>-subgraph where {_u,v_} is the middle edge, we only account for it once in the final polynomial.

We have already seen in Section 3 how to use (_p,q_)-width tree decompositions to produce circuits of size _O(n<sup>p</sup>m<sup>q</sup>_) for homomorphism polynomials. In the coming sections, we show that these improved constructions along with the above idea can be used to derive faster algorithms for many patterns.
