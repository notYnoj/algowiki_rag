### 6 Induced Paths and Cycles in Bipartite Graphs

In this section, we consider a simple extension of the dynamic programming algorithms given by Díaz, Serna and Thilikos \[4\] and Komarath, Kumar, Mishra and Sethia \[7\] that constructs polynomials different from the homomorphism polynomial. Suppose a bag _B_ in the tree decomposition of the pattern graph _G_ that we use in the dynamic programming algorithm contains vertices _u_ and _v_ such that \(\{u,v\}\unknown\in E(H)\) for the input graph _H_. Then, we can remove monomials that correspond to any homomorphism \(\phi\) from _G_ to _H_ where \(\{\phi(u),\phi(v)\}\in E(H)\) while building the arithmetic circuit for Hom<sub>_G,H_</sub>. We use this idea to obtain the following improved algorithms for detecting induced even length paths and cycles in bipartite graphs.

**Theorem 5.** _Given an m-edge bipartite host graph H as input, we can detect whether H has an induced P_<sub>2_k_</sub> _in_ \(\widetilde{O}(m^{k-1})\)_-time._

_Proof._ We consider the following (0_,k_-1)-width path decomposition of _P_<sub>2_k_</sub>: _B_<sub>1</sub>--_B_<sub>2</sub>--_B_<sub>3</sub> where _B_<sub>1</sub>={1_,...,_2_k_-2}, _B_<sub>2</sub>={2_,...,_2_k_-1}, and _B_<sub>3</sub>={3_,...,_2_k_}. We add conditions to check that the graph induced on images of {1_,...,_2_k_-2} does not have any edges other than that in the labeled _P_<sub>2_k_</sub> using the bag _B_<sub>1</sub>. Similar checks can be done for the bags _B_<sub>2</sub> and _B_<sub>3</sub> as well. Therefore, the only edges other than the ones in labeled _P_<sub>2_k_</sub> will be _e_<sub>1</sub>={1,2_k_}, _e_<sub>2</sub>={1,2_k_-1}, _e_<sub>3</sub>={2,2_k_}. Among these _e_<sub>2</sub> and _e_<sub>3</sub> cannot exist if {1_,...,_2_k_} is a path as that would form an odd cycle in _H_, which is not possible in a bipartite graph _H_. Therefore, the only supergraph of _P_<sub>2_k_</sub> appearing as monomials would be _C_<sub>2_k_</sub>. But a _C_<sub>2_k_</sub> contains a _P_<sub>2_k_</sub> an even number of times. So evaluation over rings of characteristic two will eliminate it. In addition, we use the condition that \(\phi(k)<\phi(k+1)\) to remove one of the automorphisms of _P_<sub>2_k_</sub> from the polynomial. Therefore, the multilinear monomials of the constructed polynomial is in one-to- one correspondence with the monomials of Ind<sub>_P_<sub>2_k_</sub>_,H_</sub> (and not Sub<sub>_P_<sub>2_k_</sub>_,H_</sub>). Since this arithmetic circuit can be constructed and evaluated in \(\widetilde{O}(m^{k-1})\)-time, the theorem follows.

**Theorem 6.** _Given an n-vertex, m-edge bipartite host graph H as input, we can detect whether H has an induced C_<sub>2_k_</sub> _in_ \(\widetilde{O}(nm^{k-1})\)_-time._

_Proof._ We consider the following (1_,k_-1)-width path decomposition for _C_<sub>2_k_</sub>: _B_<sub>1</sub>--_B_<sub>2</sub> where _B_<sub>1</sub>={1_,...,_2_k_-1} and _B_<sub>2</sub>={1,3_,...,_2_k_}. Then, we add the check that in _B_<sub>1</sub> and _B_<sub>2</sub> edges other than the ones in the labeled _C_<sub>2_k_</sub> are absent. The only remaining edge that could occur is {2,2_k_}. But this edge in _C_<sub>2_k_</sub> would lead to an odd cycle, which is not possible in a bipartite _H_. We also add the check \(\phi(1)<\phi(i)\) for all \(i\neq 1\). Therefore, only two automorphisms of _C_<sub>2_k_</sub> will survive. The multilinear part of the resulting polynomial is exactly 2Ind<sub>_C_<sub>2_k_</sub>_,H_</sub>. To check that Ind<sub>_C_<sub>2_k_</sub>_,H_</sub> is non-zero, we can simply check whether the computed polynomial has a non-zero multilinear monomial modulo 3.
