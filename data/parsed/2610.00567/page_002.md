In a seminal paper, Nešetřil and Poljak [9] showed that every 3_k_-vertex pattern graph can be found in \(O(n^{\omega k})\)-time and asked the question whether there are patterns where we can do significantly better. To the best of our knowledge, there is only one pattern family for which we know a (slightly) better upper-bound than the one given by Nešetřil and Poljak [9]’s 41-year-old algorithm. Therefore, research on finding induced copies of fixed size patterns has focused on (1) improvements for small fixed patterns, mostly on four to nine vertices and (2) combinatorial algorithms, where we improve upon the trivial _O(n<sup>k</sup>_)-time bound without using fast matrix multiplication algorithms (See [1,5,10]). For example, Bläser, Komarath, and Sreenivasaiah [1] showed that there is a _O(n_<sup>5</sup>)-time algorithm for finding _C_<sub>7</sub> and recently Dalirrooyfard and Williams [3] showed that this is optimal assuming _K_<sub>5</sub> <sup>1</sup> requires _O(n_<sup>5</sup>)-time for combinatorial algorithms.

In practice, many host graphs in which we wish to find patterns are sparse. Therefore, there has also been research on deriving faster algorithms taking sparse host graphs as input. A common restriction is to assume that the host graph is _d_-degenerate for some fixed _d_ [2]. For example, we can find _C_<sub>7</sub> in _O(n_<sup>2</sup>)- time in a given _n_-vertex, _d_-degenerate graph. The _O(._) here hides factors that are exponential in _d_. Since the degeneracy of a graph can be as high as _n_, these algorithms are not suitable for arbitrary host graphs.

Another line of research to improve the running-time on sparse host graphs is to consider the running-time as a function on both the number of vertices and the number of edges in the host graph. For example, recently, Komarath, Kumar, Mishra and Sethia, [7] have shown that _C_<sub>6</sub> has \(\widetilde{O}(m^2)\)-time <sup>2</sup> algorithms. They obtained this improvement by defining matched treewidth, a new notion of width of tree decompositions. A key sub-routine in their paper is an algorithm to construct small _arithmetic circuits_ (Definition 7) for _graph homomorphism polynomials_ (Definition 10) when the pattern graph has small matched treewidth. To use these arithmetic circuits to find induced patterns, they then construct specific tree decompositions with the required matched treewidth and an additional property that the tree decomposition can be used to avoid duplicate homomorphisms to the same occurence of the pattern as a subgraph while constructing the circuit. However, their work is mainly about counting (not necessarily induced) subgraphs.
