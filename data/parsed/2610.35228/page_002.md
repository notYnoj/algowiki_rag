## 1 Introduction

An independent set in a graph is a set of vertices containing no edge. Given a graph _G_=(_V,E_) on _N_ vertices, the maximum independent set problem asks for an independent set of largest possible size; this size is denoted by \(\alpha(G)\). An approximation algorithm with ratio _R(N_) must output an independent set of size at least \(\alpha(G)/R(N)\). Taking the complement of a graph exchanges independent sets and cliques, so approximation guarantees and hardness results for maximum clique transfer directly to maximum independent set. The decision version is NP-complete by graph complementation and Karp’s NP-completeness result for clique \[Kar72\].

Classical polynomial-time approximation algorithms for general graphs achieve a modest improvement over the trivial factor _N_. Boppana and Halldórsson \[BH92\] obtained an _O(N/_(log_N_)<sup>2</sup>)- approximation by exploiting the structure of graphs that exclude certain subgraphs. Feige \[Fei04\] improved the approximation ratio to _O(N_(loglog_N_)<sup>2</sup>/(log_N_)<sup>3</sup>). These results show that a polylogarithmic saving over the trivial ratio is possible, but they do not give a saving that is a fixed power of the number of vertices.

The theory of probabilistically checkable proofs provides a framework for proving hardness of approximation \[AS98, ALM<sup>+</sup>98\]. Feige, Goldwasser, Lovász, Safra, and Szegedy \[FGL<sup>+</sup>96\] established a connection between interactive proofs and the hardness of approximating clique. Håstad \[Hås99\] subsequently proved that, for every fixed \(\epsilon>0\), a polynomial-time \(N^{1-\epsilon}\)-approximation would imply NP = ZPP. Zuckerman \[Zuc07\] removed the randomness from this hardness result, proving that achieving the same ratio is NP-hard. Thus, assuming \(\mathrm{P}\neq\mathrm{NP}\), polynomial time cannot provide a fixed polynomial saving over the trivial approximation ratio.

Quasi-polynomial time allows a finer range of approximation ratios. For every fixed _a\>_0, enumerating all vertex sets of size at most \(k:=\lceil(\mathrm{log}N)^a\rceil\) gives an _O(N/_(log_N)<sup>a</sup>_)-approximation in time _N_<sup>_O_((log_N)<sup>a</sup>_)</sup>. The largest independent set found is a maximum independent set when \(\alpha(G)<k\) and has size _k_ otherwise. On the hardness side, Khot \[Kho01\] proved hardness of approximation within \(N/2^{(\mathrm{log}N)^{1-\gamma}}\), for some absolute constant \(\gamma>0\), assuming that NP has no zero-error randomized quasi-polynomial-time algorithms. Zuckerman \[Zuc07\] obtained the same form of hardness using deterministic quasi-polynomial-time reductions, under the assumption that NP has no deterministic quasi-polynomial-time algorithms. Khot and Ponnuswami \[KP06\] strengthened the hardness factor to \(N/2^{(\mathrm{log}N)^{3/4+\epsilon}}\) for every fixed \(0<\epsilon<1/4\), assuming that NP does not have randomized quasi-polynomial-time algorithms with bounded error. Their theorem is stated for polynomial-time approximation algorithms, but their randomized reduction has quasi-polynomial running time and output size. Composing it with a quasi-polynomial-time approximation algorithm would therefore contradict the same assumption.

Recently, Lovett \[Lov26\] gave a deterministic quasi-polynomial-time algorithm with an approx imation ratio of \(N/2^{\Omega((\mathrm{log}N)^{1/3})}\), improving the polylogarithmic saving obtained by enumeration to a stretched-exponential saving. More precisely, there is an absolute constant _c\>_0 such that, for every integer \(1\le t\le c(\mathrm{log}N)^{1/3}\), given the promise \(\alpha(G)\ge 2^{-t}N\), his algorithm finds an independent set of size at least 2_<sup>t</sup>_ in time _N_<sup>_O(t_)</sup>. The resulting approximation algorithm runs in time _N_<sup>_O_((log_N_)<sup>1/3</sup>)</sup>. This leaves a substantial gap between the exponent in the algorithmic guarantee and the exponent in the hardness result of Khot and Ponnuswami \[KP06\].

Semidefinite relaxations provide another perspective on this problem. Lovász’s theta function \[Lov79\] gives a semidefinite upper bound on the independence number, and the hierarchy of Lasserre \[Las01\] strengthens such relaxations by imposing consistency and positivity on higher moments. The power of this hierarchy for independent set is limited by the integrality gaps of Tulsiani \[Tul09\]: even \(2^{\Omega(\sqrt{\mathrm{log}N\mathrm{loglog}N})}\) levels can have a gap of \(N/2^{O(\sqrt{\mathrm{log}N\mathrm{loglog}N})}\).
