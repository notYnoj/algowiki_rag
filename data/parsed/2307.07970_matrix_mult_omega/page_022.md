\(\varepsilon_{\ell-1}\)-interface tensor, so we can keep applying the constituent tensor stage algorithm on each level-\((\ell-1)\) interface tensors that was outputted previously until we get a tensor product between a matrix multiplication tensor and independent copies of a level-1 \(\varepsilon_1\)-interface tensor. Finally, we show that each level-1 \(\varepsilon_1\)-interface tensor can be easily degenerated into a matrix multiplication tensor, so we obtain independent copies of matrix multiplication tensors of dimension \(\langle m,m^\kappa,m\rangle\).

## 4.2 Algorithm Outline

We first give a high-level outline of each step of the global stage algorithm. The constituent tensor stage algorithm will share similar high-level ideas.

The algorithm takes in \(\left(\mathrm{CW}_q^{\otimes 2^{\ell-1}}\right)^{\otimes n}\) as input and outputs level-1-independent level-\(\ell\) interface tensors as a degeneration of the input (for simplicity, we consider the \(\varepsilon=0\) case in this outline). In the algorithm, we define the notion of compatibility between level-1 blocks and level-\(\ell\) triples with respect to some specified complete split distributions, so that if all level-1 blocks in the remaining tensor are compatible with _exactly one_ level-\(\ell\) triple, then the subtensors over each remaining triple are level-1-independent. So the goal of the algorithm is to zero out some level-\(\ell\) and level-1 variable blocks such that each remaining level-1 block is compatible with a unique level-\(\ell\) triple. The structure of the algorithm is similar to the global stage algorithm in \[DWZ23\] with the main modification being the generalization from split distributions to complete split distributions.

On input \(\left(\mathrm{CW}_q^{\otimes 2^{\ell-1}}\right)^{\otimes n}\), we first view the tensor as the tensor product of three terms, where each term is called a region, i.e., we write \(\left(\mathrm{CW}_q^{\otimes 2^{\ell-1}}\right)^{\otimes n}\) as \(\otimes_{r\in[3]}\left(\mathrm{CW}_q^{\otimes 2^{\ell-1}}\right)^{\otimes A_r\cdot n}\) for some \(A_1,A_2,A_3\ge 0\) and _A_<sub>1</sub>+_A_<sub>2</sub>+_A_<sub>3</sub>=1. Recall that we are only able to allow the sharing of level-\(\ell\) variable blocks in one of _X_-, _Y_ -, _Z_-dimensions, so each region will allow the sharing of level-\(\ell\) variable blocks in different dimensions and we will perform the subsequent steps on the three regions separately. This step helps balance the number of remaining variable blocks in the three dimensions due to the asymmetric nature of the subsequent procedure.

From now on, we describe the procedure on the first region where we allow the sharing of level-\(\ell Z\)- variable blocks. We perform the same procedure up to rotation of the three dimensions on the other two regions separately.

1. **Zero out according to** \(\alpha\)**.** For a distribution \(\alpha\) over the level-\(\ell\) constituent subtensors and its induced marginals \(\alpha_X,\alpha_Y,\alpha_Z\) in the _X_-, _Y_ -, _Z_-dimensions, we zero out level-\(\ell X\)-, _Y_ -, _Z_-variable blocks that are not consistent with \(\alpha_X,\alpha_Y,\alpha_Z\) respectively.<tbc>

2. **Asymmetric hashing.** We use pairwise independent hash functions that hash level-\(\ell\) index sequences to the set {0_,...,M_-1} for some _M_ which partitions the level-\(\ell\) variable blocks into buckets based on its hash value. Within each bucket, we do asymmetric cleanup so that every level-\(\ell X\)-variable block _X<sub>I</sub>_ or _Y_ -variable block _Y<sub>J</sub>_ is contained in a unique level-\(\ell\) triple _X<sub>I</sub>Y<sub>J</sub>Z<sub>K</sub>_, while a level-\(\ell Z\)-variable block _Z<sub>K</sub>_ could be contained in multiple level-\(\ell\) triples.<tbc>

3. **Compatibility zero-out I.** We define a notion of _compatibility_ with respect to the complete split distributions between level-1 blocks and level-\(\ell\) triples for a set of specified level-\(\ell\) complete split distributions \(\{\beta_{X,i,j,k},\beta_{Y,i,j,k},\beta_{Z,i,j,k}\}_{i+j+k=2^\ell}\) for the _X_-, _Y_ -, _Z_-blocks. We zero out all the level-1 _X_- or _Y_ -blocks that are not consistent with \(\{\beta_{X,i,j,k}\}_{i+j+k=2^\ell},\{\beta_{Y,i,j,k}\}_{i+j+k=2^\ell}\) respectively (we can only do this because every level-\(\ell X\)-variable block _X<sub>I</sub>_ or _Y_ -variable block _Y<sub>J</sub>_ is contained in a unique level-\(\ell\) triple). We zero out all the level-1 _Z_-blocks that are incompatible with any level-\(\ell\) triples.<tbc>
