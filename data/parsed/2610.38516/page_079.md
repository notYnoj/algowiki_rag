### R Data efficiency: the WS layer and the fair baseline on subsets of fold 1

Sections 11.2-11.5 end with the WS layer level with its fair baseline on the full training fold (F1 0.795 / PQ 0.649 against 0.794 / 0.655), and a reviewer may read that as "a tuned U-Net and a classical watershed always match the WS layer". The classical case for a structured output layer is not accuracy at full data but data efficiency: the solve carries a prior (a connected, marker- labelled partition with a soft boundary) that the network would otherwise have to learn, so the structured model should degrade more slowly as the training set shrinks.
