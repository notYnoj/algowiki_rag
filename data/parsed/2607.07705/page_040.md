**Case** \(F'\cap S\neq\emptyset\)**.** It follows that \(F'\) is nonempty. Recall that A defines \(F'\) this way only if there exists an _x_-active edge from \(B\backslash B'_0\). In this case, \(F'\) consists of edges lying on the subpath of _P_ from \(x'(e)\) to _x_, where \(e\in B\backslash B'_0\) is an _x_-active edge with the lowest \(x'(e)\). Claim 17 then tells us that _e_ is (_x,S_)-active. Returning to the earlier dichotomy, we conclude that _X_ contains no path from \(x'(e)\) to _v_. Since \(U_2=U_1\cup\{x'(e)\}\) and we have already shown that no path exists from any vertex of _U_<sub>1</sub> to _v_, the inductive hypothesis for _U_<sub>2</sub> applies. Thus _X_ satisfies C<sub>2</sub>, and consequently C.

In both cases, _X_ satisfies C, which completes the converse direction. \(\lrcorner\)

Therefore, the constraint set C:=A({_u},F_<sub>0</sub>) satisfies all the properties required by the lemma.

Finally, we generalize this construction of C to arbitrary vertices _u_ and _v_. Consider a path from _u_ to _v_ in the underlying graph of _T_. Let _L_:=_v_<sub>1</sub>_,...,v<sub>t</sub>_ be the sequence of vertices on this path, where _v_<sub>1</sub>=_u_ and _v<sub>t</sub>=v_. For each pair of consecutive vertices _v<sub>i</sub>_, _v_<sub>_i_+1</sub> such that the edge in _T_ between them is directed from _v<sub>i</sub>_ to _v_<sub>_i_+1</sub>, we mark _v<sub>i</sub>_ and _v_<sub>_i_+1</sub>. Additionally, we mark _v_<sub>1</sub> and _v<sub>t</sub>_.

We first show that if _X_ is of the form _T-S_+Inv(_S_) for some \(S\subseteq T\), then any path from _u_ to _v_ in _X_ must visit all marked vertices in the order they appear in _L_. Obviously, any such path contains _v_<sub>1</sub>. Now, suppose that some path from _u_ to _v_ contains all marked vertices up to \(v_\ell\) in the required order and does not contain _v<sub>r</sub>_, where \(v_\ell\) and _v<sub>r</sub>_ are marked and all vertices between them are unmarked. Clearly, \(v_r\neq v_1\) and \(v_r\neq v_t\). Then _T_ contains either an edge (_v_<sub>_r_-1</sub>_,v<sub>r</sub>_) or an edge (_v<sub>r</sub>,v_<sub>_r_+1</sub>). Let _e_ be any of these edges that is present in _T_, and let _R_ and _Q_ be the weakly connected components of _T-e_ labeled so that \(v_\ell\in R\) and \(v_r\in Q\). Note that _v<sub>t</sub>_ is then also in _Q_. Observation 3 states that no blocked edge goes from _R_ to _Q_. Additionally, the only tree edge that goes between these components is _e_. Since \(X\subseteq T+B\), the only edge in _X_ leading from _R_ to _Q_ is _e_. Consequently, any path from \(v_\ell\in R\) to \(v_t\in Q\) must contain the edge _e_, and therefore the vertex _v<sub>r</sub>_, which contradicts the definition of _v<sub>r</sub>_.

For each pair \(v_\ell\) and _v<sub>r</sub>_ of consecutive marked vertices in _L_ (such that \(v_{\ell+1},\dots,v_{r-1}\) are unmarked), we construct a separate constraint set \(\mathcal{C}_{\ell,r}\), and then define C as their union. For a given pair \(v_\ell\) and _v<sub>r</sub>_, we distinguish two cases.

1. If \(\ell+1=r\) and _T_ contains an edge \((v_\ell,v_r)\), we define \(\mathcal{C}_{\ell,r}\) as \(\{(F_0,R,B'_0)\}\), where \(R=R_0\cup\{(v_\ell,v_r)\}\). Note that this restriction triple obeys the second property of the lemma statement.<tbc>

2. Otherwise, _T_ contains a path from _v<sub>r</sub>_ to \(v_\ell\). Indeed, if \(\ell+1=r\) and the previous case does not apply, then \((v_r,v_\ell)\in E(T)\). If \(\ell+1<r\), then all vertices _v<sub>i</sub>_ with \(\ell<i<r\) are unmarked, and hence the tree _T_ contains the edges (_v<sub>i</sub>,v_<sub>_i_-1</sub>) and (_v_<sub>_i_+1</sub>_,v<sub>i</sub>_). Concatenating these edges yields a path from _v<sub>r</sub>_ to \(v_\ell\).<tbc>
