Next, we prove that \(\tilde{X}\) is acyclic. If there is a cycle in \(\tilde{X}\), it must contain at least one edge that was not present in _X_. Suppose that it contains an edge \(e\in E_r\subseteq E_p\), and let _u_ and _v_ be the starting and ending vertices of _e_, respectively. By Observation 1, there must be a directed path from _v_ to _u_ in \(\tilde{X}\). We aim to obtain a contradiction with this fact. Recall that _E<sub>p</sub>_ consists of edges from the three paths mentioned in the lemma statement. We consider two cases, depending on which path contains _e_.

1. Assume that _e_ lies either on the path from _v_<sub>1</sub> to _v_<sub>2</sub> or on the path from _v_<sub>3</sub> to _v_<sub>2</sub>. Then \(v\in V_p\), so _v_ has two incident edges in \(\tilde{X}\), both from _E<sub>p</sub>_. If \(v\neq v_2\), it is an internal vertex of the path and thus has exactly one outgoing edge in \(\tilde{X}\). Moreover, the vertex at the opposite end of this edge also belongs to _V<sub>p</sub>_, and we can apply the same reasoning to it. Traversing such edges repeatedly, we eventually reach the vertex _v_<sub>2</sub>, while _u_ is never visited along this walk. Note that _v_<sub>2</sub> is a sink in \(\tilde{X}\): it belongs to _V<sub>p</sub>_ and is therefore incident only to tree edges. Furthermore, \(v_2\in S'\) and is hence either a sink or a source in _T_. Given the directed path from _v_<sub>1</sub> to _v_<sub>2</sub> in _T_, we infer that _v_<sub>2</sub> is a sink. Consequently, _u_ is not reachable from _v_ in \(\tilde{X}\), which leads us to a contradiction.<tbc>

2. The second case is analogous. The only difference is that we consider the path from _v_ to _u_ from the end. If the edge _e_ lies on the path from _v_<sub>3</sub> to _v_<sub>4</sub>, then \(u\in V_p\). If \(u\neq v_3\), then it has exactly one incoming edge in \(\tilde{X}\); let \(u'\) be the starting vertex of this edge. Note that \(u'\in V_p\) as well. By repeatedly moving to the starting vertex of the unique incoming edge, we eventually reach _v_<sub>3</sub>. The vertex _v_<sub>3</sub> is a source in \(\tilde{X}\), and _v_ is never visited along this backward walk. Consequently, a directed path from _v_ to _u_ cannot exist in \(\tilde{X}\), yielding a contradiction.
