Then, our algorithm identifies _T_, _A_ and _B_ in polynomial time. Then, for each \(e\in E(T)\) the algorithm evaluates **p**(_e_). If \(\mathbf{p}(e)\ge k\), the algorithm reports _T-e_+Inv(_e_) as a correct solution (see Observation 4) and stops. Then, the algorithm evaluates **w**(_A_). If \(\mathbf{w}(A)\ge 3k\), the algorithm constructs a solution to I using Lemma 2, outputs it and stops.

The algorithm now targets towards an application of Lemma 4. Let _D_ be the set of all vertices \(v\in V(T)\) such that in-degree and out-degree of _v_ in _T_ are both exactly one. From Lemma 3 we know that |_V(T_)\\_D_| is at most O(_k_+|_A_|)=O(_k_), by \(|A|\le\mathbf{w}(A)<3k\). Let _V<sub>A</sub>_ be the set of vertices incident to _A_ in _G_. Denote \(C:=(V(T)\backslash D)\cup V_A\), |_C_|=O(_k_). The algorithm evaluates _C_ in polynomial time.

Then, in polynomial time, the algorithm computes a set of directed paths of _T_ with both endpoints in _C_. This set is defined uniquely since each vertex in _V(T_)\\_C_ has in-degree and out- degree one in _T_, and has exactly _t_=|_C_|-1 paths. Clearly, this set of paths satisfies the first three points of the Definition 6 of proper path covers. The algorithm then arranges (in polynomial time) the paths in an order _P_<sub>1</sub>_,P_<sub>2</sub>_,...,P<sub>t</sub>_ according to the last point in Definition 6. The formed sequence is a proper path cover P of _T_ with _t_=O(_k_) paths. After that, the algorithm construct a P-respecting ordering _e_<sub>1</sub>_,...,e_<sub>_n_-1</sub> of _E(T_).

We finally move on to the "heart" of our algorithm. The algorithm performs a recursive branching subroutine `extend` (see Algorithm 1) to guess a correct choice of _S_ given by Lemma 4. For the sake of clarity, `extend` does not return the solution (only reports Yes) in the pseudo-code, but it is straightforward to change it so it returns the solution. The algorithm runs \(\text{\texttt{extend}}(\mathcal{I},\mathcal{P},e_1,\dots,e_{n-1},\emptyset,0)\) as an entry-point to this recursive procedure. This finishes the description of the algorithm.

**Correctness.** Note that `extend` cannot give false-positives, since it returns Yes only if \(|S|\ge k+t\) or Lemma 5 returns a solution (which cannot be false-positive). In the first case, |_S_| should have at least _k_ edges with positive remaining profit (which gives a solution by Observation 6), because `extend` takes at most one edge with non-positive **rp** per each path in P.

Now assume that `extend` does not return Yes on I. By Lemma 4, there is a set _S_ that satisfies all three properties from the statement, and applying Lemma 5 to I and _S_ gives a solution to I. `extend` never returned Yes, that is, `extend` was never called with this value of _S_. But the properties of _S_ imply that, if \(e_i,e_j\in S\) are consecutive (with respect to the order _e_<sub>1</sub>_,...,e_<sub>_n_-1</sub>) edges in _S_, then either

• _e<sub>j</sub>_ belongs to the same path as _e<sub>i</sub>_, its remaining profit is positive, and there is no _k_ with _i\<k\<j_ such that **rp**(_S<sub>i</sub>,e<sub>k</sub>_)=**rp**(_S<sub>i</sub>,e<sub>j</sub>_), or<tbc>

• _e<sub>j</sub>_ belongs to path \(P_{\ell^\prime}\) that goes after the path that _e<sub>i</sub>_ belongs to, and there is no _k_ such that \(e_k\in P_{\ell^\prime}\) and **rp**(_S<sub>i</sub>,e<sub>k</sub>_)=**rp**(_S<sub>i</sub>,e<sub>j</sub>_).

In the first case, `extend` will consider the correct choice of \(p\in[k]\) that leads to this choice of _j_, since there is no other edge inbetween _e<sub>i</sub>_ and _e<sub>j</sub>_ with this value of remaining profit. In the second case, `extend` will consider the correct choice of both \(\ell'\in[\ell+1,t]\) and \(p\in[-\mathbf{w}(A),k]\). This will lead to the correct choice of _j_ similarly to the first case. Therefore, we can prove by induction that `extend` will construct _S_ correctly in one of its recursion paths if never returned Yes in process. This contradiction finishes the correctness discussion.

It invokes Lemma 5, which gives \(2^{k^{\mathcal{O}(1)}}\cdot n^{\mathcal{O}(1)}\) multiplier in the running time.
