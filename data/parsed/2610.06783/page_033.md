For \(|W|=O(n^2/\sqrt{D})\), which is what the reductions below produce, the running time in Corollary 16 is _O(n_<sup>2</sup>_/D_<sup>0.063</sup>).

The reduction of Section 3.2 is stated for an arbitrary _D_, with the number of oracle calls and the additional time as functions of _D_ and a free parameter _g_, and Section 3.3 chooses _D_ and _g_.

## 3.2 A deterministic reduction from Exact Triangle to Lop-AE-SparseTri

### Exact Triangle.

An instance of _**Exact Triangle**_ (also called Zero-Weight Triangle, and sometimes "Love Triangle" \[GP18\]) consists of a complete tripartite graph on vertex parts _A,B,C_ of _n_ vertices each, and an integer weight _w(e_) on every edge, with \(|w(e)|\le n^\nu\) for some constant \(\nu\ge 1\). Let _S(a,b,c_):=_w(a,b_)+_w(b,c_)+_w(a,c_). A _**zero triangle**_ is a triangle \((a,b,c)\in A\times B\times C\) with _S(a,b,c_)=0, and the task is to decide whether one exists. As is standard, an instance on an arbitrary _n_-vertex graph reduces to this form by taking three copies of the vertex set and giving every missing edge the weight \(3n^\nu+1\), which lies in no zero triangle (this replaces \(\nu\) by \(\nu+1\)), and the search version, which asks the algorithm to find a zero triangle if one exists, is equivalent to the decision version via a simple self-reduction (the reduction below finds one anyway).

**Theorem 17** (Exact Triangle to Lop-AE-SparseTri, deterministically)**.** _Let_ \(16\le D\le n\)_, and let_ \(1\le g\le\sqrt{D}\) _be an integer. Exact Triangle on n vertices per part with weights of absolute value at most_ \(n^\nu\) _reduces deterministically to at most_ 4_ng instances of_ Lop-AE-SparseTri(_n,D), each with at most_ \(n^2/\sqrt{D}\) _query pairs, plus_ \(O(\nu n^3logn/g+n^{\omega+o(1)}D^{3/2}+n^2Dg)\) _additional time, where_ \(\omega<2.372\) _is the matrix multiplication exponent \[ADV_<sup>+</sup>_25\]. The reduction is non-adaptive: it produces all the instances before it makes any oracle call, so they can be solved in any order, or all together._

The parameter _g_ trades the number of instances against the cost of the search for witnesses in the last step of the proof (the term \(\nu n^3logn/g\)); Section 3.3 balances the two. The oracle returns at most \(n^2/\sqrt{D}\) answers per instance, and the time to read them is counted as part of the oracle calls, rather than as additional time.

_Proof._ The proof has three steps: we hash the weights modulo a prime, build the instances, and search for witnesses.

_Hashing modulo a prime._ We reduce the weights modulo a prime \(p\in[\sqrt{D}/2,\sqrt{D})\), chosen deterministically. This size of _p_ fits the instances below: a piece of _C_ of up to \(\sqrt{D}\) vertices, paired with the _p_ labels, gives a middle part of at most _D_ vertices, and the _n_<sup>2</sup> pairs (_a,b_) fall into _p_ residue classes of about \(n^2/\sqrt{D}\) pairs on average, which is the number of query pairs that an instance may have. A _**false positive**_ of _p_ is a triple (_a,b,c_) with \(S(a,b,c)\neq 0\) and _p|S(a,b,c_); let _F(p_) denote the number of false positives of _p_. For every prime _p_ in the range we count the triples with \(S(a,b,c)\equiv 0(modp)\). This number is the number of false positives _F(p_) plus _Z_<sub>0</sub>, the number of zero triangles, which does not depend on _p_. Each _F(p_)+_Z_<sub>0</sub> is computed by a standard trick for small weights \[AGM97, Zwi02\]: let _P_\[_a,c_\]:=_x_<sup>_w(a,c_)mod_p_</sup> and _Q_\[_c,b_\]:=_x_<sup>_w(b,c_)mod_p_</sup> be matrices over the ring Z\[_x_\]/(_x<sup>p</sup>_-1), so that the coefficient of _x<sup>r</sup>_ in (_PQ_)\[_a,b_\] is the number of \(c\in C\) with \(w(a,c)+w(b,c)\equiv r(modp)\); then _F(p_)+_Z_<sub>0</sub> is the sum over the pairs \((a,b)\in A\times B\) of the coefficient of _x_<sup>-_w(a,b_)mod_p_</sup> in (_PQ_)\[_a,b_\]. Computing _PQ_ takes \(n^{\omega+o(1)}\) ring operations, or _O(n_<sup>log<sub>2</sub></sup><sup>7</sup>) with Strassen’s algorithm \[Str69\], each of them _O(p_<sup>2</sup>) word operations, so \(n^{\omega+o(1)}D^{3/2}\) time over the fewer than \(\sqrt{D}\) primes in the range.
