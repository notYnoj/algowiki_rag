• **The** 3**SUM class.** The subquadratic equivalence class of 3SUM contains the variant with three input sets _A_, _B_, and _C_ (is there \(a\in A,b\in B\), \(c\in C\) with _a+b=c_?) and GeomBase (given _n_ points with integer coordinates on the three horizontal lines _y_=0, _y_=1, and _y_=2, is there a non-horizontal line through three of them?) \[GO95\], All-Numbers 3SUM (for every input number, decide whether it is part of a solution) \[VW10, VW18\] (the reduction becomes deterministic with the self-reductions of \[LVWW16, GP18\], as noted in \[FKP24\]), Convolution-3SUM (do _x_<sub>0</sub>_,...,x_<sub>_n_-1</sub> satisfy _x<sub>i</sub>+x<sub>j</sub>=x_<sub>_i+j_</sub> for some _i,j_?) \[Pˇat10, CH20\], and every nontrivial variant of 3-Linear Degeneracy Testing (are there distinct input numbers _x_<sub>1</sub>_,x_<sub>2</sub>_,x_<sub>3</sub> with \(\alpha_1x_1+\alpha_2x_2+\alpha_3x_3=t\), for fixed integers \(\alpha_1,\alpha_2,\alpha_3,t?\)), such as 3AP, the case _x_<sub>1</sub>+_x_<sub>2</sub>=2_x_<sub>3</sub> (do three of the numbers form an arithmetic progression?) \[DGS20\]. The counting version #3SUM is also in the class \[CVX23, FJX25\]; see the last item below. _We give the first truly subquadratic algorithms for all of these problems._<tbc>

• **The** (min,+)**-convolution class.** The (min,+)-convolution of two sequences _a_ and _b_ of _n_ integers is defined as the sequence _c_ with _c_\[_k_\]=min<sub>_i+j=k_</sub>(_a_\[_i_\]+_b_\[_j_\]) for all _k_. This convolution version of APSP is fine-grained reducible to both the (min,+)-product \[BCD<sup>+</sup>14\] and 3SUM \[BIS17, CMWW19\]. Problems equivalent to (min,+)-convolution include Superadditivity Testing (is \(a[i+j]\ge a[i]+a[j]\) for all _i,j_?), Maximum Consecutive Subsums (for every _k_, the largest sum of _k_ consecutive elements), and Tree Sparsity (a subtree with _k_ vertices of maximum weight in a vertex-weighted tree) \[CMWW19\]. _We give the first truly subquadratic algorithms for all of these problems_, refuting the (min,+)-convolution hypothesis \[KPS17, CMWW19\]. (This would have been possible by refuting either the APSP or the 3SUM hypothesis, and we refute both.)<tbc>

• **Knapsack and Approximate Subset Sum.** Both 0/1 and Unbounded Knapsack, with _n_ items and capacity _t_, reduce to (min,+)-convolution \[CMWW19\]. So does approximating Subset Sum to within a factor \(1-\varepsilon\), which is in fact equivalent to it: an algorithm for (min,+)-convolution in time _T(n_) gives a randomized approximation scheme in \(\tilde{O}(n+T(1/\varepsilon))\) time \[BN21\]. For 0/1 Knapsack, the best known bound in terms of _n_ and the largest item weight \(w_\mathrm{max}\le t\) is \(\tilde{O}(n+w_\mathrm{max}^2)\) \[Bri24, Jin24\]. _We give the first algorithms running in_ \(\tilde{O}(n+t^{2-\delta})\) _time, and the first approximation scheme running in_ \(\tilde{O}(n+(1/\varepsilon)^{2-\delta})\) _time, for a constant_ \(\delta>0\). Only the algorithm for Unbounded Knapsack is deterministic.<tbc>
