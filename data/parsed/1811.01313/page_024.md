## Reduction to Network Coding.

We are ready to make the reduction to network coding. We basically re-execute the reduction we did for sorting. Let \(\Gamma\) be the set of input matrices promised by Lemma 14 and let _G_ be the corresponding I/O-graph.

We create a new graph _G_<sup>∗</sup> from _G_ by adding all nodes and edges from _G_ to _G_<sup>∗</sup>. The edges between block nodes and memory nodes have capacity _b_ bits. The edges between memory nodes have capacity _m_ bits. We also create _n_<sup>2</sup> sources _s_<sub>1,1</sub>_,...,s<sub>i,j</sub>,...,s<sub>n,n</sub>_ and _n_<sup>2</sup> sinks _t_<sub>1,1</sub>_,...,t<sub>i,j</sub>,...,t<sub>n,n</sub>_. We create the coordinator node _u_ and extra nodes _p_<sub>1,1</sub>_,...,p<sub>n,n</sub>_. We add a directed edge from the _s<sub>i,j</sub>_’s to _u_ with capacity _w_. We add a directed edge from _s<sub>i,j</sub>_ to _p<sub>i,j</sub>_ also with capacity _w_. We also add a directed edge from each _p<sub>i,j</sub>_ to the input block node representing entry (_i,j_), having capacity _w_ bits. Similarly, we add a directed edge from the the output block node representing entry (_i,j_) to sink _t<sub>i,j</sub>_ for every _i_. These edges also have capacity _w_ bits. Finally, we add edges with capacity \(\rho_{i,j}\) from _u_ to both _t<sub>i,j</sub>_ and _p<sub>i,j</sub>_ where the parameters \(\rho_{i,j}>0\) will be fixed later.

As in the proof for sorting, we obtain a network coding solution for _G_<sup>∗</sup> as follows: Each source _s<sub>i,j</sub>_ thinks of its _w_-bit input _X<sub>i,j</sub>_ as the entry (_i,j_) of an input matrix to the matrix transpose problem. The sources start by transmitting their input to the special coordinator node _u_. The node _u_ invokes Lemma 7 to obtain a (prefix-free) message _R<sub>i,j</sub>_ for each (_i,j_). The coordinator sends this message _R<sub>i,j</sub>_ to _p<sub>i,j</sub>_ and _t<sub>i,j</sub>_. The sources _s<sub>i,j</sub>_ also forward their input to the nodes _p<sub>i,j</sub>_. From Lemma 7, the nodes _p<sub>i,j</sub>_ can now compute a vector _v<sub>i,j</sub>_ such that, if each _p<sub>i,j</sub>_ replaces _X<sub>i,j</sub>_ by \(X_{i,j}\oplus v_{i,j}\), then the resulting inputs correspond to a matrix \(A\in\Gamma\). The nodes _p<sub>i,j</sub>_ thus compute \(A_{i,j}=X_{i,j}\oplus v_{i,j}\) and sends it to the corresponding input block node. We therefore fix \(\rho_i=\mathbb{E}[|R_{i,j}|]\). The input block nodes now knows the contents of the input blocks when the input matrix is _A_. Thus the network can simulate the entire algorithm A<sup>∗</sup> (see the proof for sorting), which results in the output block nodes knowing the values _A<sub>i,j</sub>_ (A<sup>∗</sup> is correct on all matrices in \(\Gamma\) and uses the same fixed I/O-graph _G_). The output block nodes forward _A<sub>i,j</sub>_ to _t<sub>i,j</sub>_. The sink nodes _t<sub>i,j</sub>_ compute _v<sub>i,j</sub>_ from the message from _u_ and replaces _A<sub>i,j</sub>_ with \(X_{i,j}=A_{i,j}\oplus v_{i,j}\). This completes the simulation. We refer the reader to the proof of the sorting lower bound for a more detailed description.

## Deriving the Lower Bound.

The network coding solution we obtained for _G_<sup>∗</sup> achieves a network coding rate of _w_ bits as all capacity contraints are respected (again, see the proof for sorting for more details). From Conjecture 1, it follows that the multicommodity flow rate has to be at least _w_ for the undirected version of _G_<sup>∗</sup>.

We can again examine how much flow that can be transmitted from the sources to the sinks via a path that uses the node _u_. Since any flow using _u_ as an intermediate node must traverse at least two edges incident to _u_, we conclude that the total amount of flow that can use the node _u_ as an intermediate node on the path to a sink is at most \(n^2w/2+\sum_i\rho_i\). From Lemma 7, we get that if \(|\Gamma|\ge 2^{n^2w-o(n^2w)}\), then \(\sum_i\rho_i=o(n^2w)\). Combining this with Lemma 15, we get that there is at least \((4/5)n^2w-n^2w/2-o(n^2w)=\Omega(n^2w)\) flow that has to traverse a path of length \(\Omega(lg_{2m/b}B)\) in _G_<sup>∗</sup> (the flow must use a path in the undirected version of _G_). Thus the sum of capacities in _G_<sup>∗</sup> must be \(\Omega(n^2wlg_{2m/b}B)\) if \(|\Gamma|\ge 2^{n^2w-o(n^2w)}\). Every I/O made by A<sup>∗</sup> adds _O(b_) bits of capacity to _G_<sup>∗</sup>, thus we get a lower bound of \(t=\Omega(n^2w/b\cdot lg_{2m/b}B)=\Omega(n^2/B\cdot lg_{2M/B}B)\) I/Os, provided that \(|\Gamma|\ge 2^{n^2w-o(n^2w)}\). From Lemma 14, we know that \(|\Gamma|\ge 2^{n^2w}/2(t+2n^2/B+1)^{t+1}\) hence we conclude that either \(t=\Omega(n^2/B\cdot lg_{2M/B}B)\) or \(tlg(t+2n^2/B+1)=\Omega(n^2w)\Rightarrow t=\Omega(n^2w/lg(n^2w))\). This concludes the proof of Theorem 5.
