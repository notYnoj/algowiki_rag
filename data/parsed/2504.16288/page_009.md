Let \(w\in\mathsf{L}(A_\mathsf{sup})\), i.e., let _w_ be a string such that _A_<sub>sup</sub> has an accepting run on _w_. Let _u=u_<sub>0</sub>_w_\[1\]_u_<sub>1</sub>_w_\[2\]_...u_<sub>|_w_|-1</sub>_w_\[|_w_\]]_u_<sub>|_w_|</sub> be the string that we obtain by listing the transitions of this accepting run in order, substituting each \(\Sigma\)-transition (_p,b,q_) by _b_, each original \(\varepsilon\)-transition of _A_ by \(\varepsilon\), and every \(\varepsilon\)-transition that has been added due to some \(\Sigma\)-transition (_p,b,q_) by _b_ (since there might be several choices for this, we take just any of those). By construction, there must be an accepting run of _A_ on _u_, which means that \(u\in\mathsf{L}(A)\) and therefore \(w\in\Lambda_{\unknown_\mathsf{sub}}(\mathsf{L}(A))\).

Consequently, we can solve the subsequence and supersequence matching problem by checking whether \(w\in\mathsf{L}(A_\mathsf{sub})\) and \(w\in\mathsf{L}(A_\mathsf{sup})\), respectively, via state-set simulation. Since \(|A_\mathsf{sub}|=O(n|\Sigma|+m)\) and |_A_<sub>sup</sub>|=_O(m_), we get the following:

**Theorem 3.4.** _The subsequence matching problem can be solved in time_ \(O(|w|(n|\Sigma|+m))\) _and the supersequence matching problem can be solved in time O_(|_w|m)._

## 3.3 Improved Algorithms for Sub- and Supersequence Matching

It has been observed in \[BLS15, Lemma 9\] that the \(\varepsilon\)NFAs _A_<sub>sub</sub> and _A_<sub>sup</sub> have special properties that can be exploited in the state-set simulations to improve the bounds of Theorem 3.4.

Firstly, for _A_<sub>sub</sub>, whenever a state _p_ of _A_<sub>sub</sub> is added to the set of active states in the state- set simulation, it will stay active until the end of the state-set simulation. This is due to the existence of the transitions (_p,b,p_) for every \(b\in\Sigma\). Consequently, for the state-set simulation of _A_<sub>sub</sub>, we have \(S_0\subseteq S_1\subseteq\dots\subseteq S_{|w|}\). Secondly, for _A_<sub>sup</sub>, we can observe that the state-set simulation starts with \(S_0=\mathsf{C}_\varepsilon^*(\{q_0\})=Q\), i.e., the set of all states, which is due to the fact that every state in _A_<sub>sup</sub> is reachable from _q_<sub>0</sub> by \(\varepsilon\)-transitions and therefore is in the \(\varepsilon\)-closure of _q_<sub>0</sub> with respect to _A_<sub>sup</sub>. Moreover, when a state _q_ is removed, it is never added back. Indeed, assume by contradiction that \(q\notin S_{i-1}\) but _q_ gets added to _S<sub>i</sub>_ by an update step. Then _q_ is not reachable from _S_<sub>_i_-1</sub> by \(\varepsilon\)-transitions, but it is reachable from C<sub>_w_\[_i_\]</sub>(_S_<sub>_i_-1</sub>) by \(\varepsilon\)-transitions: this is impossible because in _A_<sub>sup</sub> there is a transition \((p,\varepsilon,q)\) for every existing transition (_p,b,q_) with \(b\in\Sigma\). Thus, \(S_0\supseteq S_1\supseteq\dots\supseteq S_{|w|}\).

This means that in the state-set simulation for _A_<sub>sub</sub> and _A_<sub>sup</sub> on an input string _w_, we can encounter at most _n_+1 different sets of active states. Further, for each set of active states, there are at most \(|\Sigma|\) possible update steps necessary (since if \(\mathsf{C}_\varepsilon^*(\mathsf{C}_{w[i+1]}(S_i))=S_i\) and _w_\[_i_+1\]=_w_\[_j_+1\] and _S<sub>i</sub>=S<sub>j</sub>_ for some _i\<j_ hold, then we do not need to update _S<sub>j</sub>_). Every actual update can again be done in time _O(m_), which yields the following:

**Theorem 3.5.** _There are algorithms that solve the subsequence matching problem in time_ \(O(|w|+n|\Sigma|\cdot(n|\Sigma|+m))\) _and the supersequence matching problem in time_ \(O(|w|+n|\Sigma|m)\).

_Proof._ According to Lemmas 3.2 and 3.3, we can solve the subsequence and supersequence matching problem by checking \(w\in\mathsf{L}(A_\mathsf{sub})\) and \(w\in\mathsf{L}(A_\mathsf{sup})\), respectively. The proof of the theorem therefore follows from the fact that for both _A_<sub>sub</sub> and _A_<sub>sup</sub> a state-set simulation can be performed in time \(O(|w|+n|\Sigma|\cdot|A_\mathsf{sub}|)\) and \(O(|w|+n|\Sigma|\cdot|A_\mathsf{sup}|)\) instead of \(O(|w|\cdot|A_\mathsf{sub}|)\) and \(O(|w|\cdot|A_\mathsf{sup}|)\), respectively (note that _n_ is the number of states of _A_, _A_<sub>sub</sub> and _A_<sub>sup</sub>). Let us discuss this first for the case of _A_<sub>sub</sub>.
