Initially, we set \(S_0=\mathsf{C}_\varepsilon^*(\{q_0\})\), where this \(\varepsilon\)-closure is computed as described above, i.e., ignoring marked \(\varepsilon\)-transitions (of which, at this step of the algorithm, none exist anyway) and marking the traversed \(\varepsilon\)-transitions. We note that this initialisation takes time proportional to the number of transitions that we mark.

Further, by traversing the lists _L_\[_q_\], for \(q\in S_0\), we can also compute, for each \(a\in\Sigma\), the list \(H[a]=\{(q,a,q')\in\delta|q\in S_0,q'\in Q\}\); note that these transitions are not marked yet, as we have only marked \(\varepsilon\)-transitions until now, and also that there are no unmarked \(\varepsilon\)-transitions leaving the states of _S_<sub>0</sub>. This takes time proportional to the sum of |_S_<sub>0</sub>| and the number of transitions inserted into the lists stored in _H_.

Let us now explain the update step, i.e., how _S<sub>i</sub>_ is computed and _H_ is updated for \(1\le i\le|w|\).

We initially set _S<sub>i</sub>=S_<sub>_i_-1</sub> and let _R_ be an auxiliary empty queue, which will be used to collect all the new states from _S<sub>i</sub>_\\_S_<sub>_i_-1</sub>. Now, for each \((q,w[i],q')\in H[w[i]]\), we mark the transition \((q,w[i],q')\), remove it from _H_\[_w_\[_i_\]\], and, if \(q'\notin S_i\), then we add \(q'\) to _S<sub>i</sub>_ and _R_. It is worth noting that, after this loop concludes, the set _H_\[_w_\[_i_\]\] will be empty. Moreover, for all states \(q\in S_{i-1}\), there is no unmarked transition \((q,w[i],q')\) for any \(q'\in Q\). Then we compute \(\mathsf{C}_\varepsilon^*(R)\), but again we ignore marked \(\varepsilon\)-transitions and mark all traversed \(\varepsilon\)-transitions. All states \(q\in\mathsf{C}_\varepsilon^*(R)\) with \(q\notin S_i\) are added to both _R_ and _S<sub>i</sub>_. At this point, for all states \(q\in S_i\), there is no unmarked transition \((q,\varepsilon,q')\) for any \(q'\in Q\). Finally, for every \(r\in R\) and for every transition \((r,a,r')\in L[r]\) with \(a\in\Sigma\) and \(r'\in Q\), we add \((r,a,r')\) to _H_\[_a_\] (note that this transition could not have been marked before, as _r_ was not contained in any set _S<sub>j</sub>_ for _j\<i_); this step takes time proportional to the sum of |_R_| and the number of transitions inserted into the lists stored in _H_.

Once the state-set simulation is completed, we terminate and answer positively if and only if \(q_\mathsf{f}\in S_{|w|}\).

As far as the complexity of the above algorithm is concerned, we note that we have to perform _O_(|_w_|) individual updates. The total number of steps over all these updates is upper-bounded by the number of transition-insertions in the lists of \(H[\cdot]\) and transition-markings. Each transition is either never marked, or it is marked in the initialisation, where we compute \(\mathsf{C}_\varepsilon^*(\{q_0\})\), or it is inserted in one of the lists of the array \(H[\cdot]\) for some _i_, and then it may be marked at most once and never considered again (also, it will never be reinserted in \(H[\cdot]\) because its source state became active when the transition was inserted so the state will never be added to the queue _R_ in further update steps). Thus, our algorithm runs in _O_(|_w_|+_m_) time.

The correctness follows from the observation that our algorithm computes exactly the sets _S_<sub>0</sub>_,S_<sub>1</sub>_,...,S_<sub>|_w_|</sub> of the state-set simulation with respect to the automaton _A_sub on input _w_ (see Section 3). Indeed, the set _S_<sub>0</sub> is correctly computed in the initialisation, where we also compute \(H[a]=\{(q,a,q')\in\delta|q\in S_0,q'\in Q,(q,a,q')\text{unmarked}\}\) for every \(a\in\Sigma\). Then, assuming that _S_<sub>_i_-1</sub> is correctly computed and the contents of _H_ satisfy \(H[a]=\{(q,a,q')\in\delta|q\in S_{i-1},q'\in Q,(q,a,q')\text{unmarked}\}\) for every \(a\in\Sigma\), we compute _S<sub>i</sub>_ by first computing C<sub>_w_\[_i_\]</sub>(_S_<sub>_i_-1</sub>) by adding all \(q'\) for every \((q,w[i],q')\in H[w[i]]\). Then we compute \(\mathsf{C}_\varepsilon^*(\mathsf{C}_{w[i]}(S_{i-1}))\) by adding the \(\varepsilon\)-closure of the states from _R_, but only with respect to unmarked \(\varepsilon\)-transitions, which is correct, since all marked transitions lead to states already in _S_<sub>_i_-1</sub> and can therefore be ignored. Finally, _H_ is correctly updated by adding \((r,a,r')\) to _H_\[_a_\] for every \(r\in R\) and every transition \((r,a,r')\in L[r]\) with \(a\in\Sigma\); as noted before, no transition starting in _r_ was marked, so the transitions added in this step are all unmarked, and there are no other transitions originating in _S<sub>i</sub>_ that do not already belong to the lists of _H_.

Therefore, we have shown a correct algorithm, solving the subsequence matching problem in _O_(|_w_|+_m_) time.
