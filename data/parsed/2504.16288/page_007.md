In each of our problems, the input always consists of an \(\varepsilon\)NFA and a string over \(\Sigma\). As we are aiming for low complexities, it is important to define formally how the input is written: we will always assume that it obeys the following assumptions. For an \(\varepsilon\)NFA \(A=(Q,\Sigma,q_0,q_\ell,\delta)\) with |_Q_|=_n_, \(|\Sigma|=\sigma\), and \(m=|\delta|\), we assume that _Q_={1_,...,n_} and \(\Sigma=\{1,\dots,\sigma\}\); we can thus assume that both _Q_ and \(\Sigma\) are ordered sets, w.r.t. the canonical order on natural numbers. It follows that the processed strings are sequences of integers (representing the symbols), each of these integers fitting in one memory word. This is a common assumption in string algorithms: the input alphabet is said to be _an integer alphabet_ (see, e.g., \[CHL07\]). Due to the assumptions about \(\varepsilon\)NFAs made above, we also know that \(n,\sigma\) are in _O(m_). Moreover, such an automaton _A_ is given by its number of states, size of the input alphabet, initial and final state, and a list of _m_ transitions of the form \((q,a,q')\), with \(q,q'\in Q\) and \(a\in\Sigma\cup\{\varepsilon\}\).

Further, using radix sort, we can prepare for each state _q_ the list _L_\[_q_\] of outgoing transitions, sorted first according to the symbol labelling them, and then by the target state; for states without outgoing transitions we set \(L[q]\leftarrow\emptyset\). This allows us to simultaneously construct, for each \(q\in Q\) and \(a\in\Sigma\cup\{\varepsilon\}\) for which _q_ has an outgoing _a_-transition, the list _T_\[_q,a_\] of transitions of the form \((q,a,q')\); _T_\[_q,a_\] is undefined for \(q\in Q\) and \(a\in\Sigma\cup\{\varepsilon\}\) in the case where _q_ has no outgoing _a_-transition. We will make the convention that, in the case that a self-loop (_q,a,q_) exists, then (_q,a,q_) is the first transition stored in _T_\[_q,a_\]; this allows us to test in _O_(1) whether there exists a self-loop (_q,a,q_) for any \(q\in Q\) and \(a\in\Sigma\cup\{\varepsilon\}\). Both \(L[\cdot]\) and \(T[\cdot,\cdot]\) are implemented as arrays (of lists), which are lazily initialised (as mentioned above). So, computing the defined elements of \(L[\cdot]\) and \(T[\cdot,\cdot]\) can be done in linear time, i.e., in _O(m_).

## 3 State-Set Simulation and Simple Upper Bounds

Given a string \(w\in\Sigma^*\) and a regular expression represented as an \(\varepsilon\)NFA _A_, we can solve the regex matching problem of deciding whether \(w\in\mathsf{L}(A)\) using the classical approach of _state-set simulation_. It is well-known \[BI16\] that, assuming the strong exponential time hypothesis (SETH), this yields an optimal \(O(|w|\cdot|A|)\) algorithm. For our variants of regex matching, it is often possible to build an \(\varepsilon\)NFA \(A'\) from _A_ that accepts suitable strings (e.g., the subsequences or supersequences of strings of L(_A_)), so that we can solve the matching problem by checking whether \(w\in\mathsf{L}(A')\) by state-set simulation (though this is generally not optimal). Since many of our algorithms will nevertheless be specialised variants of state-set simulation, we review the technique in more detail below.

### 3.1 State-Set Simulation for \(\varepsilon\)NFA

For an NFA _A without_ \(\varepsilon\)-transitions and an input string _w_, the state-set simulation starts with _S_<sub>0</sub>={_q_<sub>0</sub>} and then, for every _i_=1,2_,...,|w_|, computes the set _S<sub>i</sub>_=C<sub>_w_\[_i_\]</sub>(_S_<sub>_i_-1</sub>), where, for any state set _S_ and symbol \(b\in\Sigma\), we call C_<sub>b</sub>(S_) the set of all states that can be reached from a state in _S_ by a _b_-transition, i.e., \(\mathsf{C}_b(S)=\{q|\exists p\in S\wedge(p,b,q)\in\delta\}\). Clearly, each _S<sub>i</sub>_ contains exactly the states that are reachable from _q_<sub>0</sub> by a _w_\[1:_i_\]-labelled path. Now if we are dealing with an \(\varepsilon\)NFA, then we can use the same idea, but we also have to compute the \(\varepsilon\)_-closures_ \(\mathsf{C}_\varepsilon^*(S)\) in between, i.e., the set of all states that can be reached from a state in _S_ by a path of \(\varepsilon\)-transitions. More precisely, we start with \(S_0=\mathsf{C}_\varepsilon^*(\{q_0\})\) and then, for every _i_=1,2_,...,|w_|, we compute the set \(S_i=\mathsf{C}_\varepsilon^*(\mathsf{C}_{w[i]}(S_{i-1}))\). Now each _S<sub>i</sub>_ contains exactly the states that are reachable from _q_<sub>0</sub> by a path that is labelled with _w_\[1:_i_\] (with \(\varepsilon\)-transitions being ignored in the path label). Computing _S_<sub>0</sub> is called the _initialisation_ and computing _S<sub>i</sub>_ from _S_<sub>_i_-1</sub> is called an _update step_ of the state-set simulation. For every _i_=0,1,2_,...,|w_|, the set _S<sub>i</sub>_ is the set of _active states at step i_. We also say that a state _p_ is _active at step i_ if \(p\in S_i\).
