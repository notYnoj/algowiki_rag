<tbc>plication process. In the forward multiplication process, the entries of the product matrix are evaluated in row-major order from row 1 to row _n_, in each row from left to right. In the backward multiplication process, entries are evaluated from row _n_ to row 1, in each row from right to left.

To compute the all-pairs shortest time paths in a temporal graph, we adopt the basic concept of in-place ordered matrix multiplication in Hu’s algorithm mentioned above and introduce appropriate modifications on it to deal with the time-varying nature of the connecting edges. First, the matrix multiplication is equivalently replaced by an operation where, in computing an element of the product matrix, the multiplication of two elements of a matrix is replaced by \(\otimes\) operation between _P_ and _A_ and second, the summation of these computed products is replaced by augmenting each of the (_p,q)<sup>th</sup>_ entries, \(1\le p,q\le n\) of the product matrix with the newly generated 3-tuples containing information of additional contacts from _p_ to _q_ during the period under consideration. Finally, from each such (_p,q)<sup>th</sup>_ entry of the product matrix, the 3-tuple with the minimum time between the start and finish intervals is chosen to find the shortest time path from _p_ to _q_. Our proposed algorithm for computing all-pairs shortest time paths of a temporal graph is<tbc>

<tbc>shown in Algorithm 1, where we essentially perform the in- place computation of the path matrix \(P(p,r),1\le p,r\le n\) through a forward and backward process of this equivalent matrix multiplication operation.

In this algorithm, we first initialize the path matrix \(P(p,r),1\le p,r\le n\) by executing Procedure 2. In this procedure, for each diagonal entry (_p=r_), we initialize \(\nu_{pr}=I_s^{pr}[1]=I_f^{pr}[1]=pred^{pr}[1]=0\). For non diagonal entry (\(p\neq r\)), we call _find\_next\_run_ (Procedure 1) to find all the consecutive runs of length _t<sub>pr</sub>_ from \(CS_{pr}\in A\), and set \(\nu_{pr}=k\), where _k_ is the total number of runs of length _t<sub>pr</sub>_, \(1\le k\le M-t_{pr}\), and update all the entries \(I_s^{pr}[k],I_f^{pr}[k]\), and _pred<sup>pr</sup>_\[_k_\], accordingly. Once we initialize the path matrix _P_, we start the forward and backward process by executing _update\_all\_possible\_contacts_ (Procedure 3). In this procedure, for each entry of _P(p,r_), we find all possible paths through the vertex _q_, \(1\le q\le n\) and \(q\neq r\), avoiding any duplicate entry ans also entries with larger duration for a given finish time interval \(I_f^{pr}\). After computing all the intervals of _P(p,r_), we call Procedure 4 to find the minimum time path among all the intervals in _P(p,r_). Finally, we set the interval number \(\nu_{pr}=1\) and update \(I_s^{pr}[1],I_f^{pr}[1],pred^{pr}[1]\) by the minimum time path accordingly. Thus, Algorithm 1 computes all-pairs shortest time communication paths in 6G networks based on temporal graph representation.
