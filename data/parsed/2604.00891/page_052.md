First, when combining two solutions, we can no longer assume that the two subgraphs are edge- disjoint. Instead, we subtract the weight of all edges induced by \(\mathcal{M}'\) from the total sum as these are precisely the edges that are counted twice. Second, we need to compute which graph the union of two graphs models exactly. Here, we make a case distinction between self loops and other edges. For self loops, we use a slight adaptation of Lemma 13 to compute the number of self loops (the feedback edge number) of the union of two forests represented by two partitions. For each other edge _e_={_u_<sub>1</sub>_,u_<sub>2</sub>} between two nodes in _Z_, it is easy to verify that the union of two graphs models exactly \(\delta_1(e)+\delta_2(e)-g(e)\) parallel edges with endpoints _e_, where \(\delta_1(e)\) is the number of parallel edges modeled by the first graph, \(\delta_2(e)\) is the number of edges modeled by the second graph, and _g(e_) is the number of edges induced by \(\mathcal{M}'\) that have one endpoint \(v_1\in c_1(u_1)\) and one endpoint \(v_2\in c_1(u_2)\) (note that we require that \(v\in c_1(u)\) if and only if \(v\in c_2(u)\) for all \(u\in U\) and \(v\in\mathcal{M}'\)). Finally, we only consider counting functions for separations with at most _t_ nodes and thus Lemma 18 allows us to enumerate them all in \(2^{\mathcal{O}(log(\psi(H))\sqrt{d}log^8(d)}\) time. Choosing \(\gamma_H(d)\in 2^{\mathcal{O}(log(\psi(H))\sqrt{d}log^{10}(d))}(\sigma_t(H))^2\) allows us to also iterate over all pairs of counting functions. The rest of the proof is nearly identical to the proof of Theorem 6.

Combined with Lemmas 16 and 17, this also shows that Maximum-Weight Rooted Parallel Induced Minor can be solved in 2<sup>O(_k/_log(_k_))</sup>_n_<sup>2.49</sup> time.

**Corollary 5.** _For planar input graphs,_ Maximum-Weight Rooted Parallel Induced Minor _can be solved in_ 2<sup>O(_k/_log_k_)</sup>_n_<sup>2.49</sup> _time._

_Proof._ We simply compute \(\psi(H)\) in O(|_U_|+|_F_|) time. If \(\psi(H)>k\), then we return no. This is correct by Lemma 16. Otherwise, the running time presented in Theorem 7 is upper bounded by 2<sup>O(_k/_log_k_)</sup>_n_<sup>2.49</sup> by Lemma 17.

Similar to the previous subsection, Maximum-Weight Induced Subgraph Isomorphism is the special case of Maximum-Weight Rooted Parallel Induced Minor where _k_=|_U_|. Note that if _H_ is not a simple graph, then the answer is always no in this case. Moreover, Maximum- Weight Induced Matching is a special case of Maximum-Weight Induced Subgraph Isomorphism where the number of non-isomorphic separations of size at most \(12000\sqrt{k}log^8(k)\) is in \(2^{\tilde{\mathcal{O}}(\sqrt{k})}\). This yields the following.

**Corollary 6.** _For planar input graphs,_ Maximum-Weight Induced Subgraph Isomorphism _can be solved in_ 2<sup>O(|_U_|/log(|_U_|))</sup>_n_<sup>2.49</sup> _time and in_ 2<sup>O(_k/_log(_k_))</sup>_n_<sup>2.49</sup> _time._ Maximum-Weight Induced Matching _can be solved in_ \(2^{\tilde{\mathcal{O}}(\sqrt{k})}n^{2.49}\) _time for planar input graphs._

## 5 Conclusion

We introduced a general framework for developing subexponential parameterized algorithms for problems on planar graphs that ask for a set of at most _k_ vertices satisfying some property. The framework is applicable to non-bidimensional problems where the solution can induce a graph with many connected components and it can handle directed graphs and weighted problems as well. We showed how to apply the framework to a selection of problems that were previously unknown to have subexponential parameterized algorithms for planar input graphs. In the case of (unweighted) Densest _k_-Subgraph, this resolves an open problem from the literature.
