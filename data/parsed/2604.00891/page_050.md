The number of ways to distribute the at most \(\mathrm{log}(\psi(H))/\mathrm{180}\) edges incident to vertices in _C_ to the set of edges in _G<sub>C</sub>_ and the edges between vertices in _C_ and vertices in _Z_ such that each edge has multiplicity at least one (the number of options for characteristic (v)) is equivalent to the number integer compositions<sup>5</sup> of the number \(\lfloor\mathrm{log}(\psi(H))/\mathrm{180}\rfloor\), which is upper-bounded by \(2^{\mathrm{log}(\psi(H))/\mathrm{180}}\) \[Sta97\]. Combining all of the above, the number of non-isomorphic small connected components is at most \(2^{\mathrm{36}\mathrm{log}(\psi(H))/\mathrm{180}}\cdot 37t\cdot 2^{\mathrm{log}(\psi(H))/\mathrm{30}}\cdot 2^{\mathrm{log}(\psi(H))/\mathrm{180}}<37t2^{\mathrm{45}\frac{\mathrm{log}(\psi(H))}{\mathrm{180}}}=37t\psi(H)^{\mathrm{1}/\mathrm{4}}\in\mathcal{O}(\psi(H)^{\mathrm{11}/\mathrm{12}})\) as \(t\in\mathcal{O}(\psi(H)^{\mathrm{2}/\mathrm{3}})\).

Given the separator \(Z=X\cap Y\) for unknown _X_ and _Y_ , the number of highly connected connected components in _H_\[_U_\\_Z_\] is at most 5_t_ \[GHO<sup>+</sup>13\]. We next analyze the number of heavy connected components. Note that the number of edges in _H_ is at most \(^{\mathrm{5}\psi(H)/\mathrm{2}}\). Since each heavy connected component is incident to at least \(\mathrm{log}(\psi(H))/\mathrm{180}\) edges and there are no edges between two such connected components (because _Z_ is a separator), there are at most \(^{\mathrm{450}\psi(H)/\mathrm{log}(\psi(H)}\) heavy connected components in _H_\[_U_\\_Z_\]. Hence, the number of possible partitions of highly connected and heavy connected components to either _X_ or _Y_ is at most \(2^{\mathrm{5}t}2^{\mathrm{450}\psi(H)/\mathrm{log}(\psi(H))}\in 2^{\mathcal{O}(\psi(H))/\mathrm{log}(\psi(H))}\).

We now combine all previous steps. The number of possible separators _Z_ is in \(\psi(H)^{\mathcal{O}(\psi(H)^{\mathrm{2}/\mathrm{3}})}\). The number of possible partitions of highly connected and heavy connected components to either _X_ or _Y_ is in \(2^{\mathcal{O}(\psi(H))/\mathrm{log}(\psi(H))}\). The number of non-isomorphic connected components is in \(\mathcal{O}(\psi(H)^{\mathrm{11}/\mathrm{12}})\) and we decide for each of them how many are added to _X_. There are at most \(\psi(H)\) vertices in _H_ and this also upper bounds the total number of connected components in _H_\[_U_\\_Z_\]. Thus, the number of non-isomorphic separations of _H_ is in

\(\psi(H)^{\mathcal{O}(\psi(H)^{\mathrm{2}/\mathrm{3}})}\cdot 2^{\mathcal{O}(\psi(H)/\mathrm{log}(\psi(H)))}\cdot\psi(H)^{\mathcal{O}(\psi(H)^{\mathrm{11}/\mathrm{12}})}\subseteq 2^{\mathcal{O}(\psi(H)/\mathrm{log}(\psi(H)))}.\)

It remains to analyze the running time for enumerating all non-isomorphic separations of _H_. Note that \(|U|+|F|\in\mathcal{O}(\psi(H))\) by definition of \(\psi\). The time required to iterate over all possible separators _Z_ of size at most _t_ is in \(\mathcal{O}(\genfrac(){pt}{2}{|U|}{t})\). Computing the connected components of _H_\[_U_\\_Z_\] takes \(\mathcal{O}(\psi(H))\) time. Next, we show how to partition all connected components of _H_\[_U_\\_Z_\] such that for two connected components with vertex sets _C_<sub>1</sub> and _C_<sub>2</sub> it holds that _C_<sub>1</sub> and _C_<sub>2</sub> are in the same block of the partition if and only if \(G[Z\cup C_\mathrm{1}]\) is isomorphic to \(G[Z\cup C_\mathrm{2}]\). To this end, we first compute simple planar graphs \(G'_i\) for each connected component with vertex set _C<sub>i</sub>_ such that \(G[Z\cup C_i]\) and \(G[Z\cup C_j]\) are isomorphic if and only if \(G'_i\) and \(G'_j\) are isomorphic. For each pair of graphs, we then check whether they are isomorphic in \(\mathcal{O}(\psi(H))\) time \[HW74\]. Since the number of connected components is at most \(|U|\le\psi(H)\), this takes \(\mathcal{O}(\psi(H)^\mathrm{3})\) time for all pairs combined and this immediately yields the desired partition.

Note that \(\sigma_t(H)\) is precisely the sum of the number of combinations of how many connected components from each block of the partition are added to _X_ over all separations _Z_ of size at most _t_. Moreover, for each possible combination, we can compute the separation (_X,Y_) in \(\mathcal{O}(\psi)\) time. Thus, the overall time required to compute all non-isomorphic separations of _H_ is in \(\mathcal{O}(\psi(H)^\mathrm{3}\sigma_t(H))\). This concludes the proof.

Note that when _H_ is a simple graph, then it is 5-degenerate and therefore \(\psi(H)=|U|\). Thus, the lemma also directly implies Corollary 3, which we restate here for convenience.

**Corollary 3.** _Given a (simple) planar graph H_=(_U,F_) _and a non-negative integer_ \(t\in\mathcal{O}(|U|^\frac{\mathrm{2}}{\mathrm{3}})\)_, the number_ \(\sigma_t(H)\) _of non-isomorphic separations of size at most t of H is in_ \(2^{\mathcal{O}(|U|/\mathrm{log}(|U|))}\)_. The separations can be enumerated in_ \(\mathcal{O}(|U|^\mathrm{3}\sigma_t(H))\) _time._
