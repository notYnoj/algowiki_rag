most \(\mathcal{O}(\gamma(D)n^\rho)=\mathcal{O}(n^\rho)\) time.

For the second step, note that in an iteration of the two for-loops for a node _u_ in T , each single line takes at most \(\mathcal{O}(\gamma(D)|Y_u|^\rho)\) time as subgraphs can be computed in linear time and updating \(S_\pi\) and computing \(R_\pi\) take \(\mathcal{O}(\gamma(D)|Y_u|^\rho)\) time by requirements R2 and R3. The use of Requirement R4 also takes \(\mathcal{O}(\gamma(D)|Y_u|^\rho)\) time and brute-forcing the solutions in Line 3 takes constant time as each bag contains a constant number of vertices.

It remains to analyze the running time for nodes in T . To this end, we consider all nodes at a given depth _t_ together. Let _U<sub>t</sub>_ be the set of all these nodes and note that we can assume without loss of generality that the number of nodes in T is at most _n_ and thus \(|U_t|\le n\). Note that since T is a tree decomposition, it holds that \(\sum_{u\in U_t}|Y_u|\le n+\sum_{u\in U_t}|X_u|\le n(1+18\alpha_\pi d)\in\mathcal{O}(n)\). Hence, the running time for all nodes at depth _t_ combined is in \(\mathcal{O}(n^\rho)\) and summed over the O(log(_n_)) different depths, this yields the final running time of \(\mathcal{O}(n^\rho log(n))\).

## 3.3 Reduce Portals

In this section, we show that `red-portals` works as intended, that it, it reduces an instance of \(\pi\)- Request with \(x\ge 40log^7(d)\) to 2<sup>O(log<sup>3</sup>(_d_))</sup> instances of \(\pi\)-Request where \(x\le 22log(d)\) holds in each instance. We start with a description of the main idea of the algorithm. We are given a partition of the portal sets (_B_he_,B_li_,B_di) into sets (_X_he_,X_li_,X_di) and (_Y_he_,Y_li_,Y_di). Initially _X<sub>i</sub>=B<sub>i</sub>_ and \(Y_i=\emptyset\) for each \(i\in\{\mathrm{he},\mathrm{li},\mathrm{di}\}\) and the goal is to call `solve-\(\pi\)-`r` with a small set \(B_\mathrm{he}\cup B_\mathrm{li}\). We do this by iteratively finding a <sup>3</sup>/4-balanced cycle separator for the weight function that assigns weight \(1/|X_\mathrm{he}\cup X_\mathrm{li}|\) to each vertex in \(X=X_\mathrm{he}\cup X_\mathrm{li}\) and zero to all other vertices. For this cycle separator, we apply Lemma 6 to find a set of cycle separators that are balanced for the mentioned weight function. We then guess the cycle separator \(C'\) that does not intersect the solution in too many vertices, add its heavy vertices \(C'_\mathrm{he}\) to _Y_he, its light vertices \(C'_\mathrm{li}\) to _Y_li, and its discarded vertices \(C'_\mathrm{di}\) to _Y_di and call `red-portals` on the interior and the exterior. Clearly, the set _X_ shrinks by a factor of <sup>3</sup>/4 in each iteration. Hence, after calling `red-portals` for O(log(|_X_|)) times, the set _X_ will have constant size. We also show that the set _Y_ does not become too large in the process. Hence, we can then call `solve-\(\pi\)-`r` with \(B_i=X_i\cup Y_i\) for each \(i\in\{\mathrm{he},\mathrm{li},\mathrm{di}\}\) (modeled as an oracle in the following lemma).

**Lemma 10.** _Let_ \((d,G=(V,E),x,y,X_\mathrm{he},Y_\mathrm{he},X_\mathrm{li},Y_\mathrm{di},X_\mathrm{di},Y_\mathrm{di},S_\pi)\) _be given to `red-portals` as input, and let it satisfy the requirements of Lemma 8. Let also_ \(\pi\)-Request _satisfy the requirements of Theorem 3. Given access to an oracle for instances_ \((d,G'=(V',E'),B',x',S'_\pi)\) _with_ \(|V'|<|V|\) _and_ \(x'\le 44log(d)\)_, `red-portals` solves the instance_ \((d,G,(X_\mathrm{he}\cup Y_\mathrm{he},X_\mathrm{li}\cup Y_\mathrm{li},X_\mathrm{di}\cup Y_\mathrm{di}),x+2y,S_\pi)\) _of_ \(\pi\)-Request _with at most_ 2<sup>2000log<sup>3</sup>(_d_)</sup> _oracle calls in_ \(2^{\mathcal{O}(\sqrt{d})}\gamma(d)n^{\mathrm{max}(\rho,2)}\) _time._

_Proof._ We will prove the statement by induction over _z_=22log(_d_)-_y_. If _z_=1, then we have _y_=22log(_d_)-1 and Lemma 8 yields \(2y+1\le 44log(d)\) and

\(|X_\mathrm{he}\cup X_\mathrm{li}|\le(3/4)^{22\mathrm{log}(d)-1}\cdot 50d^6\le 4/3\cdot 2^{22\mathrm{log}(3/4)\mathrm{log}(d)+7\mathrm{log}(d)}\le 4/3\cdot 2^{-2\mathrm{log}(d)}\le 1\)

and Line 2 is therefore reached. Note that if Line 2 is reached, then the oracle calls give the correct solution for the subinstances by assumption as \(2y+1\le 44log(d)\).

If Line 2 is not reached, then we let S be the set of cycle separators computed in Line 2. We call `red-portals` for each separator in S and in each call, the value of _y_ is increased by 1, that is, the value of _z_ is reduced by one. Hence, the induction hypothesis states that the recursive calls in Line 2 are computed correctly. For each cycle separator \(C\in\mathcal{S}\), it holds by Lemma 6 that (_C,_1) is measured for _d_ and 1 and therefore also for _d_ and \(\alpha_\pi\). Thus, we can apply Requirement R4 to guarantee that we return the correct solution. This concludes the proof of correctness.
