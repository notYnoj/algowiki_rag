Finally, we present a reduction from _k_-Subgraph Scoring to _k_-Subgraph Scoring Request and analyze the running time. To this end, we apply Lemma 1 with _d_=3_k_+1 to compute 3_k_+13_k_-outerplanar graphs. We then solve _k_-Subgraph Scoring Request for each of these graphs using Theorem 3 with _d=k_, portal set \(B=(\emptyset,\emptyset,\emptyset)\), _x_=1, the input weight and cost functions, and input values \(\alpha_1,\alpha_2,\alpha_3\) and \(\beta\). For each such iteration, we query the optimal solution for request \((\emptyset,k)\), which corresponds to an optimal solution consisting of vertices of cost exactly _k_. If any iteration finds a solution with score at least _W_, then we output yes and otherwise we output no. Since the correctness can easily be verified, it remains to analyze the running time. Using Theorem 3 and the arguments above, solving each instance of _k_-Subgraph Scoring Request takes \(2^{\tilde{\mathcal{O}}(\sqrt{3k})}\gamma(k)n^{2.49}\) time. The time for computing all inputs is in O(_kn_) yielding an overall running time in \(\mathcal{O}((3k+1)2^{\tilde{\mathcal{O}}(\sqrt{k})}2^{240\sqrt{k}log^2(k)}k^2n^{2.49})+\mathcal{O}(nk)=2^{\tilde{\mathcal{O}}(\sqrt{k})}n^{2.49}\), concluding the proof.

We next show that Maximum-Weight Independent Set, Weighted Partial Vertex Cover, Densest _k_-Subgraph, and Maximum (_k,n-k_)-Cut are all special cases of _k_-Subgraph Scoring and hence we can show subexponential parameterized algorithms for all of them without needing to apply the framework for each of them. Subexponential parameterized algorithms for planar graphs were already known for Maximum-Weight Independent Set \[vN20\], Maximum (_k,n-k_)-Cut in undirected planar graphs \[FGIK24\], and (unweighted) Partial Vertex Cover \[FGIK24\] (even for apex-minor free graphs). They were not known for the directed variant of Maximum (_k,n-k_)-Cut and Weighted Partial Vertex Cover. Moreover, the existence of such an algorithm was asked as an open problem for (unweighted) Densest _k_- Subgraph \[FGIK24\], which we resolve here in the affirmative. We mention is passing that an optimal solution for Densest _k_-Subgraph might contain many connected components and hence the treewidth-pattern-covering approach does not work.

**Corollary 2.** Maximum-Weight Independent Set, Weighted Partial Vertex Cover, Densest _k_-Subgraph, _and_ Maximum (_k,n-k_)-Cut _can all be solved in_ \(2^{\tilde{\mathcal{O}}(\sqrt{k})}n^{2.49}\) _time for planar input graphs._

It is easy to verify that _k_-Subgraph Scoring for the chosen values of \(\alpha_1,\alpha_2,\alpha_3\) and \(\beta\) corresponds to Maximum (_k,n-k_)-Cut and Densest _k_-Subgraph, respectively.
