## 2 Preliminaries

In this section, we first give an overview of the notation and basic concepts we use. Then, we give all formal problem definitions. In a third step, we formalize **_request variants_** of problems. Recall that for Independent Set, we want to solve a more general version where we output a lookup table that answers for each set _Z_ of certain size (and certain interaction with heavy, light, and discarded vertices of the cycle separators), whether an independent set of a certain size exists where exactly the vertices in _Z_ are contained from the cycle separators. This is the request variant for Independent Set and we give a definition (plus some intuition) of what type of generalized problem we can solve using our framework. Finally, we give an overview of the different results from the known literature that our framework relies on.

We start with some notation and assume familiarity with standard notation from graph theory and theoretical computer science. In particular, we denote by _n_ and _m_ the number of vertices and edges in a graph, respectively. We use N to denote the set of **_positive integers_** and \(\tilde{\mathcal{O}}\) to hide polylogarithmic factors in the Bachmann-Landau (big-O) notation. For an integer \(\ell\), we use \([\ell]\) to denote the set \(\{1,2,\dots,\ell\}\). The base of all logarithmic functions in this work is 2 and we assume the word RAM model of computation (which means that operations like computing sums or minima over a constant number of real numbers take constant time independent of the size of the numbers). Given a graph _G_=(_V,E_) and a vertex set \(V'\subseteq V\) , we denote the graph **_induced_** by \(V'\) by \(\mathbf{G}[\mathbf{V}']\) and the graph obtained by deleting all vertices in \(V'\) (and all edges incident to those vertices) by \(\mathbf{G}-\mathbf{V}'\). For a set \(F\subseteq E\) of edges, we use **G**-**F** as a shorthand for (_V,E_\\_F_). Given a set _W_ (not necessarily a subset of _V_ ), we denote by \(W[G]=W\cap V\) the intersection of _W_ and the vertex set of _G_.

An embedding of a planar graph is 1-outerplanar if it is outerplanar, that is, all vertices lie on the outer face. For \(d\ge 2\), an embedding of a planar graph is _d_-outerplanar if removing all vertices on the outer face results in a (_d_-1)-outerplanar embedding. A graph is **d_-outerplanar_** if it has a _d_-outerplanar embedding. A planar graph is **_triangulated_** if each face is bounded by three edges. A **_separation_** of _G_ is a pair (_X,Y_) of vertex subsets such that \(X\cup Y=V\) and there are no edges between vertices in _X_\\_Y_ and _Y_\\_X_. The set \(X\cap Y\) is called the **_separator_** and slightly overloading notation, we will sometimes also refer to some graph with vertex set \(X\cap Y\) as the separator. The size of a separation (_X,Y_) is the number of vertices in its separator. Two separations (_X,Y_) and \((X',Y')\) are **_isomorphic_** if there is an isomorphism \(f:V\rightarrow V\) such that \(\bigcup_{v\in X}f(v)=X'\) and _f(v_)=_v_ for each \(v\in X\cap Y\) . In a planar graph together with an embedding, (the vertex set of) each simple cycle _C_ is a separator that separates the strict **_interior_** (the graph enclosed by _C_) from the strict **_exterior_**. We therefore prefer to use the term cycle separator rather than simple cycle. The union of the strict interior/exterior of _C_ and _C_ is denoted by the (non-strict) interior/exterior of _C_. For a cycle separator _C_, we denote the interior by _C_<sub>in</sub> and the exterior by _C_<sub>ex</sub>.

A **_tree decomposition_** of a graph _G_=(_V,E_) is a rooted tree T=(_U,A_) in which each node _u_ represents a subset _X<sub>u</sub>_ of vertices called the _bag_ of _u_ such that

• each vertex in _V_ is contained in at least one bag,<tbc>

• for each edge \(\{v,w\}\in E\), there is a node \(u\in U\) with \(v,w\in X_u\), and<tbc>

• for each \(v\in V\) it holds that all nodes _u_ of T with \(v\in X_u\) form a connected subtree of T .

The **_width_** of a tree decomposition is \(\mathrm{max}_{u\in U}|X_u|-1\) and the **_treewidth_** of _G_ is the minimum width of all possible tree decompositions of _G_. The depth of a tree decomposition is the length of a longest path from the root to any other node and a tree decomposition is binary if each node has at most two children. Given a tree decomposition T=(_U,A_) of a graph _G_ and a node \(u\in U\), we denote by _Y<sub>u</sub>_ the union of all bags of _u_ and descendants of _u_ in T .
