\((P_1,P'_2)\) is acyclic, and we update the result for request _r_. This means that neither _W_<sub>1</sub> nor _W_<sub>2</sub> are \(-\infty\). Hence, there are vertex sets _Z_<sub>1</sub> and _Z_<sub>2</sub> corresponding to solutions for \((\mathcal{M}'_\mathrm{in},P_1,\ell')\) and \((\mathcal{M}'_\mathrm{ex},P_2,\ell-\ell'+|Z_1\cap Z_2|)\). By Lemma 13, \(G[Z_1\cup Z_2]\) is then acyclic and has connected components for M as described by \(P_1\sqcup P_2=P\). Moreover, the weight of the union is exactly the sum of weights of _Z_<sub>1</sub> and _Z_<sub>2</sub> minus the weight of the intersection, that is, the weight of \(\mathcal{M}'\). Since this is precisely what we compute, this shows that every update we do is valid, concluding the proof of correctness.

We next analyze the running time of our algorithm for Requirement R4. The number of possible pebble sets \(\mathcal{M}'\) for (_C,_1) is by Lemma 11 in \(\mathcal{O}(2^{80\sqrt{d}\mathrm{log}^2(d)})\) and the pebble sets can be enumerated in \(\mathcal{O}(2^{80\sqrt{d}\mathrm{log}^2(d)}d)\) time. Iterating over all \(\ell\le d\) adds an additional factor of _d_. Computing \(\mathcal{M}_\mathrm{in},\mathcal{M}_\mathrm{ex},\mathcal{M}'_\mathrm{in},\mathcal{M}'_\mathrm{ex}\) can all easily be done in O(_n_<sup>2</sup>) time. We then iterate over all possible partitions \(P_1\in\mathcal{B}(\mathcal{M}'_\mathrm{in})\) and \(P_2\in\mathcal{B}(\mathcal{M}'_\mathrm{ex})\). The number of possibilities is in \(\mathcal{O}((2^{66000\sqrt{d}\mathrm{log}^{10}(d)})^2)\) by Lemma 14 and all partitions can be computed in \(\mathcal{O}(2^{66000\sqrt{d}\mathrm{log}^{10}(d)}d)\) time. Computing \(E_{\mathcal{M}^\prime}\) can be done in O(_n_<sup>2</sup>) time. Computing \(G'\) and \(G''\) can also be done in the same time as follows. For \(G'\), start with a graph which has a vertex for each \(v\in\mathcal{M}'_\mathrm{ex}\) and each \(p\in P_2\). Then, add all edges in \(E_{\mathcal{M}^\prime}\). For each \(p\in P_2\) and each \(v\in p\), add an edge between the two corresponding vertices if (and only if) this edge does not create a cycle. Using union-find data structures, each such incidence can be checked in \(O(\alpha(n))\) time, where \(\alpha\) is the inverse Ackermann’s function. Since each vertex appears in exactly one set in _P_<sub>2</sub>, this results in an overall running time of \(\mathcal{O}(n\alpha(n))\subseteq\mathcal{O}(n^2)\). For \(G''\), simply remove the edges in \(E_{\mathcal{M}^\prime}\). Computing \(P'_2\) can then also be done in the same time by computing the connected components in \(G''\). Finally, checking whether \(P_1\sqcup P_2=P\) and whether \((P_1,P'_2)\) is acyclic also take \(\mathcal{O}(n\alpha(n))\subseteq\mathcal{O}(n^2)\) time. Recall that \(\gamma(d)=2^{80\sqrt{d}\mathrm{log}^2(d)}\big(2^{66000\sqrt{d}\mathrm{log}^{10}(d)}\big)^2d\) and \(\rho=2\). The overall running time for our algorithm for Requirement R4 is in

\(\mathcal{O}(2^{80\sqrt{d}\mathrm{log}^2(d)}d+2^{80\sqrt{d}\mathrm{log}^2(d)}d(n^2+2^{66000\sqrt{d}\mathrm{log}^{10}(d)}d+(2^{66000\sqrt{d}\mathrm{log}^{10}(d)})^2n^2))\subseteq\mathcal{O}(\gamma(d)n^\rho).\)

The final step is to show a reduction from Maximum-Weight Induced Forest to Maximum- Weight Induced Forest Request and analyze the running time. To this end, we apply Lemma 1 with _d=k_+1 to compute _k_+1_k_-outerplanar graphs. We then solve Maximum- Weight Induced Forest Request for each of these graphs using Theorem 3 with _d=k_, portal set \(B=(\emptyset,\emptyset,\emptyset)\), _x_=1, and the input weight function. For each such iteration, we query the optimal solution for request \((\emptyset,\emptyset,k)\), which corresponds to an optimal solution consisting of at most _k_ vertices. If any iteration finds a solution with weight at least _W_, then we output yes and otherwise we output no. Since the correctness can easily be verified, it remains to analyze the running time. Using Theorem 3 and the arguments above, solving each instance of Maximum-Weight Induced Forest Request takes time

\(2^{\tilde{\mathcal{O}}(\sqrt{k})}2^{80\sqrt{k}\mathrm{log}^2(k)}\big(2^{66000\sqrt{k}\mathrm{log}^{10}(k)}\big)^2kn^{2.49}\subseteq 2^{\tilde{\mathcal{O}}(\sqrt{k})}2^{132081\sqrt{d}\mathrm{log}^{10}(k)}n^{2.49}\subseteq 2^{\tilde{\mathcal{O}}(\sqrt{k})}n^{2.49}.\)

The time for computing all inputs is in O(_kn_) by Lemma 1 and because induced subgraphs can be computed in _O(n+m_) time and since \(m\in\mathcal{O}(n)\) for planar graphs. The overall running time is therefore in \(\mathcal{O}((k+1)2^{\tilde{\mathcal{O}}(\sqrt{k})}n^{2.49})+\mathcal{O}(nk)=2^{\tilde{\mathcal{O}}(\sqrt{k})}n^{2.49}\). This concludes the proof.
