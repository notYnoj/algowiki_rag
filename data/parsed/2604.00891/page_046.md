The three requirements we need to show are (i) for each \(u\in X\) it holds that \(c(u)\cup\mu(u)\subseteq f(u)\), (ii) when contracting all edges _e_ in \(G_P^*\) for which there exists a \(u\in X\) with \(e\subseteq f(u)\), then the resulting graph is isomorphic to _H_\[_X_\]-E and the isomorphism maps for each node \(u\in X\) the vertex that is the result of contracting all vertices in _f(u_) to _u_, and (iii) for each \(u\in X\), the graph \(G'[f(u)]\) has connected components for _c(u_) as described by _P<sup>u</sup>_. Let \(u\in X\) be any node. For the first requirement, note that each node \(v\in\mu(u)\) is contained in _f(u_) as both _c_<sub>1</sub> and _c_<sub>2</sub> are extensions of \(\mu\) and therefore \(v\in f_1(u)\) if \(u\in X_1\) and otherwise \(v\in f_2(u)\) as \(X=X_1\cup X_2\) by construction. In either case, it holds that \(v\in f(u)\) and the first requirement is fulfilled.

We next show the third requirement. This follows from Lemma 12 as follows. We make a case distinction whether \(u\in X_1\cap X_2\) or not. If \(u\notin X_1\cap X_2\), then assume without loss of generality that \(u\in X_1\backslash X_2\). Then, the following holds as _G_<sub>2</sub> does not contain any vertices in _f(u_) and, in particular, \(\mathcal{M}'\) also does not contain any vertices from _c_<sub>1</sub>(_u_): _G_<sup>∗</sup>\[_f(u_)\]=_G_<sub>1</sub>\[_f(u_)\], _c(u_)=_c_<sub>1</sub>(_u_), and \(P^u=P_1^u\). Note that _f_<sub>1</sub> guarantees that _G_<sub>1</sub>\[_f(u_)\]=_G_<sup>∗</sup>\[_f(u_)\] has connected components for _c_<sub>1</sub>(_u_)=_c(u_) as described by \(P_1^u=P^u\). So assume next that \(u\in X_1\cap X_2\). Then, _u_ is part of the domain of both _c_<sub>1</sub> and _c_<sub>2</sub> and \(c_1(u)\cap c_2(u)=f(u)\cap\mathcal{M}'\). We have that _G_<sub>1</sub>\[_f(u_)\] has connected components for _c_<sub>1</sub>(_u_) as described by \(P_1^u\) for each \(u\in X_1\) and _G_<sub>2</sub>\[_f(u_)\] has connected components for _c_<sub>2</sub>(_u_) as described by \(P_2^u\) for each \(u\in X_2\). Moreover, \(P^u=P_1^u\sqcup P_2^u\) by construction. Thus, Lemma 12 states that the union of the two graphs (which is equal to _G_<sup>∗</sup>\[_f(u_)\]) has connected components for \(c(u)\subseteq c_1(u)\cup c_2(u)\backslash\mathcal{M}'\) as described by \(P_1^u\sqcup P_2^u\). This shows that the third requirement is fulfilled.

Finally, we prove that the second requirement holds. To this end, notice that _f_<sub>1</sub> witnesses that _G_<sub>1_P_<sub>1</sub></sub> is a model for \(H[X_1]-\mathcal{E}_1=(X_1,E'_1)\) and _f_<sub>2</sub> is a witness for the fact that _G_<sub>2_P_<sub>2</sub></sub> is a model for \(H[X_2]-\mathcal{E}_2=(X_2,E'_2)\). We show that _f_ witnesses that \(G_P^*\) is a model for _H_\[_X_\]-E. First, we show that \(G_P^*[f(u)]\) is connected for each \(u\in X\). Afterwards, we show that each edge in _H_\[_X_\]-E is modeled by \(G_P^*\). Towards the former, note that \(G_P^*[f(u)]\) is only potentially disconnected if _G_<sup>∗</sup>\[_f(u_)\] contains a connected component that does not contain any vertex in M as all these vertices appear in _P<sup>u</sup>_ and are either contained in the same block or not. In the former case, the vertices appear in the same connected component of _G_<sup>∗</sup>\[_f(u_)\] as given by the third requirement. In the latter case, an edge is added in \(G_P^*\) and thus the graph is trivially connected. So assume that _G_<sup>∗</sup>\[_f(u_)\] contains a connected component that does not contain any vertex in M. Note that this implies that \(u\notin Y\) by the definition of _c_ and _f_. If \(u\notin X_1\cap X_2\), then assume without loss of generality that \(u\in X_1\backslash X_2\). Then, \(P^u=P_1^u\) holds as _G_<sub>2</sub> does not contain any vertices in _f(u_) and therefore \(G_P^*[f(u)]=G_{1P_1}[f(u)]\) and since _f_<sub>1</sub> witnesses that _G_<sub>1_P_<sub>1</sub></sub>\[_f(u_)\] is connected, the same holds for \(G_P^*[f(u)]\). If \(u\in X_1\cap X_2\), then \(u\in(X_1\cap X_2)\backslash Y\) as \(u\notin Y\) . Then, we require that \(P_1^u\sqcup P_2^u\) consists only of a single set. Since _G_<sub>1</sub>\[_f(u_)\] and _G_<sub>2</sub>\[_f(u_)\] have connected components for \(c_1(u)=c_2(u)\subseteq\mathcal{M}'\) as described by \(P_1^u\) and \(P_2^u\) and since \(P_1^u\sqcup P_2^u\) only consists of a single set, Lemma 12 states that the union _G_<sup>∗</sup>\[_f(u_)\] has only one connected component. Thus, \(G_P^*[f(u)]\) indeed has only one connected component.

Next, we show that each edge in _H_\[_X_\]-E is modeled. Since \(H[X_1\cup X_2]\) is isomorphic to _H_\[_X_\], it holds for all edges in \(H[X_1]-(\mathcal{E}_1\cup\mathcal{E}_2)\) that they are modeled in _G_<sup>∗</sup>. It remains to analyze the edges in E<sub>1</sub>\\E<sub>2</sub> (the argument for edges in E<sub>2</sub>\\E<sub>1</sub> is symmetric). Note that each such edge is modeled in _G_<sub>2</sub> and therefore also by _G_<sup>∗</sup>. Hence, \(G_P^*\) is a model for _H_\[_X_\]-E as witnessed by _f_ and the second requirement is fulfilled. All three requirements are fulfilled and _G_<sup>∗</sup> therefore fulfills request _r_, concluding the proof of correctness for our algorithm for Requirement R4.
