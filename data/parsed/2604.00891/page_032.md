<tbc>created in the process, so Requirement R1 holds for \(\alpha_\pi=3\) for _k_-Subgraph Scoring Request (and _k_-Subgraph Scoring).

The penultimate step is to show that Requirement R4 holds, that is, there is an algorithm that given a separator _C_=(_C_he_,C_li_,C_di) such that (_C,_1) is measured for _d_ and 3, a pebble set M for (_B,d,_3_,x_), and the solutions for instances

\((d,C_\mathrm{in},((B_\mathrm{he}\cup C_\mathrm{he})[C_\mathrm{in}],(B_\mathrm{li}\cup C_\mathrm{li})[C_\mathrm{in}],(B_\mathrm{di}\cup C_\mathrm{di})[C_\mathrm{in}]),x+1,S_\pi[C_\mathrm{in}])\text{and}\)<br>
\((d,C_\mathrm{ex},((B_\mathrm{he}\cup C_\mathrm{he})[C_\mathrm{ex}],(B_\mathrm{li}\cup C_\mathrm{li})[C_\mathrm{ex}],(B_\mathrm{di}\cup C_\mathrm{di})[C_\mathrm{ex}]),x+1,S_\pi[C_\mathrm{ex}]),\)

can compute the solutions for all requests \(r\in R_\pi(d,G,B,\mathcal{M},S_\pi)\) that do not intersect _C_di and intersect _C_li in at most \(60\sqrt{d}\mathrm{log}(d)\) vertices in \(\mathcal{O}(\gamma(d)n^2)\) time. So assume that we are given _C_, solutions res<sub>1</sub> for the interior instance and res<sub>2</sub> for the exterior instance, and a pebble set M for (_B,d,_3_,x_). Let M<sub>in</sub> and M<sub>ex</sub> be the subsets of M which appear in _C_in and _C_ex, respectively. We iterate over all possible pebble sets \(\mathcal{M}'\) for (_C,d,_3,1), that is, sets which do not contain any vertices in _C_di and at most \(60\sqrt{d}\mathrm{log}(d)\) vertices in _C_li. Let _A<sub>C</sub>_ be the set of arcs with both endpoints in \(C_\mathrm{he}\cup C_\mathrm{li}\cup C_\mathrm{di}\). Let \(A_1,A_2,A_3\subseteq A_C\) be the sets of arcs \((u,v)\in A_C\) such that (1) both _u_ and _v_ belong to \(\mathcal{M}'\), (2) \(u\in\mathcal{M}'\) and \(v\notin\mathcal{M}'\), and (3) \(u\notin\mathcal{M}'\) and \(v\in\mathcal{M}'\). Then, for each such set \(\mathcal{M}'\), we iterate over all \(\ell'\le\ell\) and lookup the result for the interior for request \((\mathcal{M}_\mathrm{in}\cup\mathcal{M}',\ell')\) and for the exterior for \((\mathcal{M}_\mathrm{ex}\cup\mathcal{M}',\ell-\ell'+\sum_{v\in\mathcal{M}^\prime} c(v))\). Let _s_<sub>1</sub> and _s_<sub>2</sub> be these scores. We then compute \(s=s_1+s_2-(\alpha_1(\sum_{a\in A_1}w(a))+\alpha_2(\sum_{a\in A_2}w(a))+\alpha_3(\sum_{a\in A_3}w(a))+\beta(\sum_{v\in\mathcal{M}^\prime} w(v)))\) and return the highest computed _s_ as a solution for _r_.

We next prove that our computation is correct, that is, (i) we show for each request and any solution for that request that we store a value that is at least as large as the score of the solution and (ii) we show that each time we update a request, there is a partial solution of that score. Before doing so, note that \(((B_\mathrm{he}\cup C_\mathrm{he},B_\mathrm{li}\cup C_\mathrm{li},B_\mathrm{di}\cup C_\mathrm{di}),x+1)\) is measured for _d_ and 3 as (_B,x_) and (_C,_1) are both measured for _d_ and 3. Thus, the solutions res<sub>1</sub> and res<sub>2</sub> have entries for \((\mathcal{M}_\mathrm{in}\cup\mathcal{M}',\ell')\) and \((\mathcal{M}_\mathrm{ex}\cup\mathcal{M}',\ell')\) for each \(\mathcal{M}'\) with \(\mathcal{M}'\cap C_\mathrm{di}=\emptyset\) and \(|\mathcal{M}'\cap C_\mathrm{li}|\le 60\sqrt{d}\mathrm{log}(d)\) and for each \(\ell'\le d\), respectively.

Now, consider a set _Z_ of vertices corresponding to a solution for _r_ with no vertices in _C_di and at most \(60\sqrt{d}\mathrm{log}(d)\) vertices in _C_li. Let _Z_in and _Z_ex be the subsets of _Z_ in _C_in and _C_ex, respectively, and let _s_in and _s_ex be the scores achieved by _Z_in in _C_in and _Z_ex in _C_ex, respectively, where \(\mathcal{M}'=Z_\mathrm{in}\cap Z_\mathrm{ex}\). Note that the queries \((\mathcal{M}_\mathrm{in}\cup\mathcal{M}',\sum_{v\in Z_\mathrm{in}}c(v))\) and \((\mathcal{M}_\mathrm{ex}\cup\mathcal{M}',\sum_{v\in Z_\mathrm{ex}}c(v))\) return values at least _s_in and _s_ex, respectively. Moreover, all arcs in \(A_1\cup A_2\cup A_3\) as well as _w(v_) for all \(v\in\mathcal{M}'\) are counted in both _s_in and _s_ex and no other arc is counted in both solutions as _C_ is a separator. Thus, the score of _Z_ is \(s_\mathrm{in}+s_\mathrm{ex}-(\alpha_1(\sum_{a\in A_1}w(a))+\alpha_2(\sum_{a\in A_2}w(a))+\alpha_3(\sum_{a\in A_3}w(a))+\beta(\sum_{v\in\mathcal{M}^\prime} w(v)))\), which is precisely what we computed.

In the other direction, note that any value we compute corresponds to a set of vertices of cost precisely \(\ell\) which does not intersect _C_di and which intersects _C_li in at most \(60\sqrt{d}\mathrm{log}(d)\) vertices. This is true as both res<sub>1</sub> and res<sub>2</sub> guarantee this property for the two solutions we combine and both solutions contain precisely the same vertices in _C_. The value we subtract from the sum of the two scores is precisely the amount we counted twice (once in each of the two scores _s_<sub>1</sub> and _s_<sub>2</sub>). Thus, the computation is correct.

We next analyze the running time of our algorithm for Requirement R4. The number of possible pebble sets \(\mathcal{M}'\) for (_C,_1) is by Lemma 11 in \(\mathcal{O}(2^{240\sqrt{d}\mathrm{log}^2(d)})\) and they can be enumer ated in \(\mathcal{O}(2^{240\sqrt{d}\mathrm{log}^2(d)}d)\) time. We then iterate over all possible values of \(\ell\le d\) and all other computations can be performed in O(_n_<sup>2</sup>) time. The overall running time is therefore bounded by \(\mathcal{O}(2^{240\sqrt{d}\mathrm{log}^2(d)}d^2n^2)=\mathcal{O}(\gamma(d)n^2)\) and Requirement R4 thus holds for _k_-Subgraph Scoring Request.
