In particular if \(v\in\mu(u'')\) for some \(u''\in U\backslash Z\), then there is no extension of \(\mu\) as _v_ must be assigned to \(u''\) so it cannot be assigned to any node in _Z_. We next analyze the number of possible coloring functions and show how to enumerate them. In order to apply the lemma more conveniently later, we will focus on the case where M is a pebble set. We mention that the proof is basically the same as for Lemma 14.

**Lemma 15.** _Let_ (_B,x_) _be a pair that is almost measured with respect to two integers d and_ \(\alpha\) _and let_ M _be a pebble set for_ \((B,d,\alpha,x)\)_. Let V,U, and Z be sets such that_ \(\mathcal{M}\subseteq V\) _and_ \(Z\subseteq U\)_. Let_ \(\mu:U\rightarrow 2^V\) _be a function. Then, the number of possible coloring functions_ \(c:Z\rightarrow 2^\mathcal{M}\) _that are extensions of_ \(\mu\) _is in_ \(\mathcal{O}(2^{66000\sqrt{d}log^{10}(d)})\)_. All such coloring functions can be enumerated in_ O(2<sup>66000\sqrt{d}log^{10}(d)}d)\) _time._

_Proof._ Since (_B,x_) is almost measured with respect to _d_ and \(\alpha\), it holds that \(x\le 200log^7(d)\). Moreover, \(\mathcal{M}\subseteq(B_\mathrm{he}\cup B_\mathrm{li})\), \(|B_\mathrm{he}|\le 40x\alpha\sqrt{d}\) and \(|\mathcal{M}\cap B_\mathrm{li}|\le 20x\alpha\sqrt{d}log(d)\) because M is a pebble set for \((B,d,\alpha,x)\). Thus, \(|\mathcal{M}|\le 60(200log^7(d))\alpha\sqrt{d}log(d)=12000\alpha\sqrt{d}log^8(d)\).

We next show that the number of coloring functions from _Z_ to M is in \(\mathcal{O}(2^{66000\sqrt{d}log^{10}(d)})\). This clearly also upper bounds the number of coloring functions that are extensions of \(\mu\). First, note that \(|Z|\le|\mathcal{M}|\) as otherwise there is no coloring function from _Z_ to M as each vertex in _Z_ is assigned a non-empty subset of M and each vertex in M is assigned exactly one vertex in _Z_. Recall that an equivalent interpretation of coloring functions is to assign each vertex in M to exactly one vertex in _Z_. Thus, the number of coloring functions is at most \(|Z|^{|\mathcal{M}|}\le|\mathcal{M}|^\mathcal{M}\). If \(d<256\cdot 2^\alpha\), then this number is constant, that is, in O(1). So assume that \(d\ge 256\cdot 2^\alpha\). Then,

\(|\mathcal{M}|^{|\mathcal{M}|}\le(12000\alpha\sqrt{d}log^8(d))^{12000\alpha\sqrt{d}log^8(d)}\)<br>
\(\le(d^2\sqrt{d}d^3)^{12000\alpha\sqrt{d}log^8(d)}\)<br>
\(\le 2^{66000\sqrt{d}log^{10}(d)}.\)

The second inequality is true because \((256\alpha)^2>12000\alpha\) and \(log^8(d)\le d^3\) for all \(d\ge 256\). The third inequality is due to the fact that \(\alpha\le log(d)\).

Note that we can enumerate all coloring functions in \(\mathcal{O}(|Z|^{|\mathcal{M}|}d)\subseteq\mathcal{O}(2^{66000\sqrt{d}log^{10}(d)}d)\) time by iterating over all possible choices of assigning a "color" to each node in M. This takes O(|_Z_|<sup>|M|</sup>) time. We then check in O(_d_) time whether the function extends \(\mu\) and assigns a non-empty set to each node \(u\in Z\). This concludes the proof.

The last ingredient for the proof of the subexponential parameterized algorithm for Minimum- Weight Rooted Simple Minor is a restriction of partitions of M for coloring functions. Formally, we say that a partition \(P\in\mathcal{B}(\mathcal{M})\) **_refines_** a coloring function \(c:Z\rightarrow 2^\mathcal{M}\) if the following holds for each pair \(v_1,v_2\in\mathcal{M}\) of vertices in M. Let \(u_1,u_2\in Z\) be the nodes such that \(v_1\in c(u_1)\) and \(v_2\in c(v_2)\). If \(u_1\neq u_2\), then _u_<sub>1</sub> and _u_<sub>2</sub> are contained in different blocks in _P_. Intuitively, _P_ refines _c_ if whenever _c_ assigns _v_<sub>1</sub> and _v_<sub>2</sub> different colors, then _v_<sub>1</sub> and _v_<sub>2</sub> are contained in different blocks in _P_. Note that we _do not_ require that whenever _c_ assigns two vertices the same color, then they also appear in the same block in _P_. It will be convenient for us to interpret such a partition as a collection of partitions, one for each node _u_. For a partition, we denote the subset of _P_ containing vertices in _c(u_) for some \(u\in Z\) by _P<sup>u</sup>_. Note that \(P=\bigcup_{u\in Z}P^u\). Afterwards, we show how to use this result to get a subexponential parameterized algorithm for Minimum-Weight Rooted Simple Minor parameterized by only _k_.
