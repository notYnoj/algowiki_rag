**Theorem 6.** _Let_ \(t=12000\sqrt{k}\mathrm{log}^8(k)\). Minimum-Weight Rooted Simple Minor _can be solved in_ \(2^{\tilde{\mathcal{O}}(\sqrt{k})}(\sigma_t(H))^2n^{2.49}\) _time for planar graphs, where_ \(\sigma_t(H)\) _denotes the number of non-isomorphic separations of H of size at most t._

_Proof._ We follow the same recipe as usual. We choose \(\rho=2\) and \(\alpha_\pi=1\). The function \(\gamma\) depends on the pattern graph _H_=(_F,U_) and we choose \(\gamma_H(d)=(\sigma_t(H))^22^{5t}|U|^32^{264080\sqrt{d}\mathrm{log}^{10(d)}}d\). The set \(S_\pi\) contains the weight function _w_ and the function \(\mu\) defining the roots of the input graph _G_ (both restricted to the current subgraph). A request \(r\in R_\pi(d,G,B,\mathcal{M},S_\pi)\) will be a 6-tuple \((\mathcal{M},(X,Y),c,P,\mathcal{E},\ell)\). Let us give a description of the different entries. The set M is a pebble set and (_X,Y_) is a separation of _H_ of size at most _t_. Let \(Z=X\cap Y\) be the separator and _H_\[_Z_\]=(_Z,E<sub>Z</sub>_) be the graph induced by _Z_. The entry \(c:Z\rightarrow 2^\mathcal{M}\) is a coloring function that is an extension of \(\mu\) and \(P\in\mathcal{B}(\mathcal{M})\) is a partition of M that refines _c_. The set \(\mathcal{E}\subseteq E_Z\) is a subset of the edges in _H_\[_Z_\] which are not yet realized by the model, and \(\ell\le d\) is an upper bound on the number of vertices in a partial solution. The output for a request \(r=(\mathcal{M},(X,Y),c,P,\mathcal{E},\ell)\) is defined as follows. Therein, we use \(G_P=(V,E\cup\{\{u,v\}|c(u)=c(v)\wedge\forall p\in P\). \(\{u,v\}\unknown\subseteq p\})\) as a shorthand for the graph _G_ where we additionally add all edges between two vertices that are mapped to the same node in _H_ but do not appear together in a block in _P_. Recall that for a set \(E'\) of edges, \(G-E'\) denotes the graph where all edges in \(E'\) have been removed. We can now state the conditions for when a subgraph \(G'=(V',E')\) of _G_ fulfills _r_:

• \(|V'|\le\ell\), and<tbc>

• there exists a function \(f:X\rightarrow 2^{V^\prime}\) such that<tbc>

1. for each \(u\in X\), \(c(u)\subseteq f(u)\),<tbc>

2. when contracting all edges _e_ in \(G'_P\) for which there exists a \(u\in X\) with \(e\subseteq f(u)\), then the resulting graph is isomorphic to _H_\[_X_\]-E and for each node \(u\in X\), the isomorphism maps the result of contracting all vertices in _f(u_) to _u_, and<tbc>

3. for each \(u\in X\), the graph \(G'[f(u)]\) has connected components for _c(u_) as described by _P<sup>u</sup>_.

The weight of \(G'\) is \(\sum_{e\in E^\prime} w(e)\) and the output for _r_ is the minimum weight of any graph fulfilling _r_ (or \(\infty\) if no such graph exists).

We next show that \(S_\pi[G']\) for any subgraph \(G'\) and \(R_\pi(d,G,B,\mathcal{M},S_\pi)\) can be computed in \(\mathcal{O}(\gamma_H(d)n^\rho)\) time. Since \(S_\pi\) only contains the weight function and the root function \(\mu\), it can be maintained trivially in \(\mathcal{O}(n^2)=\mathcal{O}(n^\rho)\) time. For any given 5-tuple \((d,G,B,\mathcal{M},S_\pi)\), we can compute \(R_\pi(d,G,B,\mathcal{M},S_\pi)\) as follows. Since M is part of the input for \(R_\pi\), we only need to copy the vertices, which takes O(_n_) time. By Corollary 3, we can enumerate all separations (_X,Y_) of _H_ of size at most _t_ in \(\mathcal{O}(|U|^3\sigma_t(H))\) time. All coloring functions that are an extension of \(\mu\) can be computed in \(\mathcal{O}(2^{66000\sqrt{d}\mathrm{log}^{10(d)}}d)\) time by Lemma 15. All possible parti tions of _P_ can be enumerated in \(\mathcal{O}(2^{66000\sqrt{d}\mathrm{log}^{10(d)}})\) time by Lemma 14 and we can check for each of them whether they refine _c_ in O(_n_) time. Finally, since E is a subset of the edges in _H_\[_Z_\], we can enumerate all possible choices in O(2<sup>3_t_</sup>) time because _H_\[_Z_\] contains at most _t_ vertices and is planar and therefore contains at most <sup>5_t/_2</sup>_\<_3_t_ edges. Iterating over all possible values \(\ell\le d\) takes O(_d_) time and iterating over all possible combinations of all of the above takes \(\mathcal{O}(|U|^3\sigma_t(H)2^{66000\sqrt{d}\mathrm{log}^{10(d)}}2^{66000\sqrt{d}\mathrm{log}^{10(d)}}2^{3t}dn^2)\subseteq\mathcal{O}(\gamma_H(d)n^\rho)\) time.
