_Proof._ We show that \(\psi(H)=|U|\) for any simple planar graph _H_=(_U,F_). The corollary then is directly implied by Lemma 17. To this end, assume towards a contradiction that \(\psi(H)\neq|U|\). This implies that \(\psi(H)=2|F|/5\) and \(\psi(H)>|U|\). Note that any _d_-degenerate simple graph with _n_ vertices contains at most <sup>5_n_</sup>/2 edges. Hence, \(|F|\le^{5|U|/2}\). This yields \(\psi(H)\le^{2|F|/5}\le^{2\frac{5|U|}{2}/5}=|U|\), a contradiction.

We next define counting functions. Intuitively, these return for each edge _e_ in \(H[X\cap Y]\) a number _b<sub>e</sub>_ and we want to find a model in which exactly _b<sub>e</sub>_ parallel edges between the endpoints of _e_ are modeled. Formally, given a separations (_X,Y_) of a planar multigraph _H_, let \(Z=X\cap Y\) and _E<sub>Z</sub>_ be the set of edges of _H_\[_Z_\] after removing parallel edges (but not self loops). Then, a counting function \(\delta:E_Z\rightarrow\mathbb{N}\cup\{0\}\) is any function such that \(\delta(e)\) is at most the number of parallel edges with endpoints _e_ in \(H[X\cap Y]\). We next analyze the number of possible counting functions for a planar multigraph _H_.

**Lemma 18.** _Let H_=(_U,F_) _be a planar multigraph and let_ \(Z\subseteq U\)_. The number of possible counting functions for E<sub>Z</sub> is in_ \(2^{\mathcal{O}(log(\psi(H))|U|)}\)_. All such counting functions can be enumerated in_ \(2^{\mathcal{O}(log(\psi(H))|U|)}|U|\) _time._

_Proof._ Since _H_ is planar, the graph resulting from removing parallel edges and self-loops is 5- degenerate and therefore contains at most <sup>5|_U_|/2</sup> edges. Combined with the at most |_U_| possible self loops, this yields <sup>7|_U_|/2</sup> possible edges. For each of these edges, a counting function can assign an integer between 0 and \(|F|\in\mathcal{O}(\psi(H))\), that is, the number of possible choices is in \((\psi(H))^{\mathcal{O}(7|U|/2)}\subseteq 2^{\mathcal{O}(log(\psi(H))|U|)}\). We can iterate over all of them efficiently and for each check whether the multiplicity is at most the multiplicity in _H_ in O(|_U_|) time.

We can now present our algorithm for Maximum-Weight Rooted Parallel Induced Minor. Since it is only a slight adaptation of the subexponential parameterized algorithm for Minimum-Weight Rooted Simple Minor, we do not present the full (lengthy) proof. Instead, we give a high-level description featuring the key differences between the two algorithms and proofs.

**Theorem 7.** _Let_ \(t=12000\sqrt{k}log^8(k)\)_. For planar graphs,_ Maximum-Weight Rooted Parallel Induced Minor _can be solved in_ \(2^{\tilde{\mathcal{O}}(\sqrt{k}log(\psi(H)))}(\sigma_t(H))^2n^{2.49}\) _time, where_ \(\sigma_t(H)\) _denotes the number of non-isomorphic separations of H of size at most t._

_Proof sketch._ A request is a tuple \(r=(\mathcal{M},(X,Y),c,P,\delta,\ell)\), where M is a pebble set, (_X,Y_) is a separation of _H_ of size at most \(12000\sqrt{d}log^8(d)\), _c_ is a coloring function that assigns each vertex in M to a node in \(X\cap Y\) (formally each node in \(X\cap Y\) is assigned a non-empty subset of vertices in M), _P_ is a partition of M that refines _c_, \(\delta\) is a counting function for \(H[X\cap Y]\) (\(\alpha_\pi\) is again 1), and \(\ell\le d\) is an upper bound on the number of vertices in a solution. For a request _r_, let \(Z=X\cap Y\) , let \(H_Z^\delta\) be the subgraph of _H_\[_Z_\] that has edge multiplicities as specified by \(\delta\), and let \(H_X^\delta\) be the subgraph of _H_\[_X_\] that has the same multiplicities as _H_ for all edges incident to at least one node in _X_\\_Y_ and multiplicities as in \(H_Z^\delta\) for all other edges. Then, an optimal solution for request _r_ corresponds to a set of at most \(\ell\) vertices that induce a subgraph of maximum weight that models \(H_X^\delta\) exactly after adding the following edges: for each \(u\in Z\), choose one representative from each set in _P<sup>u</sup>_ and add a forest between all representatives for _u_. We say that a graph models \(H_X^\delta\) exactly, if after contracting all vertices in the model of _u_ along a spanning tree, the resulting edge multiplicities exactly coincide with \(H_X^\delta\).

When combining two solutions along a separator _C_=(_C_<sub>he</sub>_,C_<sub>li</sub>_,C_<sub>di</sub>), we iterate over all pebble sets \(\mathcal{M}'\) that contain at most \(20\sqrt{d}log(d)\) vertices from _C_<sub>li</sub> and no vertices from _C_<sub>di</sub>. The procedure is similar to the case of Minimum-Weight Rooted Simple Minor Request with two exceptions.
