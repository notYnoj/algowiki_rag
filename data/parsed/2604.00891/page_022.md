For the third point, notice that since \(|X_\mathrm{he}\cup X_\mathrm{li}|\le(3/4)^y\cdot 50d^6\) by assumption and \(|X_\mathrm{he}\cup X_\mathrm{li}|\ge 1\) as we passed Line 2, it holds that \((3/4)^y\cdot 50d^6\ge 1\), which implies \(y\le\frac{-\mathrm{log}(50d^6)}{\mathrm{log}(3/4)}\le\frac{-\mathrm{log}(d^7)}{-1/3}\le 21\mathrm{log}(d)\). Thus, it holds that \(y'=y+1<22\mathrm{log}(d)\). Using Lemma 6, we next get that

\(|Y'_\mathrm{he}|\le|Y_\mathrm{he}\cup C'_\mathrm{he}|\)<br>
\(\le 40(2y)\alpha_\pi\sqrt{d}+40\sqrt{\alpha_\pi d}\)<br>
\(\le 40(2y+1)\alpha_\pi\sqrt{d}<40(2y')\alpha_\pi\sqrt{d}\text{and}\)

\(|Y'_\mathrm{li}|\le|Y_\mathrm{li}\cup C'_\mathrm{li}|\le 60(2y)\alpha_\pi d\mathrm{log}(d)+60\alpha_\pi d\mathrm{log}(\alpha_\pi d)\)<br>
\(\le 60(2y)\alpha_\pi d\mathrm{log}(d)+60\alpha_\pi d\mathrm{log}(d^2)\)<br>
\(\le 60(2y+2)\alpha_\pi d\mathrm{log}(d)\)<br>
\(\le 60(2y')\alpha_\pi d\mathrm{log}(d).\)

This concludes the proof.

## 3.2 Base Case

Here, we prove that `base-case` works as intended. Before doing so, let us give an intuitive description of what the algorithm does. As stated in Lemma 8, the algorithm is only called when _d_ is constant (because \(\alpha_\pi\) is a constant). Recall that for a node _u_ of the tree decomposition, _X<sub>u</sub>_ denotes the vertices in the bag of _u_ and _Y<sub>u</sub>_ denotes the union of _X<sub>v</sub>_ for all descendants of _v_ (including _u_). We use standard dynamic programming ideas on the tree decomposition to solve request for pebble sets _of any size_ where we consider all vertices in the bag of the current node as heavy vertices (in addition to the input portal set _B_); this can be viewed as setting \(x=\infty=d\). In order to improve the polynomial part of the running time, we will consider balanced binary tree decompositions, that is, binary tree decompositions of depth O(log_n_).

For the dynamic program over the balanced binary tree decomposition, we first solve certain small instances using brute force and then use Requirement R4 to combine solutions. The small instances are those induced by vertices in \(X_u\cup X_{u^\prime}\) for any node _u_ (except the root) in the tree decomposition and where \(u'\) is the parent of _u_. Since each bag has constant size and we assume that \(\pi\)-Request is computable, this results in a constant-time algorithm for each edge in the tree decomposition. We then combine solutions as follows. For each node _u_ and each child _v<sub>i</sub>_ of _u_, we combine the solutions for _G_\[_Y<sub>v<sub>i</sub></sub>_\] and \(G[X_u\cup X_{v_i}]\) using _X<sub>v<sub>i</sub></sub>_ as a separator consisting of heavy vertices using Requirement R4. We call these instances \(I_u^1\) (for _v_<sub>1</sub>) and _J<sub>u</sub>_ (for _v_<sub>2</sub>). Therein, we keep the vertices in _X<sub>u</sub>_ as heavy portal vertices. If _u_ has two children, then we combine the solutions for both instances to get a solution for _G_\[_Y<sub>u</sub>_\]. After this is done for all nodes, we are left with two minor inconveniences. On the one hand, the vertices in _X<sub>p</sub>_ (_p_ is the root of the tree decomposition) are currently treated as heavy portal vertices. However, using Requirement R4, we can view _X<sub>p</sub>_\\_B_ as a separator for the separation (_G,X<sub>p</sub>_\\_B_), that is, no vertices are separated from \((V\backslash X_p)\cup B\). Applying Requirement R4 then allows us to drop the vertices in _X<sub>p</sub>_\\_B_ from the portal set. A key step in the proof will be to show that \(((X_u\cup X_{u^\prime},\emptyset,\emptyset),1)\) is measured for 4_d_<sup>2</sup> and \(\alpha_\pi\) and hence Requirement R4 can be applied. On the other hand, we now have a lookup table storing _too much_ information. We did not yet consider the size of possible pebble sets as we imagined \(x=\infty=d\). However, this is trivial to fix. We simple iterate over each pebble set for \((B,d,\alpha,x)\), compute all requests for it and copy the solution for it. We will show that all of the above can be done in \(\mathcal{O}(n^\rho\mathrm{log}(n))\) time assuming _d_ is a constant.
