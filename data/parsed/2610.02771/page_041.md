## D.3 Embedding and change of measure

Define the _K_-arm base instance \(\nu^{(0)}:=(P_0,P_-,\dots,P_-)\), where arm 1 is optimal and all suboptimal gaps equal \(\Delta\). For each \(i\in\{2,\dots,K\}\), let \(\nu^{(i)}\) differ only in arm _i_, whose distribution is changed from _P_<sub>-</sub> to _P_<sub>+</sub>. Arm _i_ is then uniquely optimal, with gap \(\Delta\) to arm 1. Let Pr<sub>0</sub> and Pr_<sub>i</sub>_ denote the corresponding probability measures induced by the interaction of the algorithm, and let E<sub>0</sub> and E_<sub>i</sub>_ denote their expectations. The same anchors _c<sub>k</sub>_=0 are supplied under every instance. Write _N<sub>i</sub>(t_) for the number of queries to arm _i_ up to time _t_.

Let \(\tau\) be the algorithm’s stopping time. At each round \(t\le\tau\), the algorithm selects an arm \(K_t\in\{1,\dots,K\}\) and a measurable query set \(A_t\subseteq\mathbb{R}\), then observes the 1-bit feedback \(Y_t=\mathbf{1}\{X_t\in A_t\}\) where _X<sub>t</sub>_ is drawn from the distribution of the pulled arm. To facilitate a clean change-of-measure argument over a deterministic time horizon, we formally extend this to an infinite padded transcript \(Z_t:=(\tilde{K}_t,\tilde{A}_t,\tilde{Y}_t)\) defined for all integers \(t\ge 1\).

Let \(\emptyset\) represent an empty query set and \(\perp\) a null observation where \(\perp\notin\{0,1\}\), and define the padded variables piecewise:

\(\tilde{K}_t:=\left\{\begin{array}{ c c c }
K_t, & \text{if}t\le\tau, &  \\
1, & \text{if}t>\tau, &  \\
\tilde{A}_t:= & \left\{\begin{array}{ c c }
A_t, & \text{if}t\le\tau, \\
\emptyset, & \text{if}t>\tau,
\end{array}\right. & 
\end{array}\right.\tilde{Y}_t:=\left\{\begin{array}{ c c }
Y_t, & \text{if}t\le\tau, \\
\perp, & \text{if}t>\tau.
\end{array}\right.\)

By construction, once the algorithm stops (\(t>\tau\)), the transcript deterministically locks to the state \((1,\emptyset,\perp)\), ensuring no further statistical information is gathered under either instance. We denote the history up to time _t_ as _Z_<sub>1:_t_</sub>=(_Z_<sub>1</sub>_,...,Z<sub>t</sub>_), which, together with an independent initial random seed _U_ containing the algorithm’s internal randomness, generates the natural filtration \(\mathcal{F}_t=\sigma(U,Z_{1:t})\). The law of _U_ is the same under every instance. Consequently, both the stopping time \(\tau\) and the final arm recommendation \(\widehat{k}\) are measurable with respect to the infinite-horizon \(\sigma\)-algebra \(\mathcal{F}_\infty=\sigma\big(\bigcup_{t=1}^\infty\mathcal{F}_t\big)\).

**Lemma 37** (Data processing for the error event)**.** _If the algorithm is_ \(\delta\)_-correct over the instance class, then for each_ \(i\ge 2\)

\(\mathrm{KL}(\mathrm{Pr}_0,\mathrm{Pr}_i)\ge c_1\mathrm{log}(1/\delta)\)

_for an absolute constant c_<sub>1</sub>_\>_0_. The same conclusion holds for_ \((\varepsilon,\delta)\)_-PAC algorithms when_ \(0<\varepsilon<\Delta/2\)_, since only the unique best arm is_ \(\varepsilon\)_-optimal in either instance._

_Proof._ Let \(E:=\{\widehat{k}=1\}\) be the event that the algorithm recommends arm 1. By the \(\delta\)-correctness requirement, the algorithm must identify the correct arm with probability at least \(1-\delta\). Therefore, \(\mathrm{Pr}_0(E)\ge 1-\delta\) and \(\mathrm{Pr}_i(E)\le\delta\). Because the recommendation \(\widehat{k}\) is entirely determined by the full transcript \((U,(Z_t)_{t\ge 1})\), the data-processing inequality implies:<tbc>

\(\mathrm{KL}(\mathrm{Pr}_0,\mathrm{Pr}_i)\ge\mathrm{kl}(\mathrm{Pr}_0(E),\mathrm{Pr}_i(E))\ge\mathrm{kl}(1-\delta,\delta).\)

<tbc>For any \(\delta\in(0,1/4)\),

\(\mathrm{kl}(1-\delta,\delta)\ge(1-2\delta)\mathrm{log}\frac{1-\delta}{\delta}\ge c_1\mathrm{log}(1/\delta)\)

for some _c_<sub>1</sub>_\>_0.

**Lemma 38** (Transcript divergence bound)**.** _For each_ \(i\ge 2\), \(\mathrm{KL}(\mathrm{Pr}_0,\mathrm{Pr}_i)\le 4C_0\frac{\Delta^2}{J\sigma^2}\mathbb{E}_0[N_i(\tau)]\).

_Proof._ Fix \(i\ge 2\). Let \(\mathrm{Pr}_0^{(T)}\) and \(\mathrm{Pr}_i^{(T)}\) denote the marginal laws of the truncated transcript (_U,Z_<sub>1:_T_</sub>). By the chain rule for relative entropy:

\(\mathrm{KL}(\mathrm{Pr}_0^{(T)},\mathrm{Pr}_i^{(T)})=\sum_{t=1}^T\mathbb{E}_0\big[\mathrm{KL}(\mathrm{Pr}_0^{(T)}|U,Z_{1:t-1})\|\mathrm{Pr}_i(Z_t|U,Z_{1:t-1}))\big].\)

Let F<sub>_t_-1</sub> be the \(\sigma\)-algebra generated by (_U,Z_<sub>1:_t_-1</sub>). Conditioned on F<sub>_t_-1</sub>, the event \(\{t\le\tau\}\) is determined.
