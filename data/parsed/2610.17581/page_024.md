<tbc>_Proof._ We begin by showing that DSH (and thus DSG) is a \((\frac{1}{logn},n)\)-heavy subgraph problem. For a hypergraph _H_=(_V,E,w_), we let the set of solutions S be the induced subhypergraphs of _H_ and partition them into S<sub>1</sub>_,...,_S_<sub>n</sub>_ such that \(\mathcal{S}\in\mathbb{S}_k\) if |_V_(S)|=_k_. Setting \(f_k=\frac{1}{k}\) for each \(k\in[n]\), we have that \(\rho(\mathcal{S})=|E(\mathcal{S})|/|V(\mathcal{S})|=f_k\cdot w(\mathcal{S})\), and so DSH is locally linear of rank _n_. We now show that DSH is \(\gamma\)-bounded for \(\gamma=\frac{1}{logn}\). Assuming \(\gamma log|\mathbb{S}_k|\ge 1\), we use the fact that \(\rho^*(G)\ge\rho(V)\ge m/n\) to obtain

\(f_k\frac{m}{n}max\{\gamma log|\mathbb{S}_k|,1\}=\frac{1}{k}\frac{m}{n}\frac{1}{logn}log\genfrac(){pt}{2}{n}{k}\le\frac{1}{k}\frac{m}{n}\frac{1}{logn}klogn=\frac{m}{n}\le\rho^*(G).\)

The inequality uses the rough upper bound of \(\genfrac(){pt}{2}{n}{k}\le n^k\). In the case that \(\gamma log|\mathbb{S}_k|<1\), we trivially have \(\rho^*(G)\ge m/n\ge m/kn\).

For the remaining problems, we will prove that Proposition 3 holds under our new definition of heavy subgraph problems. Namely, we will argue each problem satisfies two conditions: (i) generalizability to weighted graphs, (ii) and our strengthened definition of \(\gamma\)-boundedness. For point (i), we argue that the same lower bounds on _f_(S<sup>∗</sup>) still hold and so the original \(\gamma\) bound of \[16\] is true. For the latter point, observe that if the original \(\gamma\) bound holds, it will suffice to show that \(\gamma log|\mathbb{S}_G^k|\ge 1\) for all \(k\in[\ell]\), or to prove that \(f(\mathcal{S}^*)\ge f_k\frac{m}{n}\) for any _k_ violating this condition.

• **Densest Bipartite Subgraph.** We use a similar approach to DSG and let S_<sub>k</sub>_ be the set of cardinality-_k_ solutions, including all 2<sup>_k_-1</sup> possible bipartitions of each set \(S\in\genfrac(){pt}{2}{V}{k}\). However, we exclude all singleton solutions (i.e, there is no S<sub>1</sub>), which does not affect our problem as they trivially have zero density. The lower bound of \(f(\mathcal{S}^*)\ge m/2n\) on the optimal value comes from applying the first-moment method to a random bipartition of _V_ , which still applies to weighted graphs, showing (i). Defining \(f_k=\frac{1}{k}\), we have that \(f_k\frac{m}{n}\le\frac{m}{2n}\le f(\mathcal{S}^*)\) for all \(k\ge 2\); since we exclude _k_=1 by construction, this yields (ii).<tbc>

• _d_-**Max Cut.** We use a single set of solutions. For (i), the first-moment method on a random coloring of _V_ to obtain a lower bound of \(f(\mathcal{S}^*)\ge m/d\) applies also to weighted graphs. We have \(log|\mathbb{S}_k|=logd^n=nlogd\ge 2logd=\gamma^{-1}\), showing (ii).<tbc>

• _d_-**Sum-Max Clustering.** We again use a single set of solutions, but instead use the first-moment method on a random choice of _d_-1 vertices to be colored uniquely and then color all other _n-d_+1 vertices with a single color. This lower bound of \(f(\mathcal{S}^*)\ge m\frac{(n-d+1)(n-d)}{n(n-1)}\ge m\frac{n-2d}{n}\) still applies to weighted graphs, giving (i). For (ii), we have \(log|\mathbb{S}_k|=logd^n=nlogd\ge\frac{nlogd}{n-2d}=\gamma^{-1}\), by the assumption _d\<n/_2.

## A note on Densest Directed Subgraph.

Densest Directed Subgraph problem can be defined as a \((\frac{1}{2\sqrt{nlogn}},n^2)\)-heavy subgraph problem similarly to Densest Bipartite Subgraph. For each set of sources _S_ and destinations _T_, not necessarily disjoint, the solution on _S_ and _T_ contains only the induced arcs _E(S,T_) and has density \(\rho(S,T)=w(E(S,T))/\sqrt{|S||T|}\). While Directed Densest Subgraph is still a heavy subgraph problem under our redefinition, we unfortunately get no approximation for the problem because of a barrier in learning directed arcs in the cut model. Since a directed cut(_S_) query returns the weight of arcs _E(S,<o>S</o>_), computing cut(_S_)+cut(<o>_S_</o>) yields the undirected cut function, allowing us to compute properties (such as sampling random edges) of the underlying undirected graph. However, this process combines arcs (_u,v_) with weight _w_ and (_v,u_) with weight \(w'\) into an undirected edge {_u,v_} with weight \(w+w'\). Even in the simplest case where two vertices are connected by a single unweighted arc, current techniques are not able to recover the direction of this arc. For more discussion on this topic, see the recent work on directed reachability in DAGs \[5, 25\].
