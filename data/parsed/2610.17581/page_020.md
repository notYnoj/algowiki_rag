**Theorem 6.1.** With only cut and is-edge<sup>?</sup> access to a hypergraph, there exists a hypergraph _H_ with a node subset _S_ such that it is impossible for an algorithm making _t_ queries to obtain any approximation to add(_S_) with probability greater than \(\frac{1}{2}+\frac{2t}{2^{n/5}}\).

_Proof._ For _r=n/_8, we will define a family of unweighted _r_-uniform hypergraphs on _n_ vertices partitioned into 4 sets of _n/_4 vertices, _A<sup>L</sup>,A<sup>R</sup>,B<sup>L</sup>_, and _B<sup>R</sup>_, each labeled \(a_1^L,\dots,a_{n/4}^L\), \(a_1^R,\dots,a_{n/4}^R\), \(b_1^L,\dots,b_{n/4}^L\), and \(b_1^R,\dots,b_{n/4}^R\). For a subset \(I=\{i_1,\dots,i_\ell\}\subseteq[n/4]\), we let \(A_I^L\) denote the set \(\{a_{i_1}^L,\dots,a_{i_\ell}^L\}\), and define \(A_I^R\), \(B_I^L\), and \(B_I^R\) analogously. Now, for each subset \(J\in\genfrac(){pt}{2}{[n/4]}{r}\), we define the hypergraph \(H_L^J\) as the union of hypergraphs \(H_0^{A_J^L,B_J^L}\), \(H_1^{A_J^R,B_J^R}\), and both \(H_1^{A_I^L,B_I^L}\) and \(H_1^{A_I^R,B_I^R}\) for each other \(I\in\genfrac(){pt}{2}{[n/4]}{r}\backslash J\). We then define the left distribution H_<sub>L</sub>_ to be the uniform distribution of hypergraphs \(H_L^J\) over each \(J\in\genfrac(){pt}{2}{[n/4]}{r}\), and similarly define hypergraphs \(H_R^J\) and the right distribution H_<sub>R</sub>_.

Consider the joint distribution H=H_<sub>L</sub>/_2+H_<sub>R</sub>/_2, and let _H_∼H. By the fact that add(_A<sup>L</sup>_)=1 if \(H\in\mathcal{H}_L\) and add(_A<sup>L</sup>_)=0 if \(H\in\mathcal{H}_R\), simulating an add oracle is equivalent to distinguishing between H_<sub>L</sub>_ and H_<sub>R</sub>_. We first note that every hypergraph in H has the same cut profile, and so cut queries reveal no information about which of the underlying distributions _H_ is drawn from. Thus, we will prove an upper bound of 2_t/_2<sup>_n/_5</sup> on the total variation distance between the answers to any _t_ is-edge<sup>?</sup> queries for the left and right distributions. This yields a matching upper bound on the advantage of any distinguisher of H_<sub>L</sub>_ and H_<sub>R</sub>_, proving that no algorithm making _t_ queries can simulate an add oracle with probability greater than \(\frac{1}{2}+\frac{2t}{2^{n/5}}\).

For a set of queries Q_<sub>t</sub>=e_<sub>1</sub>_,...,e<sub>t</sub>_, we define the random variables A_<sub>t</sub>=x_<sub>1</sub>_,...,x<sub>t</sub>_ to be the outputs (single bits) of each query, such that _x<sub>i</sub>_=is-edge<sup>?</sup>(_e<sub>i</sub>_). We can condition these random variables on \(H\in\mathcal{H}_L\), denoting them as \(\mathcal{A}_t^L=e_1^L,\dots,e_t^L\) where \(x_i^L=\text{is-edge}^?(e_i)|H\in\mathcal{H}_L\). We define \(\mathcal{A}_t^R\) similarly. Lastly, we define hypergraph _H_<sup>1</sup> to be the union of both \(H_1^{A_I^L,B_I^L}\) and \(H_1^{A_I^R,B_I^R}\) for each \(I\in\genfrac(){pt}{2}{[n/4]}{r}\), i.e., the hypergraph with no copy of _H_<sub>0</sub>. Let \(\mathcal{A}_t^1=x_1^1,\dots,x_t^1\) denote the distribution of answers to queries _e_<sub>1</sub>_,...,e<sub>t</sub>_ conditioned on _H=H_<sup>1</sup>. We begin by proving that \(\Delta_\text{TV}(\mathcal{A}_t^L,\mathcal{A}_t^1)\le t/2^{n/5}\) for all \(\mathcal{Q}_t\in(2^V)^t\). Let \(H\in\mathcal{H}_L\cup\{H_1\}\). If a query _e<sub>i</sub>_ is not a cardinality-_r_ subset of \(A^L\cup B^L\) or \(A^R\cup B^R\), then _e<sub>i</sub>_ is not a hyperedge of any _H_ and so _x<sub>i</sub>_=0. Furthermore, if _e<sub>i</sub>_ contains both of \(\{a_j^L,b_j^L\}\) or both of \(\{a_j^R,b_j^R\}\) for any _j_, then it is not a hyperedge of any _H_ so _x<sub>i</sub>_=0. However, if _e<sub>i</sub>_ is a cardinality-_r_ subset of \(A^R\cup B^R\) and does not contain both \(\{a_j^L,b_j^L\}\) or both \(\{a_j^R,b_j^R\}\) for any _j_, then _x<sub>i</sub>_ is deterministic conditioned on the parity of \(|e_i\cap A^R|\). Thus, we assume that \(e_i\subseteq A^L\cup B^L\) is a cardinality-_r_ subset and does not contain both \(\{a_j^L,b_j^L\}\) or both of \(\{a_j^R,b_j^R\}\) for any _j_. Let _J<sub>i</sub>_ be the union of indices of _e<sub>i</sub>_, so that \(e_i\subseteq A_{J_i}^L\cup B_{J_i}^L\). In this case, we have that \(x_i^L\neq x_i^1\) if and only if \(H=H_L^{J_i}\). Since H_<sub>L</sub>_ is the uniform distribution of \(H_L^J\) over \(J\in\genfrac(){pt}{2}{[n/4]}{r}\), then we can upper bound the probability that \(x_i^L\neq x_i^i\) by

\(Pr[x_i^L\neq x_i^1]=1/\genfrac(){pt}{2}{n/4}{r}\le\frac{\sqrt{\pi n/8}}{2^{n/4}}\le 2^{-n/5}.\)

where the first inequality is an application of Stirling’s approximation, and the second inequality follows by taking \(n\ge 40\) so that \(2^{n/20}\ge\sqrt{\pi n/8}\). A simple union bound yields \(Pr[\mathcal{A}_t^L\neq\mathcal{A}_t^1]\le t/2^{n/5}\), and so we have \(\Delta_\text{TV}(\mathcal{A}_t^L,\mathcal{A}_t^1)\le t/2^{n/5}\) by the fact that total variation distance is equal to half of _L_<sup>1</sup> distance. Using symmetry for the \(\mathcal{A}_t^R\) case, we complete the proof by appealing to the triangle inequality to obtain \(\Delta_\text{TV}(\mathcal{A}_t^L,\mathcal{A}_t^R)\le 2t/2^{n/5}\).
