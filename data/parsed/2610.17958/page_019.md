<tbc>in no node, or both start with the same symbol, say 0, and thus occur only among the _u<sub>j</sub>_ and their complement nodes, so the endpoint _w<sub>j</sub>_ of each edge {_u<sub>j</sub>,w<sub>j</sub>_} contains neither motif; the case for symbol 1 is symmetric.

Now let {_X,Y_}, possibly with _X=Y_ , be a motif pair with \(|E_{X,Y}|\ge 1\) such that _X_ or _Y_ is special. Since every edge has the form {_u<sub>j</sub>,w<sub>j</sub>_}, we may assume by symmetry that _X_ occurs in _u<sub>j</sub>_ and _Y_ occurs in _w<sub>j</sub>_ for some edge \(\{u_j,w_j\}\in E_{X,Y}\). A special substring of _u<sub>j</sub>_ (resp. _w<sub>j</sub>_) contains #_<sub>j</sub>_, so it occurs in _u<sub>j</sub>_ (resp. _w<sub>j</sub>_) and in every padding node \(z_r^U\) (resp. \(z_r^W\)), and in no node other than _u<sub>j</sub>_, _w<sub>j</sub>_, and the padding nodes. Thus, if _X_ is special, then {_u<sub>j</sub>,w<sub>j</sub>_} is the only edge with an endpoint in _V<sub>X</sub>_, and likewise for _Y_ ; hence |_E<sub>X,Y</sub>_|=1. Moreover, _V<sub>X</sub>_ and _V<sub>Y</sub>_ contain disjoint subsets of sizes at least _m_<sup>2</sup>+1 and _m_, or vice versa: \(\{u_j,z_1^U,\dots,z_{m^2}^U\}\subseteq V_X\) if _X_ is special, \(\{w_j,z_1^W,\dots,z_{m^2}^W\}\subseteq V_Y\) if _Y_ is special, and, by the case of plain motifs, _V<sub>X</sub>_ consists of _m_ nodes among the _u<sub>k</sub>_ and their complement nodes if _X_ is plain, and _V<sub>Y</sub>_ consists of _m_ nodes among the _w<sub>k</sub>_ and their complement nodes if _Y_ is plain. Hence, \(E_{k_X,k_Y,k_{X,Y}}^\mathrm{max}\ge(m^2+1)m>m^2\) and thus \(\overline{E_{X,Y}}>\mu\). Therefore, by Theorem A.3(b), \(f_{\chi^2}(G,\{X,Y\})=s(1,\overline{E_{X,Y}})<s(1,\mu)\), which is the score of a plain pair with inner product 1.

We now combine both cases. Let \(p^\star:=\mathrm{max}_{a\in A,b\in B}\langle a,b\rangle\), and suppose first that \(p^\star\ge 1\). A plain pair \(\{0\cdot\mathsf{enc}(i),1\cdot\mathsf{enc}(i')\}\) with \(\langle a_i,b_{i^\prime}\rangle=p^\star\) scores \(s(p^\star,\mu)\ge s(1,\mu)>0\), whereas, by Theorem A.3(a), every plain pair with a smaller inner product scores less, every pair containing a special motif scores less than \(s(1,\mu)\), and every remaining pair scores 0. Hence, every motif pair maximizing \(f_{\chi^2}(G,\cdot)\) is a plain pair whose vectors have inner product _p<sup>⋆</sup>_. To solve MaxIP, we compute a maximizing pair {_X<sup>⋆</sup>,Y<sup>⋆</sup>_} and output \(\langle a_i,b_{i^\prime}\rangle\) if it is a plain pair \(\{0\cdot\mathsf{enc}(i),1\cdot\mathsf{enc}(i')\}\), and 0 otherwise. If \(p^\star\ge 1\), the output is _p<sup>⋆</sup>_ by the above. If _p<sup>⋆</sup>_=0, the output is 0 either way: if the returned pair is a plain pair, its vectors have inner product 0, and otherwise we output 0 by definition.

Each of \(u_j,w_j,u'_j,w'_j\) has length at most \(n(\ell+1)\in\mathcal{O}(n\mathrm{log}n)\), so \(|\mathcal{Z}_U|,|\mathcal{Z}_W|\le mn(\ell+1)\) and each padding node has length at most \(mn(\ell+1)^2\). Hence, we have \(N\in\mathcal{O}(m^3n\mathrm{log}^2n)\), \(|V|\in\mathcal{O}(m^2)\), and \(|\Sigma|\le 2+2m+2m^2\). The instance can be built in O(_n_polylog_n_) time, e.g., by computing Z_<sub>U</sub>_ and Z_<sub>W</sub>_ through sorting the \(\mathcal{O}(mn\ell)\) length-\(\ell\) substrings of the _u<sub>j</sub>_ and _w<sub>j</sub>_. Together with the construction, the O(_nm_)-time check for zero vectors, and the O(_m_)-time decoding, an \(\mathcal{O}(N^{2-\varepsilon}\mathrm{poly}(|E|,|V|))\)-time algorithm for CMM with \(f_{\chi^2}\) would thus solve MaxIP with \(m=c(\varepsilon/2)\mathrm{log}n\) in \(\mathcal{O}(n^{2-\varepsilon}\mathrm{polylogn})\subseteq\mathcal{O}(n^{2-\varepsilon/2})\) time, contradicting the hardness conjecture for MaxIP and hence SETH. \(\sqcap\sqcup\)

## B Materials omitted from Section 4.

### B.1 Why we cannot hope for a running time polynomial in \(\ell\).

The result of Section 4 can be couched in parameterized complexity terms to say that \((\ell,d)\)- CMM is fixed-parameter tractable (in FPT) by \(\ell\) (since \(\genfrac(){pt}{2}{\ell}{d}\le 2^\ell\)). Since \(\ell\) is a larger parameter than _d_ (except in trivial instances), it is natural to ask if \((\ell,d)\)-CMM is in FPT by _d_, too. That is, whether there is an algorithm with a running time of the form \(\mathcal{O}(f(d)\cdot\mathrm{poly}(N))\), where _f_ is any computable function. Note that we do not need to allow a separate polynomial dependence on \(\ell\) as for all non-trivial instances \(\ell\le N\).

Observation B.1. \((\ell,d)\)_-CMM is W\[1\]-hard by d for both f<sub>E</sub> and_ \(f_{\chi^2}\).

_Proof._ The result follows by checking that the reduction from \[1\] is a parameterized reduction from balanced biclique, parameterized by solution size, to \((\ell,d)\)-CMM parameterized by _d_.

An outline of the reduction strategy is as follows. The reduction takes a graph as input and produces a node-labeled graph such that a motif consisting of 0s and _d_ wildcards selects exactly the _d_ nodes at its wildcard positions, so every set of _d_ nodes can be selected (a motif containing a 1 selects at most one node). A motif pair selecting two disjoint sets of _d_ nodes each maximizes the support function if and only if the selected subgraph is a biclique. Thus finding a motif pair with _d_ wildcards and the best possible support value is equivalent to finding a biclique _K<sub>d,d</sub>_, a problem that is known to be W\[1\]-hard by solution size \[19\]. \(\sqcap\sqcup\)

In fact, the authors of \[1\] show NP-hardness for an even larger class of support functions (which they call _compliant biclique-maximal_ support functions). We omit that discussion, because it is quite technical, and refer the interested reader to \[1\].
