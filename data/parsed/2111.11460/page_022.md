A "11" bit has been sent to the node with the largest prime _p<sub>m</sub>_ in the graph _G_ by the node \(p_{s(j)}^{o_j}\) of the original graph. Now, the node _p<sub>m</sub>_ of _G_ cycles through all the edges of _p<sub>m</sub>_ to check if any of them received a special 1 in the chaining process. If it finds a bit "1" then it takes the edge and other wise it ends with first choice, that is \(p_m^0\). Note that this takes only one message from each node since they take turn in sending message to the next node. After having found no 1 message, the protocol takes the choice 0. It then goes to the second prime, namely _p_<sub>_m_-1</sub> and search for a 1 in the chaining process of _G_. After not finding it, it takes the choice of 0 again. This way it goes to finally _p<sub>s<sub>j</sub></sub>_ and finds the option _o<sub>j</sub>_ with a "1" and takes it. It means that the number is any where between \(p_{s(j)}^{o_j}\) and the number obtain by multiplying this number by any prime numbers strictly smaller than _p_<sub>_s(j_)</sub>. From now on, your path lies under this option. But the process continues and it looks at _p_<sub>_s(j_)-1</sub> and so on until it looks at _p_<sub>_s(j_-1)</sub>. In the mean time, all of _p_<sub>_s(j_)-1</sub>, _p_<sub>_s(j_)-2</sub> etc. will be set to a zero until it hits _p_<sub>_s(j_-1)</sub>. In this case, all of edges labeled _a_ be zero except _o_<sub>_j_-1</sub>. It will then add \(p_{s(j-1)}^{o_{j-1}}\) to \(p_{s(j)}^{o_j}\) thus making \(p_{s(j)}^{o_j}p_{s(j-1)}^{o_{(j-1)}}\). But this means that we have a range of values starting from this number to anything that is a product of this number and the number obtained by multiplying this number with any smaller prime numbers, that is prime numbers less than _p_<sub>_s(j_-1)</sub>. From now on, you are under these two options. This process continues until it completes the _p_<sub>1</sub> there by completing the \(p_{s(j)}^{o_j}p_{s(j-1)}^{o_{j-1}}\cdots p_{s(1)}^{o_1}\). The result is the product of these primes which is what you need. □
