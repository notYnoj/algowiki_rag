We say that a hereditary graph class C has _bounded versatile symmetric difference_ if there is an integer _d_:=_d_<sub>C</sub>_\>_0 such that for every _n_-vertex graph \(G\in\mathcal{C}\), there are at least \(\lfloor n/d\rfloor\) disjoint pairs of vertices _u,v_ satisfying \(\mathrm{sd}_G(u,v)\le d\). For \(\alpha\in[0,1)\), we say that C has _versatile symmetric difference of exponent_ \(\alpha\) if there is a constant _d_:=_d_<sub>C</sub>_\>_0 such that for every _n_-vertex graph \(G\in\mathcal{C}\), there are \(\lfloor n/d\rfloor\) disjoint pairs of vertices _u,v_ in _G_ satisfying \(\mathrm{sd}_G(u,v)\le dn^\alpha\). Thus _versatile symmetric difference of exponent 0_ coincides with _bounded versatile symmetric difference_.

## 2.3 Signed tree models and interval biclique partitions

We recall the definition of signed tree models for the sake of self-containedness. However, we will not use them in the rest of the paper. Thus, from this subsection, one can only read the definition of interval biclique partitions (given just after Lemma 11) and Lemma 13.

_Signed tree models_, originally defined in \[11\], generalize the tree models introduced in the context of twin-width \[17, 13\]. In a rooted tree _T_ and \(u,v\in V(T)\), by \(u\unknown_Tv\) we denote that _u_ is an ancestor of _v_. A pair of vertices of a rooted tree _T_ is a _transversal pair_ of _T_ if it is not between an ancestor and descendant. We say that two transversal pairs _u_<sub>1</sub>_v_<sub>1</sub> and _u_<sub>2</sub>_v_<sub>2</sub> _cross_ if one of _u_<sub>1</sub>_,v_<sub>1</sub> is a strict ancestor of one of _u_<sub>2</sub>_,v_<sub>2</sub>, and conversely, one of _u_<sub>2</sub>_,v_<sub>2</sub> is a strict ancestor of one of _u_<sub>1</sub>_,v_<sub>1</sub>.

A _full_ binary tree is a rooted binary tree where every internal node has exactly two children. A _signed tree model_ is a triple T=(_T,A,B_) where _T_ is a full binary tree, _A_ and _B_ are two disjoint sets of transversal pairs of _T_, and \(A\cup B\) does not contain any crossing pair. The transversal pairs of _A_ and _B_ are called _negative edges_ and _positive edges_, respectively.

We say that a transversal pair \(u'v'\) _covers_ the pair \(u,v\in V(T)\) if \(u'\unknown_Tu\) and \(v'\unknown_Tv\) and there is no transversal pair \(u''v''\neq u'v'\) in \(A\cup B\) with \(u'\unknown_Tu''\unknown_Tu\) and \(v'\unknown_Tv''\unknown_Tv\). We denote by _L(T_) the set of leaves of _T_. The graph _G_<sub>T</sub> represented by the signed tree model T has vertex set _L(T_), and \(u,v\in L(T)\) are adjacent in _G_<sub>T</sub> if and only if the pair _u,v_ is covered by a positive transversal pair in T .

A graph class C has _sparse signed tree models_ if there is a constant _c_ such that every \(G\in\mathcal{C}\) admits a signed tree model (_T,A,B_) with \(|A\cup B|\le c\cdot|V(T)|\). There is an efficient algorithm that turns sd-degeneracy sequences of bounded width into sparse signed tree models.
