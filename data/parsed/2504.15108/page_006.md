As illustrated in Fig. 2, we use nearest-neighbor interpolated features sampled from _F<sub>SEB</sub>_ as queries (_Q_), and utilize _F<sub>TEB</sub>_ as keys (_K_) and values (_V_). To retrieve texture features most relevant to pixel features _F<sub>TEB</sub>_, we compute the similarity matrix _R_ between queries _Q_ and keys _K_, where each element _r<sub>i,j</sub>_ is calculated according to the following formula:

\(r_{i,j}=\frac{q_i\cdot k_j}{\sqrt{q_i\cdot q_i}\sqrt{k_j\cdot k_j}}.\) (11)

Based on the similarity matrix _R_, we obtain a position index matrix _T_ that identifies the positions of the texture features _k<sub>j</sub>_ most similar to each query _q<sub>i</sub>_. For each query _q<sub>i</sub>_, we find the position with the highest relevance, as represented by the following formula:

\(t_i=argmax_j(r_{i,j}),\) (12)

where _t<sub>i</sub>_ denotes the position index of the texture feature most similar to the query _q<sub>i</sub>_, with values ranging from 1 to \(\frac{h}{2}\times\frac{w}{2}\) . Once the most relevant position _t<sub>i</sub>_ for each query is determined, we can use this index to extract the corresponding data from the texture branch feature map _V_ , obtaining the retrieved texture features _C_ as follows: _c<sub>i</sub>=v<sub>t<sub>i</sub></sub>_,where _c<sub>i</sub>_ is an element of the retrieved texture features _C_, and _v<sub>t<sub>i</sub></sub>_ represents the value at the _t<sub>i</sub>_-th position in _V_ . To fuse the retrieved texture features with the structural features _F<sub>SEB</sub>_, we first concatenate _C_ with _F<sub>SEB</sub>_ and process them through a feed-forward network to obtain the aggregated features _A_. Finally, we compute the soft attention map _S_, where the elements _s<sub>i</sub>_ in _S_ represent the confidence of each element _a<sub>i</sub>_ in the retrieved texture features _A_, calculated as follows:

\(s_i=max_j(r_{i,j}).\) (13)

The final structure-texture fusion features _F<sub>STF</sub>_ can be obtained using the following formula:

\(F_{STF}=F_{SEB}+(A\otimes S).\) (14)

## 3.5 . The Output of STEN Model

As illustrated in Fig. 2, two decoders, each implemented by an MLP, are individually used to predict the corresponding outputs based on the fused features and texture features mentioned above. Specifically, we input the texture features _F<sub>TEB</sub>_ into the MLP \(f_\theta\), allowing them to be directly decoded into RGB values. Simultaneously, the structure- texture fusion features _F<sub>STF</sub>_ are also processed through the MLP \(f_\theta\) to produce additional RGB values. Finally, we sum the RGB values obtained from both decoding processes to generate the final output image _I<sub>Pred</sub>_. The relationship can be expressed mathematically as follows:

\(I_{Pred}=f_\theta(F_{STF})+f_\theta(F_{TEB}).\) (15)

## 3.6 . Transformation Self-estimation Module

The proposed method requires two inputs: the input warped image _I_ and the transformation matrix. In practical applications, the transformation matrix is often unknown and needs to be estimated. Motivated by blur kernel estimation for blind super-resolution \[11\], we first construct and train a convolutional neural network to predict the transformation error for the estimated transformation matrix based on the warped input image, then we update the estimation of the transformation matrix based on the gradient descent algorithm. This optimization procedure is executed iteratively till the termination condition is satisfied.

This approach ensures that the input image can be restored to its original state after undergoing cycle-consistent translations \[47\], maintaining feature consistency between the input and output.

Once the transformation error estimator (error estimation CNN) is well-trained, we can estimate the unknown transformation in real-world scenarios.
