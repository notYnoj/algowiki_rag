## 5. Algorithmic proposals and complexity analysis

Due to the lower triangular block structure of A_<sub>N,M</sub>_ two different solution approaches can be considered:

**Technique 1:** the forward block substitution solution approach,

**Technique 2:** the global solution approach.

In the forward block substitution solution approach we have to solve, for _k_=1_,...,M_<tbc>

\((\ell_0I_N-\gamma D_N(a)\overline{G_{\alpha,N}})\mathbf{u}_N^{(k)}=\mathbf{f}_N^{(k)}-\sum_{i=1}^{k-1}\ell_k\mathbf{u}_N^{(i)},\)

<tbc>where each forward step requires the solution of a linear system with the very same matrix<tbc>

\(A_N=\ell_0I_N-\gamma\mathcal{D}_N(a)\overline{G_{\alpha,N}},\)

<tbc>with \(\ell_0=b_0=1\) for all \(\beta\).<br>
This can be done by considering a preconditioned GMRES where the preconditioner is chosen as<tbc>

\(P_{\alpha,N}=\ell_0I_N-\gamma d\widehat{C}_{\alpha,N},\)

<tbc>where<tbc>

\(d=\frac{1}{N}\sum_{i=1}^Nd_i,\)

<tbc>with _d<sub>i</sub>_ are the diagonal entries of D_<sub>N</sub>(a_), and where \(\widehat{C}_{\alpha,N}\) is the circulant matrix generated by the vector \(\left[g_1^{(\alpha)},\dots,g_{N-1}^{(\alpha)},g_0^{(\alpha)}\right]^T\), that is by the first column of \(\overline{G_{\alpha,N}}\) where the last entry \(g_N^{(\alpha)}\) has been replaced by the coefficient \(g_0^{(\alpha)}\), which is nonnegligible while \(g_N^{(\alpha)}\) tends to zero as _N_ tends to infinity.<br>
Otherwise, for \(\omega>0\) but small, the preconditioner is chosen as<tbc>

\(P_{\omega,\alpha,N}=\ell_0I_N-\gamma d\widehat{C}_{\omega,\alpha,N}\)

<tbc>with \(\widehat{C}_{\omega,\alpha,N}\) corresponding \(\omega-\)circulant matrix \[39, 41\] related to \(\overline{G_{\alpha,N}}\) and hence to \(\widehat{C}_{\alpha,N}\): to be precise the first column of \(\widehat{C}_{\omega,\alpha,N}\) is exactly \(\left[g_1^{(\alpha)},\dots,g_{N-1}^{(\alpha)},g_0^{(\alpha)}/\omega\right]^T\) so that the entries on the first upper diagonal of \(\widehat{C}_{\omega,\alpha,N}\) equal those of the original matrix \(\overline{G_{\alpha,N}}\) i.e.

\(\left(\widehat{C}_{\omega,\alpha,N}\right)_{j,j+1}=\left(\overline{G_{\alpha,N}}\right)_{j,j+1}=g_0^{(\alpha)},j=1,\dots,N-1.\)

The principal part of the computational cost is given by _M_ applications of preconditioned GMRES, where the preconditioner solution cost via FFT is given by _O(N_log_N_) according to \[11\], plus \(\sum_{i=1}^M(i-1)N\) matrix-vector products with diagonal matrices. To sum up the computational cost is \(\frac{1}{2}NM^2+\sharp itMO(NlogN)\), where \(\sharp it\) is the average number of preconditioned GMRES iterations required to solve the M systems with matrix _A<sub>N</sub>_.

On the other hand, a global solution approach has been considered as well, where the linear system with matrix A_<sub>N,M</sub>_ is solved by a preconditioned GMRES, where the preconditioner is chosen in a similar way as \(P_{\alpha,\beta,NM}=C_{\alpha,\beta,NM}\) circulant matrix whose first column is given by<tbc>

\([\ell_0,\dots,\ell_{M-1}]^T\otimes[1,0,\dots,0]^T-\gamma[\widehat{C}_{\omega,\alpha,N}[1,0,\dots,0]^T,0,\dots,0]^T\)
