Before we present a high level overview of Theorem 5.6, let us recall some useful definitions.

**Definition 5.7.** _For a spanning tree_ \(T\subset E\) _of a connected graph G_=(_V,E_) _on n vertices, an_ **Euler Tour** _of T is a sequence of vertices v_<sub>1</sub>_,v_<sub>2</sub>_,...,v_<sub>2_n_-1</sub> _where each vertex of G appears at least once and the edges_ \((v_i,v_{i+1})\in T\) _for all_ \(1\le i\le 2n-2\).

Given a spanning tree _T_, an Euler tour of _T_ can be found in _O_(|_T_|) time by conducting depth first search on _T_.

**Definition 5.8.** _Let G_=(_V,E_) _be a graph on n vertices and_ \(D\subset V\) _. Consider an arbitrary Euler Tour on G, denoted v_<sub>1</sub>_,...,v_<sub>2_n_-1</sub>_. X is an_ **Euler Tour Distance Matrix** _of D on V if A is a_ \(|D|\times(2n-1)\) _matrix where_ \(X(w,i)=\delta(w,v_i)\) _for_ \(w\in D\) _and v<sub>i</sub> as ordered in the Euler Tour._

It was first observed by Deng, Kirkpatrick, Rong, Vassilevska-Williams, and Zhong \[DKR<sup>+</sup>22\] that it is possible to encode the results of a **BFS** search in a row bounded difference matrix by ordering the vertices according to an Euler tour.

We now present a high level description of our algorithm.

## High Level Overview

First, we recap the algorithm of Deng et al. \[DKR<sup>+</sup>22\] and explain why it does not generalize to additive approximations beyond +2. Consider a +4 approximation. The natural approach is to use a bounded difference matrix multiplication to compute a +2 additive approximation on paths with some vertex of degree at least _n<sup>x</sup>_ and to invoke **SparseAPASP**(_G,_4) on paths where all vertices have degree at most _n<sup>x</sup>_. If \(\omega_{BD}(1,1-x,1)\) denotes the exponent required to compute a rectangular bounded difference (min,+) matrix product with input \(n\times n^{1-x}\) and \(n^{1-x}\times n\), then this algorithm requires time \(n^{2+\frac{x}{3}}\) where _x_ is the solution to \(\omega_{BD}(1,1-x,1)=2+\frac{x}{3}\) . For current bounds on \(\omega_{BD}\), this is larger than the \(\frac{11}{5}\) given by the combinatorial algorithm of Dor, Halperin, and Zwick \[DHZ00\]. Why? The **DenseAPASP** algorithm decomposes the graph _G_ into 5 levels, whereas the above algorithm has only decomposed _G_ into 4 levels.

Indeed, only using rectangular matrix multiplication \(\omega_{BD}(1,y,1)\) for some \(y\in[0,1]\), we will not be able to obtain any improvement on **DenseAPASP**(_G,_4). For example, recall that the degree thresholds are _s_<sub>1</sub>=_n_<sup>4/5</sup>_,s_<sub>2</sub>=_n_<sup>3/5</sup>_,s_<sub>3</sub>=_n_<sup>2/5</sup>_,s_<sub>4</sub>=_n_<sup>1/5</sup>. In order to improve the overall running time, we must decrease _s_<sub>4</sub> so that the final iteration of computing **Dijkstra** on _E_<sub>5</sub> from all _D_<sub>5</sub>=_V_ does not require \(\tilde{O}(n^{11/5})\) time. If we wish to decrease _s_<sub>4</sub>, then the size of _D_<sub>4</sub> increases. To limit the overall time of running **Dijkstra** from _D_<sub>4</sub> on _E_<sub>4</sub>, we must therefore decrease _s_<sub>3</sub>. Following the same reasoning, we must decrease _s_<sub>2</sub> and _s_<sub>1</sub>. However, the combinatorial algorithm **DenseAPASP** also includes the edge set \(D_2\times D_4\) when executing **Dijkstra** from _D_<sub>5</sub>=_V_ . In particular, either _D_<sub>2</sub> or _D_<sub>4</sub> needs to reduce in size, which implies that at least one of _s_<sub>2</sub>_,s_<sub>4</sub> needs to increase, contradicting our previous conclusions.

We cannot hope to succeed simply by using fast (min,+) matrix multiplication to replace the first level _D_<sub>1</sub>. However, we use fast (min,+) matrix multiplication to replace the edge set \(D_2\times D_4\) and more generally \(D_{j_1}\times D_{j_2}\) for \(j+j_1+j_2\le 2k+1\). Consider +4 approximation as a basic example. Let _P_ be a shortest path between _u,v_. If \(P\subset E_3\), then we compute a +4 approximation as in **SparseAPASP**. Therefore, suppose \(P\subset E_j\) and \(P\unknown\subset E_{j+1}\) for some \(j\in\{1,2\}\). Let _y_ be the vertex closest to _v_ such that \(P_{u,y}\subset E_5\). Let _z_ be the vertex of maximum degree in _P_. Let _y_<sup>∗</sup>=_r(y,D_<sub>4</sub>) and \(z^*=r(z,D_{\ell(z)})\). In the combinatorial algorithm, since \(D_2\times D_4\subset G_{5,v}\), we find the path \((v,z^*,y^*,y)\circ P_{y,u}\) and compute a +4 approximation. Instead, we use a fast (min,+) product to find,<tbc>

\(\hat{\delta}(v,y^*)\le min_{w\in D_2}\hat{\delta}(v,w)+\hat{\delta}(w,y^*)\le\hat{\delta}(v,z^*)+\hat{\delta}(z^*,y^*)\le\hat{\delta}(v,y)+3\)
