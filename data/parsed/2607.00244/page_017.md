Then, for the bound on the radius-(2_r_-2) merge-width, the merge sequence is done similarly: first resolve all matchings and co-matchings inside gadget cells; then resolve the co-matchings and the matchings with the vertices between adjacent gadget cells; then add every remaining edge of \(G_\mathcal{S}^r\).

\(\triangleright\) Claim 19. \(\mathrm{mw}_{2r-2}(G_\mathcal{S}^r)=\mathcal{O}(r)\).

Using the same arguments as in Claim 17, it follows that for any functions _f(k_)=_o(k_) and _g(k_), solving _k_-Dominating Set on graphs with \(\mathrm{mw}_{f(k)}\le g(k)\) is W[1]-hard. \(\blacktriangleleft\)
