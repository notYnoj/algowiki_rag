A direct greedy set cover implementation is too slow. Across all sources, there are _n_ set cover instances, each with _n_-1 candidate sets and _n_-1 elements. Explicitly materializing all sets already takes \(\Omega(n^3)\) time and space in the worst case. \[12\] circumvents this cost by avoiding building these sets explicitly. However, it incurs the cost of repeatedly updating the set of uncovered targets. For a source _s_, these updates can take \(\widetilde{\Omega}(n\cdot\mathsf{OPT}_\alpha(s))\) time, and summing over all sources gives the \(\widetilde{\Omega}(n\cdot\mathsf{OPT}_\alpha)\)-type bottleneck of prior approaches without resource augmentation.

Our main idea is to separate the tasks of proposing a cover for a set of uncovered points and applying that cover to remove those points. Locally, for each source _s_, we use a voting procedure to choose a batch of promising outgoing edges. Globally, after many such edges have been added across many sources, we use fast matrix multiplication (VerifyNav) to recompute which source- target constraints remain uncovered. Thus, the expensive materialization step is not performed after each selected edge, but only after a whole batch of updates. We will show that, for each set cover instance, each batch of edges added covers a constant fraction of the remaining constraints, so only _O_(log_n_) such global updates are needed. This is similar to the approach taken by \[25\], which also sought to repeatedly cover a constant fraction of constraints, but the method we use to achieve this bears closer resemblance to an algorithm described in \[19\], which computes covers over subsamples of a larger set cover instance.

Recall that the VerifyNav procedure requires rounding distances into a small number of geometric buckets, after which it can no longer distinguish between distances within a bucket, up to a \((1+\varepsilon)\) multiplicative factor apart. It can, however, distinguish constraints that are definitely unsatisfied at parameter \(\alpha\) from constraints that are definitely satisfied at the stronger parameter \(\alpha(1+\varepsilon)\). This is why our sparsity bound is measured against the optimal \(\alpha(1+\varepsilon)\)-navigable graph: the residual instances we continue to solve may erroneously contain points falsely believed by VerifyNav to be unsatisfied at parameter \(\alpha\), and it may not be until the graph is \(\alpha(1+\varepsilon)\)-navigable before it correctly indicates that the graph is fully \(\alpha\)-navigable.

For clarity, we have the following local notation. For \(\beta\ge 1\) and source \(s\in P\), let

\(\mathsf{OPT}_\beta(s)=min\{|\mathcal{C}|:\mathcal{C}\subseteq P\backslash\{s\}\text{and}\forall t\in P\backslash\{s\},\exists v\in\mathcal{C}\text{such that}d(v,t)<d(s,t)/\beta\}\) (1)

Equivalently, \(\mathsf{OPT}_\beta(s)\) is the minimum out-degree needed at _s_ to satisfy all \(\beta\)-navigability constraints whose source is _s_. The theorem below gives a per-source guarantee, and therefore also implies the corresponding global edge bound of Theorem 1.2 by summing over all sources.

**Theorem 3.1.** _Let P be a set of n points with distance function d and aspect ratio_ \(\Delta\)_, and let_ \(\alpha\ge 1\)_. For any_ \(\varepsilon>0\)_, there is a randomized algorithm running in_ \(\widetilde{O}(n^\omega log(\Delta)/\varepsilon)\) _time that constructs an_ \(\alpha\)_-navigable graph over P such that, with high probability, every point_ \(s\in P\) _has out-degree_ \(\le O(logn)\cdot\mathsf{OPT}_{\alpha(1+\varepsilon)}(s)\).

## Voting as approximate greedy set cover

The procedure VoteCover, introduced in \[12\], can be viewed as a fast randomized simulation of the standard greedy set cover algorithm. The standard greedy algorithm achieves a log_n_ approximation, but naively applied, leads to _O(n_<sup>3</sup>) time to find a near-optimal \(\alpha\)-navigable graph. Given a source _s_ and a set \(U\subseteq P\backslash\{s\}\) of currently uncovered targets, VoteCover repeatedly samples uncovered targets from _U_. A sampled target _t_ casts a vote for every candidate edge (i.e., set) (_s,v_) that would cover it, namely every _v_ satisfying \(d(v,t)<d(s,t)/\alpha\).
