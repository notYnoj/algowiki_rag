## Putting it all together

The total expected heat released in layers 1 and 2 is \(O(n^{(1+\alpha)/2})\) while the total for layers \(\ell\ge 3\) are each \(O(n^{(1+\alpha)/2}\mathrm{log}(n))\), which gives a total of \(O(n^{(1+\alpha)/2}\mathrm{log}^2n)\) across all non-recursive layers. Fixing our choice of \(\alpha=1/2\) makes this expression _O(n_<sup>3/4</sup>log<sup>2</sup>_n_). Since layer 0 is two recursive calls on the halves of the input, we have that if _Q(n_) is the heat released for inputs of size _n_, then _Q(n_)=2_Q(n/_2)+_O(n_<sup>3/4</sup>log<sup>2</sup>_n_) for all \(n\ge 32\). When _n\<_32 we use _Q_<sup>unif</sup> for all gates and, since the number of gates in this circuit is constant, we also get a constant upper bound for the expected heat released in this base case. Since the last term in the recursive case is sub-linear, the master theorem gives us that _Q(n_) is _O(n_). We use heat function _Q_<sup>unif</sup> across all recursive calls and we use both \(Q_\varepsilon^{(0,1)}\) and \(Q_\varepsilon^{(1,0)}\) for at most 1 unique value of \(\varepsilon\) each per recursive call. Thus there are at most 2log(_n_)+1 unique heat functions used in this construction.

In Theorem B.1 of the appendix, we give a similar proof showing that in the overwriting circuit model (see Section 2), Batcher’s sorting network can still be implemented with only _O(n_) total expected heat released.

The bound in Theorem 5.2 is asymptotically tight. We can show that the circuit entropy production of sorting _n_ bits is also \(\Omega(n)\).

**Theorem 5.4.** _When given the uniform distribution over inputs in_ {0,1}_<sup>n</sup>, for any choice of valid heat functions for each gate in Batcher’s odd-even mergesort, the circuit entropy production is_ \(\Omega(n)\).

_Proof._ We show that each base case of sorting _n_=4 inputs has constant circuit entropy production. Since this base case occurs _n/_4 times in the overall sorting network and circuit entropy production is always non-negative, the entropy production of the entire circuit must be \(\Omega(n)\). We now analyze the _n_=4 sorting network, as shown in Figure 3, on the uniform distribution over inputs. The two gates in the first layer each receive inputs 00,01,10, and 11 with probability 1/4. By Lemma 3.1 this means that the expected heat release of each of these gates when given the optimal heat function is 1/2 and the expected heat released in the first layer is 1. After the first layer, the first and third wires independently have value 1 with probability 1/4 each while the second and fourth wires independently have value 0 with probability 1/4 each. Thus by Lemma 3.1 we get that the expected heat release of these gates when given the optimal heat function is 3/8 and and the expected heat release in the second layer is 3/4. The final gate is a bit more tricky to analyze. Looking at all 16 possible inputs to the circuit, this gate receives input 00 on all inputs to the circuit with 3 or more 0’s. Likewise the gate receives input 11 on all inputs to the circuit with 3 or more 1’s. The gate receives input 01 on inputs 0011 and inputs 1100 to the circuit while the gate receives input 10 on each of the four remaining inputs with 2 zeroes and 2 ones to the circuit. Thus by Lemma 3.1 the expected heat release of this gate is (3/8)H<sub>2</sub>(1/3). Putting all of this together, the expected heat release of a 4 input sorting networks is 7/4+(3/8)H<sub>2</sub>(1/3). Meanwhile the circuit maps a uniformly random length 4 bit-string to a binomial distribution on 4 unbiased coin flips. The entropy of this output equals

\((2\mathrm{log}(16)+8\mathrm{log}(4)+6\mathrm{log}(8/3))/16=(8+16+18+6\mathrm{log}(1/3))/16=21/8-(3/8)\mathrm{log}(3)\)

and so the drop in entropy is 4-(21/8-(3/8)log(3))=11/8+(3/8)log(3). Since the released heat is 7/4+(3/8)H<sub>2</sub>(1/3), the circuit entropy production of the 4 input Batcher’s sorting network with optimal heat function is at precisely 1/8. Since the general Batcher’s odd-even mergesort network features this sub-circuit on this input distribution _n/_4 times, the overall circuit entropy production of the network is at least _n/_32 which is \(\Omega(n)\).
