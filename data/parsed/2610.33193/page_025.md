## 4.2 Approximation

We first make a simple argument that if circuits are permitted to have wires where only a 0 bit can ever appear (i.e., such as the output of an unsatisfiable formula), then it is NP-hard even to approximate an optimal heat function. Fix a circuit C and let _g_ be an erasure gate acting on the first wire at the end of that circuit. Let D be the marginal induced input distribution for _g_ when C receives a uniform distribution over its inputs and _Q_<sup>∗</sup> be a valid heat function that minimizes the expected heat release on distribution D. If Pr<sub>D</sub>\[0\]=1 then we can safely set \(Q(0)=0,Q(1)=\infty\) and observe that E<sub>_x_∼D</sub>\[_Q(x_)\]=0. However, if there is any input to C that causes the first wire to evaluate to 1 before applying _g_, then this choice of _Q_ will cause \(\mathbb{E}_{x\sim\mathcal{D}}[Q(x)]=\infty\). Thus, for any \(c\ge 1\), this choice of _Q_ is the unique choice that satisfies \(\mathbb{E}_{x\sim\mathcal{D}}[Q(x)]\le c\mathbb{E}_{x\sim\mathcal{D}}[Q^*(x)]\) when Pr<sub>D</sub>\[0\]=1 and _Q_ can never satisfy this condition when Pr<sub>D</sub>\[1\]_\>_0. Therefore by fixing C to be the \(\mathcal{C}'\) in Lemma 4.3, finding any multiplicative approximation to the optimal heat function for the added erasure gate is at least as hard as solving Sat.

However, this is a somewhat degenerate case, in the sense that _any_ optimization problem permitting an optimal value of 0 has the property that no multiplicative approximation is good unless it is exact. The more interesting case is when a wire might have both bits 0 or 1 (supp(D)={0,1}), so that we have a positive optimal expected heat E<sub>_x_∼D</sub>\[_Q_<sup>∗</sup>(_x_)\]_\>_0. Using a bit of machinery, we can prove that NP-hardness of multiplicative approximation holds even in this case.
