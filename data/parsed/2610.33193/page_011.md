## Deriving optimal heat functions

In Section 3, Lemma 3.1 shows how to derive the optimal valid heat function for a known distribution over inputs. In particular if _p<sub>x</sub>_ is the probability of input _x_ and _q<sub>y</sub>_ is the probability of output _y_, then any optimal heat function for computing _f_ on this distribution over inputs must satisfy _Q(x_)=log(_q_<sub>_f(x_)</sub>_/p<sub>x</sub>_) on all _x_ where _p<sub>x</sub>\>_0. This in turn is a key ingredient in proving our results in Sections 4, 5, and 6.

## Hardness results and approximation algorithms for computing optimal heat functions

Section 4 is concerned with computing the optimal heat functions for gates in a given Boolean circuit (so as to minimize EP), assuming the i.i.d. uniform distribution for the circuit’s inputs. We first show that the problem of computing the optimal heat function for each gate (so as to minimize total entropy production of the entire circuit) is unfortunately PP-complete (Lemmas 4.3 and 4.4). Since Lemma 3.1 shows how to compute the optimal heat function for a _single_ gate and a given input distribution to that gate, this hardness follows essentially from the fact that computing the induced input distribution for a given gate in a circuit, knowing that the circuit’s inputs are i.i.d. with probability 1/2, is itself PP-complete. The (straightforward) reduction is from the PP-complete language L<sub>SAT/2</sub> of Boolean circuits C where at least half the assignments satisfy C: by adding a single erasure gate _g_ on the output, with an optimal heat function _Q<sub>g</sub>_, \(Q_g(1)\le 1\) if and only if \(Pr[\text{output of}\mathcal{C}\text{is}1]\ge 1/2\), i.e., if and only if \(\mathcal{C}\in\mathcal{L}_{\text{SAT}/2}\). Containment in PP directly follows from an algorithm that accepts or rejects depending on the relative probabilities a gate receives a specified input _x_ or another input \(x'\neq x\) where \(f(x')=f(x)\).

Since PP-hardness rules out polynomial-time exact algorithms, this motivates the question of whether polynomial-time approximation algorithms exist. We show that this depends crucially on the form of error. With _multiplicative_ error, i.e., for some constant _c\>_1, to compute heat functions with expected value at most _c times_ optimal, then this is NP-hard, i.e., untractable unless \(\text{NP}\subseteq\text{BPP}\). There is an easy argument for this: suppose we have a Boolean formula \(\phi\) (a special type of circuit) and want to know whether \(\phi\) is satisfiable. If we then add an erasure gate _g_ to \(\phi\)’s output, then for an optimal heat function \(Q_g^*\), if \(\phi\) is unsatisfiable, \(Q_g^*(0)=0\), i.e., it costs 0 heat to erase the output since we know it is 0. If \(\phi\) is satisfiable, then \(Q_g^*(0)>0\). Thus any approximation algorithm outputting heat value _q_ will tell us whether \(\phi\) is satisfiable depending on whether _q\>_0. However, this is a somewhat degenerate case, in the sense that _any_ optimization problem permitting an optimal value of 0 has the property that no multiplicative approximation is good unless it is exact. The more interesting case is when a wire might have both bits 0 or 1 (supp(D)={0,1}), so that we have a positive optimal expected heat E<sub>_x_∼D</sub>\[_Q_<sup>∗</sup>(_x_)\]_\>_0. We can in fact prove NP-hardness of multiplicative approximation continues to hold even in this case (Lemma 4.7).
