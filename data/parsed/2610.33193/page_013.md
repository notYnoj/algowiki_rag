This circuit has Q that is _O(n_log_n_) which is asymptotically optimal.<sup>15</sup> Our circuit works by first using an _O(n_log_n_) gate network developed by Leighton and Plaxton \[LP98\] that sorts all but a small fraction of the inputs. After running that circuit, we apply Batcher to its output. The result, as we show in Theorem 5.18, is a sorting network with _O(n_log<sup>2</sup>_n_) gates that only releases _O(n_log_n_) expected heat. By first using Leighton and Plaxton’s network, the input to Batcher’s will already be sorted most of the time. Thus we can use a heavily biased heat function for the gates in Batcher’s that releases less heat whenever the input is already sorted.

## Compaction and sorting with zero entropy production

Section 6.1 shows that we can do better than Batcher by designing a bit-sorting (a.k.a., _bit-compaction_) circuit specifically to minimize EP, and in fact can achieve zero circuit entropy production (Theorem 6.1) on any exchangeable distribution over inputs. Note that this construction is not a sorting network, as it uses ancilla wires and more general gates than only comparators.

We do so by using standard Bennett-style "compute/copy output/uncompute" (applied to circuits) to convert any circuit computing the mapping \(x\mapsto f(x)\) to one reversibly computing \((x,\vec{0})\mapsto(x,f(x))\),<sup>16</sup> with only a constant increase in gate and depth complexity.<sup>17</sup> Once we have (_x,f(x_)) in memory, we give a way to pick heat functions for erasing each bit of _x_ such that the expected heat released is exactly the drop in entropy from mapping _x_ to _f(x_). The choice of heat function for erasing each _x<sub>i</sub>_ is determined based on the value of _f(x_) and the suffix of _x_ after index _i_, which can be computed and uncomputed in a logically reversible fashion even after _x<sub>i</sub>_ has been erased. We design such a circuit based on any sorting network _C_ with _t(n_) gates and depth _d(n_) that compacts _n_ inputs with _m_ bit payloads using only constant arity gates with only _O(t(n)m+n_<sup>2</sup>) gates, _O(d(n_)log_m+n_log_n_) depth, and _O(t(n_)+_nm_) ancilla wires. In Section 6.2, we show how this approach can be extended to give zero circuit entropy production circuits for sorting on any exchangeable distribution over inputs.

## New proofs of known results on mismatch cost and circuit mutual information using heat functions

Following some basic lemmas in Appendix A of the appendix and the aforementioned analysis of Batcher’s sorting algorithm in Appendix B, we prove new results connecting heat functions to mismatch costs and reprove existing results on mismatch costs using the language of heat functions in Appendices C and D. This is intended to share these insights from stochastic thermodynamics with the computer science community and better connect our heat function model with prior work on the thermodynamics of circuits. Appendix C concerns _mismatch cost_, which is informally defined as the _extra_ entropy production incurred by using a gate with a heat function optimal for distribution D<sup>∗</sup>, when in fact \(\mathcal{D}\neq\mathcal{D}^*\) is the true distribution. The mismatch cost of course depends on the physical implementation of the gate. Wolpert and Kolchinsky \[WK20\] showed that the way this physics influences the extra entropy production is entirely contained in its optimal distribution D<sup>∗</sup>, in the sense that the mismatch cost is precisely the information-theoretic terms _D_<sub>KL</sub>(D||D<sup>∗</sup>)-_D_<sub>KL</sub>(_f_(D)||_f_(D<sup>∗</sup>)), where _D_<sub>KL</sub> refers to the Kullback-Leibler divergence, see Section 2. We show how this result admits a clean proof using heat functions.
