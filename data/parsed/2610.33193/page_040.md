Let _x_<sub>min</sub> and _x_<sub>max</sub> be the smaller and larger values respectively among _x_<sub>1</sub>_,x_<sub>2</sub>. We observe that shifting exactly \(2^{k_\ell}\) elements from _A_ to _B_ (or from _B_ to _A_) that are smaller than _x_<sub>min</sub> and moving \(2^{k_\ell}\) elements larger than _x_<sub>max</sub> back results in flipping the sets \(\mathcal{O}\cap[x_\mathrm{min},x_\mathrm{max}]\) and \(\mathcal{E}\cap[x_\mathrm{min},x_\mathrm{max}]\), which has the effect of swapping the order of the two inputs to _g_. Moreover for any _A_ and _B_ resulting in _g_ receiving input _x_<sub>1</sub>_,x_<sub>2</sub>, swapping any number of elements smaller than _x_<sub>min</sub> between _A_ and _B_ and doing likewise with elements larger than _x_<sub>max</sub> will maintain the fact that _g_ receives input _x_<sub>1</sub>_,x_<sub>2</sub>. Thus we want to compare the number of possible _A_ with _s_ elements smaller than _x_<sub>min</sub> and a fixed subset _I_ of {_x_<sub>min</sub>_,...,x_<sub>max</sub>} in _A_ with the number of possible \(A'\) with \(s\pm 2^{k_\ell}\) elements smaller than _x_<sub>min</sub> and the same fixed subset of _I_ in \(A'\). The remainder of the proof is a (somewhat cumbersome) argument that these values are within a factor of \(\alpha\) of one another.

We use \(\mathcal{A}_I^s\) to denote the set of all _A_ that have \(A\cap\{x_\mathrm{min},\dots,x_\mathrm{max}\}=I\) and exactly _s_ elements smaller than _x_<sub>min</sub> in _A_. The relative size of these sets for different values of _s_ are hyper-geometrically distributed; the ‘marked’ items are elements smaller than _x_<sub>min</sub> and we want to count how many of them end up in set _A_. Since the probability mass function of the hyper-geometric distribution starts off monotonically non-decreasing until hitting some mode _s_<sup>∗</sup> and then is monotonically non-increasing, we immediately have that when \(|s-s^*|>2^{k_\ell}\) it must be the case that \(|\mathcal{A}_I^s|\le\mathrm{max}(\left|\mathcal{A}_I^{s-2^{k_\ell}}\right|,\left|\mathcal{A}_I^{s+2^{k_\ell}}\right|)\) and we are done.

When \(|s-s^*|<2^{k_\ell}\) the analysis is more involved. We show that the ratio of the squared geometric mean of \(\left|\mathcal{A}_I^{s-2^{k_\ell}}\right|\) and \(\left|\mathcal{A}_I^{s+2^{k_\ell}}\right|\) to the value of \(|\mathcal{A}_I^s|^2\) is at least some constant, \(1/\alpha^2\), by expressing \(\left|\mathcal{A}_I^{s-2^{k_\ell}}\right|\left|\mathcal{A}_I^{s+2^{k_\ell}}\right|/\left|\mathcal{A}_I^s\right|^2\) as a telescoping product. With this lower bound in hand, we can use the arithmetic, geometric mean inequality to deduce that \(\left|\mathcal{A}_I^{s-2^{k_\ell}}\right|+\left|\mathcal{A}_I^{s+2^{k_\ell}}\right|\ge|\mathcal{A}_I^s|\left(2/\alpha\right)\). This in turn gives us that if _C(a,b_) is the number of choices for _A_ resulting in _g_ receiving input _a,b_ then we always have that \(1/\alpha\le\frac{C(x_2,x_1)}{C(x_1,x_2)}\le\alpha\) as desired.
