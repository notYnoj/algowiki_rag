Theorem 6.1 assumes the distribution on the input record list is _exchangeable_, which means that any permutation of the _n_ record positions gives the same distribution over inputs. This allows payloads to be arbitrarily correlated with their keys but prevents, for example, a bias towards keys that are almost already sorted or payloads that encode the initial indices of their record.

Our circuit is based on first computing the mapping \((b,V)\mapsto(b,s,W)\), where \(b\in\{0,1\}^n\) represents the unsorted 1-bit keys, \(V\in\{0,1\}^{n\times m}\) represents the associated _m_-bit payloads, \(s\in\{0,1\}^n\) is the sorted keys, and \(W\in\{0,1\}^{n\times m}\) is the sorted payload matrix. To make the computation clean, we then erase the bits _b_ with zero EP, which requires determining the probability _p_ that a bit _b<sub>i</sub>_ is 1 and then routing it to an erasure gate optimal for that probability. It turns out that there are \(\Omega(n^2)\) many such probabilities, which implies that this technique requires \(\Omega(n^2)\) erasure gates. It remains an open question whether one can erase _n_ bits, which in total have quadratically many possible distributions, using _o(n_<sup>2</sup>) gates, or to compute the desired mapping \((b,V)\mapsto(s,W)\) with zero circuit entropy production using a different technique to obtain _o(n_<sup>2</sup>) total gates. We note that for any register _r_, both copying \((r,\vec{0})\mapsto(r,r)\) and moving \((r,\vec{0})\mapsto(\vec{0},r)\) can be done reversibly.
