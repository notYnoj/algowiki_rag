However, considering _additive_ error in approximation, we show there is a polynomial-time randomized algorithm that outputs a heat function at most \(\varepsilon\) _plus_ optimal with probability of failure at most \(\delta\); the running time is polynomial in the input, \(1/\varepsilon\), and \(1/\delta\) (Lemma 4.8). The idea is simply to sample uniformly random inputs to the whole circuit C to empirically estimate a distribution on inputs to a gate _g_ in C, from which a heat function is computed via Lemma 3.1.

## Bounds on thermodynamic costs of fixed circuits

Having shown the difficulty in computing optimal heat functions for arbitrary given circuits, Section 5 then analyzes particular circuits and derives both lower bounds on EP and upper bounds on Q. Section 5.1 begins with a warm-up exercise analyzing the computation of the _n_-input AND function \(x_1\wedge x_2\wedge\dots\wedge x_n\) on uniformly distributed inputs in {0,1}_<sup>n</sup>_, using only input-preserving binary-AND gates of the form \(\wedge(x_1,x_2,z)=(x_1,x_2,x_1\wedge x_2)\) and erasure gates _E(x_)=0. We show the (possibly) counterintuitive result that the most natural implementation, a tree of AND gates of depth _O_(log_n_), along with appropriate erasure gates to enable the circuit to cleanly compute the 1-bit output \(x_1\wedge x_2\wedge\dots\wedge x_n\), has circuit entropy production \(\Omega(n)\), whereas the "serial" variant with depth \(\Theta(n)\), can be done with circuit entropy production that is only _O_(1).

Section 5.2 then analyzes the _O(n_log<sup>2</sup>_n_)-gate, _O_(log<sup>2</sup>_n_)-depth Batcher even-odd mergesort sorting network on Boolean inputs. When applied to Boolean values, sorting networks are circuits where every gate is a 2-input, 2-output _comparator_ gate: computing the identity on inputs 00,01,11, but on input 10, swapping the bits to output 01. The main results of this section, Theorems 5.2 and 5.4, show an _O(n_) upper bound on Q using only _O_(log_n_) distinct heat functions and a matching \(\Omega(n)\) lower bound on EP over a uniform distribution of inputs in {0,1}_<sup>n</sup>_ when using the optimal valid heat function on every gate. This bound is notable in that it is asymptotically smaller than the number \(\Theta(nlog^2n)\) of gates in the circuit, despite none of the gates performing logically reversible operations. The _O(n_) upper bound (Theorem 5.2) is proven by slicing the network into regions of gates that all either (1) contain a small number of gates or (2) have one input that is overwhelmingly likely. In contrast, the \(\Omega(n)\) lower bound (Theorem 5.4) follows directly from observing that the first 3 layers of the Batcher’s odd even mergesort network consist of _n/_4 independent copies of sorting networks on 4 bits each and that each of these networks has \(\Omega(1)\) entropy production. In Appendix B we prove a similar upper bound on the Q for sorting bits in a more restricted overwriting model of circuits considered in other works (i.e., \[YCW26, YYW26\]).

Section 5.2.2 analyzes the more interesting case of the Batcher network applied to _n_ distinct values drawn uniformly at random from an ordered set _D_. In this case, we are able to show that the entropy production must be \(\Omega(nlog^2n)\) which is tightly matched by a trivial _O(n_log<sup>2</sup>_n_) upper bound on Q given using any valid heat function where the expected released heat is _O_(1) on all inputs. This result is rather technical to prove, but the key ingredient is Lemma 5.11, which shows that for a constant fraction of the gates in the network, if that gate receives input (_x_<sub>1</sub>_,x_<sub>2</sub>) with probability _p_<sub>_x_<sub>1</sub>_,x_<sub>2</sub></sub> then whenever _p<sub>a,b</sub>\>_0 it must be the case that \(1/\alpha\le p_{b,a}/p_{a,b}\le\alpha\) for some universal constant \(\alpha\). Since such gates must release \(\Omega(1)\) expected heat each, we get an \(\Omega(nlog^2n)\) lower bound on Q. Since the drop in entropy associated with sorting is only _O(n_log_n_), we can conclude that EP is \(\Omega(nlog^2n)\) in Corollary 5.14.
