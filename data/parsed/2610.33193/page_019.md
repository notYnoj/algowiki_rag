In the context of physical systems evolving according to _f_, this is simply the lower bound on the expected heat release (or more generally entropy flow) out of a system where all logical configurations contain the same number of microstates as given by the second law of thermodynamics. The following definition essentially formalizes our notion of a heat function being compatible with the second law.

**Definition 2.21.** _Let g be a gate in circuit computing a function f with domain D. A heat function_ \(Q:D\rightarrow\mathbb{R}_{\ge 0}\cup\{\infty\}\) _is_ valid _for g if and only if, for every input distribution_ D _over D, we have that:_

\(\mathcal{L}_f(\mathcal{D})\le\mathbb{E}_{x\sim\mathcal{D}}[Q(x)].\)

Definition 2.21 "directly" captures what we mean by a valid heat function--no matter the distribution it obeys the Second Law--and as stated intuitively appears to require validation over all input distributions over _D_. The following equivalent formulation of Definition 2.21 shows that validity in fact is solely a property of the value _Q(x_) on _individual_ inputs _x_. This is the deterministic specialization of Turgut’s Theorem 1 (Eq. (1)) in the simplified setting where each logical state has the same internal entropy \[Tur09\]. Zhu \[Zhu24\] subsequently rederived the same stochastic realizability criterion from a differential fluctuation theorem; with deterministic dynamics, Zhu’s condition likewise reduces to Lemma 2.22. We give a self-contained proof of Lemma 2.22 in Appendix A.

**Lemma 2.22.** _Let g be a gate in a circuit computing a function_ \(f:D\rightarrow R\)_. A heat function_ \(Q:D\rightarrow\mathbb{R}_{\ge 0}\cup\{\infty\}\) _is valid for g if and only if, for every_ \(y\in R\),

\(\sum_{x\in f^{-1}(y)}2^{-Q(x)}\le 1.\)

In practice, there is a large gap between valid heat functions (those obeying the Second Law) and physically realizable heat functions (which may release far _more_ heat than the minimum dictated by the Second Law, e.g., current CMOS technology). Additional heat is released by computation to drive the physical processes that implement the logical mapping of the gate in the desired direction in finite time \[SFS18\]. However, valid heat functions let us prove lower bounds on the thermodynamic costs of a computation and provide a limit for the physical implementation of the computation. In this paper, we state upper bounds on thermodynamic costs that make the idealized assumption that any combination of logical gate _g_ and valid heat function _Q_ for _g_ could actually be constructed. The known laws of physics neither explicitly construct such gates nor rule out their existence (in the quasistatic limit). Thus our upper bounds all implicitly require the following "spherical cow" like assumption.

**Assumption 2.23** (Idealized realizability assumption)**.** _Let_ \(f:D\rightarrow R\) _be any function and_ \(Q:D\rightarrow\mathbb{R}_{\ge 0}\cup\{\infty\}\) _be any valid heat function for computing f. Then we assume that it is possible to fabricate a gate that computes f while releasing Q(x_) _expected heat on each input where_ \(Q(x)\neq\infty\) _in the quasistatic (i.e. infinitely slowly) limit. We assume that whenever_ \(Q(x)=\infty\) _the gate is implemented in a way where it physically cannot receive such an input. In other words, the gate actually computes a restriction of f on inputs where Q(x_) _is finite._<sup>22</sup><tbc>

<sup>22</sup>The fact that \(Q(x)=\infty\) already makes this domain restriction implicit in our model. Any distribution with support on such an input would immediately make Q infinite. Thus heat functions where \(Q(x)=\infty\) on any input occurring with positive probability trivially satisfy lower bounds and would automatically make any resulting upper bound trivial.
