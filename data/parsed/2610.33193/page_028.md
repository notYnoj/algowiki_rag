_Proof._ Let _f_ be the function computed by gate _g_, _D_ be the domain of _f_, and _d_=|_D_|. We pick _t_ inputs to C uniformly at random, evaluate C on these inputs, and count the number of times we see each input to _g_. Let \(C:D\rightarrow\mathbb{Z}_{\ge 0}\) be the obtained counts for each input \(x\in D\) to _g_. From these counts, we define some empirical distribution \(\widehat{\mathcal{D}}\) and let \(\widehat{Q}(x)=\mathrm{log}(\mathrm{Pr}_{f(\widehat{\mathcal{D}})}[f(x)]/\mathrm{Pr}_\widehat{\mathcal{D}}[x])\) be the optimal heat function (per Lemma 3.1) if \(\widehat{\mathcal{D}}\) were the actual input distribution to _g_. We use \(\widehat{Q}_C,\widehat{\mathcal{D}}_C\) to denote the choices of \(\widehat{\mathcal{D}}\) and \(\widehat{Q}\) respectively resulting from observing counts _C_. We use C to denote the distribution over the observed counts. This gives us that:

\(\mathbb{E}_{C\sim\mathscr{C}}[\mathbb{E}_{x\sim\mathcal{D}}[\widehat{Q}_C(x)-Q^*(x)]]\)<br>
\(=\mathbb{E}_{C\sim\mathscr{C}}\left[\mathbb{E}_{x\sim\mathcal{D}}\left[\mathrm{log}\left(\frac{\mathrm{Pr}_{f(\widehat{\mathcal{D}}_C)}[f(x)]}{\mathrm{Pr}_{\widehat{\mathcal{D}}_C}[x]}\right)-\mathrm{log}\left(\frac{\mathrm{Pr}_{f(\mathcal{D})}[f(x)]}{\mathrm{Pr}_\mathcal{D}[x]}\right)\right]\right]\text{definition of}\widehat{Q}_C\text{; Lemma 3.1 for}Q^*\)<br>
\(=\mathbb{E}_{C\sim\mathscr{C}}\left[\mathbb{E}_{x\sim\mathcal{D}}\left[\mathrm{log}\left(\frac{\mathrm{Pr}_\mathcal{D}[x]}{\mathrm{Pr}_{\widehat{\mathcal{D}}_C}[x]}\right)-\mathrm{log}\left(\frac{\mathrm{Pr}_{f(\mathcal{D})}[f(x)]}{\mathrm{Pr}_{f(\widehat{\mathcal{D}}_C)}[f(x)]}\right)\right]\right]\text{rearrange terms}\)<br>
\(=\mathbb{E}_{C\sim\mathscr{C}}\left[\mathbb{E}_{x\sim\mathcal{D}}\left[\mathrm{log}\left(\frac{\mathrm{Pr}_\mathcal{D}[x]}{\mathrm{Pr}_{\widehat{\mathcal{D}}_C}[x]}\right)\right]-\mathbb{E}_{y\sim f(\mathcal{D})}\left[\mathrm{log}\left(\frac{\mathrm{Pr}_{f(\mathcal{D})}[y]}{\mathrm{Pr}_{f(\widehat{\mathcal{D}}_C)}[y]}\right)\right]\right]\text{since}x\sim\mathcal{D}\Longrightarrow f(x)\sim f(\mathcal{D})\)<br>
\(=\mathbb{E}_{C\sim\mathscr{C}}\left[D_\mathrm{KL}(\mathcal{D}||\widehat{\mathcal{D}}_C)-D_\mathrm{KL}(f(\mathcal{D})||f(\widehat{\mathcal{D}}_C))\right]\text{definition of}D_\mathrm{KL}\)

This connection between excess heat dissipation and the drop in KL-divergence associated with computing _f_ on a device optimized for the wrong distribution over inputs is well known in the stochastic thermodynamics of computation literature.<sup>32</sup> Since KL-divergence is non-negative, \(E_{C\sim\mathscr{C}}\left[D_\mathrm{KL}(\mathcal{D}||\widehat{\mathcal{D}}_C)-D_\mathrm{KL}(f(\mathcal{D})||f(\widehat{\mathcal{D}}_C))\right]\le E_{C\sim\mathscr{C}}\left[D_\mathrm{KL}(\mathcal{D}||\widehat{\mathcal{D}}_C)\right]\) and the expected excess heat dissipation from using \(\widehat{\mathcal{D}}\) to pick our choice of \(\widehat{Q}\) is at most the expected KL-divergence between D and \(\widehat{\mathcal{D}}\). It is known that the add-one smoothing estimator is well suited to this task. For count vector _C_∼C, this estimator sets \(\mathrm{Pr}_{\widehat{\mathcal{D}}_C}[x]=(C(x)+1)/(t+d)\). Braess, Forster, Sauer and Simon \[BFSS02\] showed that for any true distribution D, this estimator after _t_ samples satisfies

\(\mathbb{E}_{C\sim\mathscr{C}}\left[D_\mathrm{KL}(\mathcal{D}||\widehat{\mathcal{D}}_C)\right]\le\mathrm{log}\left(1+\frac{d-1}{t+1}\right),\)

which is at most (_d_-1)log(_e)/(t_+1).

Thus by using this choice of \(\widehat{\mathcal{D}}\) and \(\widehat{Q}\) we can set the number of samples \(t=\lceil\mathrm{log}(e)d/(\varepsilon\delta)\rceil\) to get that \(\mathbb{E}_{C\sim\mathscr{C}}[\mathbb{E}_{x\sim\mathcal{D}}[\widehat{Q}_C(x)-Q^*(x)]]\le\varepsilon\delta\). By Markov’s inequality, this means that the probability over _C_∼C that \(\mathbb{E}_{x\sim\mathcal{D}}[\widehat{Q}_C(x)-Q^*(x)]\ge\varepsilon\) is at most \(\delta\). Since _g_ operates on a constant number of bits, _d_ is also a constant and this can be done in a polynomial number of steps.
