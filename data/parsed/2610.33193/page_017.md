## Thermodynamic circuits

We start by giving two working definitions of circuits that we use in this paper. We start with our model of circuits, which is heavily inspired by ‘serial reinitialized’ model introduced in \[WK20\].

This model of circuits should be familiar to readers acquainted with the quantum circuit model. For those unfamiliar with such models, recall that a standard model defines a Boolean circuit as a directed acyclic graph, where each edge represents a wire connecting exactly two gates (nodes). Instead, in our model, all information is stored in a fixed set of _n_ wires, and gates operate on a subset (typically of _O_(1)-size) of these wires to update their values. However, unlike quantum circuits, we do not require gates to be unitary. Instead, they can perform any arbitrary mapping on their associated wires. While we use the language of circuits with wires and gates, this formulation works equally well to describe straight line programs where wires correspond to registers and gates correspond to operations on these registers. While we define such circuits in abstract, as is common in complexity theory, it will often be interesting to restrict them to specific gate sets (thus each gate would operate on _O_(1) wires independently of the total number of wires). This rules out the possibility of implementing arbitrary functions with a single gate acting simultaneously on all wires of the circuit and lets us analyze the thermodynamic costs of computations with restricted gate sets.<sup>19</sup>

**Definition 2.15.** _A deterministic_ circuit C _on n inputs with T gates and_ \(W\ge n\) _wires is described as an ordered collection of T gates g<sub>t</sub>_=(_I<sub>g<sub>t</sub></sub>,f<sup>g<sub>t</sub></sup>_) _for_ \(t\in\{1,\dots,T\}\)_. Each gate specifies a set_ \(I_{g_t}\subseteq[W]\) _and a function_ \(f^{g_t}:\Sigma^{I_{g_t}}\rightarrow\Sigma^{I_{g_t}}\)_. On input_ \(x_1,\dots x_n\in\Sigma^n\) _the circuit starts in the state_ \(\mathcal{C}^0\in\Sigma^W\) _where_ \(\mathcal{C}_i^0=x_i\) _for_ \(i\in[n]\) _and_ \(\mathcal{C}_i^0=0\) _for_ \(i\in[W]\backslash[n]\)_. The_ state _of the circuit at step t is given by_ \(\mathcal{C}^t=f_\uparrow^{g_t}(\mathcal{C}^{t-1})\)_. We say that wire_ \(i\in[W]\) _of_ C evaluates to \(x\in\Sigma\) _when_ \(\mathcal{C}_i^T=x\).

Note that Definition 2.15 allows to have more wires (_W_) than input bits (_n_), to allow extra "workspace" for computation. It requires all non-input wires to be initially 0. The next definition captures our notion of computing output, which similarly allows the number of output bits _m_ to be strictly less than the number of wires _W_, and similarly requires that at the end of the computation, all non-output wires are 0.<sup>20</sup>

**Definition 2.16.** _We say that a circuit_ C cleanly computes _a function_ \(f:\Sigma^n\rightarrow\Sigma^m\) _if on every input_ \(x\in\Sigma^n\)_, wire i of_ C _evaluates to f<sub>i</sub>(x_) _if_ \(i\le m\) _and evaluates to_ 0 _if i\>m._<sup>21</sup>

In this paper, restricting gates to operate on _O_(1) wires will enable stronger lower bounds on entropy production, in an analogous sense that restricting standard Boolean circuits to have _O_(1)-size gates enables nontrivial lower bounds on gate complexity. <sup>20</sup>This requirement of zeroing out non-output wires is particularly important in the context of thermodynamics of computing, because it forces on the circuit the obligation to erase any non-output bits left over from the computation. Absent this requirement, a circuit could appear naïvely to produce less entropy than one would expect, hiding the cost of erasing those leftover "garbage" bits. The definition of clean computation forces the circuit to prepare itself for reuse.
