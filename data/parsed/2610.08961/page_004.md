Helgason \[19\], McDiarmid \[34\], and Lovasz \[31\] have shown that for any polymatroid on set _N_ given by function _f_ there exists a matroid _M_=(_E,_I) with rank function _r_ with the following properties: Every element \(h\in N\) is associated with an independent set \(M_h\subseteq E\), all the _M<sub>h</sub>_ are pairwise disjoint, and for all \(X\subseteq N\) we have \(f(X)=r(\cup_{h\in X}M_h)\). This exact set of conditions occurs in \[38\] at subsection 44.6b. Although we use this underlying structure of polymatroids for our analysis, at no point is it necessary to run the algorithm.

## 3 The analysis of the two-for-one swap heuristic

We first set up the matroid in which we will apply Theorem 2.1; this is taken from \[29\] with slightly changed (clarified) notation (for this set up, we had another method based on Theorem 2.1 before we discovered \[29\]).

Let \(A\subseteq N\) be our current solution and \(B\subseteq N\) be an optimum solution. Assume no feasible addition or two-for-one swap is possible, from this we will prove that \(|A|\ge(2/(k+1))|B|\). If \(A=\emptyset\), the absence of a feasible addition implies \(B=\emptyset\); assume henceforth that \(A\neq\emptyset\). Let _M_ be the matroid with the rank function _r_ associated to the polymatroid on _N_ defined by _f_() as explained at the end of the previous section. Let \(\overline{A}=\cup_{h\in A}M_h\) and \(\overline{B}=\cup_{h\in B}M_h\). We remove from _M_ all elements outside of \(\overline{A}\cup\overline{B}\) as we will not use them for our analysis. We have \(r(\overline{A})=f(A)=\sum_{h\in A}f(h)=\sum_{h\in A}r(M_h)=\sum_{h\in A}|M_h|=|\overline{A}|\), where the first equality is from the definition of _M_, the second equality is from the fact that _A_ is independent in the polymatroid, the third equality is again from the properties of _M_, the fourth equality is from the fact that each _M<sub>h</sub>_ is independent in _M_ (as seen in the properties of _M_), and the last equality from the fact that the sets _M<sub>h</sub>_ are pairwise disjoint (as seen in the properties of _M_). We conclude that <o>_A_</o> is independent in _M_. The same reasoning is applied to obtain that <o>_B_</o> is independent in _M_.

Since <o>_A_</o> is independent in _M_, we have a maximal independent set \(\bar{I}\) in _M_ that contains <o>_A_</o>. Define \(\overline{B^{^\prime}}=\bar{I}\backslash\overline{A}\); as the ground set of _M_ is \(\overline{A}\cup\overline{B}\), we have that \(\overline{B^{^\prime}}\subseteq\overline{B}\). From here our analysis diverges from \[29\]. Contract \(\overline{B^{^\prime}}\) in _M_ to obtain matroid \(M'\). Let \(\overline{B^{^{\prime\prime}}}:=\overline{B}\backslash\overline{B^{^\prime}}\). As \(\overline{B^{^\prime}}\) is independent in _M_, by the definition of contraction, the independence of set <o>_A_</o> in \(M'\) corresponds to the independence of \(\overline{A}\cup\overline{B^{^\prime}}\) in _M_. Also, the independence of \(\overline{B^{^{\prime\prime}}}\) in \(M'\) corresponds to the independence of \(\overline{B^{^{\prime\prime}}}\cup\overline{B^{^\prime}}=\overline{B}\) in _M_. As \(\overline{A}\cup\overline{B^{^\prime}}\) is a basis in _M_, <o>_A_</o> is a basis in \(M'\), and similarly <o>_B_</o> being independent in _M_ implies that \(\overline{B^{^{\prime\prime}}}\) is an independent set in \(M'\). As such \(\overline{B^{^{\prime\prime}}}\subseteq\overline{C}\) for some basis <o>_C_</o> in \(M'\). See Figure 1 for an illustration.

Let _a_=|_A_|. With _A_={_h_<sub>1</sub>_,h_<sub>2</sub>_,...,h<sub>a</sub>_}, we have that _M_<sub>_h_<sub>1</sub></sub>_,M_<sub>_h_<sub>2</sub></sub>_,...,M<sub>h<sub>a</sub></sub>_ is a partition of <o>_A_</o>. Use Theorem 2.1 to obtain a partition _Y_<sub>1</sub>_,Y_<sub>2</sub>_,...,Y<sub>a</sub>_ of <o>_C_</o> such that, for all \(i\in\{1,2,\dots,a\}\), we have that \(\overline{A}\backslash M_{h_i}\cup Y_i\) is a basis in \(M'\). As all bases have the same size, \(|Y_i|\ge|M_{h_i}|\) for every _i_. Since \(\sum_i|Y_i|=|\overline{C}|=|\overline{A}|=\sum_i|M_{h_i}|\), equality holds for every _i_; consequently, \(Y_i\cap(\overline{A}\backslash M_{h_i})=\emptyset\). Construct a bipartite graph _G_ with parts _A_ and _B_, with an exception: for each element in both _A_ and _B_, duplicate it and put it in both parts of _G_. In _G_, we put an edge between \(h_i\in A\) and \(e_j\in B\) if \(M_{e_j}\cap Y_i\neq\emptyset\). See Figure 2 for an illustration. Call a vertex of degree 1 in _G_ a singleton.
