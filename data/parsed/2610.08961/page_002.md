Matroids are versatile mathematical structures that generalize numerous combinatorial models, including matching \[28, 29\], online computation \[3, 2\], diversity maximization \[1\] and variants of clustering problems \[8, 25, 26, 40\].

A _k_-polymatroid satisfies that \(f(e)\le k\) for all \(e\in N\). We call \(S\subseteq N\) _independent_ if \(f(S)=\sum_{e\in S}f(e)\) and _f(e)\>_0 for all \(e\in S\). Such a set was also called a _matching_ by \[33\]. The MAXIMUM INDEPENDENT SET IN A _k_-POLYMATROID (or MISkP) asks for finding a maximum-size independent set in a _k_-polymatroid. Finding maximum-size sets in downward- closed set systems is one of the most fundamental combinatorial optimization problems \[10, 38\].

MISkP was also studied under the name of Matroid _k_-Parity. MIS2P has been proposed by Lawler \[28\] and polynomial-time algorithms are known for linearly represented polymatroids \[36, 32, 9, 15\]. There are 2-polymatroids for which MIS2P is NP-hard \[38\], and Jensen and Korte \[24\] have shown that there exists no algorithm in which the matroid is represented by an independence test oracle (or an oracle polynomially related to an independence test oracle) and which solves the problem in question after a number of calls on the oracle which is bounded by a polynomial in the number of elements of the ground set of the matroid.

Lee, Sviridenko, and Vondrák \[29\] give a polynomial-time approximation scheme for MIS2P using the local search method: start with a feasible current solution, and as long as we obtain a feasible solution, swap a subset of up to _j_ elements of the current solution by a set containing one more element. The algorithm stops when no such swap is possible. Precisely, to get a \((1-\epsilon)\)- approximation, they use a _j_ that is exponential in \(1/\epsilon\). For MISkP with \(k\ge 3\), \[29\] obtain a \(((2/k)-\epsilon)\)-approximation for this swapping heuristic with \(j=\lceil(1/\epsilon)^{log_{k-1}(2k+1)}\rceil\) (\[29\] only discusses the case where _f(e_)=_k_ for all \(e\in N\), the _k_-uniform case, but after deleting elements with _f(e_)=0, one can set \(f'(X)=f(X)+\sum_{e\in X}(k-f(e))\), so that \(f'(e)=k\) for all remaining _e_ and a set is independent with respect to _f_ if and only if it is independent with respect to \(f'\)). Note that \(log_{k-1}(2k+1)\le 3\) and for large _k_, it is close to 1. It is also known that a ratio better than \(\Omega(logk/k)\) is not possible unless _P=NP_ \[18\].

In this paper, we study this local-swap heuristic with _j_=1 and obtain a tight approximation ratio of 2/(_k_+1). This is weaker than the bound of \[29\], and MISkP is most useful when _k_ is small (i.e. MIS3P may help with Maximum Planar Subgraph \[6\] and related problems where MIS2P is used for the best known approximation). We have a simple proof for our (weaker) result which may open the way for proving a \(((2/k)-\epsilon)\)-approximation with swapping fewer elements, because for fixed \(k\ge 3\), \(j=O(log(1/\epsilon))\) suffices for the much simpler case of finding a maximum matching in a _k_-hypergraph \[21\]. Also, one can further try to apply the method of Cygan \[11\] with the goal of a \(((3/(k+1))-\epsilon)\)-approximation. Our method is based on exchange properties of Greene and Magnanti \[17\] (with special cases in \[16, 5\], also Exercise 8.48 in \[10\]) and a particular (base) case of the analysis of Hurkens and Schrijver \[21\].

As explained in \[29\], MISkP can approximately solve a number of other problems such as finding the maximum-size set that is independent in _k_ given matroids on the same ground set, which we call the _k_-Matroid Intersection Problem. 2-Matroid Intersection is a classical combinatorial optimization problem that admits polynomial-time algorithms \[13, 38\].
