<tbc>correctness is already accounting for such errors. \[BLL<sup>+</sup>21\] have proven that defining the entire algorithm using some element-wise approximation \(\overline{x},\overline{s},\overline{\tau}\) still guarantees convergence, where this was exploited to develop data structures that maintain/compute only \(\overline{x},\overline{s},\overline{\tau}\) rather than exact \(x,s,\tau\).
