Our algorithm is based on solving linear programs in the streaming model. Other work using this approach (though not for flows, but instead for other linear programs such as bipartite matching) include \[LSZ<sup>+</sup>23, AG11, AKZ19, CC05\]. From the communication perspective, linear programs have been studied in \[VWW20, GLP<sup>+</sup>24\]. The crucial aspect is that previous work studies linear programs of form \(minc^\top\) subject to \(\mathbf{A}^\top x=b,x\ge 0\) for tall matrices **A**, but max-flow requires additional capacity constraints \(x\le u\). Encoding those within the matrix **A** turns the matrix from tall into an almost square matrix, thus losing any space/communication gains from the small width of **A**.

## 2 Preliminaries

We write "with high probability" (w.h.p.) if the failure probability is at most 1/poly(_n_). We use \(\chi_e\) to denote the _e_-th standard unit vector. For an integer _n_, we use \[_n_\] to denote the set \(\{1,2,\cdots,n\}\). We use \(\widetilde{O}(\cdot)\) to hide poly(log_m_) factors. In addition to \(O(\cdot)\) notation, for two functions _f,g_, we use the shorthand \(f\lesssim g\) (resp. \(\unknown\)) to indicate that \(f\le C\cdot g\) (resp. \(\ge\)) for an absolute constant _C_. For a vector \(v\in\mathbb{R}^m\), we use \(\|v\|_\infty\) to denote its \(\ell_\infty\) norm, i.e., \(\|v\|_\infty:max_{i\in[m]}|v_i|\). We use \(\|v\|_p\) to denote its \(\ell_p\) norm, i.e., \(\|v\|_p:=(\sum_{i=1}^m|v_i|^p)^{1/p}\). For a positive semi-definite matrix **M** we write \(\|v\|_\mathbf{M}:=(v^\top\mathbf{M}v)^{1/2}\). For vectors \(x,s,\tau\in\mathbb{R}^m\) we write **X**,**S**,**T** for the diagonal matrices with \(\mathbf{X}_{i,i}=x_i,\mathbf{S}_{i,i}=s_i,\mathbf{T}_{i,i}=\tau_i\) on the diagonals for \(i\in[m]\). Similarly, for function \(\phi:\mathbb{R}\rightarrow\mathbb{R}\), we write \(\Phi(x)\) for the diagonal matrix with \(\Phi(x)_{i,i}=\phi(x_i)\) on the diagonals for \(i\in[m]\). Given vectors \(a,b\in\mathbb{R}^m\), we use _ab_ to denote entry-wise products, i.e., (_ab)<sub>i</sub>=a<sub>i</sub>b<sub>i</sub>_. We define \(cosh(x):=\frac{1}{2}(exp(x)+exp(-x))\). We define \(sinh(x):=\frac{1}{2}(exp(x)-exp(-x))\). Note that \(cosh(x)'=sinh(x)\) and \(sinh(x)'=cosh(x)\).

The _leverage scores_ \(\sigma(\mathbf{A})\in\mathbb{R}_{>0}^m\) of a matrix \(\mathbf{A}\in\mathbb{R}^{m\times n}(m\ge n)\) are defined as \(\sigma(\mathbf{A})_i:=(\mathbf{A}(\mathbf{A}^\top\mathbf{A})^{-1}\mathbf{A}^\top)_{i,i}\) for \(i\in[m]\).

For \(a,b\in\mathbb{R}\) and \(\epsilon>0\) we write \(a\approx_\epsilon b\) when \(exp(-\epsilon)a\le b\le exp(\epsilon)a\). We extend the notation to vectors when the approximation holds entry-wise. For PSD matrices \(\mathbf{A},\mathbf{B}\in\mathbb{R}^{n\times n}\) we write \(\mathbf{A}\approx_\epsilon\mathbf{B}\) when for all vectors \(v\in\mathbb{R}^nv^\top\mathbf{A}v\approx_\epsilon v^\top\mathbf{B}v\), i.e., **A**,**B** are spectral approximations of each other.

We say a vector \(v\in\mathbb{R}^E\) is given in implicit representation with space _O(S_) and query time _O(T_), if we have a data structure that uses _O(S_) space and supports queries that receive as input edge, edge-cost, and edge-capacity (_e,c<sub>e</sub>,u<sub>e</sub>_) and then return _v<sub>e</sub>_ in _O(T_) time.

The line of work \[AG09, KL11, AGM12, KPPS17, KLM<sup>+</sup>17, KMM<sup>+</sup>20, KNST19, CKST19, LSZ<sup>+</sup>23\] developed streaming algorithms for spectral sparsifiers.

**Lemma 2.1** (\[KPPS17, Theorem 1.1\])**.** _Let_ \(\mathbf{A}\in\mathbb{R}^{E\times V}\) _be an incidence matrix,_ \(w\in\mathbb{R}^E\) _be some weights where any w<sub>e</sub> can be queried in time T<sub>w</sub>, and let_ \(\epsilon>0\)_. Then within a single pass over the rows of_ **A** _(i.e., edges), we can compute an_ \(\widetilde{O}(n/\epsilon^2)\)_-sized spectral sparsifier_ \(\mathbf{H}\approx_\epsilon\mathbf{A}^\top\mathbf{A}\)_. This takes_ \(\widetilde{O}(mT_w)\) _total time._

This lemma was proven for weighted incidence matrices in \[KPPS17\] where _w<sub>e</sub>_ is given together with edge _e_ in the stream. It directly implies the above, by instead querying _w<sub>e</sub>_ when edge _e_ is read from the stream.

## 3 Technique Overview

In particular, we show that the algorithm of \[BLL<sup>+</sup>21\] can be implemented in \(\widetilde{O}(n^{1.5})\) space.
