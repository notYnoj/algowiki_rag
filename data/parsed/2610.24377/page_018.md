<tbc>bilinear algorithm, and hence an #NC(Q) circuit of multiplicative depth 1. Applying this bilinear algorithm recursively, and then unrolling the recursion, gives an #NC(Q) circuit of multiplicative depth 1 and size \(n^{\omega+o(1)}\) for \(n\times n\) matrix multiplication.

In order to use a ring we can actually store in registers, we let _d_ be the least common multiple of all the denominators used in that bilinear algorithm, and consider working in \(\mathbb{Z}/m'\mathbb{Z}\), where \(m'=dnm^2+1\) -- here, we know \(d^{-1}\equiv-nm^2\), so we can easily replace the constants over Q with constants over \(\mathbb{Z}/m'\mathbb{Z}\). This gives a fast catalytic algorithm for matrix multiplication over \(\mathbb{Z}/m'\mathbb{Z}\); in order to multiply over Z_/m_Z, we first take the representative of each number in \[_m_\], think of those as elements of \(\mathbb{Z}/m'\mathbb{Z}\), and do the multiplication there. All of the entries of the product lie in \[1_,nm_<sup>2</sup>\], so the results mod_m_ are uniquely determined by the results mod \(m'\). So, this algorithm adds the desired output values into dirty registers mod \(m'\). In Appendix A, we observe that it is possible to generically convert such an algorithm into one which bitwise-XORs the desired output values mod _m_ into the dirty space.

We can then apply this to get fast catalytic versions of algorithms involving matrix multiplication. For instance, using a reduction due to Itai and Rodeh \[IR77\],

**Corollary 1.7** (Triangle counting)**.** Let _G_ be an _n_-vertex simple undirected graph, given as an adjacency matrix. There exists a catalytic algorithm which, using \(n^{\omega+o(1)}\) time, \(n^{\omega+o(1)}\) catalytic space, and _O_(log_n_) clean space, counts the number of triangles in _G_.

_Proof._ Consider an arithmetic circuit which cubes the adjacency matrix and then takes the trace. Since matrix multiplication can be done in multiplicative depth 1 and size \(n^{\omega+o(1)}\), and trace can be done in multiplicative depth 0 and size _O(n_), overall this circuit has multiplicative depth 2 and size \(n^{\omega+o(1)}\). We can therefore catalytically compute the result applying the construction of Corollary 4.11 to get the result over Z/(_n_<sup>3</sup>+1)Z. The result will be 6 times the number of triangles in the graph; since the value is _O_(log(_n_)) bits, we can compute it directly into the clean space and then divide by 6 at the end.

By a classic reduction due to Nešetřil and Poljak \[NP85\], this similarly allows us to count 3_k_-cliques in time \(n^{k\omega+o(1)}\) for constant _k_. Their reduction is local (i.e. given read-access to the graph _G_, we can find the ith bit of the input graph \(G'\) to the triangle counting algorithm in logarithmic space and polylogarithmic time), which allows us to apply Corollary 1.7 directly.<sup>15</sup> Given a counting algorithm, we can also _find_ a 3_k_-clique catalytically, using a space-efficient version of a standard search-to-decision reduction (\[VW18\]). This gives:

**Corollary 4.12** (Clique Counting)**.** Let _G_ be an _n_-vertex simple undirected graph, given as an adjacency matrix. Let _k_ be a constant positive integer. There exists a catalytic algorithm which, using \(n^{k\omega+o(1)}\) time, \(n^{k\omega+o(1)}\) dirty space, and _O_(log_n_) clean space, counts the number of 3_k_-cliques in _G_ (and outputs a clique if one exists).

Using the color-coding approach of \[AYZ94\], we can detect _k_ paths (and _k_ cycles) in directed graphs in matrix multiplication time with an exponential dependency on _k_. We first solve an auxiliary problem. Given a set of _t_ colors _C_ such that each node in the graph is labeled with such a color, a (_t_-1)-length path _p_ is said to be _C_**-colorful** if each color in _C_ appears exactly once in _p_.

**Lemma 4.13** (Colorful Paths)**.** Let _G_=(_V,E_) be an _n_-vertex simple directed graph given as an adjacency matrix. Let \(C\subseteq[n]\) be a set of _t_ colors. Suppose the colors of each vertex of _G_ are provided as input. There exists a catalytic algorithm which detects if a _C_-colorful path exists in _G_ in \(n^{\omega+o(1)}2^{O(t)}\) time, \((tlogn)\cdot n^{\omega+o(1)}\) dirty space, and _O(t_log_t_+log_n_) clean space.

<sup>15</sup>A technical detail is that, to ensure efficient locality, we must use a slightly modified reduction which produces a _n<sup>k</sup>_-node graph: each _k_-tuple of values in \[_n_\] is a node, and an edge (_u,v_) exists if both _u_ and _v_ are in strictly increasing order and form a 2_k_ clique. The number of triangles equals \(c=(3k)!/(k!^3\cdot 3!)\) times the number of cliques in _G_. We can simply compute the clique count into our clean space first and then divide by _c_.
