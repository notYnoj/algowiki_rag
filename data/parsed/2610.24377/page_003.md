**Catalytic computation as a means of speeding up low-space algorithms.** For all its successes in complexity theory, so far catalytic computing has not caught on as a major topic of study for the rest of core theoretical computer science. One major reason is that almost all positive results in catalytic computing have been solely focused on minimizing space, while disregarding _running time_. For most TCS researchers, runtime is the gold standard of algorithm performance; space usage is important as a secondary optimization target, but an enormous runtime precludes usefulness. Most known catalytic algorithms are of limited interest from this perspective, as they involve \[BCKLS14\]’s TC<sup>1</sup> simulation, which has a prohibitively large runtime overhead. (For instance, using standard reductions, the resulting CL algorithm for directed _st_-connectivity -- the canonical NL-complete problem -- would have a runtime of \(\widetilde{\Theta}\left(n^8\right)\).)

There has been some recent effort to correct this: Cook and Pyne initiated this direction by giving \(\widetilde{O}\left(n^3m\right)\)- time and \(\widetilde{O}\left(nm\right)\)-time deterministic and randomized CL algorithms, respectively, for directed _st_ connectivity \[CP26\]. Subsequent works have shown that most of the space usage in some existing time-space tradeoff upper bounds can be made catalytic \[CDKMR26\].

In this paper, we give strong additional evidence that dirty space can be useful for designing fast algorithms. We implement several essential tools in modern algorithm design (most centrally, sorting, fast matrix multiplication, and fast Fourier transform) catalytically with little loss in runtime, using only _O_(log_n_) clean space. Near-linear time sorting and Fourier transforms are known to be _unconditionally impossible_ using only \(n^{1-\Omega\left(1\right)}\) workspace in total, so our results demonstrate that dirty space can yield strictly faster algorithms than would be otherwise possible (similar results are known for matrix multiplication) \[BC80; Bea91; Yes84; Abr91\]. (Our algorithm’s output is provided by XORing into a chunk of dirty space, as opposed to the separate-output-tape model under which those lower bounds are usually stated. However, we also show that catalytic algorithms have a strict _unconditional speedup_ in output models where the lower bounds apply.)

## 1.1 Our Results

**Fast catalytic algorithms.** We begin by showing that threshold circuit evaluation, from which (under derandomization assumptions) most known containments in CL follow, can itself be done substantially faster: a single-bit-output circuit of size _w_ and depth _d_ can be evaluated in catalytic logspace in time \(\widetilde{O}\left(w2^d\right)\).<sup>1</sup> (The algorithm of \[BCKLS14\] has runtime \(\widetilde{\Theta}(wf4^d)\), where _f_ is the circuit’s maximum fan-in.) Our algorithm is substantially simpler than that of \[BCKLS14\], relying on a single combinatorial trick as opposed to their algebraic approach.

This approach can also be applied to circuits with _multi-bit_ outputs. When the output is too large to store in the machine’s clean space, we say a catalytic algorithm "computes" a function _g_ if, instead of terminating with the dirty space restored, it terminates with _g(x_) bitwise-XORed into an initial segment of the dirty space. (Note that the dirty space could then be restored by running the algorithm a second time. This output model is particularly natural for designing and composing catalytic algorithms, and hence is our default. See the end of this section, and Section 2, for discussion of alternative models that instead use a separate output tape, which is necessary for comparing to non-catalytic algorithms.) Our circuit evaluation result in this model is as follows:

**Theorem 1.1.** There exists a catalytic algorithm using _O_(log(_w_)+_d_) clean workspace and \(\widetilde{O}\left(w2^d\right)\) time, which takes in a _d_-layer, _w_-wire circuit of symmetric gates, and an input to the circuit, and computes the circuit’s output.

We then show several consequences of fast circuit evaluation:

**Corollary 1.2.** Any problem with size-_S(n_) (uniform) NC<sup>1</sup> circuits has a time-_S(n_)<sup>1+_o_(1)</sup> catalytic algorithm using _O_(log(_n_)) clean space.

<sup>1</sup>As is standard, we use \(\widetilde{O}(T(n))\) as shorthand for \(T(n)\cdot poly(logT(n))\).
