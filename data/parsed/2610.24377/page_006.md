## 1.3 Proof Intuition

We give here an overview of the proofs of the above results. The main ideas are quite simple, although there are some technical details that one needs to be careful about.

### Evaluating low-depth SYM circuits.

The algorithm given in \[BCKLS14\] for evaluating low-depth threshold circuits involved treating the dirty space as a sequence of "register" values over a finite field. They show that, given an algorithm _A_ which results in a pair of values \(a,b\in\mathbb{F}\) being added into two "registers" of the dirty space, one can use two calls to _A_ to get an algorithm which adds their product _ab_ into another register, while not storing anything except a global timestep counter in-between calls. They give similar constructions for powering, and then use Fermat’s little theorem to show that, given an algorithm _A_ which adds a vector of values \(v\in\mathbb{F}^m\) to a sequence of registers, they can make four calls to _A_ and spend \(\widetilde{O}\left(wf\right)\) additional time in order to add the output of any single layer of threshold gates (with _w_ wires and maximum fan-in _f_) over _v_ to another sequence of registers. Recursing this algorithm then lets them evaluate low-degree circuits of threshold gates.

We use a similar recursive approach, but replace the algebraic methods with a single combinatorial trick, similar to one suggested by Cook \[Coo21\]. Our approach works for circuits of arbitrary symmetric gates (i.e., gates whose output only depends on the number of 1s among input wires), including threshold gates. The underlying idea is as follows. Suppose you can toggle between seeing the value \(\tau\) and the value \(\tau+x\), for some \(\tau,x\in\mathbb{F}_m\). Given a large "helper" array _H_ of dirty values, if you add 1 to \(H[\tau+x-i]\) for every \(i\in S\subseteq\mathbb{F}_m\), then this will increment the value of \(H[\tau]\) if and only if \(x\in S\). Using this fact, we can go from an algorithm adding a vector of bits, to an algorithm adding a _w_-wire layer of symmetric gates over those bits, using only two calls and \(\widetilde{O}\left(w\right)\) time overhead. Recursing this gives an evaluation algorithm running in time \(\widetilde{O}\left(w2^d\right)\) for circuits of depth _d_.

We then observe that this algorithm is near-linear time for circuits of depth _o_(log(_n_)), so obtaining fast catalytic algorithms reduces to designing small, _o_(log(_n_))-depth (uniform) circuits of symmetric gates. In order to get such circuits, we take bounded fan-in circuit models (NC circuits, sorting networks) of depth _O_(log(_n_)), and observe that we can collapse groups of a super-constant number of layers together into constant-depth SYM circuits at only a sub-polynomial blowup in size. This lets us directly convert known results in these models into fast catalytic algorithms.

### Evaluating low-degree arithmetic circuits.

The algebraic approach of \[BCKLS14\] allows evaluating arithmetic circuits, with work which they note grows exponentially with the number of layers of the circuit. But, actually, the work needs only to grow exponentially in the number of layers of the circuit _which involve non-linear product gates_: layers of the circuit which only compute linear functions (i.e. scalar product gates) needn’t contribute. The fast Fourier transform can be written as a small circuit of only linear gates, and any fast matrix multiplication algorithm can (without loss of generality) be written as a small circuit with a single layer of binary products and all other layers linear. So, these algorithms can be simulated with minimal runtime overhead catalytically.

### Time-space tradeoff lower bounds.

The above algorithms are stated in a model where, instead of having a separate output tape, the catalytic algorithm is simply required to XOR the output into an initial portion of its catalytic tape. We observe that any algorithm in this model can be directly simulated in the 2-output- pass model: in the first pass, output an initial portion of the catalytic tape; then, run the original algorithm until it gets to that specified intermediate point, and output the catalytic tape again in the second pass. We therefore get fast algorithms for sorting, DFT, and matrix multiplication in this model.

On the other hand, we observe that any non-catalytic _k_-output-pass algorithm can be converted into a 1- output-pass algorithm using only an _O(k_)-factor increase in space and an \(\widetilde{O}\left(1\right)\)-factor increase in time, by holding _k_ different machine states in memory and simulating all _k_ passes in parallel. So, the lower bounds proven in the transducer (1-output-pass) model directly apply to the 2-output-pass model as well, giving a separation between catalytic and non-catalytic algorithms.
