_Proof._ We first detail the recursive algorithm of \[AYZ94\]. The goal will be to recursively compute a matrix _D_ such that _D<sub>ij</sub>\>_0 if there exists a _C_-colorful path starting at _i_ and ending at _j_ in _G_, and _D<sub>ij</sub>_=0 otherwise. (The final answer is simply the sum over all _D<sub>ij</sub>_.) Fix a partition \(C=C_1\sqcup C_2\), and let _V_<sub>_C_<sub>1</sub></sub> and _V_<sub>_C_<sub>2</sub></sub> be the vertices in _G_ with those respective colors. Recursively compute matrix _A_<sub>_C_<sub>1</sub></sub> which encodes the above colorful path pair relation for vertices in _V_<sub>1</sub> and color set _C_<sub>1</sub>. Similarly, compute matrix _A_<sub>_C_<sub>2</sub></sub> for _V_<sub>2</sub> with colors _C_<sub>2</sub>. Define (_B_<sub>_C_<sub>1</sub>_,C_<sub>2</sub></sub>)_<sub>ij</sub>_ to be 1 iff \(i\in V_1,j\in V_2\) and \((i,j)\in E\) (and 0 otherwise), and compute \(A_{C_1}\cdot B_{C_1,C_2}\cdot A_{C_2}\). (Each entry of matrix _B_ can be computed in _O_(log_n_) clean space and polylog_n_ time using the adjacency matrix.) Accumulating a sum of this quantity over all partitions _C_<sub>1</sub> and _C_<sub>2</sub> of _C_ of sizes \(\lceil t/2\rceil\) and \(\lfloor t/2\rfloor\) respectively in a fixed ordering yields the desired matrix _D_. There are at most \(\genfrac(){pt}{2}{t}{\lceil t/2\rceil}\le 2^t\) such partitions. (As a base case, when |_C_|=1, return the identity matrix.) All matrices remain of dimension _n_ throughout.

To encode this as a low multiplicative depth circuit, first observe that the recursion depth is log_t+O_(1). We can make all the calls at some depth to appear in parallel within the circuit. Each section within a level (provided color set \(C'\)) consists of getting _D_ by computing \(A_{C_1^\prime}\cdot B_{C_1^\prime,C_2^\prime}\cdot A_{C_2^\prime}\) (given \(A_{C_1^\prime},A_{C_2^\prime}\) from the level below) using fast matrix multiplication and then summing over all \(C'=C'_1\sqcup C'_2\) partitions. This will have multiplicative depth _O_(log_t_) and size \(2^{O(t)}\cdot n^{\omega+o(1)}\).

We now resolve some details. Let \(s'_i=(t/2^i+1)\). At the _i_th level (0th is initial call), we have 2<sup>_s<sub>i</sub>_</sup> such sections, for \(s_i=\sum_{j=0}^{i-1}s'_j\). Each section at level _i_ invokes \(2^{s_i^\prime}\) new recursive instances. (We round up so the number of calls is always this power of two. WLOG, let the rest of the calls just return the zero matrix.) In order to figure out which color set \(C'\) is the input to a given section within a level, we can first figure out an (at most) log_t_-length tuple where the _i_th entry indicates the index in \([2^{s_i^\prime}]\) of which recursive path we took in each layer. Using this tuple find the appropriate color set by simulating which color partitions were recursively chosen. This incurs a multiplicative factor of 2<sup>_O(t_)</sup> and only _O(t_log_t_) additional clean space is needed. By applying the construction of Corollary 4.11 and using Theorem 4.3 over an appropriate modular ring we obtain a \(n^{\omega+o(1)}2^{O(t)}\) time catalytic algorithm using _O(t_log_t_+log_n_). Choosing a \(\Theta(t\mathrm{log}n)\)-bit modular ring is sufficient to avoid overflow, so the dirty space usage is \((t\mathrm{log}n)\cdot n^{\omega+o(1)}\).

Now, following the approach of \[AYZ94\], we can detect _k_-paths given a colorful path detector using perfect hashing:

**Corollary 4.14** (Detecting Paths)**.** Let _G_ be an _n_-vertex simple directed graph given as an adjacency matrix. Let _k\>_2 be a positive integer. There exists a catalytic algorithm deciding if a _k_-length simple path in _G_ exists in \(2^{O(k)}\cdot n^{\omega+o(1)}\) time, \((k\mathrm{log}n)\cdot n^{\omega+o(1)}\) dirty space, and _O(k_log_k_+log_n_) clean space.

_Proof._ Use the (_k_+1)-perfect hash family from \[_n_\] to \[_k_+1\] of Lemma 2.5, and iterate over all 2<sup>_O(k_)</sup>poly(log_n_) hash functions using _O(k_+log_n_) space. For each hash function _h_, let a node _j_ be colored with \(h(j)\in C=[k+1]\). This induces a coloring on the vertices, which is computable given any vertex in polylog(_n_) time and _O_(log_n_) clean space. For any simple length-_k_ path \(p=(p_1,\cdots,p_{k+1})\) in _G_, there will be a hash function in the family such that _p_ is _C_-colorful, using the (_k_+1)-perfect property (Definition 2.4). Therefore, we can simply take the `OR` of the outputs of the algorithm from Lemma 4.13.

By proceeding almost exactly as the _k_-length path approach above, modifying it slightly, we can obtain an algorithm detecting _k_-length _cycles_. The idea is that if the possible start and end vertices of colorful paths of length exactly (_k_-1) are appropriately encoded in the final matrix (before summing all entries) of Lemma 4.13, we can then filter for paths whose end vertex has an edge directed towards the start vertex via an additional matrix multiplication -- this forms a _k_-cycle. Iterating over hashes in perfect families exactly as in Corollary 4.14 yields:

**Corollary 4.15** (Detecting Cycles)**.** Let _G_ be an _n_-vertex simple directed graph, and let _k\>_2 given as an adjacency matrix _A_. There exists a catalytic algorithm deciding if a _k_-length simple cycle in _G_ exists in \(2^{O(k)}\cdot n^{\omega+o(1)}\) time, \((k\mathrm{log}n+k)\cdot n^{\omega+o(1)}\) dirty space, and _O(k_log_k_+log_n_) clean space.
