## 5.1 A lossless graph "compression"

The algorithm in \[5\] has a preprocessing step that removes the vertices for which we can be certain on their inclusion in any putative MWCs. This reduces the graph size in which we need to find the MWCs, and the process of recovering the MWCs of the original graph is extremely simple: for each MWC of the reduced graph, simply take the set union of the MWC and the vertices we had established must be in any MWC of the original graph. Note that this process is 1-to-1 between the MWCs of the original and reduced graphs - we are simply adding the same vertices to every MWC of the reduced graph. Therefore, for our quantum QUBO/QAOA based approaches where we hope to extract all via MWCs via exploiting the use of shots, this does not cause a reduction in the number of shots required to solve the problem (for a fixed accuracy), which is one of the major resource costs. That is not to say the reduction is useless: simply by reducing the graph size, this reduces the size of the resulting QAOA circuit and hence will be cheaper, more accurate, and faster. Therefore, we looked towards reductions that could also reduce the number of MWCs within the new reduced graph, but for which we can still easily recover the full set of the MWCs for the original graph.

Here, let us work in the complement graph as it is much sparser and the native object the QAOA approach considers. Further, recall that the Maximum Weighted Clique enumeration problem becomes the Maximum Weighted Independent Set enumeration problem in the complement graph. Crucially, the solutions for the two problems are exactly the same.

Suppose we wish to find all MWISs within a graph _G_. Call the set of MWISs _C_. The idea of these reductions is to produce a graph \(G'\) such that its set of MWISs, \(C'\), is easier to compute, and given \(C'\), we can easily recover _C_. Let \(\omega_G(v)\) be the weight of a vertex _v_ in the graph _G_.

In the most simple case, we can remove all vertices of degree 1. Let _v_ be a vertex of degree 1 that is connected to the vertex _w_ on _G_. We know that any MWIS that contains _w_ cannot contain _v_ by definition, but crucially, also that any MWIS that doesn’t contain _w_ will always contain _v_ as _v_’s only conflict is with _w_, and including _v_ will increase the weight. Therefore, all cliques from the graph must contain exactly one of _v,w_, and _v_’s inclusion in an MWIS is fully determined simply by whether _w_ is in it. This is also true of the weight of _v_’s inclusion in the weight of the putative MWIS. So by considering _v_ as being included in the MWIS _unless w_ is in the MWIS, we can consider the action of adding a vertex \(w'\) (which has the same connectivity as _w_ in _G_, with the exception of the edge to _v_) to an independent set in \(G'\) as adding _w_ and removing _v_ to an independent set in _G_. Therefore, we would want \(\omega_{G^\prime}(w')=\omega_G(w)-\omega_G(v)\), and the maximum weight having an additive constant of \(\omega_G(v)\), which we can store separately.

This reduces the number of vertices and number of edges both by 1. But now let us consider the new vertex \(w'\). It has a weight of \(\omega_G(w)-\omega_G(v)\), which is no longer guaranteed to be positive. Indeed, if the weight is negative, it is never in any MWIS and so can be excluded from the graph (and so _v_ is always in all MWIS of _G_). If the weight is 0, then whether \(w'\) is included in a potential IS does not change its weight, and so its inclusion is determined purely by whether its conflicts are in the MWIS.
