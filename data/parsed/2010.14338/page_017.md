Moreover, for each of the _n_ variable gadgets _GX<sub>i</sub>_, we have a demand (_S,x<sub>i</sub>_), a demand (_x<sub>i</sub>,d<sub>i</sub>_), and two demands \((x_i^+,d_i)\) and \((x_i^-,d_i)\). Together, these account for all non-_SC_ demands.

We start with the easier direction of the reduction, showing that a satisfiable assignment of \(\phi\) gives rise to a MinGMConn solution of size \(\alpha\).

**Lemma 15.** _If_ \(\phi\) _is satisfiable, then there exist solutions to_ \((P_\phi,D_\phi)\) _of size_ \(\alpha\).

_Proof._ Consider the family of (partial) solutions \(Q_\phi\) constructed as follows: For each of the \(\alpha-n\) non-_SC_ and non-_XD_ demands \(d\in D_\overline{SC}\backslash\{(x_i,d_i)|i\in[n]\}\), add the top-left corner of demand _d_ to \(Q_\phi\), ensuring that _d_ is trivially satisfied. For the _nXD_ demands (_x<sub>i</sub>,d<sub>i</sub>_) however, we add _either_ the top-left corner of the demand \((x_i,x_i^+)\) _or_ of the demand \((x_i,x_i^-)\) to \(Q_\phi\). Note that in both cases, since \(x_i^+\) and \(x_i^-\) each have already established a trivial connection to _d<sub>i</sub>_, we get a M-path from _x<sub>i</sub>_ to _d<sub>i</sub>_, satisfying the _XD_ demand (_x<sub>i</sub>,d<sub>i</sub>_).

Any (partial) solution \(Q_\phi\) constructed in this way has size \(\alpha\) (it contains one new point for each non-_SC_ demand), satisfies all non-_SC_ demands, and may or may not satisfy some _SC_ demands. Moreover, there is a natural one-to-one mapping between such partial solutions and variable assignments for \(\phi\) (set _X<sub>i</sub>_=1 if and only if (_x<sub>i</sub>,d<sub>i</sub>_) is satisfied via \(x_i^+\)). Now consider which _SC_ demands are satisfied by such a solution/variable assignment \(Q_\phi\). Note that \(Q_\phi\) yields a M-path from \(x_i^+\) to _c<sub>j</sub> if and only if C<sub>j</sub>_ contains the positive literal _X<sub>i</sub>_ (the M-path can then use the corresponding positive variable-clause path). Similarly, \(Q_\phi\) produces a M-path from \(x_i^-\) to _c<sub>j</sub> if and only if C<sub>j</sub>_ contains the negative literal \(\neg X_i\). On the other hand, \(Q_\phi\) yields a M-path from _S_ to \(x_i^+\) _if and only if_ the variable assignment \(Q_\phi\) sets _X<sub>i</sub>_=1 and a M-path from _S_ to \(x_i^-\) otherwise. Together, we get a M-path from _S_ to _c<sub>j</sub>_ if and only if _C<sub>j</sub>_ is satisfied via _X<sub>i</sub>_ in the variable assignment \(Q_\phi\). As a consequence, the solution \(Q_\phi\) satisfies exactly those _SC_ demands (_S,c<sub>j</sub>_) for which _C<sub>j</sub>_ is satisfied by the variable assignment \(Q_\phi\). In summary, \(Q_\phi\) is a boolean solution (as defined in Section 3).

Now, if \(\phi\) is satisfiable, fix a solution \(Q_\phi\) that corresponds to a satisfying variable assignment. From the above it follows that \(Q_\phi\) has size \(\alpha\) and satisfies all demands in \(D_\phi\).

The remainder of this section proves the remaining direction, namely that any solution of size \(\alpha\) implies that \(\phi\) is satisfiable (Lemma 18). As this turns out to be more involved, we require some preparation. First, we provide a simple result about the structure of "triangular" instances. Afterwards, we describe a partitioning of \((P_\phi,D_\phi)\) and \(Q_\phi\) into suitable subinstances/-solutions (some of which are triangular). This allows us to argue separately about the structure of these subinstances (triangular instances and the variable-clause paths), which will help us to get the desired result.

### Triangular Instances.

A _triangular instance_ \((P_\Delta,D_\Delta)\) of size \(n\in\mathbb{N}\) consists of _n_+1 input points \(P_\Delta=\{p_0,p_1,\dots,p_n\}\) and of _n_ demands \(D_\Delta=\{(p_0,p_i)|i\in[n]\}\). The points _p_<sub>1</sub>_,p_<sub>2</sub>_,...,p<sub>n</sub>_ form a descending diagonal and lie to the top-right of _p_<sub>0</sub>. We refer to the point set \(G_\Delta:=\{(x,y)|\exists i,j\in[n]_0:x=x(p_i),y=y(p_j)\}\cap R(D_\Delta)\) as the _(triangular) grid_ of \((P_\Delta,D_\Delta)\).

Optimal solutions for triangular instances have size _n_, since there are solutions of that size (e.g., the _n_ grid points above _p_<sub>0</sub>) and the _n_ demands from \(D_\Delta\) are monotone and vertically separable (implying a lower bound of _n_ by Lemma 6). The next proposition states that any optimal solution to a triangular instance lies on the instance’s triangular grid.

**Proposition 16.** _Consider a triangular instance_ \((P_\Delta,D_\Delta)\) _of size_ \(n\in\mathbb{N}\)_. If_ \(Q_\Delta\) _has size n and satisfies_ \(D_\Delta\)_, then_ \(Q_\Delta\) _is a subset of the instance’s grid_ \(G_\Delta\).
