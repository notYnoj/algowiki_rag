**3.1. Proof Overview**

We consider T (see page 5 for the definition) on vertex set with coordinate representatives \([-\frac{n-1}{2},\frac{n-1}{2}]\) in each part, and in this way view the edge (0,0,0,0) as being at the _centre_ of the graph T . (When _n_ is even, we shall consider T(_n_) on vertex set with coordinate representatives \([-\frac{n}{2}+1,\frac{n}{2}]\). For the most part this is not important, and one can focus on the case when _n_ is odd, however we need to have an understanding of T(_n_) when _n_ is even for Chapter 7.) A key element of our strategy is to ensure that the leave _L_<sup>∗</sup> remaining at the end of the iterative matching process is contained entirely on coordinates which are ‘close’ to the centre of T (i.e. only on vertices whose coordinates have small moduli, where here by small \(\le n^{10-5}\) will be sufficient). We start the process by reserving a small (here meaning _o(n_) but \(\gg|L^*|\)) set of vertices _A_<sup>∗</sup>, our _absorber_, such that T\[_A_<sup>∗</sup>\] contains a perfect matching and, for every set _L_<sup>∗</sup> that might remain as the leave after the iterative matching process, \(\mathcal{T}[A^*\cup L^*]\) contains a perfect matching. We build the absorber following ideas from the method of Randomised Algebraic Construction. Details of this process and which such leave _L_<sup>∗</sup> can be absorbed by _A_<sup>∗</sup> are given in Chapter 4. We then run a random greedy edge removal process on T<sup>-_A_<sup>∗</sup></sup>:=T\[_V_(T)\\_A_<sup>∗</sup>\]. This process is analysed via the differential equations method and we follow very closely the strategy of Bennett and Bohman \[**6**\]. We are unable to use their result directly as a black box, since when we terminate the process we shall require concentration around expected values for certain properties in the remaining graph additional to those considered in \[**6**\]. We describe the details of this random greedy edge removal process in Chapter 5, and the simplicity of the algorithm allows for a straight forward counting argument which will count distinct matchings in T<sup>-_A_<sup>∗</sup></sup>. Furthermore, we shall stop the random greedy edge removal process on a graph \(H_\mathrm{gr}\subseteq\mathcal{T}\) when some _O(n_<sup>1-10<sup>-25</sup></sup>) vertices remain from T<sup>-_A_<sup>∗</sup></sup>, and show that with high probability \(H_\mathrm{gr}^{+A^*}:=\mathcal{T}[V(H_\mathrm{gr})\cup A^*]\) has a perfect matching, i.e. in almost all cases the matching found via the random greedy edge removal process extends to a perfect matching for T . (Our count will ensure that each matching counted in the random greedy edge removal process extends in such a way that for each matching \(M_i^G\) counted in the process, and the perfect matching \(M_i^{A^*}\) found in \(H_\mathrm{gr}^{+A^*}\), we have that \(\{M_i^G\cup M_i^{A^*}\}_i\) is a collection of distinct perfect matchings in T .) Now, in order to show that \(H_\mathrm{gr}^{+A^*}\) contains a perfect matching, it suffices to show that _H_gr contains a matching leaving only some small collection of vertices _L_<sup>∗</sup> which are close to the centre of T uncovered, which then, by construction, can be absorbed by _A_<sup>∗</sup>.
