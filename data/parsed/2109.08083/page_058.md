<tbc>To prove Lemma 4.12 using the information about the sub-lattice \(\mathcal{L}_1^{X+Y}(\mathcal{T})\) derived in Section 3.2, we first need to prove that we can add a sublinear number of edges to \(\Phi\) in a way that ensures \(\mathbf{v}\in\mathcal{L}_1^{X+Y}(\mathcal{T})\). An important point to note for this proof is that we shall consider the representatives {0_,...,n_-1} for the vertices in each part of T (as opposed to \(\{\frac{n-1}{2},\dots,0,\dots\frac{n-1}{2}\}\) as used for proving the main result).

Proposition 4.13. _Suppose that_ \(\mathbf{v}\in\mathcal{L}(\mathcal{T})\)_, such that_ |**v**|=:_t. Then, adding only O(t_) _edges to_ \(\Phi\)_, we can modify_ **v** _so that_ |**v**|=_O(t_) _and_ \(\mathbf{v}\in\mathcal{L}_1^{X+Y}(\mathcal{T})\).

Proof. By the zero-summing process discussed in the proof of Proposition 4.2, (though in this case there are no parity requirements), we know that by adding _O(t_) edges to \(\Phi\) we can obtain \(\mathbf{v}\in\mathcal{L}_2^{X+Y,X-Y}(\mathcal{T})\). Furthermore, by applying Proposition 3.9 (for _V_<sup>_X-Y_</sup> rather than _V_<sup>_X+Y_</sup>) to **v**<sup>**X**-**Y**</sup>, the vector taking only the support in _V_<sup>_X-Y_</sup>, we can write **v**<sup>**X**-**Y**</sup> as the sum of _O(t_) _SQ_-gens. For each of these we can efficiently generate a vector with weight added to the same coordinates in _V_<sup>_X-Y_</sup>, and then also to some coordinates in _V_<sup>_X+Y_</sup>. Thus, subtracting these vectors for each _SQ_-gen, we reduce **v**<sup>**X**-**Y**</sup> to **0**, and add at most _O(t_) weight to _V_<sup>_X+Y_</sup>, and no weight to \(V^X\cup V^Y\). □

Combining Proposition 4.13 with the next lemma is enough to prove Lemma 4.12.

Lemma 4.14. _Suppose_ \(\mathbf{v}\in\mathcal{L}_1^{X+Y}(\mathcal{T})\) _satisfies_ \(|\mathbf{v}|<O(n^{1-\alpha_1})\)_. Then, adding only_ \(O(n^{1-\alpha_2})\) _edges to_ \(\Phi\) _for some_ \(0<\alpha_2<\alpha_1\)_, we can reduce_ **v** _to_ **0**.

Proof of Lemma 4.12. Starting with \(\Phi=\emptyset\), for each vertex \(s\in S\) add an edge to \(\Phi\) through _s_. Let \(\mathbf{v}:=\partial\Phi-S\). Then \(\mathbf{v}\in\mathcal{L}(\mathcal{T})\), \(|\mathbf{v}|=O(n^{1-\alpha})\) and \(|\Phi|=O(n^{1-\alpha})\). By Proposition 4.13, we can add \(O(n^{1-\alpha})\) edges to \(\Phi\) in such a way that \(\mathbf{v}\in\mathcal{L}_1^{X+Y}(\mathcal{T})\), and \(|\mathbf{v}|=O(n^{1-\alpha})\). Thus, by Lemma 4.14, adding \(O(n^{1-\beta})\) edges to \(\Phi\) for some \(0<\beta<\alpha\) we can reduce **v** to **0**. Clearly \(\Phi\in\mathbb{Z}^{E(\mathcal{T})}\) and satisfies \(\partial\Phi-S=\mathbf{0}\), and \(|\Phi|=O(n^{1-\alpha})+O(n^{1-\beta})=O(n^{1-\beta})\), for some \(\beta>0\). □
