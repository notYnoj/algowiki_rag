<tbc>Definition 3.22 (edge types and _i_-legal zero-sum configurations). We say that an edge _e_ is of type \((\alpha,\beta,\gamma)_i\) if _e_ contains \(\alpha\) vertices in _K<sub>i</sub>_\\_K_<sub>_i_+1</sub>, \(\beta\) vertices in _J<sub>i</sub>_\\_K<sub>i</sub>_ and \(\gamma\) vertices in _I_<sub>_t_<sub>1</sub></sub>\\_J<sub>i</sub>_. We refer to the \(\alpha\) vertices as _i-small_ vertices, \(\beta\) vertices as _i-medium_ vertices, and \(\gamma\) vertices as _i-large_ vertices, or _small_, _medium_ and _large_ when _i_ is clear from the context. We say that an edge _e_ is _i-bad_ if _e_ is of type \((\alpha,\beta,\gamma)_i\) with \(\alpha\neq 0\) and \(\gamma\neq 0\), and that an edge _e_ is _bad_ if there exists \(i\in[c_g]\) such that _e_ is _i_-bad. We define an _i-legal zero-sum configuration_ to be a zero-sum configuration such that _M_<sup>+</sup> consists of an _i_-bad edge _e_, and three other edges which are all of types (1,0,3)_<sub>i</sub>_ and (0,1,3)_<sub>i</sub>_, and _M_<sup>-</sup> consists of one edge of type \((\alpha,\beta,0)_i\), with \(\alpha\neq 0\), and three edges of types (0,1,3)_<sub>i</sub>_ and (0,0,4)_<sub>i</sub>_. We denote the collection of all _i_-legal zero-sum configurations in T by Z<sub>_i,_T</sub>.

Now for an edge _e_ that is in an _i_-legal zero-sum configuration either as \(e\in M^+\) or \(e\in M^-\) for any \(i\in[c_g]\), we need to know how many _i_-legal zero-sum configurations that edge is in as an edge in _M_<sup>+</sup> and as an edge in _M_<sup>-</sup>. We let

\(\mathcal{Z}_{i,e,G}^\pm(\alpha,\beta,\gamma)\)

denote the family of _i_-legal zero-sum configurations in the graph \(G\subseteq\mathcal{T}\) , which contain the edge _e_ in \(M^\pm\), which is an edge of type \((\alpha,\beta,\gamma)_i\). We consider \(\mathcal{Z}_{i,e,\mathcal{T}}^\pm(\alpha,\beta,\gamma)\) for all \(i\in[c_g]\) and every edge and possible edge type \((\alpha,\beta,\gamma)_i\).

Note first that, by construction, \(\mathcal{Z}_{i,e,\mathcal{T}}^\pm(\alpha,\beta,\gamma)=\emptyset\) for all but the following:<tbc>

\(\mathcal{Z}_{i,e,\mathcal{T}}^+(1,0,3),\mathcal{Z}_{i,e,\mathcal{T}}^+(1,1,2),\mathcal{Z}_{i,e,\mathcal{T}}^+(1,2,1),\mathcal{Z}_{i,e,\mathcal{T}}^+(0,1,3),\)

<tbc>and

\(\mathcal{Z}_{i,e,\mathcal{T}}^-(4,0,0),\mathcal{Z}_{i,e,\mathcal{T}}^-(3,1,0),\mathcal{Z}_{i,e,\mathcal{T}}^-(2,2,0),\)<br>
\(\mathcal{Z}_{i,e,\mathcal{T}}^-(1,3,0),\mathcal{Z}_{i,e,\mathcal{T}}^-(0,1,3),\mathcal{Z}_{i,e,\mathcal{T}}^-(0,0,4).\)

In particular, recalling that no wrap-around edges appear in the positive or negative matching of an _i_-legal zero-sum configuration for any \(i\in[c_g]\) since all vertices are in _I_<sub>_t_<sub>1</sub></sub> and T\[_I_<sub>_t_<sub>1</sub></sub>\] contains no wrap-around edges, we cannot have edges of type \((\alpha,\beta,\gamma)_i\) with \(\alpha\ge 2\) and \(\gamma\neq 0\), for any \(i\in[c_g]\). That is, _i_-bad edges can only be those of types (1,0,3)_<sub>i</sub>_, (1,1,2)_<sub>i</sub>_ and (1,2,1)_<sub>i</sub>_ for every \(i\in[c_g]\), with most _i_-bad edges being of type (1,0,3)_<sub>i</sub>_. Thus it should be clear that all those \((\alpha,\beta,\gamma)\) not listed explicitly above satisfy \(\mathcal{Z}_{i,e,\mathcal{T}}^\pm(\alpha,\beta,\gamma)=\emptyset\), since an _i_-legal zero-sum configuration is a zero-sum configuration with positive matching _M_<sup>+</sup> consisting of an _i_-bad edge _e_, and three other edges which are all of types (1,0,3)_<sub>i</sub>_ and (0,1,3)_<sub>i</sub>_, and negative matching _M_<sup>-</sup> comprising of one edge of type \((\alpha,\beta,0)_i\), with \(\alpha\neq 0\), and three edges of types (0,1,3)_<sub>i</sub>_ and (0,0,4)_<sub>i</sub>_. That gives, for example, that an edge _e_ of type (0,4,0)_<sub>i</sub>_ cannot appear as a positive or negative matching edge in an _i_-legal zero-sum configuration. Thus the number of _i_-legal zero-sum configuration containing _e_ in \(M^\pm\) is exactly 0. Note also that type (0,1,3)_<sub>i</sub>_ edges appear in a negative matching if and only if there are edges of type (1,2,1)_<sub>i</sub>_ or (1,1,2)_<sub>i</sub>_ in the positive matching of a configuration. As well as the types of edge and types of zero- sum configuration to which they belong listed above, we shall also be interested in the number of zero-sum configurations containing at least two bad edges (all with positive sign). We leave the motivation for this to Section 6.2, but introduce the relevant notation here.
