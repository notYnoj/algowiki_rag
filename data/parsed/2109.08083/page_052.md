Since \(A'\subseteq I'_{n^{2.7\times 10^{-5}}}\), certainly there are at most \(O(n^{5.4\times 10^{-5}})\) edges for which we need to build a cascade.

Recalling the definition of a cascade in Section 4.2.1, given _e_=(_e_<sub>1</sub>_,e_<sub>2</sub>_,e_<sub>3</sub>_,e_<sub>4</sub>), we have two free choices to define a zero-sum configuration \(Z'\) covering _e_. We shall wish to make these choices so that any vertices used are in \(A\backslash\bigcup T'\), and not yet used in the collection of cascades, C, which have been created in this process. For each pair (_S<sub>i</sub>,T<sub>i</sub>_) a cascade contains a zero-sum configuration, _Z<sub>i</sub>_, such that all vertices in _Z<sub>i</sub>_ apart from those in (_S<sub>i</sub>,T<sub>i</sub>_) have not previously been used in the process. For each \(i\in[4]\) there is one degree of freedom to choose _Z<sub>i</sub>_ for (_S<sub>i</sub>,T<sub>i</sub>_). So in total we have six free choices we can make to build our cascade \(C_{e_T}=(Z',Z_1,Z_2,Z_3,Z_4)\) for _e_. Each of these choices must dictate edges only on vertices in \(A\subseteq I'_{n^{10-4}}\). In particular, this means that the number of choices for each degree of freedom is at most _n<sub>c</sub>_:=2_n_<sup>10<sup>-4</sup></sup>. Furthermore, for each of these free choices and the edges they subsequently dictate, we wish to avoid introducing vertices in \(\bigcup T'\), and any other cascade choices already made. This gives \(O(n^{2.7\times 10^{-5}}+i)\) vertices to avoid, and hence \(O((n^{2.7\times 10^{-5}}+i)n_c^5)\) cascades to avoid, when building the (_i_+1)_<sup>th</sup>_ cascade.
