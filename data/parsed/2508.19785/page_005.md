[26] consider the information-theoretic problem of detecting whether a given tournament is generated by choosing each arc direction uniformly at random, or according to the outcomes of independent noisy comparisons. They show that this can be done w.h.p. when \(p=\frac{1}{2}-\omega(n^{-3/4})\), and this is tight. Moreover, for \(p=\frac{1}{2}-\omega(n^{-3/4})\), it is possible to recover the correct ranking with probability 1-_o_(1), which is also tight. In the latter case, an approximate ranking w.r.t. to some _ranking alignment measure_ can be found in polynomial time. Another recent paper [25] considers similar detection and recovery problems in the case in which a noisy tournament is planted as a subgraph in an otherwise randomly directed _host_ graph, where the arcs of both the planted tournament and the host graph only exist with some fixed probability.

Finally, we point out that this manuscript is an extended and improved version of two conference papers [17, 18], which found applications in the context of learning theory [21], graph clustering [8], knowledge and data engineering [7], and database management [1]. The major improvement from [17, 18] is the novel BasketSort algorithm, which supersedes WindowSort [17] in RiffleSort, and allows us to relax the previous constraint \(p<\frac{1}{16}\) on the probability of error to \(p<\frac{1}{4}\). Following the publication of [17], we developed the aforementioned \(\widetilde{O}(n\sqrt{n})\)-time algorithm [19], which is now superseded by RiffleSort.

## 1.3 Organization of the paper

Section 2 describes the error model and introduces some basic notation. Sections 3 to 5 are organized in a top-down fashion: Section 3 presents the main algorithm RiffleSort by using NoisySearch and BasketSort as black-box subroutines; then Section 4 and Section 5 present the details of NoisySearch and BasketSort, respectively. ## 2 Preliminaries

_Basic notation._ Given a set or a sequence _S_ of elements and an element _x_ (not necessarily in _S_), we define the _rank_ of _x_ w.r.t. _S_ as \(\text{rank}(x,S)=1+|\{y\in S:y<x\}|\). Moreover, if _S_ is a sequence and \(x\in S\), we use \(\text{pos}(x,S)\in[1,|S|]\) to denote the _position_ of _x_ in _S_. Furthermore, let \(\text{disl}(x,S)=|\text{pos}(x,S)-\text{rank}(x,S)|\) denote the _dislocation_ of _x_ in _A_, and let \(\text{disl}(S)=max_{x\in S}\text{disl}(x,S)\) denote the _maximum dislocation_ of the sequence _S_. Throughout the paper we use ln_z_ and log_z_ to refer to the natural and the binary logarithm of \(z\in\mathbb{R}\backslash\{0\}\), respectively.

_Our error model for approximate noisy sorting._ In the approximate noisy sorting problem, we consider a set _S_ of elements possessing a true linear order that can only be observed through noisy comparisons. Given any two distinct elements \(x,y\in S\), we write _x\<y_ (resp. _x\>y_) to denote that _x_ is smaller (resp. larger) than _y_ according to the true order. For each unordered pair {_x,y_} of distinct elements, there exists _an error probability p_<sub>{_x,y_}</sub> such that a comparison between the two elements reports the correct order relation (i.e., _x\<y_ or _x\>y_) with probability 1-_p_<sub>{_x,y_}</sub> and the complementary, erroneous, outcome with probability _p_<sub>{_x,y_}</sub>. We write _x\<y_ or _y\>x_ (resp. _x\>y_ or _x\<y_) to denote that _x_ is reported to be smaller (resp. larger) than _y_. Comparison errors between different pairs of elements happen independently while the comparison outcome of each pair of elements is _persistent_ so that comparing the same pair of elements multiple times always returns the same relative order of the elements (i.e., resampling is not allowed).
