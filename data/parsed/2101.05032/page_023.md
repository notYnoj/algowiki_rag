\(\blacktriangleright\) **Proposition A.1.** _Let W(x_)=_xlgx. It holds that_ \(W^{-1}(x)=\Theta(x/lgx)\).

**Proof.** First we claim that \(W^{-1}(x)\ge 2\) for \(x\ge 2\). It holds that _W_<sup>-1</sup>(_x_) is injective for _x\>_0, because _y_lg_y_ is increasing for _y\>_1, and \(ylgy\le 0\) for \(0<y\le 1\) but _y_lg_y\>_0 for _y\>_1. Thus _W_<sup>-1</sup>(2) is unique and it is easy to check that _W_<sup>-1</sup>(2)=2. By implicit differentiation,

\(x=W^{-1}(x)lgW^{-1}(x)\)<br> \(1=\left(lgW^{-1}(x)+\frac{1}{ln2}\right)\frac{dW^{-1}(x)}{dx}\)<br> \(\frac{dW^{-1}(x)}{dx}=\frac{1}{\left(lgW^{-1}(x)+\frac{1}{ln2}\right)},\)

which is greater than zero for _x\>_0, because _W_<sup>-1</sup>(_x)\>_1 for _x\>_0, because lg_y_ is not defined for \(y\le 0\), and \(lgy\le 0\) for \(0<y\le 1\). Therefore _W_<sup>-1</sup>(_x_) is increasing and \(W^{-1}(x)\ge 2\) for \(x\ge 2\). Now we prove the asymptotic bounds for \(x\ge 2\). First, \(\frac{x}{lgx}=\frac{W^{-1}(x)lgW^{-1}(x)}{lg(W^{-1}(x)lgW^{-1}(x))}\le W^{-1}(x)\cdot\frac{lgW^{-1}(x)}{lgW^{-1}(x)}=W^{-1}(x),\) where the inequality holds because \(ylgy\ge y\) for \(y=W^{-1}(x)\ge 2\). Furthermore, \(\frac{2x}{lgx}=\frac{2W^{-1}(x)lgW^{-1}(x)}{lg(W^{-1}(x)lgW^{-1}(x))}\ge\frac{2W^{-1}(x)lgW^{-1}(x)}{lg(W^{-1}(x))^2}=\frac{2W^{-1}(x)lgW^{-1}(x)}{2lgW^{-1}(x)}=W^{-1}(x),\) where the inequality holds because \(ylgy\le y^2\) for \(y=W^{-1}(x)\ge 2\). Thus, we have shown that \(\frac{x}{lgx}\le W^{-1}(x)\le\frac{2x}{lgx}\) for all \(x\ge 2\). \(\blacktriangleleft\)

## B Selection with Arbitrary Intervals

In this section we prove that Theorem 5.6 also holds for arbitrary intervals. An instance of the Selection problem is given by a set I of _n_ intervals and an integer _i_, \(1\le i\le n\). The _i_-th smallest value in the set of _n_ precise values is denoted by _v_<sup>∗</sup>. The task is to find _v_<sup>∗</sup> as well as identify all intervals in I whose precise value equals _v_<sup>∗</sup>. We allow arbitrary intervals as input: trivial intervals containing a single value, open intervals, closed intervals, and intervals that are closed on one side and open on the other. Lemma 5.2 and its proof hold also for arbitrary intervals without any changes. We call the left endpoint \(\ell_i\) of an interval _I<sub>i</sub>_ an **open left endpoint** if the interval does not contain \(\ell_i\) and a **closed left endpoint** otherwise. The definitions of the terms **open right endpoint** and **closed right endpoint** are analogous. When we order the left endpoints of the intervals in non-decreasing order, equal left endpoints are ordered as follows: closed left endpoints come before open left endpoints. When we order the right endpoints of the intervals in non-decreasing order, equal right endpoints are ordered as follows: open right endpoints come before closed right endpoints. Equal left endpoints that are all open can be ordered arbitrarily, and the same holds for equal left endpoints that are all closed, for equal right endpoints that are all open, and for equal right endpoints that are all closed. Informally, the order of left endpoints orders intervals in order of the "smallest" values they contain, and the order of right endpoints orders intervals in order of the "largest" values they contain. We call the resulting order of left endpoints \(\unknown_L\) and the resulting order of right endpoints \(\unknown_U\).
