\(\blacktriangleright\) **Theorem 4.4.** \(BAL_k\le opt_k+O(lgmin\{k,m\})\).

**Proof.** First we prove the bound for \(m\le k\). Index the sets in such a way that _S<sub>i</sub>_ is the _i_-th set that is solved by BAL, for \(1\le i\le m\). Sets that are solved in the same round are ordered by non-decreasing number of queries made in them in that round by BAL. In the round when _S<sub>i</sub>_ is solved, there are at least _m_-(_i_-1) active sets, so the number of wasted queries in _S<sub>i</sub>_ is at most \(\frac{k}{m-(i-1)}\). (BAL makes at most \(\left\lceil\frac{k}{m-(i-1)}\right\rceil\) queries in _S<sub>i</sub>_, and at least one of these is not wasted.) The total number of wasted queries is then at most \(\sum_{i=1}^m\frac{k}{m-(i-1)}=\sum_{i=1}^mk/i=k\cdot H(m)\), where _H(m_) denotes the _m_-th Harmonic number. By Proposition 2.1, \(BAL_k\le opt_k+O(lgm)\).

If _m\>k_, observe that the algorithm does not waste any queries until the number of active sets is at most _k_. From that point on, it wastes at most \(k\cdot H(k)\) queries following the arguments in the previous paragraph, so the number of rounds is bounded by opt_<sub>k</sub>_+O(log_k_). \(\blacktriangleleft\)

We now give a more refined analysis that provides a better bound for opt_<sub>k</sub>_=1, as well as a better multiplicative bound than what would follow from Theorem 4.4.

\(\blacktriangleright\) **Lemma 4.5.** _If_ opt_<sub>k</sub>_=1_, then_ \(BAL_k\le O(lgm/lglgm)\).

**Proof.** Consider an arbitrary instance of the problem with opt_<sub>k</sub>_=1. Let _R_+1 be the number of rounds needed by the algorithm. For each of the first _R_ rounds, we consider the fraction _b<sub>i</sub>_ of active sets that are not solved in that round. More formally, for the _i_-th round, for \(1\le i\le R\), if _a<sub>i</sub>_ denotes the number of active sets at the start of round _i_ and _a_<sub>_i_+1</sub> the number of active sets at the end of round _i_, then we define _b<sub>i</sub>=a_<sub>_i_+1</sub>_/a<sub>i</sub>_.

Consider round _i_, \(1\le i\le R\). A set that is active at the start of round _i_ and is still active at the start of the round _i_+1 is called a **surviving set**. A set that is active at the start of round _i_ and gets solved by the queries made in round _i_ is called a **solved set**. For each surviving set, all queries made in that set in round _i_ are useful. For each solved set, at least one query made in that set is useful. We claim that this implies the algorithm makes at least _kb<sub>i</sub>_ useful queries in round _i_. To see this, observe that if the algorithm makes \(\lfloor k/a_i\rfloor\) queries in a surviving set and \(\lceil k/a_i\rceil\) queries in a solved set, we can conceptually move one useful query from the solved set to the surviving set. After this, the _a_<sub>_i_+1</sub> surviving sets contain at least _k/a<sub>i</sub>_ useful queries on average, and hence \(a_{i+1}\cdot k/a_i=b_ik\) useful queries in total.

As OPT<sub>1</sub> must make all useful queries and makes at most _k_ queries in total, we have that \(\sum_{i=1}^Rkb_i\le opt_1\le k\), so \(\sum_{i=1}^Rb_i\le 1\). Furthermore, as there are _m_ active sets initially and there is still at least one active set after round _R_, we have that \(\prod_{i=1}^Rb_i=a_{R+1}/a_1\ge 1/m\). To get an upper bound on _R_, we need to determine the largest possible value of _R_ for which there exist values _b<sub>i</sub>\>_0 for \(1\le i\le R\) satisfying \(\sum_{i=1}^Rb_i\le 1\) and \(\prod_{i=1}^Rb_i\ge 1/m\). We gain nothing from choosing _b<sub>i</sub>_ with \(\sum_{i=1}^Rb_i<1\), so we can assume \(\sum_{i=1}^Rb_i=1\). In that case, the value of \(\prod_{i=1}^Rb_i\) is maximized if we set all _b<sub>i</sub>_ equal, namely _b<sub>i</sub>_=1_/R_. So we need to determine the largest value of _R_ that satisfies \(\prod_{i=1}^R1/R\ge 1/m\), or equivalently \(R^R\le m\), or \(RlgR\le lgm\). This shows that \(R\le W^{-1}(lgm)=O(lgm/lglgm)\). \(\blacktriangleleft\)

\(\blacktriangleright\) **Corollary 4.6.** _If_ opt_<sub>k</sub>_=1_, then_ \(BAL_k\le O(lgk/lglgk)\).

**Proof.** If \(k\ge m\), then the corollary follows from Lemma 4.5. If _k\<m_, there can be at most _k_ active sets, because the optimum performs at most _k_ queries since opt_<sub>k</sub>_=1. Hence, we only need to consider these _k_ sets and can apply Lemma 4.5 with _m=k_. \(\blacktriangleleft\)
