## 1 Introduction.

Nearest neighbor search has been a fundamental problem in computer science \[Ben75, KOR98, IM98, JDS10, MY16\], with wide applications in modern AI systems \[JDJ19, LPP<sup>+</sup>20, GXG<sup>+</sup>23\]. In this problem, we are given a point set _P_ together with a pairwise distance function \(\mathsf{d}(\cdot,\cdot)\), and the goal is to build an efficient data structure which (approximately) answers \(argmin_{p\in P}\mathsf{d}(p,q)\) for a query point _q_ in the underlying metric space. Locality-sensitive hashing has been a classical approach with abundant theoretical studies for this problem \[AIL<sup>+</sup>15\], but it becomes inefficient for large high-dimensional datasets. A recent line of practical work has adopted graph-based paradigms, including HNSW \[MY16\], NSG \[FXWC17\], and DiskANN \[SDK<sup>+</sup>19\]; these heuristic approaches have yielded impressive empirical performance on real-world datasets \[WXYW21, AEP25\]. A central theoretical abstraction behind graph-based search is _navigability_, which is defined as follows.

**Definition 1.1** (\[SDK<sup>+</sup>19, IX23\])**.** Given a constant parameter \(\alpha\ge 1\), for any ordered pair \((s,t)\in P\times P\) with \(s\neq t\) and any point \(u\in P\), we say that a directed edge (_s,u_) is an \(\alpha\)_-navigation from s to t_ if

\(\mathsf{d}(u,t)<\frac{\mathsf{d}(s,t)}{\alpha}.\)

A directed graph _G_=(_P,E_) is said to be \(\alpha\)_-navigable_ if for every ordered pair \((s,t)\in P\times P\) with \(s\neq t\), the vertex _s_ has at least one outgoing edge that forms an \(\alpha\)-navigation toward _t_.

Graph-based nearest-neighbor search methods typically proceed in two stages. In the preprocessing stage, one builds a navigable graph _G_=(_P,E_) on the dataset. At query time, many such methods perform a greedy or greedy-search-like traversal over _G_: starting from one or several entry points, they repeatedly inspect out-neighbors of currently active vertices and try to move the search toward points closer to the query. Thus, the quality of the graph is governed by two competing requirements: the graph should contain enough edges to satisfy the navigation constraints, but it should also be sparse so that memory usage and the cost of inspecting neighbors remain small. It was shown in \[IX23\] that, for any \(\alpha>1\), any \(\alpha\)-navigable graph can be used to construct a data structure which returns \(\left(\frac{\alpha+1}{\alpha-1}+\epsilon\right)\)-approximate nearest neighbors in \(O\left(log_\alpha\frac{\Delta}{(\alpha-1)\epsilon}\right)\) greedy steps, where \(\Delta\) is the aspect ratio of the metric, namely the ratio of the maximum to the minimum distance between distinct points of _P_.

This motivates the following problem: given an _n_-point metric space (_P,_d) and a parameter \(\alpha\ge 1\), construct an \(\alpha\)-navigable graph using as few edges as possible. The authors of \[DGM<sup>+</sup>24\] showed that every set of _n_ distinct points admits a 1-navigable graph with \(\widetilde{O}(n^{3/2})^1\) edges, and gave a \(\widetilde{O}(n^2)\)-time construction. In a different direction, Arya and Mount \[AM93\] showed that, for point sets in _d_-dimensional Euclidean space, one can construct a 1-navigable graph with maximum degree 2<sup>_O(d_)</sup>. However, they are not instance-optimal: a particular input _P_ may admit a much sparser navigable graph than the worst-case bound.

Two recent concurrent works \[KPW26, CDFC<sup>+</sup>26\] have initiated the study of approximation algorithms for constructing sparse \(\alpha\)-navigable graphs in general metrics. In both works, the authors showed a reduction from Set Cover to \(\alpha\)-navigable graphs, establishing NP-hardness of _o_(log_n_)- approximations of the sparsest \(\alpha\)-navigable graphs. On the algorithmic side, both works designed an \(\tilde{O}\left(min\{n\cdot OPT_\alpha,n^{2.5}\}\right)\) time algorithm which computes _O_(log_n_)-approximations of the sparsest \(\alpha\)-navigable graphs, where \(OPT_\alpha\) is the number of edges in the optimal solution. Besides, for the special case of \(\alpha=1\), the authors of \[CDFC<sup>+</sup>26\] showed a \(\tilde{O}(n^2)\) time algorithm with _O_(log_n_)- approximation.
