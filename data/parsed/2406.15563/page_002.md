The hardness of approximating graph coloring in polynomial time has motivated the design of algorithms that provide a more fine-grained trade-off between running time and approximation factors; see \[8, 9, 12\] for some such work in graph coloring, as well as the closely related Independent Set problem. As a simple example, one can obtain an _r_-coloring of a 3-colorable graph _G_ in time _O_<sup>∗</sup>(exp(_O(n/r_))) as follows: partition _G_ into _r/_3 blocks of size 3_n/r_ each and use an exact 3- coloring exponential-time algorithm on each block. In general, this idea is surprisingly close to the best we can do: any _r_-approximation to Graph Coloring requires at least exp(_n_<sup>1-_o_(1)</sup>_/r_<sup>1+_o_(1)</sup>) time, assuming ETH \[24\].

## 1.1 Promise Constraint Satisfaction Problems and Width-based Algorithms

Graph colorability is an example of a larger class of problems known as _constraint satisfaction problems_ (CSPs). The input to a CSP is a set of variables _X_ over a domain _D_, along with a set of constraints. Each constraint specifies, for some subset of variables, a relation that it must takes values in. The goal is to find a valid assignment of values from the domain to each variable that satisfies all constraints. Equivalently, one can model CSPs as a problem of finding homomorphism between relational structures \[14\]. That is, we can think of the input as two structures: X=(_X,S_<sub>1</sub>_,...,S<sub>n</sub>_), where \(S_i\subseteq X^{r_i}\), D=(_D,R_<sub>1</sub>_,...,R<sub>n</sub>_), where \(R_i\subseteq D^{r_i}\). The goal is to find a function \(f:X\rightarrow D\) such that \(f((x_1),\dots,f(x_{r_i}))\in R_i\) for all \((x_1,\dots,x_{r_i})\in S_i\). In the case of _r_-graph colorability, the variables are the vertices of the graph, the sets _S<sub>i</sub>_ are the edges, the domain is the set of colors {1_,...,r_}, and the constraints _R<sub>i</sub>_ are all tuples of two different colors.

Brakensiek and Guruswami \[11\], building on work in \[2\], recently proposed a generalization of this class of problems, known as _promise constraint satisfaction problems_ (PCSPs); these are CSPs in which we are guaranteed that the input satisfies an even stronger set of constraints. Formally, we are given three relational structures X,A,B where there exists a homomorphism from B to A. Given the promise that there exists some homomorphism from X to B, the goal is to find one from X to A. It is easy to see that the problem of _r_-coloring a 3-colorable graph is an example of a promise CSP, with A corresponding to _r_-colorability and B to 3-colorability.

Fixed-template CSPs are CSPs in which the structure A is fixed and the input specifies X. One of the few known techniques for solving fixed-template CSPs in polynomial time is _local consistency checking_. This technique considers _k-strategies_, which are sets of partial solutions on subsets of variables of size at most _k_. These sets must be closed under restrictions and all partial solutions of subsets of size less than _k_ must be extendable to all supersets up to size _k_. Clearly, if there exists a homomorphism from X to A, then there exists a _k_-strategy for all \(k\le|X|\). A CSP is said to have _width k_ if the converse holds: a non-empty _k_-strategy implies a homomorphism from X to A. For any fixed _k_, this gives a simple polynomial time algorithm to solve the CSP: find all partial solutions on subsets of size at most _k_ and remove the ones that don’t satisfy the closure and extension properties until we either have a non-empty _k_-strategy or an empty set.
