## 4.1 Strict orders

We consider the case that the master poset is a strict order. Then, an easy algorithm solves the problem: Just match the first _d_ agents from the master poset together, delete them, and recurse. Note that the preferences of any agent cannot be directly derived from the master poset, as e.g. an agent may prefer either {_a_<sub>1</sub>_,a_<sub>4</sub>} to {_a_<sub>2</sub>_,a_<sub>3</sub>} or {_a_<sub>2</sub>_,a_<sub>3</sub>} to {_a_<sub>1</sub>_,a_<sub>4</sub>}. Thus, the input contains the complete preferences of all agents, and the input size is \(\Theta(d\genfrac(){pt}{2}{n}{d-1})\). In this sense, the running time of our algorithm is sublinear.

**Proposition 4.1.** _If_ \(\unknown_\mathrm{ML}\) _is a strict order, then any_ MDSR-Poset _instance admits a uniquely determined stable matching. Assuming that the poset is given as a ranking_ \(a_1\succ_\mathrm{ML}a_2\succ_\mathrm{ML}\cdots\succ_\mathrm{ML}a_n\)_, this stable matching can be found in O(n_) _time, where n is the number of agents. If the poset is given via pairwise comparisons, then the unique stable matching can be found in O(n_<sup>2</sup>) _time._

_Proof._ We number the agents in such a way that \(a_1\succ_\mathrm{ML}a_2\succ_\mathrm{ML}\cdots\succ_\mathrm{ML}a_n\).

We claim that \(M:=\{\{a_{d(i-1)+1},a_{d(i-1)+2},\dots,a_{di}\}:1\le i\le\lfloor\frac{n}{d}\rfloor\}\) is a stable matching. We prove this claim by contradiction, so assume that there is a blocking _d_-set {_a_<sub>_i_<sub>1</sub></sub>_,a_<sub>_i_<sub>2</sub></sub>_,...,a<sub>i<sub>d</sub></sub>_} with \(i_1<i_2<\cdots<i_d\). Let \(\{a_{i_1},b_2,b_3,\dots,b_d\}\in M\) be the _d_-set containing _a_<sub>_i_<sub>1</sub></sub>. Note that such a _d_-set exists as _M_ leaves at most the _d_-1 last agents of the master poset unmatched, and the agents _a<sub>i<sub>j</sub></sub>_, \(j\in\{2,3,\dots,d\}\), are ranked after _a_<sub>_i_<sub>1</sub></sub> in the master poset. Since _a<sub>i<sub>j</sub></sub>_ is after _a_<sub>_i_<sub>1</sub></sub> in the master poset, we have \(b_j\unknown_\mathrm{ML}a_{i_j}\) for all \(j\in\{2,3,\dots,d\}\). Thus, _a_<sub>_i_<sub>1</sub></sub> cannot prefer {_a_<sub>_i_<sub>2</sub></sub>_,...,a<sub>i<sub>d</sub></sub>_} to _M_, a contradiction. If the master poset is given as the order \(a_1\succ_\mathrm{ML}\cdots\succ_\mathrm{ML}a_n\), then _M_ can clearly be constructed in _O(n_) time. If the master poset is given via pairwise comparisons, then we compute the strict order \(a_1\succ_\mathrm{ML}\cdots\succ_\mathrm{ML}a_n\) in _O(n_<sup>2</sup>) time using a sorting algorithm, and from this, we can compute _M_ in _O(n_) time.

It remains to show that _M_ is uniquely determined. Assume that there is a stable matching \(M'\neq M\). Let _i_ be the smallest index such that _a<sub>i</sub>_ is matched differently in _M_ and \(M'\). Since only the at most _d_-1 agents with highest index are unmatched in _M_, we get that _a<sub>i</sub>_ is matched in _M_. As either all or no agent from a _d_-set \(t\in M\) are matched differently in _M_ and \(M'\), and all _d_-sets from _M_ are of the form {_a_<sub>_d(j_-1)+1</sub>_,a_<sub>_d(j_-1)+2</sub>_,...,v<sub>dj</sub>_}, it follows that _i=d(j_-1)+1 for some \(j\in\lfloor\lfloor\frac{n}{d}\rfloor\rfloor\).

We claim that _t_:={_a<sub>i</sub>,a_<sub>_i_+1</sub>_,a_<sub>_i_+2</sub>_,...,a_<sub>_i+d_-1</sub>} is a blocking _d_-set for \(M'\). By the definition of _i_, matching \(M'\) does not contain a _d_-set with one agent with index smaller than _i_ and one agent with index at least _i_, and we have that \(t\notin M'\). Thus, for any \(a\in t\) with \(t'_a:=M'(a)\neq\emptyset\), the bijection \(\sigma_v:t\backslash\{a\}\rightarrow t'_a\backslash\{a\}\) matching the agent with the _j_-th-lowest index in _t_\\{_a_} to the agent with the _j_-th-lowest index in \(t'_a\backslash\{a\}\) satisfies \(b\unknown_\mathrm{ML}\sigma(b)\) for all \(b\in t\backslash\{a\}\). Since the preferences are derived from \(\unknown_\mathrm{ML}\), it follows that _a_ prefers _t_\\{_a_} to \(t'_a\). Thus, _t_ is a blocking _d_-set.
