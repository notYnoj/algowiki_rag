For _i_=1, we set \(\tau[1,M]:=\mathsf{true}\) if and only if _M_ does not contain a blocking _d_-set inside _a_<sub>1</sub>_,...,a<sub>k</sub>_.

To compute \(\tau[i,M]\) for _i\>_1, we need to determine whether we can extend _M_ to a local matching _M_<sup>∗</sup> on _a_<sub>1</sub>_,...,a<sub>i+k</sub>_ such that every blocking _d_-set involves an agent _a<sub>j</sub>_ with _j\>i+k_. Any such extension _M_<sup>∗</sup> induces a matching _M_<sub>_i_-1</sub> by taking all _d_-sets containing an agent from _a_<sub>_i_-1</sub>_,...,a_<sub>_i_-1+_k_</sub>, and _M_<sup>∗</sup> also witnesses that \(\tau[i-1,M_{i-1}]=\mathsf{true}\). However, given a matching _M_<sub>_i_-1</sub> with \(\tau[i-1,M_{i-1}]=\mathsf{true}\) and _M_<sub>_i_-1</sub>(_a<sub>j</sub>_)=_M(a<sub>j</sub>_) for all \(j\in\{i,i+1,\dots,i+k-1\}\) does not imply that \(\tau[i,M]=\mathsf{true}\), as there might be a blocking _d_-set involving _a<sub>i+k</sub>_ and _d_-1 other agents from _a_<sub>1</sub>_,...,a_<sub>_i_-1+_k_</sub>. Since _M_<sub>_i_-1</sub> does not store how _a_<sub>1</sub>_,...,a_<sub>_i_-2</sub> are matched, we cannot just enumerate all such _d_-sets and check whether they are blocking, but only can do this for _d_-sets consisting solely of agents from _a_<sub>_i_-1</sub>_,...,a<sub>i+k</sub>_. We will show that for any matching \(M_{i-1}^*\) witnessing that \(\tau[i-1,M_{i-1}]=\mathsf{true}\) that no blocking _d_-set containing _a<sub>i+k</sub>_ and at least one agent from _a_<sub>1</sub>_,...,a_<sub>_i_-1+_k_</sub> can occur; therefore, it is enough to check for blocking _d_-sets containing only agents from _a_<sub>_i_-1</sub>_,...,a<sub>i+k</sub>_. Thus, in order to compute \(\tau[i,M]\), we look up whether there exists a local matching _M_<sub>_i_-1</sub> with \(\tau[i-1,M_{i-1}]:=\mathsf{true}\) and _M(a<sub>j</sub>_)=_M_<sub>_i_-1</sub>(_a<sub>j</sub>_) for all \(j\in[i,i+k-1]\) such that \(M_{i-1}\cup M\) does not admit a blocking _d_-set consisting of agents from _a_<sub>_i_-1</sub>_,...,a<sub>i+k</sub>_. If this is the case, then we set \(\tau[i,M]=\mathsf{true}\), and otherwise we set \(\tau[i,M]=\mathsf{false}\).

Since there are at most _k_<sup>_O(k_)</sup> partitions of a _k_-element set \[12\], table \(\tau\) contains at most _nk_<sup>_O(k_)</sup> entries. Each entry can be computed in _k_<sup>_O(k_)</sup> time, resulting in an overall running time of \(k^{O(k)}n=(\kappa d^4)^{O(\kappa d^4)}n\).

It remains to show the correctness of this dynamic program, which we do by induction. For _i_=1, the values \(\tau[i,M]\) are computed correctly by definition. Let _i\>_1. First assume that \(\tau[i,M]=\mathsf{true}\). Let _M_<sub>_i_-1</sub> be the local matching with \(\tau[i-1,M_{i-1}]=\mathsf{true}\) and _M(a<sub>j</sub>_)=_M_<sub>_i_-1</sub>(_a<sub>j</sub>_) for all \(j\in[i,i+k-1]\) and \(M_{i-1}\cup M\) not admitting a blocking _d_-set consisting of agents from _a_<sub>_i_-1</sub>_,...,a<sub>i-k</sub>_. By the induction hypothesis, \(\tau[i-1,M_{i-1}]\) was computed correctly, implying that there exists a local matching \(M_{i-1}^*\) on _a_<sub>1</sub>_,...,a_<sub>_i_+_k_-1</sub> such that for each \(j\in[i-1,i+k-1]\), we have \(M_{i-1}(a_j)=M_{i-1}^*(a_j)\), and no blocking _d_-set consists solely of agents from _a_<sub>1</sub>_,...,a_<sub>_i_+_k_-1</sub>. Note that _M_<sup>∗</sup> is indeed a (local) matching since _a_<sub>_i_-1</sub> cannot be matched to agents with index at least _i+k_ and _a_<sub>_i+k_</sub> cannot be matched to agents with index at most _i_-1 by the locality of \(M_{i-1}^*\) and _M_. Clearly, it holds that _M(a<sub>j</sub>_)=_M_<sup>∗</sup>(_a<sub>j</sub>_) for all \(j\in[i,i+k]\). Next, we show that _M_<sup>∗</sup> contains no blocking _d_-set consisting solely of agents from \(A[\le i+k]\). Any such _d_-set _t_ must contain _a_<sub>_i+k_</sub>, since \(M_{i-1}^*\) does not admit blocking _d_-sets consisting solely of agents from _a_<sub>1</sub>_,...,a_<sub>_i_-1+_k_</sub>. Furthermore, it must contain at least one agent _a<sub>j</sub>_ with _j\<i_-1 since we checked for all _d_-sets of agents from _a_<sub>_i_-1</sub>_,...,a<sub>i+k</sub>_ whether they are blocking. Since \(k=2d(d-1)2\kappa d^2+4\kappa+3d+1\), it follows that there exists some \(\ell\in[i+(d-1)2\kappa d^2+4\kappa+3d+1,i+k-(d-1)2\kappa d^2+4\kappa+3d+1]\) such that _t_ contains no agent from \(A[\ell-(d-1)(2\kappa d^2+4\kappa+3d+1),\ell+(d-1)(2\kappa d^2+4\kappa+3d+1)]\), and \(a_\ell\) is matched in _M_<sup>∗</sup> (note that such an agent exists since at most _d_-1 agents from \(A[\le i+k-1]\) can be unmatched in _M_<sup>∗</sup>). Let \(t'\in M^*\) with \(a_\ell\in t'\), and let _t_<sup>∗</sup> contain the _d_ agents with minimum index from \(t\cup t'\). Every agent \(a\in t^*\cap t\) prefers every agent \(b\in t^*\cap t'\) to every agent \(c\in t\backslash t^*\) since the index of _b_ is at least \(2\kappa\) positions before _c_ in the order _a_<sub>1</sub>_,...,a<sub>n</sub>_. Similarly, every agent \(a\in t^*\cap t'\) prefers every agent \(b\in t^*\cap t\) to every agent \(c\in t'\backslash t^*\) since the index of _b_ is at least \(2\kappa\) positions before _c_ in the order _a_<sub>1</sub>_,...,a<sub>n</sub>_. Hence, _t_<sup>∗</sup> forms a blocking _d_-set consisting solely of agents from \(A[\le i+k-1]\), a contradiction to the definition of \(M_{i-1}^*\).
