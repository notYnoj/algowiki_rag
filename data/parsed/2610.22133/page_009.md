<tbc>In a general graph, the number of distinct components in \(\tilde{\mathbf{G}}\) can be as large as \(\Omega(n^2)\); however, we only need to consider AT-free graphs. That is, if we can prove an upper bound of \(\alpha(n)\) on the number of distinct components for AT-free graphs, we can first check whether the actual number of distinct components exceeds this bound. If it does, we immediately report that an AT triple exists; otherwise, we run a triangle detection instance on \(\mathcal{O}(\alpha(n))\) nodes. It turns out--and we believe this is a highly interesting structural result of independent interest--that such a bound is indeed possible for AT-free graphs.

**Theorem 4.7.** _Let_ **G**=(_V,E_) _be an AT-free graph. Moreover, let_ \(\mathbf{G}_x:=\mathbf{G}[V\backslash N[x]]\)_, and let_ \(\mathcal{C}_x=\{C_x(v)\}_{v\in\mathbf{G}_x}\) _be the set of all connected components of_ **G**_<sub>x</sub>. Then there are at most_ O(_n_log_n_) _distinct components across all_ **G**_<sub>x</sub>; that is,_ \(|\mathcal{C}|\le 400n\mathrm{log}n\) _for_ \(\mathcal{C}:=\bigcup_{x\in V}\mathcal{C}_x\).

Although the full proof is one of the more involved parts of our paper, it rests on a simple observation. The following basic fact serves as the first building block of the proof and provides intuition for why the absence of an AT yields the desired bound.

Consider a node \(v\in V\) and three distinct connected components _X_, _Y_ , and _Z_ of **G**_<sub>v</sub>_. Furthermore, consider three nodes \(x\in X\), \(y\in Y\) , and \(z\in Z\), together with the out-neighborhoods _N(X_), _N(Y_), and _N(Z_), which consist entirely of nodes in _N(v_) (see Figure 2b). Observe that if {_x,y,z_} forms an AT, then all of the following conditions must hold: \(N(X)\backslash N(z)\neq\varnothing\), \(N(X)\backslash N(y)\neq\varnothing\), \(N(Z)\backslash N(x)\neq\varnothing\), \(N(Z)\backslash N(y)\neq\varnothing\), \(N(Y)\backslash N(x)\neq\varnothing\), and \(N(Y)\backslash N(z)\neq\varnothing\); otherwise, the neighborhood-disjoint paths required for the AT could not exist. Consequently, if **G** is AT-free, at least one of these conditions must fail. Without loss of generality, assume that \(N(X)\backslash N(z)=\varnothing\), which is equivalent to \(N(X)\subseteq N(z)\). It is not difficult to see that this implies _X_ is also a connected component of **G**_<sub>z</sub>_. In this sense, being AT-free restricts the number of distinct components, though establishing the full bound requires a more involved argument.

## 2.3 Listing Dominating Pairs in Matrix Multiplication Time

Next, we turn to listing all dominating pairs _u,v_ of an input graph **G**. Recall that _u,v_ form a dominating pair if every _u-v_ path is a dominating set, and recall that _C<sub>x</sub>(y_) denotes the connected component containing _y_ in **G**_<sub>x</sub>_. The connection between this problem and neighborhood-deleted components is that _u,v_ is _not_ a dominating pair if and only if there is some node \(w\notin N[u]\cup N[v]\) such that _C<sub>w</sub>(u_)=_C<sub>w</sub>(v_); that is, there exists a _u-v_ path avoiding the neighborhood of _w_. In such a case, we say that the component _C<sub>w</sub>(u_)=_C<sub>w</sub>(v_) _witnesses_ the non-dominating pair _u,v_.

Following this logic, a naive algorithm would simply iterate over each \(v\in V\) , examine each connected component _C_ of **G**_<sub>v</sub>_, and mark all pairs of distinct nodes _x_, \(y\in C\) as non-dominating. We note that for a subset C of connected components (potentially spanning different **G**_<sub>v</sub>_), we can implement this in time O(MM(_n,_|C|_,n_)). To achieve this, it suffices to construct an \(n\times|\mathcal{C}|\) matrix _M_, indexed by vertices in _V_ and components in C respectively, with _M_<sub>_v,C_</sub>=1 if \(v\in C\). The Boolean product \(MM^\top\) indicates exactly when a pair _u,v_ is witnessed as non-dominating by some component in C, which occurs precisely when \((MM^\top)_{u,v}=1\). Kratsch and Spinrad’s approach distinguishes between large components, which contain at least \(\Delta\) nodes, and small ones. Since there can be at most \(n^2/\Delta\) of the former across all **G**_<sub>v</sub>_, marking all their pairs as non-dominating via the matrix method takes \(MM(n,n^2/\Delta,n)=\mathcal{O}(n^{\omega+1}/\Delta)\) time. They also show how to process small components in \(\mathcal{O}(n^2\cdot\Delta)\) time; balancing these two bounds yields an overall running time of \(\mathcal{O}(n^{(\omega+3)/2})\).

Our algorithm differs in two ways:

1 Instead of collecting into the set C all connected components above a threshold size \(\Delta\), we include only the largest connected component from each **G**_<sub>v</sub>_. By doing so, it takes only \(\mathcal{O}(n^\omega)\) time to find all non-dominating pairs witnessed by these components.
