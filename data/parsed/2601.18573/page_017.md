As we no longer require a maximum-cardinality matching, we can ignore line 1 of Algorithm 1. In lines 14-17 of Algorithm 1, when searching for a maximum-cardinality matching among the agents not yet matched in _M<sub>D</sub>_ such that every agent in _Q_ is matched, we can drop the maximum-cardinality requirement. This simplifies the construction of (_G,w_) because we can ignore what happens to agents that are "far enough" away from agents in _D_, as they do not influence the stability of agents in _D_. Agents within neighbourhood distance 2 can influence the stability of agents in _D_, though: if an agent \(r\in D\) is matched to some agent \(x\notin D\), but _r_ prefers \(y\notin D\) to _x_, then either _y_ is blocking with _x_, or _y_ gets a partner _z_ better than _x_. Notice that _z_ is in _N_<sub>2</sub>\[_D_\] but might not be in _N_<sub>1</sub>\[_D_\]. However, we can simply leave all agents outside of this radius unmatched. Hence, we let the graph _G_ consist of all agents that are at most two agents away from some agent in _D_ (i.e., within neighbourhood distance 2 of some agent in _D_ in the acceptability graph of _I_) and not yet matched in _M<sub>D</sub>_ as vertices, and all acceptable pairs among these agents as edges. This affects line 14 in Algorithm 1 (which should be changed to \(V\leftarrow N_2[D]\backslash A(M_D)\)). Furthermore, we change line 16 of Algorithm 1 such that _w_ is defined as follows: for every acceptable pair of agents _a<sub>r</sub>,a<sub>s</sub>_ present in the instance, we let \(w(\{a_r,a_s\})=|\{a_r,a_s\}\cap Q|\), i.e., we assign a weight of 1 for every endpoint in _Q_.

We can construct (_G,w_) in linear time in the graph we create, assuming that preference lists of any given agent can be explored efficiently. By the preference list lengths, there are at most \(|D|d_\mathrm{max}^2\) many agents that are at most two agents away from some agent in _D_ (and, as argued above, contrary to the algorithm in Theorem 4.1, we can ignore all agents outwith the neighbourhood distance two of any agent in _D_), and _G_ has at most \(|D|d_\mathrm{max}^3\) edges. Thus, we can create (_G,w_) in \(O(|D|d_\mathrm{max}^3)\) time. Now we find a maximum-weight matching _M<sub>mw</sub>_ using the algorithm by Huang and Kavitha \[33\], which runs in \(O(\sqrt{n_*}m_*N\mathrm{log}(n_*^2/m_*)/\mathrm{log}(n_*))=O(|D|^{3/2}d_\mathrm{max}^4)\) time. Leftover conformists that are distance at least 3 away from any deviator can simply be left unmatched.

If there exists an agent \(a_r\in Q\) that is not matched in _M<sub>mw</sub>_, we can reject this configuration (_M<sub>D</sub>,B_). Otherwise, by construction, _M<sub>D</sub>_ and _M<sub>mw</sub>_ are disjoint, so we can accept \(M=M_D\cup M_{mw}\) as our solution. This simplifies the condition in line 18, as we no longer need to verify the size of the matching.

Notice that dropping the maximum-cardinality requirement here results in a time complexity of at most \(O(|D|^{k+3/2}d_\mathrm{max}^{|D|+k+4})\) compared to the time complexity of at most \(O(|D|^kd_\mathrm{max}^{|D|+k+1}n^{5/2})\) we concluded in Theorem 4.1 for _k_-Deviator-Max-sri, which is more efficient whenever _n_ is much larger than _D_ and _d_<sub>max</sub>.

Again, due to a similar argument as in Corollary 4.2, we can immediately note the following complexity classification.

**Corollary 4.4.** _k_-Deviator-sri _is in_ FPT _with respect to_ (|_D|,d_<sub>max</sub>) _and in_ XP _with respect to_ |_D|. Furthermore,_ Deviator-sri _is in_ FPT _with respect to_ (|_D|,d_<sub>max</sub>) _and in_ XP _with respect to_ (|_D|,opt), where_ \(opt=\mathrm{min}_{M\in\mathcal{M}}|\bigcup_{a_i\in D}bp_{a_i}(M)|\).

## 5 Minimising the Number of Blocking Deviators Instead

As discussed in Section 2.2, an alternative approach to minimising blocking pairs is to minimise the number of blocking agents. There is an inherent trade-off: minimising blocking pairs minimises the aggregate instability of the matching, but might involve a higher total number of blocking agents that have an individual incentive to deviate. Minimising blocking agents instead aims to give as few agents as possible an incentive to deviate, although their individual incentives or opportunities to deviate might be higher due to possibly more blocking pairs that they are a part of. As a third option, minimax almost-stable matchings, which were recently investigated by Glitzner and Manlove \[25\], minimise the maximum individual incentive to deviate.
