<tbc>\(a_r\in Q\) that is not matched in _M<sub>mw</sub>_, we can reject this configuration (_M<sub>D</sub>,B_). Otherwise, by construction, _M<sub>D</sub>_ and _M<sub>mw</sub>_ are disjoint, so if \(|M_D\cup M_{mw}|=|M_S|\), then we can accept \(M=M_D\cup M_{mw}\) as our solution. Otherwise, _M<sub>D</sub>_ does not extend to a solution with respect to _B_, and we can reject this configuration (_M<sub>D</sub>,B_).

Of course, if we accept _M_, then _M_ is a maximum-cardinality matching of _I_. Furthermore, by construction, \(|ba(M)\cap D|\le|B|\le k\). Thus, _M_ is a solution to _k_-Deviator-BA-Max-sri. Otherwise, if, for every configuration (_M<sub>D</sub>,B_) and an associated maximum-weight matching _M<sub>mw</sub>_, it is the case that either \(|M_D\cup M_{mw}|<|M_S|\) or not every agent in _Q_ is matched, then it must be true that (_I,D_) is a no-instance to _k_-Deviator-BA-Max-sri, i.e., that there exists no solution to the problem for this instance. To see this, notice that if \((I=(A,\succ),D)\) has a solution _M<sub>P</sub>_, then _M<sub>P</sub>_ can be divided into a part _M_<sub>1</sub> in which every pair contains at least one agent from _D_, and a part _M_<sub>2</sub> which does not contain any pair with an agent from _D_. Clearly, _M_<sub>1</sub> satisfies the requirements of the candidate matchings M_<sub>D</sub>_, and _M_<sub>2</sub> must be a maximum-cardinality matching among the remaining agents (otherwise _M<sub>P</sub>_ would not be a maximum-cardinality matching). Let us fix this \(M_1\in\mathcal{M}_D\).

By being a solution, it must furthermore be true that, for every agent \(a_i\in D\) and every agent \(a_r\in A\) such that \(a_r\succ_iM_P(a_i)\), either \(a_i\in ba(M_P)\cap D\) or \((a_i\notin ba(M_P)\cap D\) and \(M_P(a_r)\succ_ra_i)\). We keep track of agents satisfying the latter case in the set _Q_. Note that it must be the case that \(|ba(M_P)\cap D|\le k\), so we would have considered this set \(ba(M_P)\cap D\) as a candidate set _B_ in our execution. Furthermore, _M_<sub>2</sub> must be a maximum-cardinality matching of our maximum-weight matching instance (_G,w_) (for some configuration (_M<sub>D</sub>,B_)) that matches all such agents _Q_, and, by the key property we stated about maximum-weight matchings in Theorem 4.1, _M_<sub>2</sub> must be a maximum-weight matching of (_G,w_), too. Thus, our algorithm would have identified this solution \(M_1\cup M_{mw}\), or a different solution, to the problem.

Putting the complexity analysis together, we consider \(O(d_\mathrm{max}^{|D|})\) candidate matchings and, for every candidate matching, we consider _O_(|_D|<sup>k</sup>_) sets of blocking agents, leading to \(O(d_\mathrm{max}^{|D|}|D|^k=O(|D|^kd_\mathrm{max}^{|D|})\) candidate configurations. We construct a maximum-weight matching instance in _O(d_<sub>max</sub>_n_) time for each candidate configuration and, subsequently, compute a maximum-weight matching in _O(d_<sub>max</sub>_n_<sup>5/2</sup>) time. Hence, we arrive at a final complexity of \(O(|D|^kd_\mathrm{max}^{|D|+1}n^{5/2})\).
