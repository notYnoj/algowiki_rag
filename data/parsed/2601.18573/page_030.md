## A Omitted Full Proofs of FPT Algorithms

### A.1 _k_-Deviator-sri FPT Algorithm Proof

**Theorem 4.3.** _Let_ \((I=(A,\succ),D)\) _be an instance of k_-Deviator-sri _with maximum pref erence list length d_<sub>max</sub>_. Then the problem k_-Deviator-sri _is solvable in_ \(O(|D|^{k+3/2}d_\mathrm{max}^{|D|+k+4})\) _time._

_Proof._ Recall that we aim to find a matching _M<sub>P</sub>_ of _I_ such that the agents in _D_ are collectively involved in at most _k_ blocking pairs in _M<sub>P</sub>_. Again, we will denote such blocking pairs by _bp(M<sub>P</sub>_)|_<sub>D</sub>_. Clearly, every agent in \(a_i\in D\) is either matched to one of the at most _d_<sub>max</sub> many agents on their preference list or remains unmatched. Thus, there are (_d_<sub>max</sub>+1)<sup>|_D_|</sup>=\(O(d_\mathrm{max}^{|D|})\) possible combinations of choices of partner, including the possibility of being unmatched, for the agents in _D_. We can immediately discard any combinations of choices that are not matchings, and we denote the remaining set of candidate matchings by M_<sub>D</sub>_. Next, we consider each candidate matching sequentially and aim to extend it to a solution to our problem. Let us fix a candidate matching \(M_D\in\mathcal{M}_D\).

Now, we consider each possible set of blocking pairs involving some agent in _D_ of size at most _k_. There are clearly at most \(\sum_{1\le r\le k}\genfrac(){pt}{2}{|D|d_\mathrm{max}}{r}\) many such sets. We can apply the loose upper bound \(\genfrac(){pt}{2}{|D|d_\mathrm{max}}{r}\le(|D|d_\mathrm{max})^r\) and conclude that \(\sum_{1\le r\le k}(|D|d_\mathrm{max})^r=\frac{(|D|d_\mathrm{max})^{k+1}-1}{|D|d_\mathrm{max}-1}\) by the geometric series. Furthermore, the bound \(\frac{(|D|d_\mathrm{max})^{k+1}-1}{|D|d_\mathrm{max}-1}\le\frac{(|D|d_\mathrm{max})^{k+1}}{|D|d_\mathrm{max}-1}\le 2(|D|d_\mathrm{max})^k=O((|D|d_\mathrm{max})^k)\) applies. Let us fix a candidate set of blocking pairs _B_. Clearly, no pair of agents can be simultaneously matched and blocking, so if \(M_D\cap B\neq\varnothing\), then we reject this configuration (_M<sub>D</sub>,B_).

Then, for every agent \(a_i\in D\) and every agent \(a_r\in A\) such that \(a_r\succ_iM_D(a_i)\) and \(\{a_i,a_r\}\notin B\), agent _a<sub>r</sub>_ must end up with a partner better than _a<sub>i</sub>_ (according to \(\succ_r\)). Thus, we truncate \(\succ_r\), discarding every agent worse than and including _a<sub>i</sub>_ (if multiple agents in _D_ satisfy this criterion with respect to _a<sub>r</sub>_, we truncate at the best-ranked such agent according to \(\succ_r\)). We must keep track of these agents _a<sub>r</sub>_ to later verify that they do indeed have a partner, and denote the set of all such agents _a<sub>r</sub>_ by _Q_.

If, after carrying out these truncations, some agent \(a_i\in D\) has a partner in _M<sub>D</sub>_ that is no longer in their preference list (or vice versa), we can reject this configuration (_M<sub>D</sub>,B_). Otherwise, we need to look for a matching among the agents not yet matched in _M<sub>D</sub>_ such that every agent in _Q_ is matched. We can do this as follows: we construct a maximum-weight matching instance (_G,w_) (where _G_ is a graph and _w_ is a weight function from the set of edges to non-negative integers) consisting of all agents that are at most two agents away from some agent in _D_ and not yet matched in _M<sub>D</sub>_ as vertices<sup>3</sup> and all acceptable pairs among these agents as edges. Furthermore, we construct _w_ as follows: for every acceptable pair of agents _a<sub>r</sub>,a<sub>s</sub>_ present in the instance, we let \(w(\{a_r,a_s\})=|\{a_r,a_s\}\cap Q|\), i.e., we assign a weight of 1 for every endpoint in _Q_.

We can construct (_G,w_) in linear time in the graph we create, assuming that preference lists can be explored efficiently given an agent. For example, given that the set of agents _D_ is given explicitly, the preference lists of each such agent could be implemented in a linked-list-style representation, which would allow the exploration of all relevant matchings without necessarily exploring the whole instance. Note that by the preference list length, there are at most \(|D|d_\mathrm{max}^2\) many agents that are at most two agents away from some agent in _D_, i.e, _G_ contains at most \(|D|d_\mathrm{max}^2\) vertices, and every such agent has a preference list of length at most _d_<sub>max</sub>, so _G_ has at most \(|D|d_\mathrm{max}^3\) edges.
