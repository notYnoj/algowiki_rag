We now describe our enumeration algorithm. Algorithm 1 builds set \(T_K^\unknown\) by induction using the following formula:

\(T_0^\unknown=\{()\}\)<br>
\(T_k^\unknown=\{\mathbf{v}\circ t:\mathbf{v}\in T_{k-1}^\unknown\text{and}t\in T(\mathbf{v})\}\text{where}T(\mathbf{v})=\{t_k:\mathbf{t}\in T_N^\unknown\text{s.t.}(t_1,\dots,t_{k-1})=\mathbf{v}\}\)

The aim of Algorithm 2 is to compute _T_(**v**), i.e., the set of possible triples for the _k<sup>th</sup>_ com ponent of a vector in \(T_k^\unknown\) starting by the (_k_-1)-vector **v**. The idea is to impose restrictions on the considered stable marriages so that the least satisfied agents as well as their matches correspond to the ones in **v**. For this purpose, we impose mandatory rotations (set `IN<sub>v</sub>`) and forbidden rotations (set `OUT<sub>v</sub>`). Note that, each time a rotation is made mandatory (resp. forbidden), the set of its ancestors (resp. descendants), denoted by \(\mathtt{Anc}(\rho)\) (resp. \(\mathtt{Desc}(\rho)\))), are also made mandatory (resp. forbidden) so that `IN<sub>v</sub>` (resp. _P_\\`OUT<sub>v</sub>`) remains a closed set of rotations. For each triple \((d,a,a')\) belonging to **v**, we ensure that agent _a_ is matched with agent \(a'\) by making rotation \(\rho_\mathtt{get}(a,a')\) mandatory and \(\rho_\mathtt{break}(a,a')\) forbidden (Lines 3-5). Additionally, to ensure that the _k_ least satisfied agents are indeed those involved in **v**, we put a threshold on the dissatisfactions of the agents in \(\mathcal{A}_\overrightarrow{\mathbf{v}}=\mathcal{M}\cup\mathcal{W}\backslash\{a:(d,a,a')\in\mathbf{v}\}\). Note that the set \(\mathcal{A}_\overrightarrow{\mathbf{v}}\) is updated in Line 3. Let _d_<sub>min</sub>(**v**) denote the dissatisfaction of the last triple in **v** (i.e., the lowest level of dissatisfaction in **v**). The dissatisfactions of the agents in \(\mathcal{A}_\overrightarrow{\mathbf{v}}\) should not be strictly greater than _d_<sub>min</sub>(**v**). This condition is imposed by using again sets `IN<sub>v</sub>` and `OUT<sub>v</sub>`. More precisely, given a rotation \(\rho=(m_{i_0},w_{i_0}),\dots,(m_{i_{r-1}},w_{i_{r-1}})\), we define \(d_\mathrm{max}^w(\rho)=\mathrm{max}_{k=0,\dots,r-1}d(w_{i_k},m_{i_k})\) the highest dissatisfaction of a woman involved in \(\rho\) before \(\rho\) is eliminated, and \(d_\mathrm{max}^m(\rho)=\mathrm{max}_{k=0,\dots,r-1}d(m_{i_k},w_{i_{k+1}})\) the highest dissatisfaction of a man involved in \(\rho\) after \(\rho\) is eliminated. To make sure that the agents in \(\mathcal{A}_\overrightarrow{\mathbf{v}}\) have a dissatisfaction lower than or equal to _d_<sub>min</sub>(**v**), we make mandatory (resp. forbidden) any rotation \(\rho\in P\backslash\mathtt{OUT}_\mathbf{v}\) (resp. _P_\\`IN<sub>v</sub>`) such that \(d_\mathrm{max}^w(\rho)>d_\mathrm{min}(\mathbf{v})\) (resp. \(d_\mathrm{max}^m(\rho)>d_\mathrm{min}(\mathbf{v})\)) (Lines 6-7, resp. Lines 8-9). The enumeration of the triples in _T_(**v**) is performed by branching on the gender (man or woman) of the agent that will realize the _k<sup>th</sup>_ highest dissatisfaction. We denote by _T<sub>W</sub>_(**v**) (resp. _T<sub>M</sub>_(**v**)) the set of triples \((d,a,a')\in T(\mathbf{v})\) where \(a\in\mathcal{W}\) (resp. \(a\in\mathcal{M}\)). We have of course \(T_W(\mathbf{v})\cup T_M(\mathbf{v})=T(\mathbf{v})\). Algorithm 3 enumerates the triples in _T<sub>W</sub>_(**v**) while Algorithm 4 enumerates the triples in _T<sub>M</sub>_(**v**) (Line 10 of Algorithm 2). The validity of the approach follows from the validity of Algorithms 3 and 4.
