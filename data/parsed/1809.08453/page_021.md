## Validity of the approach.

The operations of Algorithms 3 and 4 are similar. They proceed in the spirit of the algorithm proposed by Gusfield \[1987\] for determining a minmax stable marriage. Let **x**_<sub>R</sub>_ denote the stable marriage corresponding to a set _R_ of rotations. Note that we have built sets `IN`<sub>**v**</sub> and `OUT`<sub>**v**</sub> such that if \(R\cap\mathtt{IN}_\mathbf{v}=\mathtt{IN}_\mathbf{v}\) and \(R\cap\mathtt{OUT}_\mathbf{v}=\emptyset\) then \(\mathbf{v}\in T_{k-1}^\unknown(\mathbf{x}_R)\). Furthermore, the special case **x**<sub>`IN`<sub>**v**</sub></sub> (resp. **x**<sub>_P_\\`OUT`<sub>**v**</sub></sub>) is the stable marriage compatible with `IN`<sub>**v**</sub> and `OUT`<sub>**v**</sub> that satisfy most the men (resp. women) as it takes as few (resp. much) rotations as allowed by sets `IN`<sub>**v**</sub> and `OUT`<sub>**v**</sub>. We only explain the operation of Algorithm 3, because the operation of Algorithm 4 is symmetric.

The aim of Algorithm 3 is to enumerate all triples \((d,a,a')\) in _T<sub>W</sub>_(**v**). Notably, we will enumerate these triples by nonincreasing values of _d_ by exploring carefully the set of stable marriages compatible with sets `IN`<sub>**v**</sub> and `OUT`<sub>**v**</sub>. More precisely, at each iteration _i_ of the algorithm (loop `while` in Line 5) we will consider a stable marriage **x**_<sub>i</sub>_ compatible with sets `IN`<sub>**v**</sub> and `OUT`<sub>**v**</sub> such that all women are always better off in **x**_<sub>i</sub>_ than in **x**<sub>_i_-1</sub> for \(i\neq 0\) (with at least one woman strictly better off). At each iteration, the new triples are found by looking at set _W<sub>i</sub>_ that includes all women in A<o>**v**</o> whose dissatisfaction can be ranked in _k<sup>th</sup>_ position in **x**_<sub>i</sub>_, i.e., whose dissatisfaction is equal to \(d_k^\unknown(\mathbf{x}_i)\) (Lines 3 and 13)<sup>2</sup>.

Obviously, for the women, the worst stable marriage compatible with `IN`<sub>**v**</sub> and `OUT`<sub>**v**</sub> is **x**<sub>`IN`<sub>**v**</sub></sub>. If no woman can be ranked in _k<sup>th</sup>_ position w.r.t. stable marriage **x**<sub>`IN`<sub>**v**</sub></sub>, then no woman can be ranked in _k<sup>th</sup>_ position for _any_ stable marriage compatible with `IN`<sub>**v**</sub>. Indeed, eliminating additional rotations would only increase the dissatisfactions of men and decrease the dissatisfactions of women. Otherwise the recurrence is initialized with **x**<sub>0</sub>=**x**<sub>`IN`<sub>**v**</sub></sub> and stable marriage **x**<sub>_i_+1</sub> is obtained from **x**_<sub>i</sub>_ by eliminating rotation \(\rho_\mathtt{break}(m,w)\) (and all required ancestors) for all woman _w_ in _W<sub>i</sub>_ so that their dissatisfactions are strictly decreased (Line 10). Loop `while` stops if one of the following conditions occurs:

- if \(W_i=\emptyset\), it means that only men can be ranked in _k<sup>th</sup>_ position in **x**_<sub>i</sub>_; as eliminating rotations will only improve the situation of women and deteriorate the situation of men, we can safely conclude that all triples in _T<sub>W</sub>_(**v**) have been enumerated;<tbc>

**-** if at least one rotation \(\rho_\mathtt{break}(m,w)\) does not exist or is forbidden (i.e., \((m,w)\in\mathbf{x}_{P\backslash\mathtt{OUT}_\mathbf{v}}\)); indeed, in this case, we can conclude that it is not possible to find a triple in _T<sub>W</sub>_(**v**) with a dissatisfaction strictly less than the current value \(d_k^\unknown(\mathbf{x}_i)\) (the boolean Flag is then set to True in Line 9).

## Complexity analysis and proof of termination.

In Algorithm 3, at every step _i_ of the `while` loop, all agents in _W<sub>i</sub>_ share the same dissatisfaction level \(d_k^\unknown(\mathbf{x}_i)\). Furthermore, for all \(i\neq 0\), we have that \(d_k^\unknown(\mathbf{x}_i)<d_k^\unknown(\mathbf{x}_{i-1})\). As there are only _n_ dissatisfaction levels (corresponding to the _n_ possible ranks), the `while` loop necessarily terminates in _O(n_) iterations. The nested `for` loop also terminates in _O(n_) iterations because there can be at most _n_ women in _W<sub>i</sub>_. All instructions inside the `for` loop are in _O_(1), except the instruction in Line 10 which is in _O(n_<sup>2</sup>) (the number of rotations is upper bounded by _n(n_-1)/2). Overall, Algorithm 3 is in _O(n_<sup>4</sup>). The analysis of Algorithm 4 is similar.
