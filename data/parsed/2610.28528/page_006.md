### E. Adaptive Stopping Criteria

Processing all \(\genfrac(){pt}{2}{|S|}{2}\) pairs is feasible when the solution pool is small, but becomes prohibitively expensive as the pool grows during exploration. We therefore implement an adaptive stopping strategy that selects among three modes at runtime. When the total pair count is below 10<sup>4</sup>, the algorithm runs exhaustively, guaranteeing complete pairwise coverage. For larger pools, it monitors the discovery rate over a sliding window of 500 consecutive pairs and halts when the number of new solutions found within that window falls below 0.1% of the current pool size, indicating that the accessible manifold region has been saturated. A hard cutoff of 10<sup>5</sup> pairs bounds the number of pair comparisons regardless of discovery dynamics, although this limit was never reached in our experiments. The largest number of pairs processed in any single pass was 16539, and in any higher-level pass 6951 (the second-level pass of `L17\_seed46`).

### F. Validation

As a safeguard against implementation error, rather than as a test of the algorithm, all solutions in S<sub>final</sub> are validated post-hoc by verifying independence (no edge connects two selected vertices), maximality (no unselected vertex can be added without creating a conflict), and target cardinality (solution size equals _k_<sub>final</sub>). This last check confirms membership at the size the run reached, which coincides with the certified optimum only where the two agree. It is not an independent test of global optimality. The protocol was applied to all 15511 solutions from the three instances where classical post- processing discovered a larger independent set than the quantum hardware, with a 100% pass rate. Throughout, the reference (true) maximum independent set size of each instance is taken from the reference values distributed with the data set of Ref. [7, 17]. These values were computed with an exact sweeping-line solver, not with the qReduMIS pipeline [17]. Our transfer- matrix dynamic programming over the lattice columns, exact for these geometries since all atoms occupy integer lattice sites and the blockade couples only adjacent columns, reproduces both the optimum size and the exact ground-state degeneracy for all 121 reference instances that record them. Since the reference solver is also a sweep over the lattice, this agreement checks our implementation rather than constituting an independent certificate. It likewise reproduces every optimum quoted in this work, including all nine in  I and that of `L16\_seed4816` (64, with degeneracy 4480). We use these reference sizes both to identify which instances quantum hardware failed to solve and to quantify the residual gap of the post-processed solutions ( I). ## III. RESULTS

### A. Overview of Amplification Results

Figure 2 shows the amplification results for the 40 instances whose best independent-set size did not change under post-processing, grouped by type. The three instances where post-processing found a strictly larger independent set are treated separately in Section IIID. Across the full 43-instance dataset, Houdayer cluster updates consistently expand the quantum-generated solution pools: amplification factors range from \(1.0\times\) to \(11923\times\), with a median of \(24.3\times\) and a mean of \(657.2\times\). The distribution is strongly right-skewed, driven by a handful of instances with unusually large degenerate manifolds. Amplification was not universal, however: three instances with more than one distinct quantum solution showed none at all (`L3\_seed3849`, `L5\_seed4703`, and `L5\_seed2142`, all at exactly \(1.0\times\)). These are the smallest in the test bed, at 7, 20, and 20 atoms, and their seed pools already contained the complete ground-state manifold, so \(1.0\times\) is the best attainable result rather than a failure (Section IIIE).

Figure 3 shows the initial quantum solution counts against the final counts using Houdayer cluster updates. Most points lie above the diagonal, confirming amplification across all problem types and sizes. The four points on the diagonal are instances that showed no amplification. The spread along the vertical axis for fixed initial count illustrates that amplification is not simply proportional to the size of the quantum seed pool: instances with similar initial counts can differ by orders of magnitude in final count, reflecting differences in underlying manifold structure rather than sampling volume.
