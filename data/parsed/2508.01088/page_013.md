\(S_{v_{n,\lambda}^1}^r(i)=\left\{\begin{array}{ c c }
0, & \text{if}i\le\lambda+2\text{or}i=n, \\
-T(n-7-2\lambda)(\lambda+3), & \text{if}i=\lambda+3, \\
(n-7-2\lambda)(\lambda+3), & \text{if}\lambda+4\le i\le n-(\lambda+3), \\
(n-7-2\lambda)(n-i), & \text{if}n-(\lambda+2)\le i\le n-1;
\end{array}\right.\) (12)

\(S_{v_{n,\lambda}^1}^c(j)=\left\{\begin{array}{ c c }
T(n-7+2\lambda)+(n-7-2\lambda)(j-1), & \text{if}j\le\lambda+3, \\
0, & \text{otherwise};
\end{array}\right.\)

\(S_{v_{n,\lambda}^1}^d(i-j+1)=\left\{\begin{array}{ c c }
-T(n-7-2\lambda)+(i-j)(n-7-2\lambda), & \text{if}0\le i-j\le\lambda+2, \\
(\lambda+3)(n-7-2\lambda), & \text{if}\lambda+3\le i-j\le n-(\lambda+4), \\
0, & \text{otherwise};
\end{array}\right.\) (13)

\(S_{v_{n,\lambda}^2}^r(i)=\left\{\begin{array}{ c c }
0, & \text{if}i\le\lambda+2\text{or}i=n, \\
-T(n-7-2\lambda)(\lambda+3), & \text{if}i=\lambda+3, \\
(n-7-2\lambda)(\lambda+3), & \text{if}\lambda+4\le i\le n-(\lambda+3), \\
(n-7-2\lambda)(n-i), & \text{if}n-(\lambda+2)\le i\le n-1;
\end{array}\right.\)<br>
\(S_{v_{n,\lambda}^2}^c(j)=\left\{\begin{array}{ c c }
-T(n-7-2\lambda)+(j-1)(n-7+2\lambda), & \text{if}j\le\lambda+3, \\
(\lambda+3)(n-7-2\lambda), & \text{if}\lambda+4\le j\le n-(\lambda+3), \\
0, & \text{otherwise};
\end{array}\right.\)<br>
\(S_{v_{n,\lambda}^2}^d(i-j+1)=\left\{\begin{array}{ c c }
T(n-7-2\lambda)+(i-j)(n-7-2\lambda), & \text{if}0\le i-j\le\lambda+2, \\
0, & \text{otherwise}.
\end{array}\right.\) (14)

Note that, since \(v_{n,\lambda}^3=\left(v_{n,\lambda}^3\right)^-=\left(v_{n,\lambda}^3\right)^+\), \(S_{v_{n,\lambda}^3}^r(i)=S_{v_{n,\lambda}^3}^c(n-i+1)=S_{v_{n,\lambda}^3}^d(n-i)\), and then

\(S_{v_{n,\lambda}^3}^r(i)=\left\{\begin{array}{ c c }
0, & \text{if}i\le\lambda+4\text{or}i=n, \\
-2(\lambda+3)(i-(\lambda+4)), & \text{if}\lambda+5\le i\le n-(\lambda+3), \\
-2(n-i)(n-7-2\lambda), & \text{if}n-(\lambda+2)\le i\le n-1;
\end{array}\right.\)<br>
\(S_{v_{n,\lambda}^3}^c(j)=\left\{\begin{array}{ c c }
0, & \text{if}j=1\text{or}j\ge n-(\lambda+3), \\
-2(n-7-2\lambda)(j-1), & \text{if}2\le j\le\lambda+3, \\
-2(\lambda+3)(n-j-(\lambda+3)), & \text{if}\lambda+4\le j\le n-(\lambda+4);
\end{array}\right.\)<br>
\(S_{v_{n,\lambda}^3}^d(i-j+1)=\left\{\begin{array}{ c c }
0, & \text{if}i-j=0\text{or}i-j\ge n-(\lambda+3), \\
-2(i-j)(n-7-2\lambda), & \text{if}1\le i-j\le\lambda+2, \\
-2(\lambda+3)(n-(i-j)-(\lambda+4)), & \text{if}\lambda+3\le i-j\le n-(\lambda+4).
\end{array}\right.\) (15)

Now we are in position to define the sum-vectors of \(v_{n,\lambda}\).
